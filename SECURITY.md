# Security policy

Egami reads untrusted image files, so we treat crashes, hangs and runaway memory use on bad input as security bugs.

## Reporting

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button on the repository's Security tab. Don't open a public issue.

Include the Egami version, the file or a way to produce it, and what happens. We aim to acknowledge reports within a few days and will credit you in the release notes unless you'd rather stay anonymous.

## Supported versions

Only the latest released version receives security fixes until 1.0. After 1.0, the latest minor release of each supported major version does.
