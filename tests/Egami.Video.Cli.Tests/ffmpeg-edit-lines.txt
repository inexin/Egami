# The ffmpeg-mode editing set (V9 design Q14, Build Plan task 22): 60 ffmpeg command lines with editing filters, of the kinds
# FFmpeg's filter documentation and wiki show (fades, speed, reverse, loops, xfade, concat, overlay, stacks, zoompan, keys,
# stabilizing). Each runs for real on 2 s clips (a.avi and b.avi: 160x120, 25 fps, with sound; c.avi: 96x64, 10 fps, without sound;
# logo.png and still.png: images). Each line is: what must happen | the line after the tool name.
# "ok" runs with exit code 0, "ok 3.5" also gives a 3.5 s output; "!! words" stops with exit code 2 and an error that holds
# the words. Written for this test from the filters' documented meaning; no FFmpeg code or test data.
