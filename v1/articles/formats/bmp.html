BMP

Egami reads Windows bitmaps with core, info, V2 to V5 and OS/2 2.x headers at 1 to 32 bits, RLE4, RLE8 and RLE24, bit fields, embedded PNG and JPEG and V5 ICC profiles. It writes 24-bit, 32-bit with alpha, 16-bit 5-5-5, 5-6-5 and 1-5-5-5, and 1, 2, 4 or 8-bit palettes, with resolution and ICC.

A BMP loads as Bgr8, or Bgra8 with alpha.

// Auto (the default): 24-bit when every pixel is opaque, 32-bit with alpha otherwise.
image.Save("duck.bmp");

// A 16-color palette, built from the image and dithered.
image.Save("duck-16.bmp", new BmpWriterOptions { PixelFormat = BmpPixelFormat.Indexed4 });

A plain 32-bit BMP's fourth byte is used as alpha unless it is 0 in every pixel, in which case the image loads opaque; an alpha mask in the header is always used. Pixels that an RLE delta skips are black. BmpPixelFormat.Indexed2 writes Windows CE 2-bit files, which many desktop readers cannot open, so Auto never picks it. Bgr555 writes the default 16-bit layout with no bit fields; Bgr565 and Bgra5551 write a V4 header with bit-field masks. Loading a 16-bit file as Bgr555, Bgr565 or Bgra5551 copies its rows when the masks match the type. Resolution is written in pixels per meter, and an ICC profile switches the header to V5 with the profile embedded.
