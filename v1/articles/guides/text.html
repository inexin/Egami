Fonts and text

Egami.Fonts is a separate package that reads TrueType, OpenType, WOFF, WOFF2 and variable fonts in managed code: faces, glyph outlines, metrics, kerning, installed fonts and subsets. Egami.Drawing uses it to draw and measure a line of text on a canvas. Egami.Drawing and Egami.Fonts are at 1.0 and their APIs are frozen. Egami.Fonts ships no font: text needs a face from a file, a stream, memory or the installed fonts, or from the opt-in substitute fonts package.

Faces

A Typeface is one face, immutable and shared by every thread. Typeface.FromFile, FromStream and FromMemory read TrueType (.ttf), OpenType CFF and CFF2 (.otf), collections (.ttc, .otc, with a face index), WOFF and WOFF2 (.woff, .woff2, collections too) and bare CFF; FromCff reads a bare CFF stream as PDF embeds it, with CffOptions for the units per em and widths it lacks. FontLoader.Probe tells a FontProbe (its FontFileKind, face count and FontOutlines) from the header, and FontLoader.LoadAll loads every face of a collection.

// One face from a file; a collection takes an index. The bytes are read once and every table is parsed when first needed.
Typeface face = Typeface.FromFile(FontFile);
Console.WriteLine($"{face.FamilyName} {face.SubfamilyName}, {face.GlyphCount} glyphs, {face.UnitsPerEm} units per em");

// What a file holds, from its header alone.
FontProbe probe = FontLoader.Probe(File.ReadAllBytes(FontFile));
Console.WriteLine($"{probe.Kind}, {probe.FaceCount} face(s), {probe.Outlines} outlines");

// Damaged fonts load leniently with diagnostics; Strict throws instead.
var seen = new List<EgamiDiagnostic>();
var options = new FontLoadOptions { Context = EgamiContext.Default with { Diagnostics = seen.Add } };
Typeface lenient = Typeface.FromMemory(File.ReadAllBytes(FontFile), 0, options);
  • The file is read into memory once and every table is a slice of it; tables are parsed when first used.
  • Loading is lenient: a missing or damaged name, OS/2, hhea, hmtx, post or cmap table gets a documented default and a Font.MissingTable or Font.BadTable diagnostic, and a broken glyph draws empty with Font.BadGlyph. Only a font with no readable glyph data throws CorruptDataException. FontLoadOptions.Strict throws on the first problem instead.
  • A WOFF or WOFF2 file is unwrapped once into an ordinary font in new memory (zlib, and Brotli through .NET's own decoder, with WOFF2's glyf, loca and hmtx transforms); the compressed bytes are not kept. Container says where a face came from, and GetWoffMetadata and GetWoffPrivateData return the file's own blocks. Every decoded table equals the reference decoders'.
  • GetNames returns every FontNameRecord; TryGetTable returns any table's bytes by FontTag. Embedding reports the FontEmbedding permissions, which Egami never enforces.
// A CFF stream as a PDF embeds it (FontFile3): no character map, glyphs by id; widths from the PDF when it gives them.
Typeface embedded = Typeface.FromCff(fontFile3, new CffOptions { UnitsPerEm = 1000 });
float width = embedded.GetAdvance(1);

// WOFF and WOFF2 files load like any font: they are unwrapped into an ordinary font in memory once.
Typeface face = Typeface.FromFile(WebFile);
FontFileKind container = face.Container;
string? metadata = face.GetWoffMetadata();

Variable fonts

A variable font is one file that holds a range of designs along its axes, such as weight from 100 to 900. IsVariable, VariationAxes (each a VariationAxis with its range) and NamedInstances (each a NamedInstance, such as "Bold") describe it. WithVariations returns the face at a position, given as FontVariation values, and WithNamedInstance at a named one: an ordinary immutable Typeface sharing the file's memory, whose outlines, advances, extents, kerning, names and subsets all answer for that position. Variations gives a face's position.

// A variable font's axes and named instances, and the face at any position on them.
Typeface flex = Typeface.FromFile(VariableFile);
foreach (VariationAxis axis in flex.VariationAxes)
{
    Console.WriteLine($"{axis.Tag} {axis.Name}: {axis.Min} to {axis.Max}, default {axis.Default}");
}

Typeface semiBold = flex.WithVariations(FontVariation.Weight(600), FontVariation.Width(90));
Typeface black = flex.WithNamedInstance(flex.NamedInstances.Count - 1);

// The optical size follows the font size unless the face sets it (OpticalSizing.None turns that off).
var caption = new Font(semiBold, 11);
Typeface drawn = caption.EffectiveTypeface;

// For a PDF, the subset is a static font at the face's position, which every viewer draws as it is.
FontSubset subset = FontSubsetter.Subset(semiBold, caption.Shape("Static at 600").Glyphs.ToArray());
  • Positions clamp to each axis; axes the font lacks are ignored, and the default position is the face itself. Faces at a position are cached, so drawing at one position costs what a static font costs.
  • Outlines vary through gvar (TrueType) or CFF2's blends, advances through HVAR (or phantom points), the extents through MVAR and kerning through GDEF's deltas, with avar versions 1 and 2. At 25 positions in each test font every outline and advance equals fontTools' within 1/64 unit.
  • A named instance takes the instance's names; another position keeps the default's names and gets a PostScript name of its own (Adobe Technical Note 5902), such as NotoSans_650wght.
  • FontCollection lists a variable face's named instances as faces, and FontFamily.Match places the face anywhere its weight, width and slant or italic axes reach, as CSS does: weight 450 is drawn at 450, not snapped to 400.
  • With Font.OpticalSizing at OpticalSizing.Auto (the default), a face with an opsz axis it leaves at the default is drawn at opsz equal to the size in canvas units; Font.EffectiveTypeface is the face drawn.
  • SubsetOptions.Variations (by default the face's own position) makes the subset a static font at that position, written as an instancer would: the varied outlines rounded to whole units, metrics, OS/2 and post at the position, CFF2 written as CFF and the variation tables left out. Its outlines, advances and bearings equal fontTools' instancer's, so a PDF shows the position.
  • A variable font's GSUB feature variations (glyph swaps by position) arrive with shaping in 2.8.

Glyphs and metrics

Everything a face returns is in font units with y up. GetGlyph maps a code point (with a variation selector, through cmap format 14), GetGlyphOutline sends an outline to an IGlyphOutlineSink, and GetAdvance, GetGlyphExtents (a GlyphExtents box) and GetKerning give the numbers. Glyph ids are ushort throughout, as OpenType caps a face at 65,535 glyphs.

// Character map, advance, ink box and kerning, all in font units with y up.
ushort a = face.GetGlyph('A'), v = face.GetGlyph('V');
float advance = face.GetAdvance(a);
GlyphExtents ink = face.GetGlyphExtents(a);
float kern = face.GetKerning(a, v);
FontExtents extents = face.Extents;

// An outline arrives through a sink: lines and quadratics for TrueType, lines and cubics for CFF.
var counter = new SegmentCounter();
face.GetGlyphOutline(a, counter);
  • TrueType outlines arrive as lines and quadratic curves and CFF outlines as lines and cubic curves, exactly as stored: every outline of the test fonts equals fontTools' point for point.
  • Extents is a FontExtents with ascent, descent, line gap, cap and x heights, decoration lines and the italic angle, by the browsers' rule: OS/2 typo metrics when the face sets USE_TYPO_METRICS, else hhea. HheaMetrics, TypoMetrics and WinMetrics give each stored VerticalMetrics set.
  • Typeface.GetKerning is GPOS pair positioning under the kern feature (the DFLT and latn scripts), else the kern table. Text drawn on a canvas is shaped with all of the font's OpenType features (see Unicode text and shaping).

Text on a canvas

A Font is a typeface at a size, the em in canvas units: pixels on a raster, points on a PDF page. Font.FromPoints sizes from points at a resolution. Canvas.DrawText puts the left end of the first line's alphabetic baseline at the origin. Font is a value type; default(Font) has no typeface, and its metrics, shaping and measuring throw InvalidOperationException.

// A caption on a photo: white text with a dark shadow, its baseline 24 pixels above the bottom.
using Raster<Rgba8> photo = Raster.Create(640, 360, new Rgba8(90, 120, 160, 255));
var font = new Font(Typeface.FromFile(FontFile), 28);
using (RasterCanvas<Rgba8> canvas = photo.CreateCanvas())
{
    var origin = new Vector2(24, photo.Height - 24);
    canvas.DrawText("Lofoten, March", origin + new Vector2(2, 2), font, new Rgba8(0, 0, 0, 160));
    canvas.DrawText("Lofoten, March", origin, font, Rgba8.White);
}
  • Font.Shape turns text into a GlyphRun with the full shaper: ligatures, kerning, marks, the script rules, bidi order, and a new line at each hard break (\n, \r\n, \r, U+0085, U+2028, U+2029). ShapingOptions set the direction, language, features and spans. A run has one font, so text that falls back to other fonts is shaped by TextShaper.Shape and drawn with Canvas.DrawShapedText; Canvas.DrawText does that by itself when the options ask for fallback. Nothing wraps; without fallback a missing character draws .notdef.
  • A ShapedText drawn with Canvas.DrawShapedText is shaped once, so it can be measured, kept and drawn again.
// Shape once, measure the result, draw it centred: no second shaping pass.
using Raster<Rgba8> banner = Raster.Create(640, 120, Rgba8.White);
Egami.Fonts.Shaping.ShapedText title = Egami.Fonts.Shaping.TextShaper.Shape("Office hours: 9 to 17", font);
var origin = new Vector2((banner.Width - title.Advance) / 2, 70);
using (RasterCanvas<Rgba8> canvas = banner.CreateCanvas())
{
    canvas.DrawShapedText(title, origin, Rgba8.Black);
}
  • A run carries the source text and a cluster per glyph, so a PDF backend keeps text searchable. Canvas.DrawGlyphRun draws a run built elsewhere with GlyphRun.Create.
  • Small glyphs are drawn from the GlyphCache of coverage masks, at whole device pixels, by the same rasterizer as paths, so caching changes speed, not pixels. Glyphs over 256 pixels per em, or under a rotation or skew, fill as paths.
// Small text draws from a process-wide cache of glyph masks; give it more room for many fonts and sizes.
GlyphCache.ByteLimit = 16 * 1024 * 1024;
GlyphCache.Clear();

Rendering quality

Four switches on a Font change how a raster draws it, never how it measures: MeasureText gives the same numbers whatever they are.

// Small text for a screen: light hinting (vertical only), quarter-pixel origins (the default) and, for an RGB display
// the image will not leave, LCD edging.
var screen = new Font(face, 13) { Hinting = FontHinting.Light, Edging = FontEdging.Lcd };
using (RasterCanvas<Rgba8> canvas = image.CreateCanvas(new CanvasOptions { PixelGeometry = PixelGeometry.RgbHorizontal }))
{
    canvas.DrawText("Crisp caption", new Vector2(8, 24), screen, Rgba8.Black);

    // A face matched for bold italic it lacks is emboldened and slanted, unless AllowSynthesis is off.
    var synthetic = new Font(face, 13) { Synthesis = FontSynthesis.Bold | FontSynthesis.Italic };
    canvas.DrawText("Synthetic bold italic", new Vector2(8, 48), synthetic, Rgba8.Black);
}
  • Font.Subpixel (on by default) keeps glyph origins at quarter pixels horizontally, each quarter its own cached mask, so small text is evenly spaced; off, origins snap to whole pixels as in 2.7.1. Vertical positions always snap to whole pixels.
  • Font.Hinting = FontHinting.Light snaps the baseline, x-height and cap-height zones (a CFF font's blue zones, else zones measured from the face's own glyphs) to whole pixels, up to 48 pixels per em; x values and advances never move. There is no TrueType bytecode hinting.
  • Font.Edging picks FontEdging.Antialias (the default), Alias (one bit, pixel centres inside the outline) or Lcd: three samples per pixel along the canvas's CanvasOptions.PixelGeometry, filtered and blended per channel. LCD text draws only onto an 8-bit RGB canvas outside layers with a solid source-over paint; anything else falls back to grayscale with one Text.LcdFallback diagnostic per canvas. Images that leave the screen they were made for carry the colour fringes with them, so LCD is opt-in.
  • Font.Synthesis (set by matching) is drawn: bold outsets the outline by em/24 at 9 pixels down to em/32 at 36 and above, advances unchanged, and italic slants 14 degrees, CSS's default oblique. Glyph paths and ink bounds include it; Font.AllowSynthesis = false turns it off.

Color fonts

Emoji and other color glyphs draw in color by themselves. Per glyph, the first format the font has wins: COLR version 1 (a graph of layers, gradients, transforms and compositing), COLR version 0 (layers of solid outlines), sbix, then CBDT and CBLC (images); anything else draws its outline in the paint. Typeface.ColorFormats says what a face holds.

// Color glyphs draw in color by themselves: COLR (layers and gradients), sbix and CBDT (images), per glyph.
using (RasterCanvas<Rgba8> canvas = image.CreateCanvas())
{
    canvas.DrawText("Ship it", new Vector2(8, 40), new Font(text, 24), Rgba8.Black);
    canvas.DrawText("\U0001F680\U0001F389", new Vector2(100, 42), new Font(emoji, 32), Rgba8.Black);
}

// The palette is a font setting; the paint's color fills a glyph's foreground parts and its alpha the whole glyph.
var darkMode = new Font(emoji, 32) { Palette = FontPalette.Dark };
ColorGlyphFormats formats = emoji.ColorFormats;

// The paint graph is there to walk, for writers that draw color glyphs their own way.
emoji.TryGetColorGlyph(emoji.GetGlyph(0x1F680), darkMode.Palette, out ColorGlyph? rocket);
  • Font.Palette picks a CPAL palette by index or by FontPaletteBackground (FontPalette.Light, FontPalette.Dark), with FontPaletteEntry overrides; Typeface.Palettes lists each FontPaletteInfo. Font.ColorGlyphs = false draws outlines.
  • The paint's color fills the glyph's foreground parts and its alpha and blend mode apply to the whole glyph, drawn as one group.
  • Typeface.TryGetColorGlyph returns a ColorGlyph: a PaintColorGlyph whose ColorPaint graph an IColorPaintVisitor walks, with variable values taken at the face's position: ColorLayersPaint, ColorSolidPaint (a GlyphColor), ColorLinearGradientPaint, ColorRadialGradientPaint and ColorSweepGradientPaint (over a ColorLine of ColorStops with a ColorExtend), ColorGlyphPaint (a glyph-outline clip), ColorGlyphReferencePaint, ColorTransformPaint and ColorCompositePaint; or a BitmapColorGlyph with its image (BitmapGlyphEncoding) and placement, from the strike nearest above the size.
  • Every canvas draws color glyphs: the default glyph hook turns them into clips, fills, gradients, layers and images, so a PDF page gets vector color. A raster caches them, up to 256 pixels per em, as color images keyed by palette.
  • OpenType SVG glyphs are not drawn: Typeface.TryGetSvgDocument returns the document for callers with an SVG renderer, and such glyphs fall back to their COLR, bitmap or outline data. Drawing them arrives with Egami.Svg.

Text on a path

Canvas.DrawTextOnPath lays a line of text along a Path by SVG's textPath rules, through Font.ShapeOnPath: each glyph's advance midpoint sits on the path, turned to its direction, and glyphs past either end are left out. TextOnPathOptions sets the start (StartOffset in canvas units plus StartFraction of the length), the TextAnchor, the BaselineShift along the normal, the TextPathSide and whether a closed contour wraps.

// A label along a curve: each glyph's midpoint on the path, turned to its direction, as SVG's textPath. The result is
// still a glyph run, so a PDF backend writes it as searchable text.
Path curve = new PathBuilder().MoveTo(20, 150).CubicTo(80, 20, 240, 20, 300, 150).ToPath();
var font = new Font(face, 18);
using (RasterCanvas<Rgba8> canvas = image.CreateCanvas())
{
    canvas.DrawTextOnPath("Text that follows the curve", curve, font, Rgba8.Black,
        new TextOnPathOptions { StartFraction = 0.5f, Anchor = TextAnchor.Center, BaselineShift = 4 });
}

// Or place glyphs yourself, each with its own turn and scale.
GlyphRun dial = GlyphRun.CreateTransformed(font, [face.GetGlyph('N'), face.GetGlyph('E')],
    [GlyphTransform.FromRotationScale(1, 0, new Vector2(150, 30)), GlyphTransform.FromRotationScale(1, 90, new Vector2(290, 90))]);
  • The result is a GlyphRun with a GlyphTransform per glyph (a rotation and uniform scale, then an origin, as Skia's RSXform), so a PDF backend writes it as real, searchable text; GlyphRun.CreateTransformed builds such runs by hand.
  • Glyphs that are only moved draw from the glyph cache like any text; turned or scaled ones fill as paths. Text is not warped: each glyph keeps its shape, as SVG and browsers draw it.

Measuring

Font.MeasureText lays text out exactly as DrawText does and returns a TextMeasure: the widest line's advance, the exact ink box as TextBounds, the line count and the vertical metrics.

// A label shrunk until it fits a 200-pixel button, then centred on it.
const string label = "Download the full report";
var box = new RectF(20, 20, 200, 40);
var font = new Font(face, 24);
while (font.MeasureText(label).Advance > box.Width - 16 && font.Size > 8)
{
    font = new Font(face, font.Size - 1);
}

TextMeasure size = font.MeasureText(label);
var origin = new Vector2(
    box.X + ((box.Width - size.Advance) / 2),
    box.Y + ((box.Height - size.Height) / 2) + size.Ascent);
using Raster<Rgba8> image = Raster.Create(240, 80, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = image.CreateCanvas())
{
    canvas.FillRoundRect(new RoundRect(box, 8), new Rgba8(30, 90, 200, 255));
    canvas.DrawText(label, origin, font, Rgba8.White);
}

MeasureText also takes a ReadOnlySpan<char>, so a slice of a longer text or a reused buffer is measured without making a string of it.

// Measure each word of a longer text in place: a span is measured without making a string of it.
ReadOnlySpan<char> text = "Measure every word of this sentence";
float widest = 0;
foreach (Range word in text.Split(' '))
{
    widest = Math.Max(widest, font.MeasureText(text[word]).Advance);
}

Text as paths

FontExtensions holds GetGlyphPath, GetTextPath and GlyphRun.ToPath, which give Paths in canvas units, y down, to stroke, clip to or combine.

// Text as a shape: outline it, or clip a picture to it.
Path title = font.GetTextPath("EGAMI", new Vector2(10, 80));
using Raster<Rgba8> image = Raster.Create(300, 100, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = image.CreateCanvas())
{
    canvas.StrokePath(title, new Stroke(2), Rgba8.Black);
    canvas.ClipPath(title);
    canvas.FillRect(new RectF(0, 50, 300, 50), Rgba8.Red);
}

Installed fonts and matching

FontCollection.System finds the installed fonts without native calls, by scanning the platform's font folders (and fontconfig's dir entries on Linux), and indexes them on first use from the name and OS/2 tables only. It is read-only. A FontCollection of your own takes faces, files and folders, and AddSystemFonts copies the installed fonts into it, so your fonts and the machine's are matched together. Families are found by typographic, legacy, full or PostScript name in any language, and FontFamily.Match picks a face by the CSS Fonts 4 rules for a FontStyle (weight, width and FontSlant). The FontMatch records the FontSynthesis a lighter or upright face would need; GenericFamily names fixed per-platform lists.

// Installed fonts, found without native calls and indexed on first use; a style is matched by the CSS rules.
FontMatch? match = FontCollection.System.Match(GenericFamily.SansSerif, FontStyle.Bold);

// Your own fonts work the same way; System is read-only, so add the installed fonts to your collection to have both.
var fonts = new FontCollection();
fonts.AddFile(FontFile);
fonts.AddSystemFonts();
FontMatch noto = fonts.Match("Noto Sans", FontStyle.BoldItalic)!.Value;
Font font = noto.ToFont(16);

Substitute fonts

Documents often name Arial, Helvetica, Times, Courier, Calibri or Cambria without carrying the font, and many machines (Linux servers and containers above all) have none of them. Egami.Fonts.Substitutes is a separate, opt-in package that bundles open fonts with the same glyph widths, so text set in a substitute keeps the original's line breaks: Liberation Sans for Helvetica and Arial, Liberation Serif for Times and Times New Roman, Liberation Mono for Courier and Courier New, Carlito for Calibri and Caladea for Cambria, each in four styles. It adds about 7 MB, which is why Egami.Fonts does not carry the fonts itself. The fonts are under the SIL Open Font License 1.1, and their licences ship in the package.

SubstituteFonts.Find takes a family name or a common alias (ArialMT, Times-Roman, Courier New; spaces, hyphens and case are ignored) and returns the face in the nearest style, or null for any other name. SubstituteFonts.Collection holds all twenty faces as a FontCollection, to match by family name or to pass to anything that takes fonts, such as MetafileRenderOptions.Fonts or SvgFontOptions.Collection.

// Bundled faces for the fonts documents name most, on any machine: Arial is Liberation Sans, Calibri is Carlito.
Typeface? arial = SubstituteFonts.Find("Arial", FontStyle.Bold);
Font body = new(SubstituteFonts.Find("Calibri", FontStyle.Normal)!, 11);

// All twenty faces as a collection, matched by family name and style.
FontMatch? mono = SubstituteFonts.Collection.Match("Liberation Mono", FontStyle.Italic);

Subsets

FontSubsetter.Subset writes a font with only some glyphs, as PDF embedding and SVG export want: TrueType, OpenType CFF or a bare CID-keyed CFF stream (SubsetFormat), closed over composites and accents, with unused CFF subroutines dropped. SubsetOptions sets the format, dense or kept glyph ids, the character map, extra tables and the subset tag; the FontSubset holds the bytes and the glyph map.

// Keep only the glyphs a page uses, as a PDF writer embeds them: renumbered from 0, with the map to write the text with.
GlyphRun run = new Font(face, 12).Shape("Invoice 2026-10");
FontSubset subset = FontSubsetter.Subset(face, run.Glyphs.ToArray(), new SubsetOptions
{
    FontNamePrefix = "ABCDEF+",
    KeepCmap = false,
});
byte[] fontFile2 = subset.Data.ToArray();
ushort first = subset.GlyphMap[run.Glyphs[0]];

// The face's embedding permissions are reported, never enforced: the writer decides.
bool restricted = face.Embedding.HasFlag(FontEmbedding.Restricted);

A PDF needs only the glyphs it draws. A subset that is to be shaped again, such as a web font for a known set of pages, sets SubsetOptions.LayoutClosure: the kept glyphs gain every glyph GSUB can substitute for them (OpenTypeLayout.GetClosure with the default features), and GSUB, GPOS and GDEF are copied unchanged. The copied tables use the old glyph ids, so it needs RetainGlyphIds.

// Keep what the text's characters can become (ligatures, contextual forms) and the layout tables, so the subset shapes
// the text as the full face does; the copied tables use the old glyph ids, so the ids are kept.
ushort[] glyphs = [.. "office".Select(c => face.GetGlyph(c))];
FontSubset subset = FontSubsetter.Subset(face, glyphs, new SubsetOptions { RetainGlyphIds = true, LayoutClosure = true });
GlyphRun shaped = new Font(subset.ToTypeface(), 12).Shape("office");

Font data for PDF

A PDF font reaches its glyphs in ways a text layout never does: by glyph name, by CID, through one particular cmap subtable or through the font program's own encoding. Typeface gives each as FreeType does, so a PDF reader built on Egami finds the glyphs PDFium finds.

  • GetGlyphName and TryGetGlyphByName read a name-keyed CFF font's charset, else the post table (versions 1, 2 and 2.5). A simple font's /Differences array names glyphs this way. When two glyphs share a name the lower id wins.
// A PDF simple font's /Differences array names glyphs: find each by name, and get names back for a ToUnicode guess.
ushort aacute = face.TryGetGlyphByName("aacute", out ushort g) ? g : (ushort)0;
string? name = face.GetGlyphName(aacute);
  • CidSystemInfo, GetCid and TryGetGlyphByCid read a CID-keyed CFF font's ROS and charset, for CIDFontType0 fonts.
// A CIDFontType0 font with /CIDToGIDMap absent reaches glyphs by CID through the CFF charset.
CidSystemInfo? collection = cjk.CidSystemInfo;            // Adobe-Identity-0 for this font
ushort glyph = cjk.TryGetGlyphByCid(1, out ushort byCid) ? byCid : (ushort)0;
int cid = cjk.GetCid(glyph);
  • CharacterMaps lists every cmap subtable as stored and FindCharacterMap picks one by platform and encoding; a CharacterMap maps the subtable's own codes (bytes for (1,0) and (3,0)), never translated, and GetMappings lists them all as CharacterMappings. BuiltInEncoding is a name-keyed CFF font's own encoding as a platform 7 map (0 Standard, 1 Expert, 2 custom). GetGlyph(codePoint) keeps choosing its one Unicode subtable as before.
// A symbolic TrueType font in PDF looks a code up in (3,0) first, then (1,0); a non-symbolic one uses (3,1).
CharacterMap? map = trueType.FindCharacterMap(3, 0) ?? trueType.FindCharacterMap(1, 0) ?? trueType.FindCharacterMap(3, 1);
ushort forA = map?.GetGlyph('A') ?? 0;

// A Type1C font without /Encoding uses the CFF program's own encoding.
CharacterMap? own = face.BuiltInEncoding;                  // platform 7, encoding 0: the Standard Encoding
ushort forB = own?.GetGlyph('B') ?? 0;

// Every code the map gives a glyph, in code order, for a PDF writer's /Widths or a ToUnicode table.
int mapped = map?.GetMappings().Count() ?? 0;
  • CffStandardStrings has the 391 standard strings and the Standard and Expert encodings, for writing CFF (a Type 1 font converted for embedding, say).
// Converting a Type 1 font to CFF: standard glyph names take their standard SIDs, others go in the String INDEX.
int sid = CffStandardStrings.TryGetSid("Aacute", out int standard) ? standard : -1;
string atCode65 = CffStandardStrings.StandardEncoding[65];   // "A"

Everything is read on first use, once per face, and is safe from several threads. Damaged data never throws: a name the post table cannot give is null, a subtable that cannot be read maps nothing, and each reports a warning (Font.BadTable) through the context's diagnostics, unless FontLoadOptions.Strict asks for an exception. On the 1,723 font programs embedded in Egap's corpus, names, CIDs, subtables and built-in encodings equal FreeType's and fontTools' (FreeType's where the two differ).
