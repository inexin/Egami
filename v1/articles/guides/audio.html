Audio

Egami.Video decodes and encodes audio with the same send and receive loop as video. It is fully managed and ships:

  • Codecs: FLAC (RFC 9639) decode and encode, and integer and float PCM.
  • Containers: WAV with RF64 and BW64 for files over 4 GB, Sony Wave64 and native FLAC, read and written; FLAC and PCM in Matroska, WebM and MP4 too.
  • A resampler between any two rates, sample format conversion with dither, and channel layouts with downmix and upmix.

Opus, Vorbis and other audio tracks are copied through untouched.

Frames

An AudioFrame holds SampleCount samples for every channel of its Layout, its SampleRate, its Format (a SampleFormat) and the Timestamp of its first sample. Frame memory comes from the context's memory source; dispose each frame. AsSpan<T>(channel) reads a channel of a planar frame, or every channel of an interleaved one; GetSpan<T> writes.

// A frame holds samples for every channel, a sample rate, a layout, a sample format and the time of its first sample.
using AudioFrame frame = new(SampleFormat.F32Planar, ChannelLayout.Stereo, 48000, 480, MediaTime.Zero);
Span<float> left = frame.GetSpan<float>(channel: 0);
for (int i = 0; i < left.Length; i++)
{
    left[i] = MathF.Sin(2 * MathF.PI * 1000 * i / 48000);
}

Console.WriteLine($"{frame.SampleCount} samples, {frame.Duration.ToTimeSpan().TotalMilliseconds} ms, {frame.Layout}");

SampleFormat has unsigned 8-bit, signed 16, 32 and 64-bit, and 32 and 64-bit float samples, each interleaved or planar. Integer frames say how many low bits they use in ValidBits: 24-bit audio is S32 with 24 valid bits, so WAV and FLAC round trip exactly. Convert and CopyTo change the format, with triangular dither when AudioConvertOptions.Dither is set; SampleFormatExtensions gives the size and kind of each format.

// Integer samples carry their valid bits: 24-bit audio is S32 with ValidBits 24, from -2^23 to 2^23 - 1.
using AudioFrame pcm24 = tone.Convert(SampleFormat.S32Planar);
Console.WriteLine($"{pcm24.Format}, {pcm24.Format.BytesPerSample()} bytes, planar: {pcm24.Format.IsPlanar()}");

// Down to interleaved 16-bit with triangular dither.
using AudioFrame cd = tone.Convert(SampleFormat.S16, options: new AudioConvertOptions { Dither = true });
ReadOnlySpan<short> interleaved = cd.AsSpan<short>();

Reading audio

AudioReader opens a file and decodes its first audio track (or the one AudioReaderOptions.TrackNumber names). Frames come as planar float by default; AudioReaderOptions asks for another SampleFormat (or null for the codec's own), another SampleRate (resampled, with a ResamplerQuality) and another Layout (mixed). Codec delay and the packets an MP4 edit list leaves out are trimmed, so the audio has exactly the samples the encoder was given; KeepAllSamples keeps them. Seek is sample exact.

// The first audio track of any file, as planar float by default; seeking is sample exact.
using AudioReader reader = AudioReader.Open("tone.flac");
Console.WriteLine($"{reader.Track.CodecId} {reader.SampleRate} Hz {reader.Layout}");
reader.Seek(MediaTime.FromSeconds(0.5));
double peak = 0;
while (reader.TryRead(out AudioFrame? frame))
{
    using (frame)
    {
        foreach (float sample in frame.AsSpan<float>(channel: 0))
        {
            peak = Math.Max(peak, Math.Abs(sample));
        }
    }
}

// Or ask for one format, rate and layout, and let the reader convert.
AudioReaderOptions options = new() { SampleFormat = SampleFormat.S16, SampleRate = 22050, Layout = ChannelLayout.Mono };
using AudioReader mono = AudioReader.Open("tone.wav", options);

Writing audio

AudioWriter encodes frames into a file or stream; the container comes from the extension. AudioWriterOptions sets the Codec (FLAC for .flac, PCM elsewhere by default), the SampleRate and Layout to write (converted when the frames differ), the BitsPerSample and the compression Level. Frames may have any length and format.

// FLAC for .flac files, PCM for .wav, .w64, .mka and .mp4 unless the options name a codec; FLAC levels run 0 to 8.
using (AudioWriter writer = AudioWriter.Create("tone.flac", new AudioWriterOptions { Level = 8, BitsPerSample = 24 }))
{
    writer.Write(tone);
}

// 16-bit WAV at 44.1 kHz: the writer resamples and converts.
using (AudioWriter writer = AudioWriter.Create("tone.wav", new AudioWriterOptions { SampleRate = 44100, BitsPerSample = 16 }))
{
    writer.Write(tone);
}

VideoWriterOptions.AudioCodec, with AudioSampleRate and AudioLayout, adds an audio track to a VideoWriter, which WriteAudio fills.

// A video writer can encode an audio track next to the video.
VideoWriterOptions options = new() { AudioCodec = FlacCodec.Instance, AudioSampleRate = 48000, AudioLayout = ChannelLayout.Stereo };
using (VideoWriter writer = VideoWriter.Create("clip.mkv", options))
{
    for (int i = 0; i < 30; i++)
    {
        writer.WriteFrame(picture);
    }

    writer.WriteAudio(tone);
}

MediaFile.Transcode copies a file like MediaFile.Remux but decodes its audio and encodes it again with another codec, keeping video and the other tracks as they are.

// Keep every other track as it is and turn the audio into FLAC.
MediaFile.Transcode("talk.mka", "talk-flac.mkv", audio: FlacCodec.Instance, audioLevel: 8);

Channel layouts and mixing

A ChannelLayout lists the Speakers its channels feed, in WAVE_FORMAT_EXTENSIBLE order, which every decoder hands out whatever order its codec stores. Presets run from Mono to Surround714; Unpositioned is for ambisonic or unknown channels, and ForChannelCount gives the layout WAV and FLAC assume when a file names none.

// Channels come in WAVE_FORMAT_EXTENSIBLE order whatever the codec stored: 5.1 is FL, FR, FC, LFE, BL, BR.
ChannelLayout layout = ChannelLayout.Surround51;
int lfe = layout.IndexOf(Speakers.LowFrequency);
Speakers fourth = layout.GetSpeaker(3);
ChannelLayout custom = new(Speakers.FrontLeft | Speakers.FrontRight | Speakers.TopFrontLeft | Speakers.TopFrontRight);
ChannelLayout ambisonic = ChannelLayout.Unpositioned(4);

ChannelMixer mixes one layout into another with a matrix. The default one follows ITU-R BS.775: center and surrounds at -3 dB, LFE dropped unless given a level, and upmixing only routes the speakers both layouts share. A matrix of your own works too.

// ITU-R BS.775 downmix: center and surrounds at -3 dB, LFE dropped unless given a level.
ChannelMixer downmix = new(ChannelLayout.Surround51, ChannelLayout.Stereo);
using AudioFrame stereo = downmix.Mix(surround);
float centerInLeft = downmix[0, 2];

// Or a matrix of one's own, indexed [output, input].
ChannelMixer swap = new(ChannelLayout.Stereo, ChannelLayout.Stereo, new float[,] { { 0, 1 }, { 1, 0 } });

Resampling

Resampler converts between any two rates with a polyphase windowed-sinc filter. ResamplerQuality.Good, the default, is flat within 0.1 dB to 0.9 of the lower Nyquist frequency and 100 dB down above it; Fast and Best (140 dB) trade speed for steepness. Time stays exact: the first output sample has the first input sample's time, and the output has the input's length at the new rate.

// 48 kHz to 44.1 kHz with the default quality (100 dB stopband); frames go in and come out like a codec's.
using Resampler resampler = new(48000, 44100, ChannelLayout.Stereo, ResamplerQuality.Good);
resampler.Send(tone);
resampler.Flush();
long samples = 0;
while (resampler.TryReceive(out AudioFrame? frame))
{
    using (frame)
    {
        samples += frame.SampleCount;
    }
}

Codecs by hand

An AudioCodec creates an IAudioDecoder for a track and an IAudioEncoder from AudioEncoderOptions; AudioCodecs finds them in a MediaContext. PcmCodec has little-endian, big-endian and float instances; FlacCodec encodes at levels 0 to 8 with the reference encoder's meaning, default 5, and sizes within 1 % of libFLAC's. Decoders take AudioDecoderOptions: Errors as a DecodeErrorMode, and VerifyChecksums for FLAC's frame CRCs and STREAMINFO MD5 (reported as Flac.BadCrc and Flac.Md5Mismatch). IAudioDecoder.SendLoss reports a lost packet.

// An encoder takes frames of any length and format and cuts packets of its frame size.
using IAudioEncoder encoder = FlacCodec.Instance.CreateEncoder(
    new AudioEncoderOptions { SampleRate = 48000, Layout = ChannelLayout.Stereo, BitsPerSample = 16, Level = 5 },
    MediaContext.Default);
encoder.Send(tone);
encoder.Flush();
List<EncodedPacket> packets = [];
while (encoder.TryReceive(out EncodedPacket? packet))
{
    packets.Add(packet);
}

// The same send and receive loop as video, for the track the encoder describes (or one a demuxer read).
using IAudioDecoder decoder = AudioCodecs.CreateDecoder(encoder.Track);
long decoded = 0;
foreach (EncodedPacket packet in packets)
{
    using (packet)
    {
        decoder.Send(packet);
    }

    while (decoder.TryReceive(out AudioFrame? frame))
    {
        using (frame)
        {
            decoded += frame.SampleCount;
        }
    }
}

// FLAC decodes to its own integers: S16Planar up to 16 bits, S32Planar above.

Containers

WavFormat.Instance reads WAV, RF64 and BW64 (PCM, float, WAVE_FORMAT_EXTENSIBLE with its channel mask, and streamed files whose sizes were never filled in), and writes WAV that turns into RF64 by itself past 4 GB. WavFormat.Wave64 is Sony Wave64. LIST/INFO and id3 tags become MediaInfo.Tags, and cue points become chapters. FlacFormat reads and writes native FLAC: Vorbis comments as tags, pictures as attachments (cover.* for the front cover), and a seek table every 10 seconds.

// WAV, Wave64 and FLAC are containers like the others: remux PCM from WAV into Wave64 without decoding.
MediaFile.Remux("tone.wav", "tone.w64");
MediaInfo info = MediaFile.Probe("tone.w64");
AudioTrackInfo track = (AudioTrackInfo)info.Tracks[0];
Console.WriteLine($"{info.FormatName}: {track.CodecId}, {track.SampleRate} Hz, {track.BitsPerSample} bits, {track.Layout}");
