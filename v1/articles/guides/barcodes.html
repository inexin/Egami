Barcodes

Egami.Barcodes writes and reads barcodes. It draws them through Egami.Drawing's canvas, so a barcode stays vector on a PDF page or in SVG output, and reads them from rasters. It is fully managed.

It writes and reads QR Code, Micro QR Code, Data Matrix, PDF417 and Aztec Code, and the linear Code 128 (with GS1-128), Code 39, Code 93, Codabar, GS1 DataBar (Omnidirectional, Truncated, Stacked, Stacked Omnidirectional, Limited, Expanded and Expanded Stacked), ITF and ITF-14, EAN-13, EAN-8, UPC-A and UPC-E. It also writes the 4-state postal codes of Japan Post, USPS (Intelligent Mail), Royal Mail (RM4SCC), PostNL (KIX) and Australia Post, which it does not read. Each has its own factory on Barcode with typed options; Barcode.Create takes a format chosen at run time with the default options.

// Labels from a table that stores each barcode's format with its data.
(BarcodeFormat Format, string Data)[] rows =
[
    (BarcodeFormat.Ean13, "590123412345"),
    (BarcodeFormat.Code128, "SHIP-0042"),
    (BarcodeFormat.Qr, "https://inexin.github.io/Egami/"),
];

foreach ((BarcodeFormat format, string data) in rows)
{
    Barcode barcode = Barcode.Create(format, data);
    using Raster<Gray8> image = barcode.ToRaster(pixelsPerModule: 3);
}

QR Code

Barcode.Qr writes a QR Code from text, bytes or GS1 element strings. Text is split into numeric, alphanumeric, byte and Kanji segments that give the fewest bits. Text in ISO 8859-1 is written as it is, text that Shift JIS holds is written in Shift JIS (its kanji in Kanji mode), and anything else as UTF-8 with an ECI that tells readers so.

By default the symbol is the smallest that holds the data at level M, and the level is then raised to Q or H while the symbol stays the same size, so spare room goes to error correction. QrOptions fixes the level, the version (1 to 40) or the mask instead.

// Level M, raised to Q or H when that fits in the same size; segments chosen for the fewest bits.
Barcode link = Barcode.Qr("https://inexin.github.io/Egami/");

// A fixed size and level, for a layout that must not change.
Barcode fixedSize = Barcode.Qr("ORDER-1180042", new QrOptions { Version = 3, ErrorCorrection = QrErrorCorrection.H });

// Bytes as they are, and GS1 element strings with FNC1.
Barcode bytes = Barcode.Qr([0x45, 0x67, 0x61, 0x6D, 0x69]);
Barcode gs1 = Barcode.Qr(Gs1.Parse("(01)09501101530003(10)AB12"));

using Raster<Gray8> image = link.ToRaster(pixelsPerModule: 4);

Micro QR Code

Barcode.MicroQr writes a Micro QR Code, the small form of QR Code with one finder pattern: versions M1 to M4, 11 x 11 to 17 x 17 modules, for marks on parts and small labels. It holds at most 35 digits, 21 alphanumeric characters or 15 bytes (M4 at level L). Segments are chosen as for QR Code, as far as the version has the mode: M1 holds digits only, M2 adds alphanumeric, M3 and M4 bytes and Kanji. Micro QR has no ECI, so the text must be ISO 8859-1 or what Shift JIS holds.

By default the symbol is the smallest version that holds the data at level L, and the level is raised to M and then Q while the symbol stays the same version. MicroQrOptions sets the level (L, M from M2, Q in M4 only; M1 only detects errors), the smallest version and whether the level is raised. The quiet zone is 2 modules.

// The smallest version that holds the text, M1 (11 x 11 modules) to M4 (17 x 17), at level L raised while it fits.
Barcode part = Barcode.MicroQr("PART-0042");

// Level M from version M3 on, for a mark that may get scuffed.
Barcode serial = Barcode.MicroQr("SN 4711", new MicroQrOptions { ErrorCorrection = QrErrorCorrection.M, MinVersion = 3 });

using Raster<Gray8> image = part.ToRaster(pixelsPerModule: 6);

Data Matrix

Barcode.DataMatrix writes Data Matrix ECC 200 from text, bytes or GS1 element strings. The six encodation modes (ASCII, C40, Text, X12, EDIFACT and Base 256) are switched for the fewest codewords, and the symbol is the smallest that holds them. Text in ISO 8859-1 is written as it is, anything else as UTF-8 with an ECI.

Symbols are square by default. DataMatrixOptions.Shape allows rectangular symbols, or the smallest of either, and AllowDmre adds the rectangular sizes of ISO/IEC 21471 (DMRE), which older readers may not read.

// Square by default; the encodation modes are switched for the fewest codewords.
Barcode part = Barcode.DataMatrix("PN 4711-0815 / LOT 2026-10");

// A narrow label: rectangular sizes, the DMRE ones too.
Barcode narrow = Barcode.DataMatrix("PN 4711-0815 / LOT 2026-10", new DataMatrixOptions
{
    Shape = DataMatrixShape.Rectangle,
    AllowDmre = true,
});

// GS1 Data Matrix, as on medicine packs.
Barcode pack = Barcode.DataMatrix(Gs1.Parse("(01)09501101530003(17)261231(10)AB12(21)XYZ"));

PDF417

Barcode.Pdf417 writes PDF417 from text or bytes, as on boarding passes and driving licences. Text, numeric and byte compaction are chosen run by run. The error correction level follows the standard's recommended minimum for the amount of data, and the columns are picked so the symbol is about three times as wide as tall; Pdf417Options sets either, or asks for compact PDF417, which leaves out the right row indicators for a narrower symbol. Rows are 3 modules tall.

// About three times as wide as tall, error level from the standard's table for the amount of data.
Barcode ticket = Barcode.Pdf417("PASSENGER DOE/JANE  FLIGHT EG1234  SEAT 12A  GATE B17");

// Six data columns and error level 5, or the compact form for a narrow space.
Barcode wide = Barcode.Pdf417("PASSENGER DOE/JANE", new Pdf417Options { Columns = 6, ErrorLevel = 5 });
Barcode compact = Barcode.Pdf417("PASSENGER DOE/JANE", new Pdf417Options { Compact = true });

Aztec Code

Barcode.Aztec writes Aztec Code from text or bytes, as on rail and airline tickets. The text is written in the Upper, Lower, Mixed, Punctuation and Digit modes and Binary Shift, switched for the fewest bits. The symbol is the smallest compact (up to 4 layers) or full-range (up to 32 layers) one that leaves at least 23 % of its codewords, plus 3, for error correction; AztecOptions raises that share or fixes the form and layers. Aztec Code finds itself by its bullseye, so it needs no quiet zone. Barcode.AztecRune makes an Aztec Rune, an 11 x 11 core that holds one value from 0 to 255.

// The smallest compact or full-range symbol with at least 23 % error correction; no quiet zone needed.
Barcode ticket = Barcode.Aztec("EG1234 BER-MUC 2026-10-19 SEAT 12A DOE/JANE");

// More error correction for a ticket that gets folded, or a fixed compact size.
Barcode robust = Barcode.Aztec("EG1234 BER-MUC", new AztecOptions { ErrorCorrectionPercent = 50 });
Barcode compact = Barcode.Aztec("EG1234", new AztecOptions { Compact = true, Layers = 2 });

// A rune: one value from 0 to 255 in an 11 x 11 core.
Barcode rune = Barcode.AztecRune(42);

Linear barcodes

Code 128

Barcode.Code128 writes any text of characters 0 to 255. It picks the code sets A, B and C, and the changes and shifts between them, that give the shortest symbol, so runs of digits go in pairs. Code128Options.Height sets the bar height in modules when the barcode is drawn at a module size; drawn into a rectangle, the bars fill it.

// The shortest mix of code sets A, B and C; the digits go in pairs.
Barcode code = Barcode.Code128("ORDER-1180042", new Code128Options { Height = 40 });
using Raster<Gray8> image = code.ToRaster(pixelsPerModule: 2);

GS1-128 and GS1 element strings

Gs1.Parse reads GS1 element strings written with each Application Identifier in parentheses, such as (01)09501101530003(17)261231, and checks each one against the GS1 General Specifications: the AI is defined, the characters and lengths fit it, and check digits, dates and times are right. A bad field throws a FormatException that says which AI is wrong and how; Gs1.TryParse returns false instead. Each Gs1ElementString has its Ai, Value and GS1's Title for the AI. A parenthesis inside a value is written \(.

Barcode.Gs1Code128 encodes element strings as Code 128 with FNC1 first, and an FNC1 after each field whose AI has no predefined length, unless it is the last.

// Each element string is checked: the AI, the length, the GTIN's check digit, the date.
IReadOnlyList<Gs1ElementString> elements = Gs1.Parse("(01)09501101530003(17)261231(10)AB12");
Barcode label = Barcode.Gs1Code128(elements);

// Mistakes say what is wrong.
if (!Gs1.TryParse("(01)09501101530004", out _))
{
    Console.WriteLine("(01) has a wrong check digit");
}

The checks come from the GS1 Barcode Syntax Dictionary. Checks that need outside lists (country and currency codes, company prefixes) and the rules about which AIs go together are not applied.

Code 39

Barcode.Code39 writes digits, capital letters, space and - . $ / + %. Text with other ASCII characters, such as lowercase letters, is written as Full ASCII, which spells them as pairs; Code39Options.FullAscii forces it on or off. A reader has to be set to Full ASCII to read such text back. Code39Options.CheckDigit adds the mod 43 check character, and WideRatio makes wide elements 2 (the default) or 3 times as wide as narrow ones.

// Capitals, digits and a few symbols; lowercase switches to Full ASCII on its own.
Barcode part = Barcode.Code39("PART-0042", new Code39Options { CheckDigit = true });
Console.WriteLine(part.HumanReadableText); // PART-0042 and its mod 43 check character

Code 93

Barcode.Code93 writes digits, capital letters, space and - . $ / + %, in a symbol shorter than Code 39's for the same text. Two check characters, C and K, are always added; they are not part of the human-readable text. Text with other ASCII characters, such as lowercase letters, is written as Full ASCII, a shift character and a letter for each; Code 93's shift characters are characters of their own, so readers decode Full ASCII without being told. Code93Options.FullAscii set to false rejects such text instead.

// The check characters C and K are added on their own; lowercase switches to Full ASCII.
Barcode part = Barcode.Code93("PART-0042");
Barcode mixed = Barcode.Code93("Part 42, lot b");
Console.WriteLine(part.HumanReadableText); // PART-0042

Codabar

Barcode.Codabar writes digits and - $ : / . + between a start and a stop character, A, B, C or D, as libraries, blood banks and parcel services use it. Text that begins and ends with A to D keeps those; other text gets CodabarOptions.Start and Stop, A by default. CheckDigit adds a modulo 16 check character before the stop character, and WideRatio makes wide elements 2 (the default) or 3 times as wide as narrow ones. The human-readable text is every character of the symbol, start, stop and any check character included, as a reader returns it. A symbol needs two characters between start and stop, or one and the check character: readers ignore shorter ones.

// A library card number between start character A and stop character B.
Barcode card = Barcode.Codabar("A31117013206375B");

// Start and stop characters from the options, and a modulo 16 check character.
Barcode checkedCode = Barcode.Codabar("40156", new CodabarOptions { Start = 'C', Stop = 'D', CheckDigit = true });
Console.WriteLine(checkedCode.HumanReadableText); // C40156, its check character, D

GS1 DataBar

GS1 DataBar (ISO/IEC 24724) holds GS1 data in symbols smaller than EAN's, for fresh foods, small items and coupons. Barcode.DataBar writes a GTIN-14 as DataBar Omnidirectional: 13 digits get their check digit added, 14 are checked, and shorter GTINs take leading zeros. DataBarOptions.Kind picks the form: Omnidirectional (the default, 33 modules tall, for scanners at any angle), Truncated (13 modules tall), Stacked (the two halves over each other, 5 and 7 modules tall) or StackedOmnidirectional (the halves each 33 modules tall). Barcode.DataBarLimited writes a GTIN-14 that starts with 0 or 1 in a shorter symbol, 79 modules wide. The human-readable text is the AI and the GTIN-14, such as (01)09501101530003.

// A GTIN-14 for a retail item, in the full-height form and stacked for a small pack.
Barcode item = Barcode.DataBar("0950110153000");
Barcode stacked = Barcode.DataBar("09501101530003", new DataBarOptions { Kind = DataBarKind.Stacked });
Barcode limited = Barcode.DataBarLimited("09501101530003");
Console.WriteLine(item.HumanReadableText); // (01)09501101530003

Barcode.DataBarExpanded writes GS1 element strings, from Gs1.Parse or as text with each AI in parentheses, in up to 74 digits or 41 letters: a GTIN with a weight, a price, a batch or a date, for variable-measure goods. A GTIN with an indicator digit 9 and a weight in kilograms or pounds, or a price, is compressed, as the standard lays out. DataBarExpandedOptions.SegmentsPerRow set to an even number 2 to 20 writes DataBar Expanded Stacked: the symbol in rows of that many symbol characters, which suits narrow labels. The stacked forms are grids of their rows (Modules.IsLinear is false), each row repeated for its height.

// A GTIN with a net weight of 1.750 kg and a best-before date, in one row and in rows of four characters.
Barcode weighed = Barcode.DataBarExpanded("(01)99501101530006(3103)001750(15)261231");
Barcode narrow = Barcode.DataBarExpanded("(01)99501101530006(3103)001750(15)261231", new DataBarExpandedOptions { SegmentsPerRow = 4 });

ITF and ITF-14

Barcode.Itf writes Interleaved 2 of 5 from digits; an odd number of digits gets a leading zero. Barcode.Itf14 writes a GTIN-14 for cartons: 13 digits get their check digit added, 14 are checked, and bearer bars 5 modules thick frame the symbol and its quiet zone. ItfOptions sets the wide ratio (3 by default), the bearer bars and the height.

// A GTIN-14 on a carton: the check digit is added, and bearer bars frame the symbol.
Barcode carton = Barcode.Itf14("1540014128876");
using Raster<Gray8> image = carton.ToRaster(pixelsPerModule: 3);

// Plain Interleaved 2 of 5 with a 2:1 wide ratio and no bearers.
Barcode itf = Barcode.Itf("0123456789", new ItfOptions { WideRatio = 2 });

EAN and UPC

Barcode.Ean13, Barcode.Ean8, Barcode.UpcA and Barcode.UpcE write retail barcodes. The check digit is added when it is left out and checked when it is given; a wrong one throws. Barcode.UpcE also takes a UPC-A number and writes its zero-suppressed form, or throws when the number has too few zeros. EanUpcOptions.AddOn adds a 2-digit or 5-digit add-on to the right, such as a magazine's issue or a book's price.

With a font, the digits are drawn as on a product: EAN-13's first digit left of the symbol and the others between the guard bars, which reach down into the text line, and an add-on's digits above its bars. Bar heights default to the standards' nominal heights.

// A book: the ISBN as EAN-13, its check digit added, and the price as an EAN-5 add-on.
Barcode book = Barcode.Ean13("978020137962", new EanUpcOptions { AddOn = "52495" });

// Fitted into a rectangle, with the digits between the guard bars.
using Raster<Rgba8> label = Raster.Create(400, 200, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = label.CreateCanvas())
{
    canvas.DrawBarcode(book, new RectF(10, 10, 380, 180), Rgba8.Black, new BarcodeDrawOptions { Font = font });
}

// A UPC-A number written in its short UPC-E form.
Barcode small = Barcode.UpcE("042100005264");

Postal barcodes

Postal barcodes are 4-state codes: each bar is a tracker, the short middle third, or reaches up, down or both ways from it. Egami writes them as grids with one dark column per bar and a light column between bars, the rows sized so that each symbology's module gives its spec's bar heights (6 rows for Japan Post and Intelligent Mail, 8 for the others), so they draw, render and turn into paths like any 2D symbol. It does not read them: BarcodeFormat.Postal holds them, and BarcodeFormat.All leaves them out.

Japan Post

Barcode.JapanPost writes the Japan Post customer barcode (カスタマバーコード) that mailers print under the address for a discount. It takes prepared data, not an address: the 7-digit postal code, with or without its hyphen, then the address number that the rules of Japan Post's postal code manual extract from the address (1-3-2-503 from 1丁目3番2号 郵便プラザ503室). Spaces or one hyphen between the two are dropped, and lowercase letters are made uppercase. The symbol holds 20 characters: the postal code takes 7, a digit or hyphen 1, and a letter 2 (a control code and a digit); CC4 pads the rest, and a check character follows. An address number that does not fit loses its end, as the manual says, a letter cut in two keeping its control code; JapanPostOptions.TruncateAddress set to false throws instead. The human-readable text is the postal code and the whole address number. At the manual's module of 0.6 mm (moduleSize: 0.6f in millimetres) the symbol is 79.8 by 3.6 mm, and its quiet zone of 4 modules gives the 2 mm the manual asks for around it.

// The postal code and the address number the manual's rules extract from the address, here 1-3-2-503.
Barcode mail = Barcode.JapanPost("100-0013 1-3-2-503");

// Drawn at the manual's 0.6 mm module (here in millimetres): 79.8 by 3.6 mm, in a 2.4 mm quiet zone.
Path bars = mail.ToPath(moduleSize: 0.6f);
Console.WriteLine(mail.HumanReadableText); // 100-0013 1-3-2-503

USPS Intelligent Mail

Barcode.IntelligentMail writes the USPS Intelligent Mail barcode (USPS-B-3200): the 20-digit tracking code (barcode identifier, service type, mailer identifier and serial number; the second digit is 0 to 4) and a routing code of 0, 5, 9 or 11 digits, the ZIP Code, ZIP+4 or delivery point. The 65 bars carry an 11-bit frame check. The human-readable text is the tracking code and, after a space, the routing code. At a module of 1/44 inch the bars are 0.136 inch tall at 22 per inch, mid USPS's ranges, and the quiet zone of 6 modules gives the 0.125 inch clear zone at each end. Barcode.Create takes the two codes as one text, the routing code after the 20th digit, a space or hyphen between them or none.

// The 20-digit tracking code and the 11-digit routing code (the ZIP Code and its delivery point).
Barcode mail = Barcode.IntelligentMail("01234567094987654321", "01234567891");

// Drawn at a 1/44 inch module (here in inches): 65 bars at 22 per inch, 0.136 inch tall.
Path bars = mail.ToPath(moduleSize: 1f / 44);
Console.WriteLine(mail.HumanReadableText); // 01234567094987654321 01234567891

Royal Mail and KIX

Barcode.RoyalMail writes the Royal Mail 4-State Customer Code (RM4SCC, the CBC of Royal Mail's mailing services): digits and letters A to Z, usually the postcode without its space and the two-character Delivery Point Suffix. A start bar, a modulo 6 check character and a stop bar are added. Barcode.Kix writes PostNL's KIX code (Klantindex) with the same characters and none of the extras, usually the postcode, the house number and, after an X, its addition. Lowercase letters are made uppercase, and the human-readable text is the characters without the check character. At a module of 0.6 mm the bars are 4.8 mm tall at 21.2 per inch, Royal Mail's sizes, and the quiet zone of 4 modules gives the 2 mm clear zone.

// A postcode without its space and the Delivery Point Suffix; the check character and start and stop bars are added.
Barcode mail = Barcode.RoyalMail("LU178XE2B");

// Drawn at a 0.6 mm module (here in millimetres): bars 4.8 mm tall at 21.2 per inch, in a 2.4 mm quiet zone.
Path bars = mail.ToPath(moduleSize: 0.6f);
Console.WriteLine(mail.HumanReadableText); // LU178XE2B

// The postcode, the house number and, after an X, its addition.
Barcode mail = Barcode.Kix("2500GG30X250");
Path bars = mail.ToPath(moduleSize: 0.6f);
Console.WriteLine(mail.HumanReadableText); // 2500GG30X250

Australia Post

Barcode.AustraliaPost writes the Australia Post 4-State Customer Barcode: the eight-digit Delivery Point Identifier (DPID) and, for Customer Barcodes 2 and 3, the customer information after it. The Format Control Code, filler bars and four Reed-Solomon check symbols are added. By default the DPID alone makes the Standard Customer Barcode (FCC 11, 37 bars) and customer information the shorter of Customer Barcode 2 (FCC 59, 52 bars) and 3 (FCC 62, 67 bars) that holds it, digits in the N table (2 bars each) and other text in the C table (letters, digits, space and #, 3 bars each). AustraliaPostOptions.Format chooses the format (an AustraliaPostFormat), the internal Reply Paid (45), Routing (87) and Redirection (92) too, and Encoding the table (AustraliaPostEncoding.N or C). The human-readable text is Australia Post's text representation: the FCC, the DPID, the customer information and the check symbols, such as 11 39549554 54 17 53 58. At a module of 0.55 mm the bars are 4.4 mm tall at 23 per 25.4 mm, and the quiet zone of 11 modules gives the 6 mm at each end that Australia Post asks for.

// A Standard Customer Barcode holds the eight-digit DPID; customer information after it takes Customer Barcode 2 or 3.
Barcode mail = Barcode.AustraliaPost("39549554");
Barcode withInformation = Barcode.AustraliaPost("54516251ABC123");
Barcode digits = Barcode.AustraliaPost("5451625112345", new AustraliaPostOptions { Format = AustraliaPostFormat.Customer3 });

// Drawn at a 0.55 mm module (here in millimetres): 37 bars, 40.15 mm long and 4.4 mm tall.
Path bars = mail.ToPath(moduleSize: 0.55f);
Console.WriteLine(mail.HumanReadableText); // 11 39549554 54 17 53 58, the FCC, the DPID and the check symbols

Reading barcodes

raster.ReadBarcodes() finds every barcode in an image and raster.ReadBarcode() the first. Reading barcodes covers the options, photos, camera frames, GS1 data and speed.

// Every barcode in the image, of any format.
foreach (BarcodeResult result in scan.ReadBarcodes())
{
    Console.WriteLine($"{result.Format}: {result.Text} at {result.Corners[0]}");
}

Drawing on a canvas

DrawBarcode, an extension method in CanvasBarcodeExtensions, draws on any canvas: a raster, a PDF or SVG page, a recording. The whole symbol is one filled path, a rectangle for each run of dark modules in a row, so a QR code is a few hundred rectangles rather than one per module, and neighbouring rectangles leave no seams.

Given a rectangle, the barcode is fitted into it and centered, with its quiet zone kept clear inside it. 2D symbols keep square modules; linear bars fill the rectangle's height. On a raster canvas with no rotation or skew, the module size snaps to whole pixels, the largest that still fits, so every edge is sharp.

using Raster<Rgba8> label = Raster.Create(300, 200, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = label.CreateCanvas())
{
    // Fitted into the rectangle and centered, quiet zone inside it; on a raster, modules snap to whole pixels.
    canvas.DrawBarcode(qr, new RectF(20, 20, 160, 160), Rgba8.Black);
}

Given a point and a module size instead, the barcode is drawn at that size, the X dimension of the standards, with the top-left corner of its quiet zone at the point. Linear bars are then BarcodeModules.Height modules tall.

BarcodeDrawOptions changes how it is drawn:

  • QuietZone keeps the quiet zone clear; it is on by default. Turn it off only when the space around the symbol is blank anyway.
  • BarWidthReduction draws each dark bar or module narrower by that much, half from each side, to make up for ink spreading on a printer. It changes drawing only, never the modules.
  • Font draws the human-readable text under the bars, centered, in that font and size. Without a font no text is drawn; Egami.Barcodes ships no font of its own.
// A 0.33 mm module (the X dimension) in points, with the text under the bars and 0.05 mm taken off each bar
// for ink spread. The quiet zone's top-left corner goes at (36, 36).
float module = 0.33f / 25.4f * 72;
page.DrawBarcode(code, new Vector2(36, 36), module, Rgba8.Black, new BarcodeDrawOptions
{
    Font = font,
    BarWidthReduction = 0.05f / 25.4f * 72,
});

Paths and rasters

ToPath returns the symbol as one path, with the quiet zone's top-left corner at the origin, ready for Path.ToSvg or your own drawing. It holds no text.

// One path, a rectangle per run of dark modules; the quiet zone's corner is at the origin.
Path path = qr.ToPath(moduleSize: 4);
string svg = path.ToSvg();

ToRaster renders black on white into a Raster<Gray8>, each module a square of whole pixels, with the quiet zone and, with a font, the text.

// Black on white, 4 pixels a module, quiet zone included.
using Raster<Gray8> image = qr.ToRaster(pixelsPerModule: 4);

Barcodes from modules

A Barcode is one symbol: its BarcodeFormat, its Modules, the QuietZone its standard asks for in modules (4 for QR, 2 for Micro QR, 1 for Data Matrix, 2 for PDF417, none for Aztec; at each end of a linear symbol, 10 for Code 128, Code 39, Code 93, Codabar and ITF, 11 for EAN-13, 7 for EAN-8, 9 for UPC, 1 for GS1 DataBar and DataBar Expanded and 5 for DataBar Limited; 4 around a Japan Post, Royal Mail or KIX barcode, 6 around an Intelligent Mail barcode and 11 around an Australia Post one) and the HumanReadableText printed under a linear symbol. Barcode.FromModules makes one from modules you already have, such as from another encoder.

// Modules from another encoder become a barcode with the quiet zone of their standard: 4 modules for QR.
Barcode qr = Barcode.FromModules(BarcodeFormat.Qr, modules);
Console.WriteLine($"{qr.Format}: {qr.Modules.Width} modules plus {qr.QuietZone} on each side");

Modules

Every symbol is a BarcodeModules: a grid of dark and light modules for a 2D code, or a row of bars and spaces for a linear one. Width and Height are in modules, the indexer says whether a module is dark, and a linear symbol also lists its bar and space widths in Runs. A grid holds the symbol only, without its quiet zone.

BarcodeModules.Create and BarcodeModules.CreateLinear make one from modules you already have, for example from another encoder.

// A 2D grid, row by row from the top; true is a dark module.
BarcodeModules grid = BarcodeModules.Create(3, 3,
[
    true, false, true,
    false, true, false,
    true, false, true,
]);

// A linear symbol: bar and space widths in modules, starting and ending with a bar.
BarcodeModules bars = BarcodeModules.CreateLinear([2, 1, 1, 1, 3], height: 20);

for (int y = 0; y < grid.Height; y++)
{
    for (int x = 0; x < grid.Width; x++)
    {
        Console.Write(grid[x, y] ? '#' : '.');
    }

    Console.WriteLine();
}

Console.WriteLine($"{bars.Width} modules wide, bars {string.Join(' ', bars.Runs.ToArray())}");

Recipes

Short answers to common tasks in this area. Each one compiles and runs in Egami's test run.

Put a QR code on a label

// A 600 x 300 label: a QR code on the left, the address beside it.
using Raster<Rgba8> label = Raster.Create(600, 300, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = label.CreateCanvas())
{
    canvas.DrawBarcode(Barcode.Qr("https://example.com/track/4711"), new RectF(20, 20, 260, 260), Rgba8.Black);
    canvas.DrawText("Parcel 4711", new Vector2(300, 80), font, Rgba8.Black);
    canvas.DrawText("Track at example.com", new Vector2(300, 120), font, Rgba8.Black);
}

On a raster, the QR code's modules snap to whole pixels, so its edges stay sharp at any size.

Save a barcode as SVG

// The symbol as one path, 4 units a module, drawn on Egami.Svg's canvas over a white quiet zone.
Barcode barcode = Barcode.DataMatrix("PN 4711-0815");
Path path = barcode.ToPath(moduleSize: 4);
float width = (barcode.Modules.Width + (2 * barcode.QuietZone)) * 4, height = (barcode.Modules.Height + (2 * barcode.QuietZone)) * 4;
using (FileStream stream = File.Create(file))
using (var canvas = new Egami.Svg.SvgCanvas(stream, width, height))
{
    canvas.FillRect(new RectF(0, 0, width, height), Rgba8.White);
    canvas.FillPath(path, Rgba8.Black);
}

Barcode.ToPath gives the whole symbol as one path, so any canvas can take it; Egami.Svg's SvgCanvas writes it as one SVG <path>. Egami.Barcodes itself does not depend on Egami.Svg.
