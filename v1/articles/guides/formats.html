Formats

Egami reads and writes PNG, APNG, JPEG, GIF, WebP, BMP, TGA, QOI and the Netpbm formats (PBM, PGM, PPM, PAM and the PFM float map), TIFF, Radiance .hdr, OpenEXR, JPEG XL, and Windows icons and cursors, AVIF, and reads JBIG2, raw CCITT fax data, JPEG 2000 and Photoshop's PSD and PSB. SVG and Windows metafiles (WMF, EMF) load through the separate Egami.Svg and Egami.Metafiles packages. HEIC phone photos load through the separate, opt-in Egami.Heic package; core Egami detects and probes them (see the HEIC guide). Every reader checks sizes against the safety limits before it allocates, and every reader has been fuzzed.

Raster.Load returns the natural type; Raster.Load<TPixel> decodes straight into the type you ask for, converting row by row.

using Raster image = Raster.Load("duck.png");
switch (image)
{
    case Raster<Rgb8> rgb:
        Console.WriteLine($"8-bit color, {rgb.Width} × {rgb.Height}");
        break;
    case Raster<Rgba8> rgba:
        Console.WriteLine($"8-bit color with alpha, {rgba.Width} × {rgba.Height}");
        break;
    default:
        Console.WriteLine($"{image.Layout.ChannelOrder}, {image.Layout.ChannelType}");
        break;
}

Detection

Loading never trusts the file extension: the format comes from the first bytes, in the order PNG, JPEG, GIF, WebP, BMP, QOI, PNM, TIFF, JBIG2, JPEG 2000, ICO, CUR, PSD, Radiance, OpenEXR, JPEG XL (FF 0A or its signature box), AVIF (an ftyp box with the avif or avis brand), HEIC (an ftyp box with a HEVC brand such as heic or heix), then TGA. TGA has no signature, so it is matched only when its whole 18-byte header is consistent. No file of another format in Egami's test corpora is taken for TGA, and neither is any of a million random headers. When you know the format, register only that one:

// TGA has no signature, so it is detected last. When you know a file is TGA, register only that format.
EgamiContext tgaOnly = EgamiContext.Default with { Formats = [TgaFormat.Info] };
using Raster image = Raster.Load("duck.tga", tgaOnly);

Data without a signature of its own, such as the JBIG2 or CCITT stream of a PDF image, loads with its format named, which skips detection. Load, LoadAll, Probe and RasterDecoder.Open all take the format this way; naming the wrong one throws CorruptDataException, as damaged data of that format would.

// Data without a signature of its own (a TGA here; a JBIG2 stream from a PDF) loads with its format named,
// which skips detection. Probe, LoadAll and RasterDecoder.Open take the format the same way.
using Raster image = Raster.Load(data, TgaFormat.Info);
RasterInfo info = Raster.Probe(data, TgaFormat.Info);

Saving to a path picks the writer from the extension; an animated raster saved as .png writes an APNG. Saving to a stream takes the format's Info.

Several images in one file

Frames are animation and share one size. A TIFF's pages are separate images, each with its own size and pixel type, so they come as a RasterList from Raster.LoadAll, which owns them; RasterInfo.ImageCount says how many there are. Every other format gives its one image, so LoadAll works on any file. Raster.SaveAll writes several rasters to a format that holds several, and one raster to any format.

// Every page at its own size and pixel type. The list owns the rasters.
using RasterList pages = Raster.LoadAll("scan.tif");
foreach (Raster page in pages)
{
    Console.WriteLine($"{page.Width} × {page.Height}");
}

// Keep one page after the list is gone.
using Raster first = pages.Detach(0);

PNG

using FileStream output = File.Create("duck-small.png");
image.Save(output, PngFormat.Info, new PngWriterOptions
{
    Reduce = true,          // the smallest exact form: no alpha if all opaque, gray or a palette when nothing is lost
    CompressionLevel = 9,   // 0 (fastest) to 9 (smallest); 5 by default
});
Option Default Does
ColorType, BitDepth The pixel type's own Force a layout, such as PngColorType.Palette
Reduce false Scan the image and write the smallest exact form
Palette 256 colors, Floyd–Steinberg How a palette is built when ColorType is Palette and the image has more colors
CompressionLevel 5 zlib level, 0 to 9
Filter Adaptive Row filter, or one fixed filter
FirstFrameOnly false Write a still PNG from an animation
Interlace false Write Adam7, so a viewer can show a coarse image early; files are usually larger
ParallelCompression false Compress images with more than 4 MiB of image data on several cores

Interlace is never taken from the source: an interlaced PNG is written plain unless you set it. With ParallelCompression, the image data is cut into fixed bands of 1 MiB that compress on up to EgamiContext.MaxParallelism threads. The file is the same on any machine and at any thread count, and in Egami's tests it was 0.1% to 0.3% larger; a 24-megapixel photo saved 8 times as fast on 12 cores. Smaller images are written exactly as with the option off.

image.Save("duck-large.png", new PngWriterOptions
{
    ParallelCompression = true, // big images compress on several cores; the same file at any thread count
    Interlace = true,           // Adam7: a coarse image shows before the whole file has arrived
});

Kept for round trips in PngDetails: gamma, chromaticities, sRGB intent, cICP, the ICC profile name, and every chunk Egami does not read itself.

BMP

// Auto (the default): 24-bit when every pixel is opaque, 32-bit with alpha otherwise.
image.Save("duck.bmp");

// A 16-color palette, built from the image and dithered.
image.Save("duck-16.bmp", new BmpWriterOptions { PixelFormat = BmpPixelFormat.Indexed4 });

A plain 32-bit BMP's fourth byte is used as alpha unless it is 0 in every pixel, in which case the image loads opaque; an alpha mask in the header is always used. Pixels that an RLE delta skips are black. BmpPixelFormat.Indexed2 writes Windows CE 2-bit files, which many desktop readers cannot open, so Auto never picks it. Resolution is written in pixels per meter, and an ICC profile switches the header to V5 with the profile embedded.

TGA

// Run-length encoded by default, bottom-left origin, with a TGA 2.0 footer that states the alpha type.
image.Save("duck.tga");
image.Save("duck-raw.tga", new TgaWriterOptions { Rle = false });

The descriptor's attribute bits say whether the extra bits are alpha, and a TGA 2.0 alpha type of "none" overrides them; premultiplied alpha is divided out on load. The extension area's author and comments become Author and Comment text entries, and the writer stores them back. TgaPixelFormat.Bgr24 drops alpha rather than blending it onto a background.

QOI

// 3 channels when every pixel is opaque, 4 otherwise. The bytes match the reference encoder's.
image.Save("duck.qoi");
image.Save("duck-rgba.qoi", new QoiWriterOptions { IncludeAlpha = true });

QOI's colorspace byte maps to RasterMetadata.ColorSpace (sRGB or linear) and back.

PNM

// Auto: P5 (PGM) for gray, P6 (PPM) for color, P7 (PAM) when the pixel type has alpha.
image.Save("duck.ppm");

// The plain-text forms, for tools that read them; lines are at most 70 characters.
image.Save("duck-plain.ppm", new PnmWriterOptions { PlainText = true });

// A 1-bit bitmap, thresholded at 50% gray.
image.Save("duck.pbm", new PnmWriterOptions { Kind = PnmKind.Bitmap });

Maxvals other than 255 and 65,535 are scaled exactly, as round(v × 255 / maxval). A PAM with an unknown tuple type is read by its depth, with a warning. A stream with several images reads the first and warns. # comments become Comment text entries and are written back. Saving to a .pbm, .pgm, .ppm, .pam or .pfm path writes that variant unless PnmWriterOptions.Kind names one; .pnm chooses from the pixel type.

PFM float maps load as RgbF32 (PF) or GrayF32 (Pf), marked as linear light, with their scale and byte order in PnmDetails; values outside 0..1 are kept. Writing uses PFM for float types without alpha, or when PnmKind.FloatMap is asked for: little-endian, scale −1, as Netpbm and ImageMagick write it.

What each writer drops

Writers never change the raster. When a format cannot hold something, it is left out:

  • Alpha: JPEG (unless JpegWriterOptions.Background blends it onto a color), BMP and TGA with Bgr24, PPM, QOI with IncludeAlpha = false.
  • Frames after the first: JPEG, BMP, TGA, QOI and PNM.
  • Metadata: every writer keeps what its format can carry; StripMetadata = true on any writer options drops it all.

See the API reference for every option.

What the file said

Every reader fills RasterMetadata.FormatDetails with the header's own terms: PngDetails, JpegDetails, GifDetails, BmpDetails, TgaDetails, QoiDetails or PnmDetails. A writer of the same format uses them to keep what it can, and ignores another format's details.

// Each reader fills in what the file's header says, in the format's own terms.
using Raster png = Raster.Load("duck.png");
if (png.Metadata.FormatDetails is PngDetails pngDetails)
{
    Console.WriteLine($"PNG {pngDetails.ColorType}, {pngDetails.BitDepth}-bit, interlaced: {pngDetails.Interlaced}");
    foreach (PngTextSource source in pngDetails.TextSources)
    {
        Console.WriteLine($"Text from a {source.ChunkType} chunk, compressed: {source.Compressed}");
    }
}

using Raster bmp = Raster.Load("duck.bmp");
BmpDetails bmpDetails = (BmpDetails)bmp.Metadata.FormatDetails!;
Console.WriteLine($"BMP {bmpDetails.BitsPerPixel}-bit, {bmpDetails.Compression}, {bmpDetails.HeaderSize}-byte header");

using Raster tga = Raster.Load("duck.tga");
TgaDetails tgaDetails = (TgaDetails)tga.Metadata.FormatDetails!;
Console.WriteLine($"TGA type {tgaDetails.ImageType}, origin {tgaDetails.Origin}, alpha {tgaDetails.AlphaType}");

using Raster qoi = Raster.Load("duck.qoi");
QoiDetails qoiDetails = (QoiDetails)qoi.Metadata.FormatDetails!;
Console.WriteLine($"QOI {qoiDetails.Channels} channels, linear: {qoiDetails.Linear}");

using Raster pgm = Raster.Load("duck.pgm");
PnmDetails pnmDetails = (PnmDetails)pgm.Metadata.FormatDetails!;
Console.WriteLine($"PNM {pnmDetails.Kind}, maxval {pnmDetails.MaxValue}, plain text: {pnmDetails.PlainText}");

More PNG and TGA writer settings:

// Force a palette, choose a filter and a zlib strategy, and keep a private chunk.
((PngDetails)image.Metadata.FormatDetails!).OtherChunks.Add(
    new PngChunk("prVt", "hello"u8.ToArray(), PngChunkPosition.AfterImageData));
image.Save("duck-palette.png", new PngWriterOptions
{
    ColorType = PngColorType.Palette,
    Filter = PngFilterMode.Paeth,
    CompressionStrategy = PngCompressionStrategy.Filtered,
});

image.Save("duck-gray.tga", new TgaWriterOptions { PixelFormat = TgaPixelFormat.Gray8, Rle = false });
using Raster back = Raster.Load("duck-gray.tga");
TgaDetails details = (TgaDetails)back.Metadata.FormatDetails!;
bool upsideDown = details.Origin is TgaOrigin.BottomLeft or TgaOrigin.BottomRight;
bool hasAlpha = details.AlphaType is TgaAlphaType.Straight or TgaAlphaType.Premultiplied;

Each format is described by a FormatInfo: its name, extensions, MIME types, and how to recognize it from its first bytes.

// Every built-in format, with its name, extensions and MIME types; Raster.Save picks one by extension.
foreach (FormatInfo format in new[] { PngFormat.Info, JpegFormat.Info, GifFormat.Info, BmpFormat.Info, TgaFormat.Info, QoiFormat.Info, PnmFormat.Info })
{
    Console.WriteLine($"{format.Name}: {string.Join(", ", format.Extensions)} ({string.Join(", ", format.MimeTypes)})");
}

// A SignatureMatcher decides from the first SignatureLength bytes whether a file is in the format.
SignatureMatcher isPng = PngFormat.Info.Matches;
bool png = isPng(File.ReadAllBytes("duck.png").AsSpan(0, PngFormat.Info.SignatureLength));
