ffmpeg command lines

egami-video ffmpeg and egami-video ffprobe take the command lines people already know, find in answers online or have in scripts, and run them with egami-video's own commands. They accept a documented subset of FFmpeg's options. Anything outside it stops with exit code 2 and names the option: nothing is ignored silently.

egami-video ffmpeg -i in.avi -c copy out.mkv
egami-video ffmpeg -ss 0.5 -i in.webm -t 1 -c copy cut.webm
egami-video ffmpeg -i in.mkv -vf fps=2 shot%03d.png
egami-video ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 in.mkv

--explain prints the native command a line stands for and stops, which is also the quickest way to learn the native syntax:

egami-video ffmpeg -i in.mkv -vf scale=640:-1,hflip -c:v mjpeg out.mkv --explain

prints egami-video run in.mkv resize 640 + flip horizontal -o out.mkv --codec mjpeg.

What a line becomes

ffmpeg line Native command
-i in -c copy out (any container change, -map, -an, -sn) remux
-ss, -to, -t with -c copy trim
several -i with -map 0 -map 1:a embed
-f concat -i list.txt -c copy concat with the files the list names
-f segment -segment_time or -segment_times segment
-itsoffset, or -r with -c copy timestamps
-metadata key=value, -map_metadata -1 metadata
an image output, %04d patterns, -vf fps=, -frames:v frames
image or Y4M input (-framerate, %04d, -f yuv4mpegpipe) encode
-vf with scale, crop, pad, transpose, hflip, vflip; -s; -c:v mjpeg or rawvideo run
-vf thumbnail, select='gt(scene,0.4)', tile=4x4 thumbnail, scenes, sheet
.gif, .apng or .webp output animate
-vn, -c:a flac, -ar, -ac, -sample_fmt audio
-f framemd5, -f framehash hash
-i distorted -i reference -lavfi psnr or ssim compare

ffmpeg encodes again by default; egami-video copies streams where ffmpeg would encode with a codec it does not have, and says so in a warning. An output that exists needs -y, as in ffmpeg.

The options

ffmpeg mode takes -i, -f, -y, -n, -ss, -to, -t, -itsoffset, -framerate, -safe, -map, -c, -codec, -c:v, -c:a, -c:s, -vcodec, -acodec, -scodec, -an, -vn, -sn, -dn, -r, -s, -frames:v, -vframes, -q:v, -qscale:v, -ar, -ac, -sample_fmt, -metadata, -map_metadata, -map_chapters, -vf, -filter:v, -lavfi and -filter_complex (psnr and ssim), -segment_time, -segment_times, -update, -progress, -stats, -nostats, -stats_period, -hide_banner, -loglevel, -v and -nostdin, with pipe: and %d patterns. The filters are scale, crop, pad, transpose, hflip, vflip, fps, thumbnail, select (scene) and tile. Codecs: copy, mjpeg and rawvideo for video, flac and the pcm_ codecs for audio.

ffprobe mode takes -i, -show_streams, -show_format, -show_packets, -show_frames, -show_chapters, -select_streams, -show_entries, -of (also -print_format, -output_format) with the json, csv, compact, default, flat and xml writers and their nokey, noprint_wrappers, print_section and item_sep options, -v, -loglevel, -hide_banner and -pretty. Its JSON is egami-video info --format ffprobe.

The tests run more than a hundred common ffmpeg and ffprobe lines: each either maps to the native command it should or stops naming its option. The subset was written from FFmpeg's published documentation only.
