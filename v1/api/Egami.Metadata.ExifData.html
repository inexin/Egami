A parsed EXIF block (a TIFF structure, CIPA DC-008): the tags of IFD0, the EXIF, GPS and interoperability sub-IFDs and IFD1 with its thumbnail, with typed getters for the common ones. An unedited block writes back byte for byte; after an edit it is laid out again, keeping the maker note at its old offset when it fits, since maker notes often hold offsets of their own.

Examples

using Raster photo = Raster.Load("sideways.jpg");
ExifData exif = photo.Metadata.Exif ?? new ExifData();

// Typed values go in with their EXIF type; fractions are exact numerator / denominator pairs.
exif.Set(ExifKey.ExposureTime, new ExifFraction(1, 250));
exif.Set(ExifKey.Artist, "A. Photographer");
if (exif.TryGet(ExifKey.ExposureTime, out ExifEntry? entry) && entry.Type == ExifType.Rational)
{
    Console.WriteLine($"Exposure {entry.AsFraction()} s = {entry.AsFraction().ToDouble()} s, in the {entry.Key.Ifd} IFD");
}

if (exif.Location is GeoPosition where)
{
    Console.WriteLine($"Taken at {where.Latitude:F5}, {where.Longitude:F5}");
}

Parse(ReadOnlySpan<byte>, SafetyLimits?)

Reads an EXIF block: a TIFF header and its IFDs, without the "Exif\0\0" prefix JPEG puts before it. Never throws: values past MaxMetadataBytes in all are dropped and the block is marked damaged.

public static ExifData Parse(ReadOnlySpan<byte> tiff, SafetyLimits? limits = null)

Parameters

tiff ReadOnlySpan<byte>

The block.

limits SafetyLimits

The limits whose MaxMetadataBytes caps the values copied. Defaults to Default.

Returns

ExifData

The parsed block; IsDamaged says whether it was all readable.

Examples

// EXIF from somewhere other than an image file (a database column, a sidecar), with a cap on the bytes of values read.
ExifData exif = ExifData.Parse(tiff.Span, SafetyLimits.Default with { MaxMetadataBytes = 64 * 1024 });
foreach (string warning in exif.Warnings)
{
    Console.WriteLine($"EXIF: {warning}");
}

ReadThumbnail(EgamiContext?)

Decodes the IFD1 thumbnail with Egami's JPEG reader under the context's safety limits. The pixels are as stored: apply the main image's orientation (Orientation) to show it upright.

public Raster<Rgb8>? ReadThumbnail(EgamiContext? context = null)

Parameters

context EgamiContext

The context whose limits apply. Defaults to Default.

Returns

Raster<Rgb8>

The thumbnail, or null when there is no JPEG thumbnail (uncompressed ones are kept as bytes). The caller must dispose it.

Examples

using Raster photo = Raster.Load("sideways.jpg");

// The thumbnail as stored, if the file has one; ReadThumbnail returns null otherwise.
using (Raster<Rgb8>? stored = photo.Metadata.Exif?.ReadThumbnail())
{
    Console.WriteLine(stored is null ? "No thumbnail" : $"Thumbnail {stored.Width} x {stored.Height}");
}

// Turning the image drops the thumbnail, which would show sideways; make a new one from the result.
photo.Apply(ops => ops.AutoOrient());
photo.Metadata.Exif?.SetThumbnail(photo);
photo.Save("upright.jpg");

Exceptions

CorruptDataException

The thumbnail is damaged.

LimitExceededException

The thumbnail is larger than the context's limits allow.

SetThumbnail(Raster, int, int)

Makes a thumbnail from raster: converted to sRGB, resized to fit maxSide (never enlarged), encoded as a baseline 4:2:0 JPEG and stored in IFD1 with compression 6. 160 pixels is the DCF thumbnail size. Operations drop a thumbnail that no longer matches the image; this rebuilds it in one line.

public void SetThumbnail(Raster raster, int maxSide = 160, int quality = 75)

Parameters

raster Raster

The image, usually the one this block belongs to after its operations. Its first frame is used.

maxSide int

The longest side, in pixels. Defaults to 160.

quality int

The JPEG quality, 1 to 100. Defaults to 75.

Examples

using Raster photo = Raster.Load("sideways.jpg");

// The thumbnail as stored, if the file has one; ReadThumbnail returns null otherwise.
using (Raster<Rgb8>? stored = photo.Metadata.Exif?.ReadThumbnail())
{
    Console.WriteLine(stored is null ? "No thumbnail" : $"Thumbnail {stored.Width} x {stored.Height}");
}

// Turning the image drops the thumbnail, which would show sideways; make a new one from the result.
photo.Apply(ops => ops.AutoOrient());
photo.Metadata.Exif?.SetThumbnail(photo);
photo.Save("upright.jpg");

Exceptions

ArgumentNullException

raster is null.

ArgumentOutOfRangeException

maxSide is below 1, or quality is outside 1 to 100.
