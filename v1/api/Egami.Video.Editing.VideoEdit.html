Class VideoEdit

Namespace
Egami.Video.Editing
Assembly
Egami.Video.dll

An edit: clips on a main Track with transitions between them, Layers drawn over it, and Effects on the result, all fitted to one Canvas. It is a description: Plan(MediaContext?) lays out the timeline and checks it, and Render(string, EditRenderOptions?, IProgress<MediaProgress>?, CancellationToken) decodes, composes and encodes it in one pass, holding only the frames in use. Save it as JSON with ToJson().

Examples

// Three clips of different sizes and rates, fitted to one 320x180 canvas at 25 fps, with fades at both ends.
VideoEdit edit = new(new EditCanvas(320, 180, new Rational(25, 1)) { Fit = ClipFit.Contain });
edit.Track
    .Add(Clip.Open("intro.avi").FadeIn(MediaTime.FromSeconds(0.5)))
    .Add(Clip.Open("talk.avi").Trim(MediaTime.FromSeconds(0.5), MediaTime.FromSeconds(1.5)))
    .Add(Clip.Open("outro.avi").FadeOut(MediaTime.FromSeconds(0.5)));
EditPlan plan = edit.Render("joined.mkv", new EditRenderOptions { Writer = new VideoWriterOptions { Codec = MotionJpegCodec.Instance, Quality = 80 } });
Console.WriteLine($"{plan.FrameCount} frames, {plan.Duration.Seconds} s");

Plan(MediaContext?)

Lays out the timeline: opens each clip to read its size, rate, length and audio, and works out where every clip, transition and layer falls, in whole frames. Problems that would make the render fail, such as a trim past a clip's end or a transition longer than a clip, throw; smaller ones become warnings.

ReadFrames(MediaContext?)

Renders the edit's pictures one at a time without encoding, for a preview or an app's own encoder: each comes as a new frame with its time, which the caller disposes. The sound is left out; Render(Stream, string, EditRenderOptions?, IProgress<MediaProgress>?, CancellationToken) writes both.

public IEnumerable<VideoFrame<Rgba8>> ReadFrames(MediaContext? context = null)

Parameters

context MediaContext

The context, or null for Default.

Returns

IEnumerable<VideoFrame<Rgba8>>

The frames, in order.

Examples

// The rendered pictures, for a preview: each is a new frame with its time, to dispose.
VideoEdit edit = new(new EditCanvas(320, 180, new Rational(25, 1)));
edit.Track.Add(Clip.Open("intro.avi")).Add(Clip.Open("outro.avi"), Transition.Dissolve(MediaTime.FromSeconds(0.5)));
foreach (VideoFrame<Rgba8> frame in edit.ReadFrames())
{
    using (frame)
    {
        count++; // show frame.Raster, or encode it
    }
}
