Namespace Egami.SystemDrawing

Classes

Bitmap

An image made of pixels, as System.Drawing's Bitmap: any of GDI+'s 14 pixel formats, with GetPixel, SetPixel, LockBits, Clone, MakeTransparent and the codecs. Pixels are kept in GDI+'s own memory layout and converted exactly as GDI+ converts them, so LockBits code and pixel values carry over.

BitmapSuffixInSameAssemblyAttribute

Marks an assembly whose resource bitmaps have a suffix in the same assembly, for the designer.

BitmapSuffixInSatelliteAssemblyAttribute

Marks an assembly whose resource bitmaps have a suffix in a satellite assembly, for the designer.

Brush

What fills shapes: the base of SolidBrush and the other brushes.

Brushes

Solid brushes of the named web colors, one per color and thread, as System.Drawing keeps them; their color can be changed, as in System.Drawing.

BufferedGraphics

An off-screen buffer to draw on and then copy to a graphics in one go, as WinForms double-buffering does.

BufferedGraphicsContext

Makes BufferedGraphics buffers.

BufferedGraphicsManager

The process's shared BufferedGraphicsContext.

Font

A family, size, style and unit for drawing and measuring text. A family that is not installed falls back to Microsoft Sans Serif (or its stand-in), with OriginalFontName keeping the name asked for; sizes convert at the target's resolution, 96 dpi for GetHeight() and SizeInPoints.

FontConverter

Converts fonts to and from strings such as "Arial, 10pt, style=Bold, Italic" for designers and serializers, and to constructor calls for code generation.

FontConverter.FontNameConverter

Converts family names, offering the installed families as the standard values.

FontConverter.FontUnitConverter

Converts font units, offering every GraphicsUnit but Display as the standard values.

FontFamily

A family of faces, such as Arial with its bold and italic faces, found among the installed fonts or a PrivateFontCollection. Where a Windows core font is missing (on Linux and macOS), a metric-compatible open font stands in under the requested name: Liberation Sans or Arimo for Arial, Liberation Serif or Tinos for Times New Roman, Liberation Mono or Cousine for Courier New, Carlito for Calibri.

Graphics

The way from a graphics to Egami's own canvas.

Icon

A Windows icon: an ICO file with images at several sizes, of which the icon shows the one nearest the size asked for (32 by 32 when none is), as System.Drawing chooses it. Save(Stream) writes the file it was loaded from.

IconConverter

Converts icons to and from bytes (the ICO file) for designers and serializers.

Image

The base of Bitmap and the metafile type: size, resolution, pixel format, palette, frames, metadata and saving, as in System.Drawing. Load one with FromFile(string) or FromStream(Stream).

ImageAnimator

Steps animated GIFs (and other images with timed frames) through their frames at their delays: a timer marks images due for their next frame and calls their handlers; UpdateFrames(Image?) then selects the frame.

ImageConverter

Converts images to and from bytes (the file they are saved as) for designers and serializers.

ImageFormatConverter

Converts image formats to and from their names, and lists the standard ones, for designers.

Pen

What draws lines and outlines: a brush and a width in world units, at least one device pixel, as in GDI+.

Pens

One-unit pens of the named web colors, which cannot be changed or disposed.

Region

An area made of rectangles and shapes combined with Union(Region), Intersect(Region), Xor(Region), Exclude(Region) and Complement(Region), as System.Drawing's Region: infinite when made with no arguments. Graphics clips to one.

SolidBrush

A brush of one color.

StringFormat

How DrawString and MeasureString lay text out: alignment along and across the lines, wrapping, trimming, clipping, tab stops, hotkey prefixes and the ranges MeasureCharacterRanges measures.

SystemBrushes

Solid brushes of the system colors, which cannot be changed or disposed.

SystemFonts

The fonts Windows uses for its own interface, with Windows 10 and 11's defaults: Segoe UI 9 for captions, menus, message boxes, icon titles and the status bar, Microsoft Sans Serif 8.25 for DefaultFont and Tahoma 8 for dialogs.

SystemIcons

Not supported: Windows' own icons. Every member throws.

SystemPens

One-unit pens of the system colors, which cannot be changed or disposed.

TextureBrush

A brush that tiles an image, from the world origin, through its transform.

ToolboxBitmapAttribute

Names a type's toolbox image: a bitmap or icon resource next to the type, as the Windows Forms designer looks it up.

Structs

CharacterRange

A range of characters: where it starts and how many characters it holds.

Interfaces

IDeviceContext

An object that hands out a Windows device context; Graphics is one, and Egami's always throws.

Enums

ContentAlignment

Where content sits in a rectangle.

CopyPixelOperation

The raster operation of CopyFromScreen(Point, Point, Size, CopyPixelOperation), which needs Windows and always throws.

FontStyle

A font's style: bold and italic choose or synthesize a face; underline and strikeout draw lines.

GraphicsUnit

The unit of a measure: the world's, the display's, pixels, points, inches, document units or millimeters.

RotateFlipType

A rotation clockwise and a flip for RotateFlip(RotateFlipType). Several names mean the same transformation and share a value, as in System.Drawing.

StockIconId

Windows' stock shell icons, which only Windows has; GetStockIcon(StockIconId, int) throws.

StockIconOptions

How Windows would draw a stock icon.

StringAlignment

Where text lines up in its layout rectangle, along a line or across the lines.

StringDigitSubstitute

How digits would be substituted for a language; Egami keeps the digits as written.

StringFormatFlags

How DrawString and MeasureString lay text out.

StringTrimming

How a line that does not fit is cut.

StringUnit

The unit of a string format's measurements.

Delegates

Graphics.DrawImageAbort

Called before a DrawImage draws; returning true stops it with an ExternalException, as in GDI+.

Graphics.EnumerateMetafileProc

Called for each record while a metafile is enumerated.

Image.GetThumbnailImageAbort

Called when GetThumbnailImage(int, int, GetThumbnailImageAbort?, nint) may stop early; GDI+ never calls it.
