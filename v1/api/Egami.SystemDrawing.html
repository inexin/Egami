Namespace Egami.SystemDrawing

Classes

Bitmap

An image made of pixels, as System.Drawing's Bitmap: any of GDI+'s 14 pixel formats, with GetPixel, SetPixel, LockBits, Clone, MakeTransparent and the codecs. Pixels are kept in GDI+'s own memory layout and converted exactly as GDI+ converts them, so LockBits code and pixel values carry over.

Brush

What fills shapes: the base of SolidBrush and the other brushes.

Graphics

Draws on a bitmap, as System.Drawing's Graphics: shapes with pens and brushes, images, clipping, transforms and the page unit, with GDI+'s defaults: aliased shapes (None), pixel centers on whole coordinates, bilinear image sampling without prefiltering, transforms prepended. Get one with FromImage(Image).

Icon

A Windows icon: an ICO file with images at several sizes, of which the icon shows the one nearest the size asked for (32 by 32 when none is), as System.Drawing chooses it. Save(Stream) writes the file it was loaded from.

Image

The base of Bitmap and the metafile type: size, resolution, pixel format, palette, frames, metadata and saving, as in System.Drawing. Load one with FromFile(string) or FromStream(Stream).

Pen

What draws lines and outlines: a brush and a width in world units, at least one device pixel, as in GDI+.

Region

An area made of rectangles and shapes combined with Union(Region), Intersect(Region), Xor(Region), Exclude(Region) and Complement(Region), as System.Drawing's Region: infinite when made with no arguments. Graphics clips to one.

SolidBrush

A brush of one color.

RotateFlipType

A rotation clockwise and a flip for RotateFlip(RotateFlipType). Several names mean the same transformation and share a value, as in System.Drawing.
