Struct MediaTime

Namespace
Egami.Video
Assembly
Egami.Video.dll

A point in time or a duration in a media stream: a whole number of ticks of a Rational time base. Exact for every container: AVI counts frames at the frame rate's reciprocal (for example 1001/30000 s), Matroska counts its timestamp scale in nanoseconds. TimeSpan rounds to 100 ns and drifts over long files; this type does not.

Examples

MediaTime frame = new(2_589_410, new Rational(1001, 30000)); // frame 2,589,410 of a 29.97 fps clip
TimeSpan at = frame.ToTimeSpan(); // 23:59:59.966...
MediaTime ns = frame.Rescale(Rational.Nanosecond); // the same instant in nanoseconds, rounded to the nearest
