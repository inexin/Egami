Class MipChain

Namespace
Egami

A chain of ever-halved copies of an image, for making many smaller sizes fast: each resize starts from the smallest level that is still at least twice the target, so a gallery of thumbnail sizes reads each source pixel about once instead of once per size. Level 0 is the source itself; each next level halves the size, rounding up, by averaging 2 × 2 blocks of premultiplied pixels.

Examples

// A responsive image set: one chain, then each width from the smallest level at least twice its size.
using MipChain chain = MipChain.Build(photo);
foreach (int width in (int[])[320, 240, 160, 120, 80])
{
    using Raster thumbnail = chain.Fit(width, width, ResampleFilter.Lanczos2);
    thumbnail.Save($"egret-{width}.png");
}

Remarks

The levels together take a third more memory than the source. Every frame of an animation gets its levels. The chain does not copy or dispose the source, which must outlive it; disposing the chain frees the levels it made.
