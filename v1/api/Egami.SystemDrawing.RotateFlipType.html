Enum RotateFlipType

Namespace
Egami.SystemDrawing
Assembly
Egami.SystemDrawing.dll

A rotation clockwise and a flip for RotateFlip(RotateFlipType). Several names mean the same transformation and share a value, as in System.Drawing.

public enum RotateFlipType

Fields

Rotate180FlipNone = 2

Rotate 180 degrees.

Rotate180FlipX = 6

Rotate 180 degrees, then flip left to right.

Rotate180FlipXY = 0

Rotate 180 degrees, then flip both ways; the same as RotateNoneFlipNone.

Rotate180FlipY = 4

Rotate 180 degrees, then flip top to bottom; the same as RotateNoneFlipX.

Rotate270FlipNone = 3

Rotate 270 degrees.

Rotate270FlipX = 7

Rotate 270 degrees, then flip left to right.

Rotate270FlipXY = 1

Rotate 270 degrees, then flip both ways; the same as Rotate90FlipNone.

Rotate270FlipY = 5

Rotate 270 degrees, then flip top to bottom; the same as Rotate90FlipX.

Rotate90FlipNone = 1

Rotate 90 degrees.

Rotate90FlipX = 5

Rotate 90 degrees, then flip left to right.

Rotate90FlipXY = 3

Rotate 90 degrees, then flip both ways; the same as Rotate270FlipNone.

Rotate90FlipY = 7

Rotate 90 degrees, then flip top to bottom; the same as Rotate270FlipX.

RotateNoneFlipNone = 0

No change.

RotateNoneFlipX = 4

Flip left to right.

RotateNoneFlipXY = 2

Flip both ways; the same as Rotate180FlipNone.

RotateNoneFlipY = 6

Flip top to bottom; the same as Rotate180FlipX.
