Examples

// EBU R 128 loudness: integrated, range and true peak at the end, momentary and short-term while the audio plays.
LoudnessMeter meter = new(new LoudnessOptions { KeepSeries = true });
MediaAnalysis.Run("shots.mkv", new MediaAnalysisOptions { Scenes = null, AudioDetectors = [meter] });
LoudnessReport loudness = meter.Report();
Console.WriteLine($"I {loudness.Integrated:0.0} LUFS, LRA {loudness.Range:0.0} LU, true peak {loudness.TruePeak:0.0} dBTP");
foreach (LoudnessValue value in meter.ShortTermSeries)
{
    Console.WriteLine($"{value.Time.ToTimeSpan()}: {value.Loudness:0.0} LUFS");
}

Parameters

Integrated double

The gated integrated loudness, as ebur128's I.

Range double

The loudness range, as ebur128's LRA: RangeHigh minus RangeLow.

RangeLow double

The 10th percentile of the gated short-term loudness, as ebur128's LRA low.

RangeHigh double

The 95th percentile of the gated short-term loudness, as ebur128's LRA high.

IntegratedThreshold double

The relative gate the integrated loudness used, 10 LU below the absolutely gated loudness.

RangeThreshold double

The relative gate the loudness range used, 20 LU below the absolutely gated short-term loudness.

TruePeak double

The highest true peak over all channels in dBTP.

SamplePeak double

The highest sample level over all channels in dBFS.

MaxMomentary double

The highest momentary loudness.

MaxShortTerm double

The highest short-term loudness.

Duration MediaTime

How much audio was measured.

ChannelTruePeaks IReadOnlyList<double>

Each channel's true peak in dBTP, in channel order.
