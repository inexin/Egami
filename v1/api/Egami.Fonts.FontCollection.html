A set of faces grouped into families: the caller's own, or System for the fonts installed on the machine. Finds families by name and faces by style with the CSS Fonts Level 4 matching steps.

Examples

// Installed fonts, found without native calls and indexed on first use; a style is matched by the CSS rules.
FontMatch? match = FontCollection.System.Match(GenericFamily.SansSerif, FontStyle.Bold);

// Your own fonts work the same way; System is read-only, so add the installed fonts to your collection to have both.
var fonts = new FontCollection();
fonts.AddFile(FontFile);
fonts.AddSystemFonts();
FontMatch noto = fonts.Match("Noto Sans", FontStyle.BoldItalic)!.Value;
Font font = noto.ToFont(16);

Remarks

Faces group under their typographic family (name ID 16, else 1). A name lookup tries, in order, the typographic family, the legacy family (ID 1), the full name (ID 4) and the PostScript name (ID 6), comparing case-insensitively in every language the fonts hold. A name not found returns null or false: nothing is swapped in silently.

Files added by path are indexed from their name and OS/2 tables only and loaded when a face is matched. Adding is thread-safe; lookups see the faces added before they started.

System

Gets the fonts installed on this machine, found without native calls by scanning the platform's font directories (Windows: the Windows and per-user Fonts folders; macOS: the System, Library and user Fonts folders; Linux: the fontconfig dir entries and the usual share/fonts folders). Indexed on first use; Refresh() rescans. It is read-only: to match your own fonts beside the installed ones, call AddSystemFonts() on a collection of your own.
