Reads and writes hOCR, the HTML format that Tesseract, OCRopus, kraken and others write: pages (ocr_page), lines (ocr_line and its kin) and words (ocrx_word) with their bbox, x_wconf, textangle and lang.

Examples

// Read hOCR from Tesseract or any other engine, under limits for files you did not make.
using FileStream file = File.OpenRead("page.hocr");
IReadOnlyList<OcrResult> pages = Hocr.Read(file, new OcrReadOptions { MaxWords = 100_000 });
Console.WriteLine($"{pages.Count} page, {pages[0].Words.Count()} words: {pages[0].Lines[0].Text}");

// Write results back as hOCR (or Alto.Write for ALTO).
using FileStream copy = File.Create("copy.hocr");
Hocr.Write(copy, pages);

Remarks

The reader takes HTML as browsers do, not only well-formed XHTML: unknown tags, missing end tags and entities are fine, and no DTD or other file is ever fetched. Lines turned by textangle 90, 180 or 270 give turned word quads. Words outside a line each get a line of their own.
