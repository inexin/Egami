Class Gs1ElementString

Namespace
Egami.Barcodes

One GS1 element string: an Application Identifier and its data field, checked against the GS1 General Specifications (characters, lengths, check digits, dates and times). Parse(string) makes a list of them from text such as (01)09501101530003(17)261231, and the GS1 symbols encode that list.

Examples

// Each element string is checked: the AI, the length, the GTIN's check digit, the date.
IReadOnlyList<Gs1ElementString> elements = Gs1.Parse("(01)09501101530003(17)261231(10)AB12");
Barcode label = Barcode.Gs1Code128(elements);

// Mistakes say what is wrong.
if (!Gs1.TryParse("(01)09501101530004", out _))
{
    Console.WriteLine("(01) has a wrong check digit");
}
