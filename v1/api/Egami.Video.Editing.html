Namespace Egami.Video.Editing

Classes

CameraMotion

How the camera moved from one frame to the next, as Analyze(string, StabilizerOptions?, IProgress<MediaProgress>?, CancellationToken) measures it: a shift, a rotation and a scale per frame, in the clip's own pixels. It is pass 1 of stabilization; pass 2, Stabilize(CameraMotion, StabilizeOptions?), smooths the path and warps the frames. Save it as JSON to stabilize again with other settings without measuring again.

ChromaKey

A chroma key for Key(ChromaKey): pixels near Color in the CbCr plane become transparent with Egami's ChromaKey(Rgba8, float, float), then Despill(DespillColor, float, float) takes the screen's colour out of the edges and see-through pixels that are left.

Clip

A piece of video, with its audio, as it goes into a VideoEdit: a file or stream, or a Stack of clips. The methods return a changed copy, so they chain: Clip.Open("a.mp4").Trim(start, end).FadeIn(duration). Nothing is decoded until the edit renders.

ClipStabilization

A clip's stabilization, set by Stabilize(CameraMotion, StabilizeOptions?): the measured camera motion and how it is smoothed.

EditCanvas

The output of a VideoEdit: picture size, frame rate, how clips are fitted, the background, and the audio format every clip's audio is resampled and remixed to. When an edit has no canvas, it takes the first clip's size and frame rate.

EditEffect

Egami operations or an app's own effect on the frames of a VideoEdit, a Clip or a Layer, optionally only inside a time window (Between(MediaTime, MediaTime?)). Effects keep the frame size.

EditPlan

An edit's timeline worked out before rendering by Plan(MediaContext?): the canvas, where every clip and layer falls in whole frames, the length, and warnings about things it fixed up, such as a trim past a clip's end.

EditRenderOptions

How Render(string, EditRenderOptions?, IProgress<MediaProgress>?, CancellationToken) encodes.

EditTrack

The main track of a VideoEdit: clips that play one after another. A Transition between two clips overlaps them by its length; without one, the next clip starts on the frame after the last one ends.

Layer

A clip drawn over the main track of a VideoEdit inside a time window: a logo, a picture-in-picture, a lower third or a keyed presenter. It has a place, an opacity, a blend mode, fades, an optional ChromaKey and keyframed motion. Layers draw in order, the last on top. The methods return a changed copy, so they chain.

PanZoomPath

A pan and zoom for PanZoom(RectangleF, RectangleF, Easing): the part of the picture shown at the start and at the end, as fractions of it.

PlannedClip

Where one clip of the main track falls in a planned edit, in whole output frames.

PlannedLayer

Where one layer falls in a planned edit, in whole output frames.

Slideshow

Builds a VideoEdit that shows images one after another, with transitions and an optional pan and zoom.

SlideshowOptions

How Create(IEnumerable<string>, SlideshowOptions?) builds a slideshow.

StabilizeOptions

How Stabilize(CameraMotion, StabilizeOptions?) smooths the camera path and treats the edges.

Stabilizer

Pass 1 of two-pass stabilization: measures the camera's motion over a clip (CameraMotion). Pass 2 is Stabilize(CameraMotion, StabilizeOptions?), which smooths the camera path with a Gaussian and warps each frame onto it.

StabilizerOptions

How Analyze(string, StabilizerOptions?, IProgress<MediaProgress>?, CancellationToken) measures.

Stack

Builds one clip out of several shown at once: side by side, one above the other, or in a grid. A stack is an ordinary Clip, so it can be trimmed, faded or joined with a transition.

StackOptions

How a Stack is drawn and how long it lasts.

TrackItem

One clip on an EditTrack and the transition into it from the clip before.

Transition

How one clip on an EditTrack changes into the next. The two clips overlap by Duration, so the edit gets shorter by it; their audio crossfades over the same time, equal power by default. Make one with the static methods, such as Dissolve(MediaTime) or Wipe(TransitionDirection, MediaTime).

VideoEdit

An edit: clips on a main Track with transitions between them, Layers drawn over it, and Effects on the result, all fitted to one Canvas. It is a description: Plan(MediaContext?) lays out the timeline and checks it, and Render(string, EditRenderOptions?, IProgress<MediaProgress>?, CancellationToken) decodes, composes and encodes it in one pass, holding only the frames in use. Save it as JSON with ToJson().

FrameEffectContext

FrameMotion

The camera's motion into one frame from the one before: about the frame's centre, in its pixels.

Interfaces

IFrameEffect

An app's own effect for Of(IFrameEffect, string?), which knows each frame's time. It changes the frame in place. The same instance runs on every frame, so keep it stateless.

IFrameSource

An app's own frames for FromSource(IFrameSource), such as titles drawn with Egami.Drawing or generated graphics. The renderer asks for the frames in time order, once per output frame.

ITransition

An app's own picture transition for Custom(ITransition, MediaTime): it draws one frame of the change from one clip to the next. The two frames and the target have the canvas size. The same instance draws every frame, possibly on several threads, so keep it stateless.
