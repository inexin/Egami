Examples

// A frame from each scene, read by seeking: the first, the middle or the last.
MediaAnalysisResult result = MediaAnalysis.Run("shots.mkv");
using VideoReader reader = VideoReader.Open("shots.mkv");
foreach (SceneFrame scene in SceneFrames.Read(reader, result.Scenes, ScenePosition.Middle))
{
    using (scene.Frame)
    using (Raster<Rgba8> picture = scene.Frame.ToRaster<Rgba8>())
    {
        picture.Save($"scene-{scene.Scene.Number}.png");
    }
}

Methods

Read(VideoReader, IEnumerable<Scene>, ScenePosition)

Reads one frame of each scene by seeking: its first frame, the one shown halfway through, or its last. Seeking costs up to a keyframe interval of decoding per scene, so for many short scenes on a file with sparse keyframes a single pass that keeps frames while SceneDetector runs is faster.

public static IEnumerable<SceneFrame> Read(VideoReader reader, IEnumerable<Scene> scenes, ScenePosition position = ScenePosition.First)

Parameters

reader VideoReader

A reader on the file the scenes came from. It must be seekable; it is left at the last frame read.

scenes IEnumerable<Scene>

The scenes.

Which frame of each scene to read.

Returns
