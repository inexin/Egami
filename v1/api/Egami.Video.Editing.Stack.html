Class Stack

Namespace
Egami.Video.Editing
Assembly
Egami.Video.dll

Builds one clip out of several shown at once: side by side, one above the other, or in a grid. A stack is an ordinary Clip, so it can be trimmed, faded or joined with a transition.

[SuppressMessage("Naming", "CA1711:Identifiers should not have incorrect suffix", Justification = "A stack of clips, the V9 Design's name (Q8), not a stack collection.")]
public static class Stack

Examples

// Two clips side by side with a 4-pixel gap, each scaled to the first one's height; a stack is a clip like any other.
VideoEdit edit = new();
edit.Track.Add(Stack.Horizontal([Clip.Open("intro.avi"), Clip.Open("talk.avi")], new StackOptions { Gap = 4, MixAudio = true }));
EditPlan plan = edit.Render("side-by-side.mkv");
Console.WriteLine($"{plan.Canvas.Width}x{plan.Canvas.Height}");
