Diagnostics

Gets the handler that receives Egami's warnings and notable decisions, or null (the default) for none, which costs nothing. It runs inline, possibly on several decode threads at once, so it must be quick and thread-safe. An exception it throws fails the call, which turns warnings into errors. Warnings a load raises arrive in Warnings order as the call ends; Info and Debug events arrive as they happen. One id is delivered at most 10 times per call, then once more as a count of the rest.

public Action<EgamiDiagnostic>? Diagnostics { get; init; }

Property Value

Action<EgamiDiagnostic>

Examples

// With Microsoft.Extensions.Logging: one line at startup sends every call's warnings to the app's log, with the id as
// a property to filter and count on. Egami itself has no logging dependency.
EgamiContext.SetDefault(new EgamiContext
{
    Diagnostics = d => logger.Log(d.Level.ToLogLevel(), "{Source} {Id} at {Offset}: {Message}", d.Source, d.Id, d.Offset, d.Message),
});

StartDiagnostics()

Starts reporting for one call outside Egami's own loads and saves, such as a video decode or a plug-in's own entry point, with the same DiagnosticLevel filter and per-id cap. Dispose it when the call ends.

public DiagnosticReporter StartDiagnostics()

Returns

DiagnosticReporter

A reporter for the call; a shared one that does nothing when Diagnostics is null.

Examples

// A decoder outside Egami (a video demuxer, a format plug-in's own entry point) reports through the same handler, with the
// same level filter and the same cap of 10 per id per call. Dispose the reporter when the call ends.
using (DiagnosticReporter diagnostics = context.StartDiagnostics())
{
    if (diagnostics.IsEnabled(DiagnosticLevel.Warning))
    {
        diagnostics.Report(DiagnosticLevel.Warning, "Avi.IndexRebuilt", "The index was missing; it was rebuilt from the frames.", offset: 4096);
    }

    diagnostics.Report(DiagnosticLevel.Info, "Mjpeg.DhtInserted", "Frames have no Huffman tables; the standard ones were used.");
}
