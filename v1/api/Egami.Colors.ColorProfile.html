What a raster's numbers mean: the color model, the primaries and white point, and the transfer function. Immutable; the built-ins cover the common encodings, and Create(ColorPrimaries, TransferFunction, string?) makes any other RGB encoding.

Examples

// A ColorProfile says what a raster's numbers mean. The built-ins cover the common encodings...
ColorProfile web = ColorProfile.Srgb;
ColorProfile wide = ColorProfile.DisplayP3;
ColorProfile hdr = ColorProfile.Rec2100Pq;

// ...and Create makes any other RGB encoding from primaries and a transfer function.
ColorProfile camera = ColorProfile.Create(ColorPrimaries.AdobeRgb, TransferFunction.Gamma(2.2), "Camera RGB");
Console.WriteLine($"{camera.Name}: {camera.Model}, HDR {camera.IsHdr}, same as Adobe RGB: {camera.IsEquivalentTo(ColorProfile.AdobeRgb)}");

Fogra39

Gets FOGRA39L: offset printing on coated paper (ISO 12647-2, paper types 1 and 2), Europe's usual press condition, built for a 300% total ink limit. The profile is colord's, built by ArgyllCMS from Fogra's measurements, as the CTAN colorprofiles package ships it (ICC version 2.2, free of known copyright restrictions); ToIcc() returns its bytes unchanged. It is read on first use. CMYK files without a profile still convert by the plain formula, not through this one.

// The inks a press would use for a color, and the color it would print, through the press's CMYK profile: here the

FromIcc(IccData)

Returns the encoding an ICC profile describes. A matrix-shaper profile gets its primaries (un-adapted from D50 by its chad tag or its white point) and its curve, so IsEquivalentTo(ColorProfile) recognizes sRGB, Display P3 and the other built-ins written as ICC; a version 4.4 cicp tag naming a known encoding wins over the rest, as it does for HDR profiles. Profiles that convert through tables, and CMYK, keep only the model and white.

ToIcc()

Returns an ICC profile for this encoding: the bytes it was read from, or a small version 4 profile written for it (4.3 with parametric curves for SDR encodings, 4.4 with a cicp tag for PQ and HLG), which Little CMS, browsers and image tools read.

public byte[] ToIcc()

Returns

byte[]

A new array holding the profile.

Examples

// Any RGB or gray encoding as a small ICC profile, for files and other software.
byte[] p3 = ColorProfile.DisplayP3.ToIcc();
bool same = ColorProfile.FromIcc(p3).IsEquivalentTo(ColorProfile.DisplayP3);

ToIccV2()

Returns a version 2 ICC profile for this encoding, for readers that do not read version 4 ones (older image editors, viewers and print drivers): the bytes it was read from when they are a version 2 profile, else a small version 2.4 matrix-shaper (or gray curve) profile written for it, with curv curves (a gamma or a 1024-entry table) and its own white as the media white point. PQ and HLG get the rolled-off tables ToIcc() writes, without the cicp tag version 2 lacks.

public byte[] ToIccV2()
