Options for writing DICOM: the transfer syntax, the quality of lossy ones, and the attributes of a Secondary Capture image. Pass them to Save(Stream, FormatInfo, WriterOptions?) with Info, or to Save(Stream, DicomWriterOptions?, EgamiContext?).

Examples

// Any raster saves as a Secondary Capture image: gray as MONOCHROME2, colour as RGB, 8 or 16 bits.
using (FileStream output = File.Create("capture.dcm"))
{
    raster.Save(output, DicomFormat.Info, new DicomWriterOptions
    {
        TransferSyntax = DicomTransferSyntax.JpegLsLossless,
        Attributes = new Dictionary<string, string>
        {
            ["PatientName"] = "Doe^Jane",
            ["PatientID"] = "12345",
            ["StudyInstanceUID"] = DicomUid.Generate(),
        },
    });
}

Properties

Attributes

Gets attributes to give a Secondary Capture image written from a raster, by PS3.6 keyword, such as PatientName, PatientID or StudyInstanceUID, each value as text (several values separated by </code>). The VR comes from PS3.6; text is written in UTF-8 (Specific Character Set ISO_IR 192) when it is not ASCII. Ignored by Save(Stream, DicomWriterOptions?, EgamiContext?), which keeps the file's own.

Gets the transfer syntax to write. Native: ExplicitVRLittleEndian (the default), ImplicitVRLittleEndian and DeflatedExplicitVRLittleEndian; lossless: RleLossless, JpegLossless, JpegLsLossless and JpegXlLossless; lossy: JpegBaseline, JpegExtended, JpegLsNearLossless and JpegXl.
