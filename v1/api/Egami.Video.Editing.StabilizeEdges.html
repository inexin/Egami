Enum StabilizeEdges

Namespace
Egami.Video.Editing
Assembly
Egami.Video.dll

What Stabilize(CameraMotion, StabilizeOptions?) does with the edges a correction uncovers.

public enum StabilizeEdges

Fields

Black = 1

Leaves the frame's size and fills uncovered edges with black.

Blur = 2

Leaves the frame's size and fills uncovered edges with a blurred copy of the frame.

Zoom = 0

Zooms in the least amount that hides every uncovered edge over the whole clip, at most 1.5 times. The default.

Examples

// Two passes: measure the camera's motion, then render the clip warped onto a smoothed path, zoomed to hide the edges.
CameraMotion motion = Stabilizer.Analyze("talk.avi");
File.WriteAllText("talk.motion.json", motion.ToJson());
VideoEdit edit = new();
edit.Track.Add(Clip.Open("talk.avi").Stabilize(motion, new StabilizeOptions { Smoothing = 20, Edges = StabilizeEdges.Zoom }));
edit.Render("steady.mkv");
