Enum BevelMaterial

Namespace
Egami.Drawing
Assembly
Egami.Drawing.dll

How a bevel's surface takes the light: how much it scatters (diffuse), how much it mirrors (specular) and how sharply. The names are DrawingML's preset materials (prstMaterial); the values are Egami's own.

public enum BevelMaterial

Fields

Clear = 8

A faint diffuse light and a sharp shine, as glass.

DarkEdge = 5

Matte, darkened toward the outer edge.

Flat = 7

No light or shade at all: the bevel draws nothing.

Matte = 0

Diffuse only, no shine.

Metal = 3

Strong shine and deep shadows, little diffuse light.

Plastic = 2

Diffuse with a small sharp shine.

Powder = 9

Soft diffuse light with low contrast.

SoftEdge = 6

Matte, with the light and shade fading out toward the outer edge.

SoftMetal = 4

Metal with a broader, softer shine.

TranslucentPowder = 10

Powder at about half strength.

WarmMatte = 1

Diffuse only, with highlights a little warm. DrawingML's default.

Examples

// A raised button: fill the shape, then draw a bevel over it, lit from the top left.
using Raster<Rgba8> button = Raster.Create(220, 90, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = button.CreateCanvas())
{
    Path shape = Path.RoundRect(new RoundRect(new RectF(10, 10, 200, 70), 16));
    canvas.FillPath(shape, new Rgba8(40, 110, 200, 255));
    canvas.DrawBevel(shape, new Bevel
    {
        Profile = BevelProfile.Circle,
        Width = 10,
        Height = 8,
        Material = BevelMaterial.Plastic,
        Light = BevelLight.FromDirection(LightDirection.TopLeft),
    });
}
