Class SubtitleDocument

Namespace
Egami.Video.Subtitles
Assembly

A subtitle file in memory: its cues, and the styles, regions and header its format carries. Loads SRT, WebVTT, ASS and SSA into one model, saves any of SRT, WebVTT and ASS, and shifts, scales, syncs and clips the timing. A document saved in the format it was read from, unchanged, gives back the same bytes; changed cues are written in the format's canonical form, and what a target format cannot hold is reported once per kind as Subtitle.Dropped.

FromPackets(TrackInfo, IEnumerable<EncodedPacket>, SubtitleReaderOptions?, MediaContext?)

Reads a subtitle track from its packets; packets of other tracks are skipped.

public static SubtitleDocument FromPackets(TrackInfo track, IEnumerable<EncodedPacket> packets, SubtitleReaderOptions? options = null, MediaContext? context = null)

Parameters

track TrackInfo

The subtitle track.

packets IEnumerable<EncodedPacket>

The packets, in file order.

options SubtitleReaderOptions

The strictness, or null for the defaults.

context MediaContext

Where diagnostics go, or null for Default.

Returns

SubtitleDocument

The document.

Examples

// Read a subtitle track out of a container: mov_text, WebVTT, SRT and ASS tracks become a document.
using (IDemuxer movie = MediaFile.OpenDemuxer("subtitled.mp4"))
{
    TrackInfo track = movie.Tracks.First(t => SubtitleDocument.IsTextCodec(t.CodecId));
    SubtitleDocument.ReadTrack(movie, track).Save("subtitled.srt");
}

// Add one to a copy of a video: the writer makes the track and its packets, merged in time order with the video's.
using IDemuxer input = MediaFile.OpenDemuxer("movie.webm");
SubtitleTrackWriter subtitles = new(captions, input.Tracks.Count + 1, SubtitleTrackWriter.CodecIdFor("webm", captions.Format));
using (IMuxer output = MediaFile.CreateMuxer("captioned.webm", [.. input.Tracks, subtitles.Track with { Language = "eng" }]))
{
    int next = 0;
    while (input.ReadPacket() is { } packet)
    {
        using (packet)
        {
            for (; next < subtitles.Packets.Count && subtitles.Packets[next].Timestamp <= packet.Timestamp; next++)
            {
                output.WritePacket(subtitles.Packets[next]);
            }

            output.WritePacket(packet);
        }
    }

    for (; next < subtitles.Packets.Count; next++)
    {
        output.WritePacket(subtitles.Packets[next]);
    }
}

Exceptions

NotSupportedException

The track's codec is not a text subtitle codec.

Load(Stream, SubtitleReaderOptions?, MediaContext?)

Loads a subtitle file from a stream, read to its end. The format comes from the content.

public static SubtitleDocument Load(Stream stream, SubtitleReaderOptions? options = null, MediaContext? context = null)

Parameters

stream Stream

The stream.

The encoding, strictness and format, or null for the defaults.

context MediaContext

Where diagnostics go, or null for Default.

Returns

SubtitleDocument

The document.

Examples

// Files without a byte order mark that are not UTF-8 are read with the encoding you name, or else as Windows-1252, with a
// Subtitle.Encoding warning. Output is always UTF-8. Strict turns every repaired line into an exception.
MediaContext context = new() { Egami = EgamiContext.Default with { Diagnostics = d => log.Add($"{d.Id}: {d.Message}") } };
SubtitleDocument old = SubtitleDocument.Load("old.srt", context: context);
SubtitleDocument latin1 = SubtitleDocument.Load("old.srt", new SubtitleReaderOptions { Encoding = Encoding.Latin1 });
Console.WriteLine($"{old.Cues[0].PlainText} / {latin1.Cues[0].PlainText}");

try
{
    SubtitleDocument.Parse("1\n00:00:01.000 --> 00:00:02.000\nHi\n", options: new SubtitleReaderOptions { Strict = true });
}
catch (CorruptDataException e)
{
    Console.WriteLine(e.Message);
}

Exceptions

UnsupportedFormatException

The data is not SRT, WebVTT, ASS or SSA.

CorruptDataException

The data is broken past repair, or is malformed and Strict is set.

Parse(string, SubtitleFormat?, SubtitleReaderOptions?, MediaContext?)

Reads subtitles from text already decoded.

public static SubtitleDocument Parse(string text, SubtitleFormat? format = null, SubtitleReaderOptions? options = null, MediaContext? context = null)

Parameters

text string

The text.

format SubtitleFormat?

The format, or null to tell it from the text.

options SubtitleReaderOptions

The strictness, or null for the defaults. The encoding is not used.

context MediaContext

Where diagnostics go, or null for Default.

Returns

SubtitleDocument

The document.

Examples

// ASS keeps its styles, layers, margins and every override tag: the ones Egami understands become fields, the rest stay
// as written in OtherTags, so a script edited here and saved again still animates.
SubtitleDocument sign = SubtitleDocument.Parse(script);
SubtitleCue cue = sign.Cues[0];
Console.WriteLine($"{cue.Style} at {cue.Position}, {sign.Styles[0].FontSize} pt");
foreach (SubtitleSpan span in cue.Spans)
{
    Console.WriteLine($"'{span.Text}' color {span.Color} tags {span.OtherTags}");
}

cue.End += MediaTime.FromSeconds(1);
string saved = sign.ToText();

Sync(MediaTime, MediaTime, MediaTime, MediaTime)

Retimes every cue by two sync points: what is at from1 moves to to1, what is at from2 to to2, and everything else in proportion. Fixes both an offset and a speed difference at once; each time is computed from its original, rounded to the nanosecond, so nothing drifts.

public void Sync(MediaTime from1, MediaTime to1, MediaTime from2, MediaTime to2)

Parameters

from1 MediaTime

A time in the subtitles, such as the first line's start.

to1 MediaTime

Where it should be in the video.

from2 MediaTime

A second time in the subtitles, far from the first, such as the last line's start.

to2 MediaTime

Where it should be in the video.

Exceptions

ArgumentException

from1 and from2 are the same time.

ToText(SubtitleFormat?, SubtitleWriterOptions?, MediaContext?)

Returns the document as text in a format, without a byte order mark.

public string ToText(SubtitleFormat? format = null, SubtitleWriterOptions? options = null, MediaContext? context = null)

Parameters

format SubtitleFormat?

The format to write, or null for Format.

options SubtitleWriterOptions

The line ending, or null for the default.

context MediaContext

Where Subtitle.Dropped diagnostics go, or null for Default.

Returns

string

The text.

Examples

// Cues hold spans of styled text. Times are exact: shifting by a frame or scaling 23.976 to 25 fps keeps the fraction.
subtitles.Cues.Add(new SubtitleCue(MediaTime.FromSeconds(7), MediaTime.FromSeconds(9),
[
    new SubtitleSpan("Out "),
    new SubtitleSpan("where?") { Bold = true, Color = new Rgba8(255, 255, 0, 255) },
]));

subtitles.Shift(MediaTime.FromSeconds(-0.5));
subtitles.Scale(new Rational(24000, 25025));
subtitles.Clip(MediaTime.Zero, MediaTime.FromSeconds(8));
subtitles.FixOverlaps();
string srt = subtitles.ToText(SubtitleFormat.Srt);

Exceptions

NotSupportedException

The format is Ssa, which is read only.
