Examples

// Each pixel type is written at its own depth: 16-bit color stays 16-bit. Deflate with the predictor is the default.
photo.Save("duck.tif");

// Tiles, LZW, BigTIFF, or the smallest exact form the pixels allow.
photo.Save("tiled.tif", new TiffWriterOptions { Compression = TiffCompression.Lzw, TileSize = 256, Layout = TiffLayout.Auto });
photo.Save("small.tif", new TiffWriterOptions { Reduce = true });

// JPEG inside TIFF: RGB is written as YCbCr 4:2:0 with the tables shared by every strip.
photo.Save("photo.tif", new TiffWriterOptions { Compression = TiffCompression.Jpeg, Quality = 90 });

Remarks

Re-saving a raster loaded from TIFF keeps the source's compression, predictor, tiling and byte order for every option left at null, so a round trip writes the same kind of file. A JPEG or WebP source compression is kept only while the raster is unchanged since loading; otherwise it falls back to Deflate, to avoid a second lossy pass.

Reduce

Gets whether to write the smallest exact form the pixels allow: 1 bit when every pixel is black or white, gray when red, green and blue are equal, a palette of up to 256 colors for opaque images, 8 bits when every 16-bit sample is a multiple of 257.
