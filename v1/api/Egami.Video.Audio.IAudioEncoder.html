Interface IAudioEncoder

Namespace
Egami.Video.Audio
Assembly
Egami.Video.dll

Turns audio frames into packets, the mirror of IAudioDecoder. Frames may have any length and any sample format; the encoder converts them to its own and cuts packets of FrameSize samples.

public interface IAudioEncoder : IDisposable
Inherited Members
IDisposable.Dispose()

Examples

// An encoder takes frames of any length and format and cuts packets of its frame size.
using IAudioEncoder encoder = FlacCodec.Instance.CreateEncoder(
    new AudioEncoderOptions { SampleRate = 48000, Layout = ChannelLayout.Stereo, BitsPerSample = 16, Level = 5 },
    MediaContext.Default);
encoder.Send(tone);
encoder.Flush();
List<EncodedPacket> packets = [];
while (encoder.TryReceive(out EncodedPacket? packet))
{
    packets.Add(packet);
}
