Class OggFormat

Namespace

Ogg (.ogg, .opus, .oga), RFC 3533, with the Opus (RFC 7845), Vorbis and FLAC mappings. Pages are CRC-checked and packets rebuilt across them; timestamps come from granule positions, with Opus's pre-skip as the track's codec delay and the last page's granule position trimming the end. Seeking uses an index of granule positions built in one pass over the page headers on open. Chained files (one stream after another, as internet radio dumps are) read as one track when the codec settings stay the same, each link's TITLE a chapter; a link that changes them ends the track with an "ogg-chained-stream" warning. The writer stores Opus, Vorbis and FLAC with tags, so a WebM's Opus track remuxes to .opus without decoding.

Examples

// An Opus track moves from WebM to an .opus file and back without decoding; the tags travel in OpusTags.
MediaFile.Remux("music.webm", "music.opus");
MediaInfo info = MediaFile.Probe("music.opus");
Console.WriteLine($"{info.FormatName}: {info.Tracks[0].CodecId}, {info.Duration?.ToTimeSpan()}, {info.Chapters.Count} chapters");
