An IOcrEngine that runs an OCR program for each image and reads the hOCR or ALTO it writes, such as tesseract {image} {output} -l {langs} --dpi {dpi} hocr. Egami ships no engine and links none: the program is yours.

Examples

// Any OCR program that writes hOCR or ALTO is an engine. No shell runs the command, and each run has its own temp folder.
CommandOcrEngine tesseract = new("tesseract {image} {output} -l {langs} --dpi {dpi} hocr", new CommandOcrOptions
{
    Languages = ["eng"],
    Timeout = TimeSpan.FromMinutes(2),
});

try
{
    OcrResult result = await tesseract.RecognizeAsync(new OcrRequest(page), Ct);
    Console.WriteLine(result.Text);
}
catch (OcrEngineException e)
{
    Console.WriteLine($"{e.Message} {e.ErrorOutput}");
}

Remarks

The command is split into words at spaces, with double or single quotes around a word that holds spaces; no shell runs it, so file names and languages can never become commands. Each word may hold these placeholders: {image}, the path of the image as a PNG file; {output}, a path (without extension) for the program's output file; {langs}, the request's languages joined by +; {dpi}, the resolution as a whole number; {page}, the page index. Write {{ and }} for literal braces.

With {output} in the command, the engine reads that file, or the one file the program wrote beside it with an extension added (Tesseract adds .hocr or .xml); without it, the engine reads the program's standard output. Each run gets a temporary folder of its own that is deleted afterwards, so runs may overlap.
