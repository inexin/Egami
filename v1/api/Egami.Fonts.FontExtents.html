Examples

// Character map, advance, ink box and kerning, all in font units with y up.
ushort a = face.GetGlyph('A'), v = face.GetGlyph('V');
float advance = face.GetAdvance(a);
GlyphExtents ink = face.GetGlyphExtents(a);
float kern = face.GetKerning(a, v);
FontExtents extents = face.Extents;

// An outline arrives through a sink: lines and quadratics for TrueType, lines and cubics for CFF.
var counter = new SegmentCounter();
face.GetGlyphOutline(a, counter);

Remarks

Ascent, Descent and LineGap follow the browsers' rule: the OS/2 typo metrics when the face sets USE_TYPO_METRICS, else the hhea metrics, falling back to the typo and then the Windows metrics when those are zero. The line height is Ascent - Descent + LineGap.

The distance from the baseline up to the top of the line, positive.

The distance from the baseline down to the bottom of the line, negative.

The extra space between lines.

CapHeight float

The height of capital letters.

XHeight float

The height of lowercase letters such as x.

UnderlinePosition float

The top of the underline, relative to the baseline (usually negative).

UnderlineThickness float

The underline's thickness.

StrikeoutPosition float

The top of the strikeout line, relative to the baseline.

StrikeoutSize float

The strikeout line's thickness.

ItalicAngle float

The slant in degrees counter-clockwise from vertical: negative for text leaning right.

BoundingBox GlyphExtents

The box around every glyph of the face.
