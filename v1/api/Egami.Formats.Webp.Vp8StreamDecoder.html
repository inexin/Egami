Class Vp8StreamDecoder

Namespace
Egami.Formats.Webp

Decodes a VP8 video stream (RFC 6386) a frame at a time, as WebM and IVF files carry it: key frames and inter frames, with the last, golden and alternate references, motion vectors and hidden frames. The frames equal libvpx's sample for sample. Feed the frames in stream order; decoding starts at a key frame. Containers are not read here: Egami.Video reads WebM and IVF and uses this decoder, and any other source of VP8 frames can too.

Examples

// VP8 frames in stream order, here from an IVF file (Egami.Video reads WebM and IVF for you).
using Vp8StreamDecoder decoder = new() { ConcealErrors = false };
YuvRaster<byte>? picture = null;
foreach (byte[] packet in IvfFrames("clip.ivf"))
{
    Vp8FrameInfo info = decoder.Decode(packet);
    if (!info.IsShown)
    {
        continue; // a hidden frame, typically an alternate reference: it only updates the references
    }

    picture ??= YuvRaster.Create(info.Width, info.Height, ChromaFormat.Yuv420, YuvColor.Bt601Limited);
    decoder.CopyFrameTo(picture); // the picture is the caller's: change it or keep it
    shown++;
}

picture?.Dispose();

Remarks

The decoder keeps four frame buffers from the context's Memory for its life and decodes a frame's macroblock rows on up to MaxParallelism threads (as many as the frame's token partitions allow). Its frame size is checked against the context's Limits. An instance is not thread-safe.

Properties

ConcealErrors

Gets or sets whether broken frames are concealed instead of throwing. When set, a frame whose data runs out has the macroblocks it could not read copied from the previous frame (mid-gray when there is none), a frame whose header cannot be read shows the previous frame again, and an inter frame with no key frame before it predicts from mid-gray; the frame's IsConcealed says so. Defaults to false: broken data throws CorruptDataException.
