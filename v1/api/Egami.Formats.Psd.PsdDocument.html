Examples

// ReadLayers gives every layer with its pixels, bottom to top; a group comes after its contents.
using PsdDocument document = PsdImage.ReadLayers("layered.psd");
foreach (PsdLayerImage layer in document.Layers)
{
    if (layer.Pixels is Raster pixels)
    {
        // Each layer at its own size, in the natural type with alpha (Rgba8 here); X and Y place it on the canvas.
        pixels.Save($"layer-{layer.Index}.png");
        Console.WriteLine($"{layer.Info.Name}: {pixels.Width}×{pixels.Height} at ({layer.X}, {layer.Y}), in group {layer.ParentIndex}");
    }
}

Flatten(PsdFlattenOptions?)

Composites the layers as Photoshop does, with each layer's Info as it is now, so a changed copy (a layer hidden, another opacity or blend mode) flattens differently: visibility, opacity, fill opacity, blend mode (all of Photoshop's), pixel and vector masks, clipping, pass-through and isolated groups, blending ranges, solid color fills and the levels, curves, hue/saturation, brightness/contrast and invert adjustments. Layer effects, other adjustments, gradient and pattern fills and knockout are left out with one warning a kind naming the layers. 8 and 16-bit documents blend their stored values, 32-bit ones linear light.

public Raster Flatten(PsdFlattenOptions? options = null)

Parameters

options PsdFlattenOptions

The options, or null for the defaults.

Returns

Raster

The flattened image at the canvas's size, in the type Load gives a file of this mode and depth: with alpha only when some pixel is not opaque. Its metadata is the document's, with the warnings of the flattening. The caller must dispose it.

Examples

// Flatten composites the layers as Photoshop does; change a layer's record first to flatten it differently.
using PsdDocument document = PsdImage.ReadLayers("layered.psd");
PsdLayerImage top = document.Layers[^1];
top.Info = top.Info with { IsVisible = false };
using Raster flat = document.Flatten();
foreach (EgamiDiagnostic warning in flat.Metadata.Warnings)
{
    // What the flattening left out, such as layer effects, one warning a kind naming the layers.
    Console.WriteLine(warning.Message);
}

flat.Save("without-top.png");

Exceptions

UnsupportedFormatException

The document is Lab, bitmap, indexed or multichannel, which Egami does not flatten.

LimitExceededException

The canvases the flattening needs break MaxTotalBytes.

ObjectDisposedException

The document has been disposed.

FlattenInk(PsdFlattenOptions?)

Composites a CMYK document's layers onto ink plates, as Flatten(PsdFlattenOptions?) does, with the ink blend math of Egami.Drawing's ink canvas: every blend mode on the inks' complements, the non-separable ones on cyan, magenta and yellow with black kept.

public InkRaster FlattenInk(PsdFlattenOptions? options = null)
