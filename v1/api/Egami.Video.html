Namespace Egami.Video

Classes

AttachmentInfo

A file stored inside the container, such as a font for subtitles or cover art ("cover.jpg").

AudioReader

Reads the audio of a file in a few lines, the twin of VideoReader: opens the container, picks the audio track, decodes it and hands out AudioFrames, converted to the sample format, rate and layout asked for (planar float by default). Codec delay and padding are trimmed, so the audio has exactly the samples the encoder was given; seeking is sample exact.

AudioReaderOptions

How an AudioReader reads and converts.

AudioTrackInfo

An audio track: a TrackInfo with the sample format.

AudioWriter

Writes an audio file in a few lines, the twin of VideoWriter: encodes each frame and muxes it, picking the container from the file extension. Frames may have any length and sample format; the writer resamples, mixes and converts them to what the codec takes. The rate, layout and bit depth come from the options or the first frame.

AudioWriterOptions

What an AudioWriter writes.

ChapterInfo

A chapter: where it starts and ends, and its title.

CodecIds

Matroska codec ids (from the Matroska codec mapping) for the codecs Egami.Video names. CodecId uses these for every container.

EncodedPacket

One compressed unit of a track, such as a Motion JPEG frame or a block of audio: what demuxers return, decoders take, encoders return and muxers write. The bytes may sit in a pooled buffer, which Dispose() returns.

Hdr10PlusMetadata

HDR10+ dynamic metadata for one frame (SMPTE ST 2094-40, application version 0 or 1), as WebM carries it in each block's BlockAdditional with BlockAddID 4 (an ITU-T T.35 payload). The values are the first processing window's, which covers the whole frame; luminances are in cd/m². Egami.Video reads and keeps it but does not tone map with it: HDR to SDR conversion uses the static metadata (Hdr).

Hdr10PlusToneCurve

An HDR10+ tone mapping curve for the target display: a knee point, then a Bezier curve through its anchors.

MediaContext

The registered containers and codecs, the safety limits for reading, and the Egami context frames are allocated from. Every entry point takes one, or uses Default. Immutable: derive a new one with with or WithContainer(ContainerFormat) and WithCodec(VideoCodec).

MediaFile

Entry points for media files: probe what a file holds, open a demuxer to read its packets, or create a muxer to write one. The container is detected from the file's first bytes when reading, and chosen by extension when writing.

MediaInfo

What a media file holds, read from its headers without decoding any frame. Returned by MediaFile.Probe.

MediaLimits

Limits that make readers reject hostile files early instead of allocating or looping without bound.

MediaMetadata

A file's tags, chapters and attachments, as a demuxer reads them and a muxer writes them.

MediaWarning

Something a reader or writer handled but reports, through Warnings.

MovTextSample

One mov_text subtitle (3GPP timed text, TS 26.245; codec MovText): its text and the style runs that make parts of it bold, italic, underlined, larger or colored. Parse a packet's bytes to read it, and write one with ToBytes(). Modifier boxes other than styles (highlight, karaoke, scroll delay, links, text box, blink, wrap) are kept as stored, so a sample read and written again keeps its bytes.

PacketAddition

Extra data stored with a packet (a Matroska BlockMore): an id saying what it is, and its bytes. Id 1 holds a WebM VP8 or VP9 track's alpha frame when the track has HasAlpha.

PlaneScores

A score per plane (Y, U, V and alpha when present) and an average.

TrackInfo

A track in a container: its number, kind and codec, as a demuxer reports it and a muxer takes it. Codecs are named with Matroska codec ids (CodecIds), which every container maps to and from, so a track read from AVI can be written to Matroska unchanged.

TrimResult

What a trim did: where the cut starts in the input, how much was copied and encoded again, and what it reported.

VideoFrame

A decoded picture with its time: a YuvVideoFrame as decoders hand it out (the codec's own planes), or a VideoFrame<TPixel> of RGB pixels from VideoReader.ReadFrames. Disposing the frame returns its pixel memory to the memory source it came from.

VideoFrame<TPixel>

A decoded picture converted to TPixel pixels, as VideoReader.ReadFrames returns it.

VideoQuality

Measures how close decoded video is to a reference, frame by frame or over a whole clip: PSNR and SSIM per plane, and MD5 hashes of frames and packets in the layout FFmpeg's framemd5 uses (planes one after another, rows without padding, little-endian 16-bit samples above 8 bits).

VideoReader

Reads the frames of a video file in a few lines: opens the container, picks the video track, decodes it and hands out frames, as the codec's planes (ReadFrames()) or as RGB rasters (ReadFrames<TPixel>()). Frame memory comes from the context's pixel memory source, pooled by default, so disposing each frame keeps memory steady over long files.

VideoReaderOptions

How a VideoReader reads.

VideoTrackInfo

A video track: a TrackInfo with the picture size, frame rate and color.

VideoWriter

Writes a video file from rasters in a few lines: encodes each frame and muxes it, picking the container from the file extension. The picture size comes from the first frame. Other tracks, such as audio copied from a source file, can be written alongside with WritePacket(EncodedPacket).

VideoWriterOptions

What a VideoWriter writes.

YuvVideoFrame

A decoded picture in the codec's own planar YUV layout, as decoders return it: for Motion JPEG the JPEG's Y, Cb and Cr planes at their own subsampling, with no color conversion.

Structs

Hdr10PlusPercentile

One point of HDR10+'s distribution of each pixel's brightest component: Percentage percent of the pixels are at or below Value cd/m².

Keyframe

A value at a time on a stream's time line, one point of an animation such as a GainEnvelope. Easing says how the value moves on to the next keyframe.

MediaProgress

How far a job such as Remux(string, string, Func<TrackInfo, bool>?, MediaContext?, IProgress<MediaProgress>?, CancellationToken) has come. A job reports once its output is open, then at most every 250 ms, then once more with IsFinal set.

MediaTime

A point in time or a duration in a media stream: a whole number of ticks of a Rational time base. Exact for every container: AVI counts frames at the frame rate's reciprocal (for example 1001/30000 s), Matroska counts its timestamp scale in nanoseconds. TimeSpan rounds to 100 ns and drifts over long files; this type does not.

MovTextStyle

A style run of a mov_text subtitle (a 3GPP StyleRecord): which characters it covers and how they look.

Rational

An exact fraction, such as a frame rate (30000/1001) or a time base (1/1000000000). Always stored in lowest terms with a positive denominator.
