Class Icon

Namespace
Egami.SystemDrawing
Assembly
Egami.SystemDrawing.dll

A Windows icon: an ICO file with images at several sizes, of which the icon shows the one nearest the size asked for (32 by 32 when none is), as System.Drawing chooses it. Save(Stream) writes the file it was loaded from.

public sealed class Icon : MarshalByRefObject, ICloneable, IDisposable

Examples

// An icon shows the image nearest the size asked for, as System.Drawing chooses it, and saves the file it came from.
using Icon icon = new(System.IO.Path.Combine(Images, "app.ico"), 24, 24);
using Bitmap image = icon.ToBitmap();  // 24 by 24, 32-bit ARGB
using MemoryStream copy = new();
icon.Save(copy);
