Examples

// Levels, saturation and broadcast range as signalstats gives them, the range really used, and optional blur and
// blockiness scores.
SignalMeter meter = new(new SignalOptions { Blur = true, Blockiness = true });
MediaAnalysis.Run("shots.mkv", new MediaAnalysisOptions { Scenes = null, VideoDetectors = [meter] });
SignalReport report = meter.Report();
Console.WriteLine($"Y {report.Y.Min}..{report.Y.Max} (mean {report.Y.Mean:0.0}), {report.OutOfRange:P1} out of range, {report.Range} range");
Console.WriteLine($"Edges {report.Blur:0.00} px wide, blockiness {report.Blockiness:0.00}");

Saturation PlaneLevels

Chroma saturation: the distance of (Cb, Cr) from the no-color middle, in code values.

OutOfRange double

The share of pixels, from 0 to 1, whose luma or chroma is outside broadcast range.

Range SignalRange

Which range the samples really use.

Alpha AlphaUse

Whether and how the alpha plane is used.

Blur double?

The mean edge width in pixels, with Blur; higher is blurrier.

Blockiness double?

How much stronger steps on a block grid are than steps between it, with Blockiness; 1 is none.
