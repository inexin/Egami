Interface ITransition

Namespace
Egami.Video.Editing
Assembly
Egami.Video.dll

An app's own picture transition for Custom(ITransition, MediaTime): it draws one frame of the change from one clip to the next. The two frames and the target have the canvas size. The same instance draws every frame, possibly on several threads, so keep it stateless.

public interface ITransition

Examples

// An app's own transition: the incoming clip appears from the top down.
VideoEdit edit = new(new EditCanvas(320, 180, new Rational(25, 1)));
edit.Track.Add(Clip.Open("intro.avi")).Add(Clip.Open("outro.avi"), Transition.Custom(new Blinds(), MediaTime.FromSeconds(1)));
edit.Render("blinds.mkv");
