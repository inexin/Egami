Class InkRaster

A printed page as plates: one plane per ink of an InkSet (a disabled spot has none) plus one alpha plane, each 8 or 16 bits. A plane holds the ink as it prints over paper, 0 for none to the depth's maximum for full ink: drawing translucently leaves less ink, so the planes are premultiplied by the alpha plane, and a plate is ready to print as it is. A new raster is blank: no ink, alpha 0.

Examples

// A page as plates: CMYK and the spot, 8 bits each, plus alpha. Rows are written in place; a plate is also a gray raster.
using InkRaster page = new(inks, 200, 100, InkDepth.Unorm8);
page.Plate("PANTONE 186 C")!.Row8(10).Fill(255);              // a full-tint line of the spot
page.Alpha.Row8(10).Fill(255);
using Raster<Gray8> spot = page.Plate("PANTONE 186 C")!.AsRaster<Gray8>();   // no copy: 0 = no ink, 255 = full ink

Remarks

Planar storage lets a plate come out as a Raster<TPixel> of Gray8 or Gray16 without copying (AsRaster<TPixel>()), and lets blend modes run one plane at a time. An A4 page at 300 dpi with CMYK and two spots takes 61 MB at 8 bits. Not thread-safe, like Raster.

Load(Stream, ColorProfile?, EgamiContext?)

Loads a separated TIFF (PhotometricInterpretation 5) as an ink raster: 8 or 16-bit strips, chunky or planar, uncompressed, LZW, Deflate or PackBits. The inks are those of the file's embedded CMYK or n-colour profile (else profile, else FOGRA39), plus a spot, without appearance, for each ink it names that the profile lacks; planes are matched by name. Without an alpha extra sample the page counts as covered (alpha at its maximum).

public static InkRaster Load(Stream stream, ColorProfile? profile = null, EgamiContext? context = null)

MeasureCoverage(float)

Measures the ink: the largest total of the printing inks (process and spots; technical inks such as varnish are not counted) on one pixel, where it is, the share of pixels over limit, and each plate's mean coverage.

public InkCoverage MeasureCoverage(float limit = 3)

Parameters

limit float

The total ink limit, as a fraction: 3.0 for 300%, FOGRA39's.

Returns

InkCoverage

The figures.

Examples

// How the plates look on screen, and whether they print within the press's total ink limit.
using Raster<Rgba8> proof = page.Proof<Rgba8>(new ProofOptions { SimulatePaper = true });
InkCoverage coverage = page.MeasureCoverage(limit: 3.0f);
bool tooMuchInk = coverage.MaxTotal > coverage.Limit;      // where: coverage.MaxAt; how often: coverage.ShareOver

Exceptions

ArgumentOutOfRangeException

limit is negative or not finite.

ObjectDisposedException

Proof<TPixel>(ProofOptions?)

Returns how the plates print, on screen: each spot's appearance at full tint, as process tints scaled by the spot's tint, adds to the process inks (capped at full ink, as Ghostscript's and MuPDF's overprint simulation do), and the result goes through the ink set's profile to Target. Technical inks and spots without an appearance do not show; unprinted paper is paper. The plates hold ink as printed, so the proof is opaque.

Save(Stream, InkTiffOptions?)

Saves the raster as one separated TIFF: a sample per plate (InkSet 1 for plain CMYK, else 2 with the ink names), stored plane by plane, and the output profile embedded; the alpha plane too when IncludeAlpha says so. libtiff and RIPs read it. Spot appearances and kinds are not kept: TIFF has no place for them.

public void Save(Stream stream, InkTiffOptions? options = null)

Parameters

stream Stream

The stream to write to, at its position.

options InkTiffOptions

The compression and whether to keep alpha, or null for the defaults.

Examples

// One separated TIFF with every plate and the ink names, Deflate by default; it loads back plate for plate.
page.Save(file, new InkTiffOptions { Compression = Egami.Formats.Tiff.TiffCompression.Lzw });
file.Position = 0;
using InkRaster loaded = InkRaster.Load(file);
// One separated TIFF with every plate and the ink names, Deflate by default; it loads back plate for plate.
page.Save(file, new InkTiffOptions { Compression = Egami.Formats.Tiff.TiffCompression.Lzw });
file.Position = 0;
using InkRaster loaded = InkRaster.Load(file);

Exceptions

ObjectDisposedException

The raster has been disposed.
