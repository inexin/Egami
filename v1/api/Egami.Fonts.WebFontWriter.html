Class WebFontWriter

Namespace
Egami.Fonts
Assembly
Egami.Fonts.dll

Writes fonts as WOFF 1.0 and WOFF 2.0 files for the web, losslessly: every table of the font is kept, and a WOFF2 file read back gives the same tables but glyf and loca, whose glyphs read the same but may be laid out more compactly, and head, whose flags gain bit 11 (the font has been through a lossless modifying transform), as the reference encoder sets it.

Examples

// WOFF2 for the web: every table kept, glyf, loca and hmtx transformed, one Brotli stream; a third of the TTF's size.
File.WriteAllBytes(System.IO.Path.Combine(folder, "NotoSans-Regular.woff2"), WebFontWriter.Write(face));

// WOFF 1.0 for old browsers, with a metadata block naming the font's license.
byte[] woff = WebFontWriter.Write(face, new WebFontOptions
{
    Format = WebFontFormat.Woff,
    Metadata = """<?xml version="1.0" encoding="UTF-8"?><metadata version="1.0"><license url="https://openfontlicense.org"/></metadata>""",
});
File.WriteAllBytes(System.IO.Path.Combine(folder, "NotoSans-Regular.woff"), woff);

Remarks

Compression uses .NET's own zlib (ZLibStream, the smallest of levels 9 and 8 with the default and filtered strategies) and Brotli (BrotliEncoder at quality 11 with a 4 MB window). A table zlib cannot shrink is stored uncompressed in WOFF 1.0. The file's version is the head table's fontRevision.

Examples

// A web font with only the characters a page uses, shaped as the full face shapes them: subset with the layout closure,
// then write WOFF2. The subset keeps the glyph ids, so the layout tables need no rewriting.
string page = "Egami: managed imaging for .NET";
ushort[] glyphs = [.. page.EnumerateRunes().Select(r => face.GetGlyph(r.Value)).Distinct()];
FontSubset subset = FontSubsetter.Subset(face, glyphs, new SubsetOptions { RetainGlyphIds = true, LayoutClosure = true });
byte[] woff2 = WebFontWriter.Write(subset);

Exceptions

ArgumentNullException

subset is null.

ArgumentException

The subset is a bare CFF stream (BareCff).

LimitExceededException

The subset is larger than the context's MaxTotalBytes.

Write(ReadOnlyMemory<byte>, WebFontOptions?)

Writes font data as a web font: an sfnt, or a TrueType or OpenType collection (WOFF2 only), whose tables are shared as in the collection. A WOFF or WOFF2 file is unwrapped and written again, keeping its metadata and private data unless the options replace them.
