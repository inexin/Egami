Class HeicWriterOptions

Namespace
Egami.Heic

Options for writing HEIC. Lossy images are coded on heif-enc's quality scale, so the same Quality gives about the same file as heif-enc -q with x265; lossless images keep every sample of 4:4:4 RGB. The names and meanings match AvifWriterOptions where the two formats share an option.

Examples

// With Egami.Heic registered, Save picks HEIC from the extension: lossy 4:2:0 at quality 50 on heif-enc's scale, effort 4.
duck.Save("duck-q50.heic");

// Smaller and softer, or every sample exact (4:4:4 RGB with the identity matrix, which needs a range extensions decoder).
duck.Save("duck-q30.heic", new HeicWriterOptions { Quality = 30 });
duck.Save("duck-lossless.heic", new HeicWriterOptions { Lossless = true });

Remarks

HEVC is covered by patents, encoding as well as decoding. Egami's authors grant no patent rights and are not lawyers. Whether you need a patent licence depends on your country and on how you use and distribute this package; commercial products may need one from the HEVC patent pools or holders.

AlphaQuality

Gets the quality of the alpha plane, 0 to 100 on the same scale as Quality: 100 (the default) keeps alpha exactly. Alpha is written straight, not premultiplied, as an auxiliary image every HEVC decoder reads.

public int AlphaQuality { get; init; }

int

Exceptions

BitDepth

Gets the bits a sample has, 8, 10 or 12, or null (the default) for 8 with 8-bit pixels and 10 (Main 10) with deeper ones; a lossless file of deeper pixels takes 12. 12 bits use HEVC's format range extensions.

public int? BitDepth { get; init; }

Property Value

int?

Exceptions

ArgumentOutOfRangeException

The value is not 8, 10 or 12.

Chroma

Gets the chroma format of lossy color, or null (the default) for 4:2:0, which every HEVC decoder reads. 4:4:4, 4:2:2 and 4:0:0 use HEVC's format range extensions, which some phones and operating systems cannot decode. 4:1:1 and 4:1:0 choose as null does.

Lossless

Gets whether to write lossless (every sample of the RGB or gray image exact: 4:4:4 with the identity matrix, coded without transform or quantization) or lossy data, or null (the default) for lossy. Lossless HEIC needs a decoder of HEVC's format range extensions, which some phones and operating systems lack.

public bool? Lossless { get; init; }

Quality

Gets the lossy quality, 0 (smallest) to 100 (best), on heif-enc's -q scale. Defaults to 50, as heif-enc does. Ignored for lossless images.

TargetSize

Gets the largest size the file may have, in bytes, or null (the default) to code at Quality: the quality is searched for the largest file not above the size, then the quantizer between that quality and the next, so the file lands close under the size. When even quality 0 is larger, that file is written and a Heic.TargetSizeExceeded warning says so. Ignored for lossless images.

public int? TargetSize { get; init; }

Property Value

int?

Exceptions

ArgumentOutOfRangeException

ThumbnailSize

Gets the size of the square a thumbnail fits in, 16 to 1024 samples, or null (the default) for no thumbnail. A thumbnail is a small HEVC image linked to the image, which file browsers show without decoding the whole picture; iPhones write one 320 samples wide.
