Examples

// Layer records come as metadata, bottom to top as the file lists them; their pixels are not loaded.
using Raster image = Raster.Load("layered.psd");
foreach (PsdLayer layer in ((PsdDetails)image.Metadata.FormatDetails!).Layers)
{
    if (layer.Kind == PsdLayerKind.GroupEnd)
    {
        continue;
    }

    string kind = layer.Kind == PsdLayerKind.Layer ? "layer" : "group";
    Console.WriteLine($"{new string(' ', 2 * layer.Level)}{layer.Name} ({kind}, {layer.BlendModeKey}, opacity {layer.Opacity:P0}{(layer.IsVisible ? "" : ", hidden")})");
}

Parameters

Name string

The layer's name: its Unicode name when the file has one, else its Pascal name.

Bounds Rect

Where the layer's pixels lie in the image; empty for groups and layers without pixels.

Opacity float

The opacity, 0 (transparent) to 1, as DrawImage takes it; the file stores it in 256 steps.

BlendModeKey string

The blend mode as Photoshop names it, such as "norm", "mul " or "pass" (pass through, for groups).

BlendMode BlendMode?

The same blend mode in Egami's terms, or null when Egami has none like it.

IsVisible bool

Whether the layer is shown.

IsClipped bool

Whether the layer is clipped to the layer below it (a clipping mask).

Kind PsdLayerKind

Whether the record is a layer or one end of a group.

Level int

How many groups the record is inside; a group's own records are at the level outside it.
