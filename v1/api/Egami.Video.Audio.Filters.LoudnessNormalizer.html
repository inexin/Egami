Class LoudnessNormalizer

Namespace
Egami.Video.Audio.Filters
Assembly
Egami.Video.dll

Brings audio to a LoudnessTarget, as EBU R 128 and ffmpeg's loudnorm do. By default it is linear: given the input's LoudnessReport from a first pass with LoudnessMeter, it applies one gain, so the dynamics stay as they are, and runs a true-peak Limiter only when that gain would take the peaks over the ceiling. NormalizeLoudnessAsync(string, string, LoudnessTarget?, AudioCodec?, int?, MediaContext?, IProgress<MediaProgress>?, CancellationToken) runs both passes over a file. For input that cannot be read twice, Dynamic(LoudnessTarget) makes a one-pass normalizer that follows the loudness with 1.5 s of lookahead and changes the dynamics to keep within the target's range.

Examples

// Two passes over a file: measure each audio track, then apply one gain (and a true-peak limiter only if needed).
IReadOnlyList<LoudnessNormalization> done = await Egami.Video.Audio.Filters.AudioFilters.NormalizeLoudnessAsync(input, output, LoudnessTarget.Podcast);
Console.WriteLine($"{done[0].Measured.Integrated:F1} LUFS, {done[0].Gain:+0.0;-0.0} dB, limited: {done[0].Limited}");

// The same as a filter, from your own first pass; or one pass, following the loudness as it goes.
LoudnessMeter meter = new();
foreach (AudioFrame frame in Music())
{
    using (frame)
    {
        meter.Add(frame);
    }
}

using LoudnessNormalizer linear = new(LoudnessTarget.EbuR128, meter.Report());
using LoudnessNormalizer live = LoudnessNormalizer.Dynamic(LoudnessTarget.Streaming);
