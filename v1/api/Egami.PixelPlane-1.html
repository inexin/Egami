A width × height grid of pixels, stored row by row. A row is always one contiguous span, but the plane as a whole may be split into several blocks of whole rows. Planes belong to the raster or operation that hands them out, which returns their memory; user code reads and writes them but never frees them.

Examples

PixelPlane<Rgba8> plane = image.Frames[0].Plane;
if (plane.TryGetContiguous(out Span<Rgba8> all))
{
    all.Fill(Rgba8.White);  // one Span over every pixel when the rows are stored back to back
}
else
{
    for (int y = 0; y < plane.Height; y++)
    {
        plane.Row(y).Fill(Rgba8.White);
    }
}

Remarks

Spans returned by Row(int) and TryGetContiguous(out Span<TPixel>) point into the plane's memory. Do not keep them after the raster is disposed, or after an operation that changes its size, which gives the frame a new plane.
