Examples

// Images, style sheets and fonts the file refers to open only through a resolver; data: URIs always work.
var options = new SvgLoadOptions
{
    Resolver = SvgResolvers.SameDirectory(folder),
    Dpi = 96,
    Context = EgamiContext.Default with { Limits = SafetyLimits.Default with { MaxTotalBytes = 64L << 20 } },
};
SvgDocument document = SvgDocument.Parse(Icon, options);

Resolver

Gets the resolver that opens files the document refers to (images, style sheets, fonts, other SVG files), or null, the default, to open nothing outside the file. data: URIs always work. It gets an absolute URI (relative ones are resolved against BaseUri) and returns a stream it may own, or null to refuse. Egami never opens a network connection itself; SvgResolvers has a ready resolver for files in one folder.

public Func<Uri, Stream?>? Resolver { get; init; }
