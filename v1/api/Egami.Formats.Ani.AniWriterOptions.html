Class AniWriterOptions

Namespace
Egami.Formats.Ani
Assembly
Egami.dll

Options for writing ANI. Each frame of the raster is a step of the animation; a frame that repeats an earlier one (same pixels, same hotspot) is stored once and shown again. Every stored frame is a cursor with the entries IcoWriterOptions would write. Delays are rounded to 1/60 s, and a delay under 20 ms is written as 100 ms, as browsers play GIFs. ANI always loops. EXIF, XMP and IPTC are not written; an ICC profile goes into PNG entries.

Examples

// Every frame is a step; frames that repeat are stored once. Each stored frame holds every size Windows may draw.
spin.Save("spin.ani", new AniWriterOptions
{
    Sizes = AniWriterOptions.CursorSizes,
    Hotspot = new Point(32, 32),
    Title = "Spinning duck",
});

Gets the square sizes every stored frame holds, 1 to 256, or null (the default) to write the frames at the raster's own size, fitted down to 256 with a warning when larger. A raster that is not square is fitted inside each square and centred on transparency, as Sizes does.
