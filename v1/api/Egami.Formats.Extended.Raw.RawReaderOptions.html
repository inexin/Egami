Examples

RawReaderOptions develop = new()
{
    WhiteBalance = RawWhiteBalance.Custom,
    Temperature = 4800,                    // kelvin
    Tint = 5,                              // toward magenta
    Exposure = -0.5,                       // stops
    Highlights = RawHighlightMode.Rebuild, // recover clipped colour from what was not clipped
    Demosaic = RawDemosaicMethod.Malvar,   // faster than the default AHD
    LuminanceNoiseReduction = 20,          // 0 to 100; off by default
    ColorNoiseReduction = 40,              // 0 to 100; 25 by default
    AutoChromaticAberration = true,        // fix colour fringes when no lens profile covers the file
    DefaultToneCurve = true,               // a contrast curve like Adobe Camera Raw's default; off by default
    ConvertColorTo = Colors.ColorProfile.DisplayP3, // rendered straight into P3, the profile attached
};
using Raster photo = Raster.Load("photo.dng", context, develop);
photo.Save("photo-p3.png");

AutoChromaticAberration

Gets whether a file that no lens correction covers (no lens opcodes, no matching profile) has its lateral chromatic aberration measured from the image and corrected: red and blue are scaled about the centre to line their edges up with green's. Defaults to false, since the measurement costs about as much as the demosaic. Applies only with LensCorrections.

public bool AutoChromaticAberration { get; init; }

DefaultToneCurve

Gets whether a develop whose camera profile has no tone curve of its own gets a default one: the contrast curve of Adobe Camera Raw's default rendering, measured as a black box, which lifts the midtones and rolls off the highlights the way most raw converters' default looks do. Defaults to false, which keeps the develop scene-linear (only the output's transfer function); maker files, whose profiles come from the camera table, have no tone curve.

public bool DefaultToneCurve { get; init; }

Property Value

bool

LensProfiles

Gets the folders of lens profiles to correct with: Lensfun database files (.xml) and Adobe lens profiles (.lcp), searched with their subfolders; a system Lensfun install and the folders Adobe's software installs its lens profiles in are searched too when they are there. A file whose own data corrects the lens (DNG's lens opcodes) uses that instead. Egami ships no profiles: Lensfun's database is under CC BY-SA and Adobe's profiles are Adobe's, so you supply them. Defaults to none. Applies only with LensCorrections.

public IReadOnlyList<string> LensProfiles { get; init; }
