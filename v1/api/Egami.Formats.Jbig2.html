Namespace Egami.Formats.Jbig2

Classes

Jbig2Details

Details only JBIG2 has, kept per page in FormatDetails.

Jbig2Format

The JBIG2 bi-level format (ITU-T T.88), read only, registered in Default. Standalone files are detected by their header; the embedded form a PDF holds has none, so it loads only with the format named, as in Load(ReadOnlyMemory<byte>, FormatInfo, EgamiContext?, ReaderOptions?).

Jbig2Globals

A parsed JBIG2 globals stream: the symbol dictionaries, pattern dictionaries and code tables a PDF shares between the JBIG2 images of a document. Parsing decodes them once; the object is immutable and safe to share across threads, so every page that refers to it reuses the decoded symbols.

Jbig2ReaderOptions

Options for reading JBIG2.
