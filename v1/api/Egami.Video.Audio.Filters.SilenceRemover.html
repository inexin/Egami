Class SilenceRemover

Namespace
Egami.Video.Audio.Filters
Assembly
Egami.Video.dll

Cuts silence out of audio, like ffmpeg's silenceremove: a sample is silent when the loudest channel's RMS over the 20 ms around it is under Threshold. Trim cuts the silence at the start and the end; Shorten also cuts long pauses down, as for a voice recording. Each cut fades or crossfades over 10 ms, so it does not click. The output runs on from the input's first timestamp without gaps, so it is shorter than the input: use it on audio alone, never on a track that has to stay in sync with video.

Examples

// Cut a voice recording's lead-in and tail, and pauses over 1 s down to 0.3 s. Audio only: the result is shorter.
using SilenceRemover remover = new(SilenceRemoval.Shorten) { Threshold = -45 };

Remarks

A silent stretch is held until sound comes back (or the input ends), since only then is it known to be a pause rather than the end, so a long silence takes memory for its length. Latency gives the 10 ms of lookahead it always holds.
