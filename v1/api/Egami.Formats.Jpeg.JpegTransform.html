Class JpegTransform

Namespace
Egami.Formats.Jpeg
Assembly
Egami.dll

Rotates, flips, crops and drops the color of JPEG files without decoding them to pixels, so nothing is lost: the quantized DCT coefficients are moved and sign-flipped block by block, as jpegtran does, and coded again. Quantization tables and chroma subsampling stay as they were. Every mode the reader takes works except lossless JPEG, which has no coefficients.

Examples

// Turns the photo upright by its EXIF orientation without re-encoding: no quality is lost, and the tag is reset.
JpegTransform.Apply("sideways.jpg", "upright.jpg", new JpegTransformOptions { Operation = JpegTransformOperation.AutoOrient });

// Rotates, crops and drops the color in one pass; a file can be transformed in place.
JpegTransformResult result = JpegTransform.Apply("upright.jpg", "upright.jpg", new JpegTransformOptions
{
    Operation = JpegTransformOperation.Rotate90,
    Crop = new Rect(0, 0, 200, 120),
    Grayscale = true,
});
Console.WriteLine($"{result.Width} × {result.Height}");

Remarks

The whole image's coefficients are held while it runs (about 2 bytes per sample, 3 bytes per pixel for a 4:2:0 photo), counted against MaxTotalBytes. The result is the same for any MaxParallelism.
