Options for writing JPEG. The defaults are libjpeg-turbo's cjpeg defaults: quality 75, 4:2:0 and the standard Huffman tables of T.81 Annex K, so files compare one to one.

Examples

using Raster photo = Raster.Load("duck.jpg", options: new JpegReaderOptions { FastUpsampling = true });
JpegDetails details = (JpegDetails)photo.Metadata.FormatDetails!;
Console.WriteLine($"{details.ColorSpace}, progressive: {details.Progressive}, quality about {details.EstimatedQuality}");
foreach (JpegComponent component in details.Components)
{
    Console.WriteLine($"Component {component.Id}: sampled {component.HorizontalSampling} × {component.VerticalSampling}");
}

// Gray output, and 4:4:4 (no chroma subsampling) for sharp colored edges.
photo.Save("gray.jpg", new JpegWriterOptions { ColorType = JpegColorType.Gray });
photo.Save("sharp.jpg", new JpegWriterOptions { Quality = 90, Subsampling = ChromaSubsampling.Subsample444 });

GainMap

Gets how to write an HDR raster as an Ultra HDR JPEG (HDR Design question 10), or null (the default) to write its pixels as they are. Set, the raster is tone mapped with Bt2390 to the SDR base image, written at Quality, and Create(Raster, Raster?, GainMapOptions?) makes the map that brings the HDR raster back, written after it as KeepGainMap says. To choose the SDR rendition yourself, set GainMap of the SDR raster to Create(Raster, Raster?, GainMapOptions?)'s map and save that. Needs the whole raster, so a streamed encode throws NotSupportedException.

public GainMapOptions? GainMap { get; init; }

Property Value

GainMapOptions

Examples

// An HDR raster as Ultra HDR: the SDR base, tone mapped with BT.2390, and a gain map that brings the HDR raster back.
using Raster<RgbaF32> hdr = Raster.Load<RgbaF32>("render.exr");
hdr.Save("render.jpg", new JpegWriterOptions { Quality = 90, GainMap = new GainMapOptions() });

// Or choose the SDR rendition: the map goes in its metadata, and saving as JPEG writes both.
using Raster<Rgb8> sdr = hdr.Derive(ops => ops.ToneMap(ToneMapping.Reinhard)).As<Rgb8>();
sdr.Metadata.GainMap = GainMap.Create(hdr, sdr, new GainMapOptions { Scale = 4 });
sdr.Save("graded.jpg", new JpegWriterOptions { Quality = 90 });

KeepGainMap

Gets a value indicating whether a gain map the raster carries (GainMap, from an Ultra HDR, ISO 21496-1 or Apple file) is written back: the gain map JPEG after the image, an MPF index, ISO 21496-1 metadata and Adobe's hdrgm XMP with a GContainer directory, so HDR displays show the HDR rendition. A map read from the file is copied as it was stored; one an operation moved is encoded again. StripMetadata leaves it out too. Defaults to true.

public bool KeepGainMap { get; init; }

Property Value

bool

Examples

// Crops, turns, flips and resizes move the gain map with the picture; saving as JPEG writes it back.
using Raster photo = Raster.Load("ultrahdr.jpg");
using Raster cropped = photo.Derive(ops => ops.Crop(16, 16, 200, 150).Rotate(90));
cropped.Save("cropped.jpg");                                             // still Ultra HDR

// Operations that change pixel values drop it (Operation.GainMapDropped), and so do formats other than JPEG
// (Save.GainMapDropped); KeepGainMap = false leaves it out on purpose.
cropped.Save("sdr-only.jpg", new JpegWriterOptions { KeepGainMap = false });

Precision

Gets the bits per sample, 8 or 12. 12 keeps the detail of 16-bit and float images (written as SOF1, or SOF2 when progressive, with Huffman tables always optimized), but no browser shows 12-bit JPEG; 8-bit pixel types gain nothing from it. Defaults to 8.

Progressive

Gets a value indicating whether to write a progressive file: libjpeg's standard scan script (ten scans for color, six for gray) with Huffman tables optimized for each scan, as cjpeg -progressive writes. Readers show a coarse image first and refine it; files are usually a few percent smaller than baseline, and decode to the same pixels. The encoder holds every quantized coefficient until the last scan, about 2 bytes per sample, counted against MaxTotalBytes; a streamed encode buffers. Re-saving a progressive file writes baseline unless this is set. Defaults to false.

public bool Progressive { get; init; }

Property Value

bool

Quality

Gets the quality, 1 (smallest) to 100 (best). It scales the example quantization tables of T.81 Annex K with the IJG formula, so the same number gives about the same file as other libjpeg-based encoders. Defaults to 75.
