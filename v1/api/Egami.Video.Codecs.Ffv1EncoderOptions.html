FFV1's expert encoder settings (Ffv1, Ffv1). The defaults are the archival profile: version 3, the range coder with a custom state table, slice CRCs on, and a slice grid picked from the frame size.

Examples

// FFV1 keeps every sample: RGB frames are coded as RGB and planes keep their layout and depth. The defaults are the
// archival profile (version 3, every frame a keyframe, slice CRCs, the range coder with a custom table).
VideoWriterOptions options = new() { Codec = VideoCodecs.Ffv1, FrameRate = new Rational(25, 1) };
using (VideoWriter writer = VideoWriter.Create("master.mkv", options))
{
    for (int i = 0; i < 5; i++)
    {
        using Raster<Rgb8> frame = duck.Derive(ops => ops.Crop(new Rect(i * 4, i * 2, 320, 240)));
        writer.WriteFrame(frame);
    }
}

// Expert settings: more slices for more threads, Golomb-Rice for speed, a keyframe every 10 frames for smaller files.
VideoWriterOptions fast = options with
{
    KeyframeInterval = 10,
    Ffv1 = new Ffv1EncoderOptions { Slices = 16, Coder = Ffv1Coder.GolombRice, ContextModel = Ffv1ContextModel.Small },
};

// Check the archive without decoding it.
bool intact = Ffv1Codec.Verify("master.mkv").IsIntact;

Properties

BitDepth

Gets the bits per sample to code, 8 to 16, or null for the planes' own depth. A smaller depth than the planes' takes the samples' high bits, which suits planes decoded from a 9, 11, 13, 14 or 15-bit source, held shifted up in 10, 12 or 16 bits, so the file keeps the source depth.

public int? BitDepth { get; init; }

ContextModel

Gets the context model, or null to pick it from Effort: the small model up to effort 6 (the default is 4), the large one from 7 on. With every frame a keyframe the small model codes smaller files, as its fewer contexts adapt within a frame; the large one pays off over longer runs of non-keyframes.

public Ffv1ContextModel? ContextModel { get; init; }

SliceCrc

Gets whether every slice ends in a CRC, so damage is found and Verify(string, MediaContext?, CancellationToken) can check the file. Default on.

public bool SliceCrc { get; init; }

Slices

Gets the number of slices each frame is cut into, 1 to 1024, or null to pick it from the frame size: 1 up to 352×288, 4 up to 1280×720, 16 up to 2560×1440 and 24 above. Slices are coded and decoded in parallel. Frames larger than 352×288 need at least 4 (RFC 9043 section 5).

public int? Slices { get; init; }
