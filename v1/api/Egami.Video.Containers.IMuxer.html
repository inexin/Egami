Interface IMuxer

Namespace
Egami.Video.Containers
Assembly
Egami.Video.dll

Writes packets into a container. Packets should come in timestamp order across tracks, as a demuxer returns them. Dispose() finishes the file if Finish() was not called.

public interface IMuxer : IDisposable
Inherited Members
IDisposable.Dispose()

Examples

using IDemuxer demuxer = MediaFile.OpenDemuxer("in.avi");
using IMuxer muxer = MediaFile.CreateMuxer("out.mkv", demuxer.Tracks);
while (demuxer.ReadPacket() is { } packet)
{
    using (packet)
        muxer.WritePacket(packet);
}

muxer.Finish();
