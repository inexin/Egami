A parsed ICC profile (ICC.1, versions 2 and 4): the header fields, the description and copyright text, and every tag with its bytes. Read-only; FromIcc(IccData) turns it into an encoding that conversion can use.

Examples

// IccData reads a profile's header and tags; it never throws, and says what was wrong with a damaged one.
IccData icc = IccData.Parse(bytes);
Console.WriteLine($"{icc.Description}: version {icc.Version}, {icc.ProfileClass}, {icc.DataSpace} to {icc.ConnectionSpace}, damaged: {icc.IsDamaged}");
foreach (IccTag tag in icc.Tags)
{
    Console.WriteLine($"  {tag.Signature} ({tag.Type}), {tag.Data.Length} bytes");
}

// ColorProfile.FromIcc makes an encoding from it: a matrix profile gets its primaries and curve, so an ICC profile written
// for Display P3 is equivalent to the built-in.
ColorProfile profile = ColorProfile.FromIcc(icc);
bool isP3 = profile.IsEquivalentTo(ColorProfile.DisplayP3);

Remarks

Parsing never throws. A profile with offsets or sizes outside it, a missing signature, or more bytes than MaxMetadataBytes is marked damaged; what could be read is available, and ToBytes() returns the bytes given.

Parse(ReadOnlySpan<byte>, SafetyLimits?)

Reads an ICC profile. Never throws: a profile larger than MaxMetadataBytes is kept but not read, and anything outside the bytes given is skipped; either way the profile is marked damaged.

public static IccData Parse(ReadOnlySpan<byte> profile, SafetyLimits? limits = null)
