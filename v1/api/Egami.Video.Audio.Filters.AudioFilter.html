Class AudioFilter

Namespace
Egami.Video.Audio.Filters
Assembly
Egami.Video.dll

The base of Egami.Video's own audio filters. It takes the rate and channels from the first frame, converts every frame to F32Planar once on the way in, and queues the output. Inside an AudioFilterChain the converted frames pass from filter to filter without another copy, and filters that keep the length (gain, fades, pan) work on them in place. To write a filter of your own, implement IAudioFilter.

Examples

// Fade in over 2 s, then turn down 3 dB: frames of any format go in, F32 planar frames come out.
using AudioFilterChain chain = new AudioFilterChain(48000, ChannelLayout.Stereo)
    .Add(new AudioFade(FadeDirection.In, MediaTime.Zero, MediaTime.FromSeconds(2)))
    .Add(new Gain(-3));
foreach (AudioFrame frame in frames)
{
    chain.Send(frame);
    while (chain.TryReceive(out AudioFrame? output))
    {
        samples += output.SampleCount; // write it to an AudioWriter or encoder here
        output.Dispose();
    }
}

chain.Flush();
