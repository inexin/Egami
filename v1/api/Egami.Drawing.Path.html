Class Path

Namespace
Egami.Drawing
Assembly
Egami.Drawing.dll

An outline of contours made of lines, quadratic and cubic Bézier curves, with the FillRule that says which points it covers when filled. A path never changes after it is built, so one path can be drawn from many threads and kept by any canvas backend. Coordinates are float pixels, y down. Build one with PathBuilder or a shape helper such as Circle(Vector2, float).

Examples

// A path is built once and never changes, so it can be drawn many times and from many threads.
Path heart = new PathBuilder()
    .MoveTo(150, 60)
    .CubicTo(150, 30, 100, 20, 90, 60)
    .CubicTo(80, 100, 130, 130, 150, 160)
    .CubicTo(170, 130, 220, 100, 210, 60)
    .CubicTo(200, 20, 150, 30, 150, 60)
    .Close()
    .ToPath();
canvas.FillPath(heart, Rgba8.Red);

// SVG's arc command, and the even-odd rule: an inner contour becomes a hole.
Path frame = new PathBuilder()
    .AddRect(new RectF(10, 10, 60, 60))
    .AddCircle(new Vector2(40, 40), 20)
    .MoveTo(10, 120)
    .ArcTo(radii: new Vector2(30, 20), rotationDegrees: 0, largeArc: false, clockwise: true, end: new Vector2(70, 120))
    .Close()
    .ToPath(FillRule.EvenOdd);
canvas.FillPath(frame, Rgba8.Black);

bool hit = heart.Contains(new Vector2(150, 100));   // hit testing on the curves themselves
RectF box = heart.TightBounds;                       // curves measured at their extremes

Examples

// A hand-drawn chart line: jittered the same way on every run, then its corners rounded.
Path data = Path.Polygon([new(10, 80), new(50, 30), new(90, 60), new(130, 20), new(170, 50)], close: false);
PathEffect sketchy = PathEffect.Jitter(segmentLength: 6, deviation: 1.5f, seed: 7).Then(PathEffect.Corner(3));
using Raster<Rgba8> chart = Raster.Create(180, 100, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = chart.CreateCanvas())
{
    canvas.StrokePath(data, new Stroke(2) { Effect = sketchy }, new Rgba8(40, 40, 40, 255));

    // Dots along the line, and hatching inside a circle.
    canvas.FillPath(data.Apply(PathEffect.Stamp(Path.Circle(Vector2.Zero, 2), advance: 12, style: StampStyle.Translate)), Rgba8.Black);
    canvas.FillPath(Path.Circle(new Vector2(150, 75), 20).Apply(PathEffect.Hatch(Matrix3x2.CreateScale(1, 5) * Matrix3x2.CreateRotation(0.6f), width: 1)), Rgba8.Black);
}

// A line that draws itself: trim it to a growing fraction of its length, frame by frame.
Path frame30 = data.Apply(PathEffect.Trim(0, 0.3f));

Combine(IEnumerable<Path>, PathOp, float)

Combines any number of paths with one operation in a single pass, as if it were applied in order, left to right: ((a op b) op c) and so on. Far faster than chaining Op(Path, PathOp, float) for many paths, since every outline is cut and sorted once. The result is as Op(Path, PathOp, float) describes.

public static Path Combine(IEnumerable<Path> paths, PathOp op, float tolerance = 0.05)

Parameters

paths IEnumerable<Path>

The paths; each keeps its own fill rule.

op PathOp

The operation.

tolerance float

How close, in path units, points must be to count as the same, as Op(Path, PathOp, float) describes.

Returns

Path

The combined path; empty when there are no paths.

Examples

// A frame: one round rectangle cut out of another, kept as curves, so a PDF or SVG backend writes it exactly.
Path frame = Path.RoundRect(new RoundRect(new RectF(0, 0, 200, 140), 24))
    .Difference(Path.RoundRect(new RoundRect(new RectF(20, 20, 160, 100), 12)));

// Many shapes in one pass, applied left to right; overlaps and self-intersections removed; an area grown by 4 units.
Path dots = Path.Combine([Path.Circle(new Vector2(40, 40), 30), Path.Circle(new Vector2(80, 40), 30), Path.Circle(new Vector2(60, 75), 30)], PathOp.Union);
Path clean = Path.Star(new Vector2(50, 50), 45, 20, 5).Simplify();
Path halo = dots.Inflate(4, LineJoin.Round);

Exceptions

ArgumentOutOfRangeException

op is not defined, or tolerance is not positive and finite.

Inflate(float, LineJoin, float)

Returns the area grown outwards by a distance, or for a negative distance shrunk inwards: the union of the path and the outline of a pen twice the distance wide, or the difference. Corners grow by the join: round keeps the distance everywhere, miter keeps them sharp up to the miter limit. Open contours count as closed, as fills close them. The grown or cut parts are straight pieces within a hundredth of the distance (at most a tenth of a unit); the rest keeps its curves.

public Path Inflate(float distance, LineJoin join = LineJoin.Round, float miterLimit = 4)

Parameters

distance float

How far to grow; negative to shrink.

join LineJoin

How grown corners look.

miterLimit float

The longest miter, in multiples of twice the distance, as MiterLimit defines it.

Returns

Path

The offset path, simplified; empty when it shrinks away.

Op(Path, PathOp, float)

Combines this path's area with another's. Each keeps its own fill rule; open contours count as closed, as fills close them. The result keeps the inputs' lines, quadratics and cubics, split exactly where outlines cross, so it is exact for PDF and SVG output; its outer contours run clockwise on screen and its holes counterclockwise, with the nonzero fill rule, and none of them cross.

public Path Op(Path other, PathOp op, float tolerance = 0.05)

Parameters

other Path

The other path.

op PathOp

The operation.

tolerance float

How close, in path units, points must be to count as the same: crossings are found to well within it, and ends, crossings and curves closer than it merge, which keeps nearly touching or overlapping outlines from making slivers. A caller who will draw the result ten times larger passes a tenth of it.

Returns

ParseSvg(ReadOnlySpan<char>, FillRule, bool)

Reads SVG path data, the grammar of an SVG d attribute (SVG 1.1 and SVG 2): every command (M, L, H, V, C, S, Q, T, A, Z and their relative forms), implicit repeats, compact numbers such as 0.5.5 and arc flags without separators. Arcs become cubic curves, as ArcTo(Vector2, float, bool, bool, Vector2) makes them. Empty or blank data is an empty path.

public static Path ParseSvg(ReadOnlySpan<char> data, FillRule fillRule = FillRule.NonZero, bool lenient = false)

Parameters

data ReadOnlySpan<char>

The path data.

fillRule FillRule

The fill rule of the path; SVG's fill-rule is not part of the data.

lenient bool

Whether to keep every complete command before the first error instead of throwing, as SVG tells renderers to draw a path with an error in it.

Returns

Path

The path.

Examples

// An icon from SVG path data, drawn four times larger, and written back as compact relative data.
Path heart = Path.ParseSvg("M12 21.35l-1.45-1.32C5.4 15.36 2 12.28 2 8.5 2 5.42 4.42 3 7.5 3c1.74 0 3.41.81 4.5 2.09" +
                           "C13.09 3.81 14.76 3 16.5 3 19.58 3 22 5.42 22 8.5c0 3.78-3.4 6.86-8.55 11.54L12 21.35z");
string d = heart.Transform(Matrix3x2.CreateScale(4)).ToSvg(new SvgPathFormat { Relative = true, Compact = true });

// Untrusted data: TryParseSvg says whether it is valid; lenient keeps what comes before an error, as browsers draw it.
bool valid = Path.TryParseSvg("M0 0 L10 10 L20", out Path? strict);
Path drawn = Path.ParseSvg("M0 0 L10 10 L20", lenient: true);
try
{
    Path.ParseSvg("M0 0 X");
}
catch (SvgPathException e)
{
    Console.WriteLine($"{e.Problem} at character {e.Position}");
}

Exceptions
