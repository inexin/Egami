Helpers for AV1 packets, which hold a temporal unit of low-overhead OBUs (AV1 specification section 5, each OBU with its size field): split a unit into its frames and merge them back, and build the av1C configuration record MP4 and Matroska store for a track.

Examples

// An AV1 packet is a temporal unit: split it into its frames and join them back; build the av1C an MP4 or Matroska
// track needs from its sequence header.
using IDemuxer demuxer = MediaFile.OpenDemuxer("clip-av1.ivf");
using EncodedPacket packet = demuxer.ReadPacket()!;
IReadOnlyList<ReadOnlyMemory<byte>> frames = Av1Packets.SplitFrames(packet.Data);
byte[] unit = Av1Packets.MergeFrames(frames);
byte[]? av1C = Av1Packets.ExtractConfig(packet.Data.Span);
Console.WriteLine($"{frames.Count} frames, av1C of {av1C?.Length} bytes");

Methods

ExtractConfig(ReadOnlySpan<byte>)

Builds the av1C configuration record (AV1 Codec ISO Media File Format Binding section 2.3) from the first sequence header OBU in obus: version 1, seq_profile, seq_level_idx_0, seq_tier_0, high_bitdepth, twelve_bit, monochrome, chroma_subsampling_x and _y and chroma_sample_position from the header, no initial_presentation_delay, then the sequence header OBU itself (with its size field). This is the CodecPrivate of an AV1 track in MP4, Matroska and WebM.

SplitFrames(ReadOnlyMemory<byte>)

Splits a temporal unit into its frames, as FFmpeg's av1_frame_split filter does: each part holds one frame header (or frame OBU) and its tile groups. A temporal delimiter, sequence header, metadata or padding OBU goes with the frame after it, and any after the last frame with that frame. A frame shown again with show_existing_frame is a part of its own. The parts are slices of temporalUnit, in order, so MergeFrames(IEnumerable<ReadOnlyMemory<byte>>) gives the unit back.
