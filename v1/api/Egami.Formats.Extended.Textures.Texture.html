Class Texture

Namespace
Egami.Formats.Extended.Textures

A whole GPU texture: every array layer, cube face and depth slice at every mip level, loaded from DDS, KTX or KTX 2, edited image by image, and saved to DDS or KTX 2 with exactly the mips it holds. Each image is a Raster in the pixel type the reader gives the format; the texture owns them and disposes them with itself.

Examples

// Every layer, face, depth slice and mip of a DDS, KTX or KTX 2 file.
using Texture sky = Texture.Load("sky.ktx2");
Console.WriteLine($"{sky.Width}×{sky.Height}, {sky.Layers} layer(s) of {sky.Faces} face(s), {sky.MipLevels} mips");

// Edit one face, make the mips again from mip 0, and save to DDS or KTX 2 with exactly those mips.
Raster top = sky.GetImage(mip: 0, face: 2);
sky.SetImage(top.Derive(x => x.Grayscale(), CancellationToken.None), mip: 0, face: 2);
sky.GenerateMips(colorSpace: ColorSpace.Linear);
sky.Save("sky-edited.dds", new DdsWriterOptions { Format = DdsTextureFormat.Bc7 });
sky.Save("sky-edited.ktx2", new Ktx2WriterOptions { Format = KtxTextureFormat.Bc7 });

// Or build one from images: here a texture array of two layers with its mip chain.
using Texture array = Texture.FromSurfaces([Raster.Load("duck.png"), Raster.Load("duck.png")]);
array.GenerateMips();
array.Save("ducks.ktx2");

Remarks

A 2D texture, texture array or cube map has Layers × Faces surfaces, each with a chain of MipLevels images halving down. A volume texture (IsVolume) has Depth slices at mip 0, and half as many (at least one) at each mip after it, as both file formats store it.

GenerateMips(int, ColorSpace)

Replaces the mips after mip 0 with new ones made from it with MipChain: each the average of 2 × 2 blocks of premultiplied pixels of the level before, down to 1 × 1 or to mipLevels levels.

public void GenerateMips(int mipLevels = 0, ColorSpace colorSpace = ColorSpace.Encoded)

Parameters

mipLevels int

How many levels to keep in all, mip 0 included: 0 (the default) for the full chain.

colorSpace ColorSpace

Where to average: Encoded (the default) as the values are stored, or Linear in linear light, right for sRGB colour.

Exceptions

NotSupportedException

The texture is a volume, whose mips would average slices too.

Save(Stream, FormatInfo, WriterOptions?)

Saves the texture with every image and mip it holds, in Info or Info. The options choose the format, effort and so on as for a raster; their mip count, when not 0, keeps only that many of the texture's mips, and their cube flag is ignored: the texture's own layout is written.

public void Save(Stream output, FormatInfo format, WriterOptions? options = null)

Parameters

output Stream

The stream.

format FormatInfo

Info or Info.

options WriterOptions

DdsWriterOptions or Ktx2WriterOptions, or null for the defaults.

Examples

// Every layer, face, depth slice and mip of a DDS, KTX or KTX 2 file.
using Texture sky = Texture.Load("sky.ktx2");
Console.WriteLine($"{sky.Width}×{sky.Height}, {sky.Layers} layer(s) of {sky.Faces} face(s), {sky.MipLevels} mips");

// Edit one face, make the mips again from mip 0, and save to DDS or KTX 2 with exactly those mips.

sky.GenerateMips(colorSpace: ColorSpace.Linear);
sky.Save("sky-edited.dds", new DdsWriterOptions { Format = DdsTextureFormat.Bc7 });
sky.Save("sky-edited.ktx2", new Ktx2WriterOptions { Format = KtxTextureFormat.Bc7 });

Exceptions

NotSupportedException

The format is not DDS or KTX 2, or DDS is asked to hold an array of volumes.
