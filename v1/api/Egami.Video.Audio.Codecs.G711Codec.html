Class G711Codec

Namespace
Egami.Video.Audio.Codecs

G.711 (ITU-T G.711) μ-law and A-law, decode only: one byte per sample, expanded to 16-bit samples by the standard's tables. Read from WAV (format tags 7 and 6), AVI, AIFF-C (ulaw, alaw) and MP4/MOV. Each instance decodes both laws. Frames come out interleaved as S16.

Examples

// AIFF holds big-endian PCM; remuxing turns WAV's samples around without decoding. Metadata goes into its text chunks.
MediaFile.Remux("tone.wav", "tone.aiff");
using (AudioWriter writer = AudioWriter.Create("titled.aiff", new AudioWriterOptions
{
    Metadata = new MediaMetadata { Tags = new Dictionary<string, string> { ["TITLE"] = "Tone" } },
}))
{
    writer.Write(tone);
}

// AIFF-C's G.711 (ulaw, alaw), sowt and float samples decode like any other track.
using AudioReader reader = AudioReader.Open("titled.aiff");
Console.WriteLine($"{reader.Track.CodecId}: {reader.Track.SampleRate} Hz, {MediaFile.Probe("titled.aiff").Tags["TITLE"]}");

Examples

// The same send and receive loop as video, for the track the encoder describes (or one a demuxer read).
using IAudioDecoder decoder = AudioCodecs.CreateDecoder(encoder.Track);
long decoded = 0;
foreach (EncodedPacket packet in packets)
{
    using (packet)
    {
        decoder.Send(packet);
    }

    while (decoder.TryReceive(out AudioFrame? frame))
    {
        using (frame)
        {
            decoded += frame.SampleCount;
        }
    }
}

// FLAC decodes to its own integers: S16Planar up to 16 bits, S32Planar above.
