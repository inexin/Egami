Class Resampler

Namespace
Egami.Video.Audio
Assembly
Egami.Video.dll

Converts audio between any two sample rates with a polyphase windowed-sinc filter (Kaiser window). The filter's phases come from the rate ratio reduced to lowest terms; when that needs more than 1024 phases (as for unusual rates), coefficients between 1024 precomputed phases are interpolated. It works in 32-bit float and keeps time exact: the first output sample has the first input sample's timestamp and every later one follows at the output rate, so a resampled track stays in sync. Frames of any length and format go in through Send(AudioFrame); frames come out through TryReceive(out AudioFrame?), in OutputFormat and OutputLayout, so conversion and channel mixing run in the same pass.

Examples

// 48 kHz to 44.1 kHz with the default quality (100 dB stopband); frames go in and come out like a codec's.
using Resampler resampler = new(48000, 44100, ChannelLayout.Stereo, ResamplerQuality.Good);
resampler.Send(tone);
resampler.Flush();
long samples = 0;
while (resampler.TryReceive(out AudioFrame? frame))
{
    using (frame)
    {
        samples += frame.SampleCount;
    }
}
