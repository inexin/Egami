Class Gate

Namespace
Egami.Video.Audio.Filters
Assembly
Egami.Video.dll

Turns the level down below a threshold, like ffmpeg's agate, to keep hiss and room noise out of the pauses: a level 1 dB under the threshold comes out Ratio dB under it, but never more than Range down. Attack sets how fast the gate opens when the level rises and Release how fast it closes. Every channel gets the same gain, from the loudest one.

Examples

// A voice chain: gate the room noise, even out the level 4:1 above -20 dBFS, then keep true peaks under -1 dBTP.
using AudioFilterChain chain = new AudioFilterChain(48000, ChannelLayout.Stereo)
    .Add(new Gate { Threshold = -50, Range = -20 })
    .Add(new Compressor { Threshold = -20, Ratio = 4, Makeup = 4 })
    .Add(new Limiter { Ceiling = -1, TruePeak = true });
