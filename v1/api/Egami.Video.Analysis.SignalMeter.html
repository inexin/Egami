Class SignalMeter

Namespace
Egami.Video.Analysis
Assembly
Egami.Video.dll

Measures the signal, as ffmpeg's signalstats and colordetect do: the lowest, 10th percentile, mean, 90th percentile and highest code values of Y, Cb and Cr; chroma saturation; the share of pixels outside broadcast range (16 to 235 for luma, 16 to 240 for chroma, scaled to the bit depth); which range the samples really use; and whether an alpha plane is used and how. With Blur and Blockiness it also scores sharpness and coding blocks, as blurdetect and blockdetect do.

Examples

// Levels, saturation and broadcast range as signalstats gives them, the range really used, and optional blur and
// blockiness scores.
SignalMeter meter = new(new SignalOptions { Blur = true, Blockiness = true });
MediaAnalysis.Run("shots.mkv", new MediaAnalysisOptions { Scenes = null, VideoDetectors = [meter] });
SignalReport report = meter.Report;
Console.WriteLine($"Y {report.Y.Min}..{report.Y.Max} (mean {report.Y.Mean:0.0}), {report.OutOfRange:P1} out of range, {report.Range} range");
Console.WriteLine($"Edges {report.Blur:0.00} px wide, blockiness {report.Blockiness:0.00}");
