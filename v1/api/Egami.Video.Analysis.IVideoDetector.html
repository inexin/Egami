Interface IVideoDetector

Namespace
Egami.Video.Analysis
Assembly
Egami.Video.dll

A detector that looks at decoded pictures one at a time, such as SceneDetector. Feed it every frame in presentation order with Add(YuvVideoFrame), then call Complete(MediaTime) once at the end; Run(string, MediaAnalysisOptions?, MediaContext?, IProgress<MediaProgress>?, CancellationToken) does both for every detector from one decode, and an app with its own decode loop can do the same. A detector reads the frame while Add(YuvVideoFrame) runs and keeps no reference to it, so the caller may dispose the frame right after.

public interface IVideoDetector

Examples

// A detector takes frames in time order; this one finds the darkest frame. The scene detector can run on its own too.
DarkestFrame darkest = new();
SceneDetector scenes = new(new SceneOptions { Method = SceneMethod.Histogram });
using (VideoReader reader = VideoReader.Open("shots.mkv"))
{
    foreach (YuvVideoFrame frame in reader.ReadFrames())
    {
        using (frame)
        {
            darkest.Add(frame);
            if (scenes.Add(frame) is { } cut)
            {
                Console.WriteLine($"Cut at frame {cut.Frame}");
            }
        }
    }

    scenes.Complete(reader.Info.Duration ?? MediaTime.Zero);
}

Console.WriteLine($"Darkest frame at {darkest.Time.ToTimeSpan()}, {scenes.Scenes.Count} scenes");
