Class Canvas

Namespace
Egami.Drawing

A surface to draw paths, shapes, strokes and images on, through a current transform and clip. The canvas itself is abstract: RasterCanvas<TPixel> draws into pixels, and other backends (a PDF page, a recorder) keep the calls as vectors. Every public call is checked and tracked here (the transform, the clip bounds, the save stack) and then ends in exactly one protected On hook, which is all a backend overrides; hooks added in later versions get default bodies, so adding them never breaks a backend.

Coordinates are float pixels, y down; the pixel at (0, 0) covers the square from 0 to 1. Calls draw when they are made. A canvas is for one thread at a time; one large call may still spread its rows over several cores.

DrawAtlas(Raster, ReadOnlySpan<SpriteTransform>, ReadOnlySpan<RectF>, ReadOnlySpan<RgbaF32>, BlendMode, SamplingOptions?, RectF?, Paint?)

Samples near a sprite's edge may read the image just outside its source rectangle, as in Skia; leave a pixel of space between sprites when that matters.

// Pack the sprites once, then draw thousands of them in one call: each with its own place, turn, scale and tint.
using SpriteSheet sheet = SpriteSheet.Pack([spark, star], new SpritePackOptions { Padding = 1 });
Random random = new(7);
SpriteTransform[] transforms = new SpriteTransform[2000];
RectF[] sources = new RectF[transforms.Length];
RgbaF32[] tints = new RgbaF32[transforms.Length];

{
    Rect frame = sheet.Frames[i % 2];
    sources[i] = frame;
    transforms[i] = SpriteTransform.FromRotationScale(
        scale: 0.3f + random.NextSingle(),
        degrees: random.NextSingle() * 360,
        position: new Vector2(random.NextSingle() * 320, random.NextSingle() * 200),
        anchor: new Vector2(frame.Width / 2f, frame.Height / 2f));
    tints[i] = new RgbaF32(1, 0.5f + (random.NextSingle() / 2), random.NextSingle(), 0.8f);
}

using (RasterCanvas<Rgba8> canvas = raster.CreateCanvas())
{
    // Plus adds the sprites up, as light does.
    canvas.DrawAtlas(sheet.Image, transforms, sources, tints, BlendMode.Modulate, paint: new SolidPaint(Rgba8.White) { BlendMode = BlendMode.Plus });
}

DrawMesh(Mesh, Paint?, BlendMode, ReadOnlySpan<GradientStop>)

Draws a triangle mesh. The triangles' union is filled once, with antialiasing on its outer edges only, so meshes show no cracks between triangles; where triangles overlap, the later one's color shows. Each pixel's color comes from its triangle: the paint (mapped through the texture coordinates when the mesh has them), combined with the interpolated vertex color by colorBlend, the vertex color as the destination and the paint as the source. A solid paint's color is not used when the mesh has colors or values, as in Skia: its alpha scales them. Vertex colors interpolate in the canvas's color space, premultiplied; values interpolate and then look up valueStops.

public void DrawMesh(Mesh mesh, Paint? paint = null, BlendMode colorBlend = BlendMode.Modulate, ReadOnlySpan<GradientStop> valueStops = default)

Parameters

The mesh, in local coordinates.

paint Paint

The paint, with the blend mode, opacity and antialiasing of the whole mesh; an opaque white solid paint when null, which draws the vertex colors as they are.

colorBlend BlendMode

How the vertex colors combine with the paint.
