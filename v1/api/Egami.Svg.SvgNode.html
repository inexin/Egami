A node of a document's render tree: the elements resolved for drawing, with styles applied, units in pixels, use expanded, references linked and shapes turned into paths, as resvg's usvg tree. It is immutable, so a document that is not being edited can be drawn on many threads at once.

Examples

// The resolved tree: groups, paths with their paints and strokes, images; styles applied and units in pixels.
static void Walk(SvgNode node, int depth)
{
    string what = node switch
    {
        SvgPath path => $"path {path.Path.Bounds} fill {path.Fill}",
        SvgGroup group => $"group of {group.Children.Count}",
        SvgImage image => $"image {image.Destination}",
        _ => node.GetType().Name,
    };
    Console.WriteLine($"{new string(' ', depth * 2)}{node.Id} {what} opacity {node.Opacity}");
    if (node is SvgGroup g)
    {
        foreach (SvgNode child in g.Children)
        {
            Walk(child, depth + 1);
        }
    }
}

Walk(document.RenderTree, 0);

Remarks

RenderTree builds the tree on first use after a load or an edit and caches it. Drawing walks it and calls only the public canvas API, so a raster canvas, a PDF page, SvgCanvas and a PictureRecorder receive the same calls. A later 1.x release may add node kinds, so a switch over nodes should keep a default case.
