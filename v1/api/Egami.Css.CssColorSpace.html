The color spaces of CSS Color 4 that a CssColor keeps its components in: the space its text was written in.

public enum CssColorSpace

Fields

A98Rgb = 3

Adobe RGB (1998)-compatible: red, green, blue. color(a98-rgb ...).

DisplayP3 = 2

Display P3, with the sRGB transfer function: red, green, blue. color(display-p3 ...).

Lab = 8

CIE Lab (D50): lightness 0 to 100, a, b. lab().

Lch = 9

CIE LCH, the polar form of Lab: lightness, chroma, hue in degrees. lch().

Oklab = 10

Oklab: lightness 0 to 1, a, b. oklab().

Oklch = 11

OkLCh, the polar form of Oklab: lightness, chroma, hue in degrees. oklch().

ProPhotoRgb = 4

ProPhoto RGB, D50 white: red, green, blue. color(prophoto-rgb ...).

Rec2020 = 5

ITU-R BT.2020: red, green, blue. color(rec2020 ...).

Srgb = 0

sRGB, gamma-encoded: red, green, blue. color(srgb ...) and every legacy syntax.

SrgbLinear = 1

Linear-light sRGB: red, green, blue. color(srgb-linear ...).

XyzD50 = 6

CIE XYZ relative to a D50 white: X, Y, Z. color(xyz-d50 ...).

XyzD65 = 7

CIE XYZ relative to a D65 white: X, Y, Z. color(xyz-d65 ...) and color(xyz ...).

Examples

// The color keeps the space it was written in, unclipped; R, G and B are the clipped sRGB.
bool isColor = CssColor.TryParse("color(display-p3 1 0.5 0)", out CssColor orange);
CssColorSpace space = orange.Space;                       // DisplayP3
double red = orange.C0;                                   // 1
bool inSrgb = orange.IsInSrgbGamut;                       // false: sRGB cannot show it

// Convert to any CSS Color 4 space, or build one in code.
(double l, double c, double h) = orange.ToColorSpace(CssColorSpace.Oklch);
CssColor lab = CssColor.FromColorSpace(CssColorSpace.Lab, 60, 40, 70, alpha: 0.5);

// CSS Color 4 gamut mapping lowers chroma until it fits, instead of clipping each channel.
CssColor mapped = orange.ToSrgbGamutMapped();
string text = orange.ToString(keepSpace: true);           // "color(display-p3 1 0.5 0)"
string legacy = orange.ToString();                        // "rgb(255, 117, 0)": clipped sRGB, as before

Remarks

Hex colors, named and system colors, rgb(), hsl() and hwb() are all Srgb, as CSS Color 4 defines them. The components of each space are the ones its CSS function takes, as numbers: 0 to 1 for the RGB spaces (beyond for colors outside their gamut), X, Y and Z with Y = 1 for white, Lab lightness from 0 to 100, Oklab lightness from 0 to 1, and hues in degrees.
