Enum Speakers

Namespace
Egami.Video.Audio
Assembly
Egami.Video.dll

Speaker positions, with the bit values of WAVE_FORMAT_EXTENSIBLE's channel mask. Channels in a ChannelLayout come in the order of these bits, lowest first, which is the order WAV and FLAC store them in.

[Flags]
public enum Speakers : uint

Fields

BackCenter = 256

Back center.

BackLeft = 16

Back left (the surround left of 5.1 in WAV order).

BackRight = 32

Back right (the surround right of 5.1 in WAV order).

FrontCenter = 4

Front center.

FrontLeft = 1

Front left.

FrontLeftOfCenter = 64

Front left of center.

FrontRight = 2

Front right.

FrontRightOfCenter = 128

Front right of center.

LowFrequency = 8

Low-frequency effects (the subwoofer, the ".1").

No speaker.

TopCenter = 2048

TopFrontCenter = 8192

TopFrontRight = 16384

Examples

// Channels come in WAVE_FORMAT_EXTENSIBLE order whatever the codec stored: 5.1 is FL, FR, FC, LFE, BL, BR.
ChannelLayout layout = ChannelLayout.Surround51;
int lfe = layout.IndexOf(Speakers.LowFrequency);
Speakers fourth = layout.GetSpeaker(3);
ChannelLayout custom = new(Speakers.FrontLeft | Speakers.FrontRight | Speakers.TopFrontLeft | Speakers.TopFrontRight);
ChannelLayout ambisonic = ChannelLayout.Unpositioned(4);
