Class Metafile

Namespace
Egami.Metafiles
Assembly
Egami.Metafiles.dll

A Windows metafile, WMF, EMF or EMF+ (and their gzip forms WMZ and EMZ), read and checked; its records stay internal (design question 3). The size facts come from the header: an EMF's frame, a placeable WMF's box and units per inch, or a plain WMF's window extent at 96 DPI. A metafile is immutable and safe to read from many threads.

Methods

Draw(Canvas, RectF?, MetafileRenderOptions?)

Draws the picture on a canvas: in points from the canvas's origin (the frame's corner there), or with its frame stretched to box exactly, as Word stretches a picture to its frame. Drawing calls only the public canvas API, so a raster canvas, a PDF page, SvgCanvas or a PictureRecorder receive the same calls. It never throws on content: what it cannot draw is skipped and reported to the context's diagnostics.

public void Draw(Canvas canvas, RectF? box = null, MetafileRenderOptions? options = null)

Parameters

canvas Canvas

The canvas.

box RectF?

The rectangle to stretch the frame to, in the canvas's coordinates, or null.

options MetafileRenderOptions

Fonts, antialiasing and playback, or null for the defaults.

Examples

Metafile picture = Metafile.Load(path);

// The frame is stretched to the box, as Word stretches a picture to its frame. The same calls draw on a PDF page.
using Raster<Rgba8> page = Raster.Create<Rgba8>(400, 300);
using RasterCanvas<Rgba8> canvas = page.CreateCanvas();
canvas.Clear(new RgbaF32(1, 1, 1, 1));
picture.Draw(canvas, new RectF(50, 50, 300, 200));

Load(Stream, MetafileLoadOptions?)

Reads a WMF, EMF, WMZ or EMZ stream from its current position to its end.

public static Metafile Load(Stream stream, MetafileLoadOptions? options = null)

Parameters

stream Stream

The stream; it is read to its end and left open.

options MetafileLoadOptions

How to read it, or null for the defaults.

Returns

Metafile

The metafile.

Examples

// Untrusted files: the context's limits bound the file size and what EMZ and WMZ inflate to; a record that runs past
// the end is skipped with a warning, and what came before it plays.
MetafileLoadOptions options = new()
{
    Context = EgamiContext.Default with { Limits = SafetyLimits.Default with { MaxTotalBytes = 16 << 20 } },
};
Metafile picture = Metafile.Load(new MemoryStream(bytes), options);
if (picture.Kind is MetafileKind.EmfPlusDual or MetafileKind.EmfPlusOnly)
{
    Console.WriteLine("Drawn by its EMF+ records, as GDI+ draws it.");
}

Exceptions

CorruptDataException

The data is no WMF or EMF file, or its header is broken.

LimitExceededException

The data, or an EMZ or WMZ stream once inflated, is larger than the context's MaxTotalBytes.
