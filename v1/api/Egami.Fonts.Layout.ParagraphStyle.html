How a paragraph is laid out: its default text style, direction, alignment, line breaking, line filling, hyphens, ellipsis and line limits, line box rules, tabs and writing mode. The defaults follow CSS: start-aligned, greedy filling, normal line height, tab stops every 8 spaces, horizontal lines.

Examples

// Font families come from a collection; later families cover what the first lacks.
FontCollection fonts = new();
fonts.AddFile(System.IO.Path.Combine(folder, "NotoSans-Regular.ttf"));
fonts.AddFile(System.IO.Path.Combine(folder, "NotoSansArabic-Regular.ttf"));
fonts.TryGetFamily("Noto Sans", out FontFamily latin);
fonts.TryGetFamily("Noto Sans Arabic", out FontFamily arabic);

// Styles nest: the inner span keeps the outer one's size and adds a color and an underline.
RichText text = new RichTextBuilder()
    .Append("Peace is ")
    .Push(new TextStyle { Size = 20 })
    .Append("\u0633\u0644\u0627\u0645 ")
    .Push(new TextStyle { Color = new Rgba8(200, 30, 30, 255), Decoration = new TextDecoration() })
    .Append("in Arabic")
    .Pop()
    .Pop()
    .AddPlaceholder(new Placeholder(16, 16, PlaceholderAlignment.Middle))
    .ToRichText();

ParagraphStyle style = new()
{
    DefaultStyle = new TextStyle { FontFamilies = [latin, arabic], Size = 16, LineHeight = LineHeight.Multiple(1.4f) },
    Align = TextAlign.Justify,
    LineBreaking = new LineBreakOptions(WordBreak: WordBreak.Normal),
};

// Shaped once: lay it out at any width later.
Paragraph paragraph = Paragraph.Create(text, style);

Examples

ParagraphStyle style = new()
{
    DefaultStyle = new TextStyle { FontFamilies = [fonts.Families[0]], Size = 16, Language = "en-US" },
    Align = TextAlign.Justify,
    Hyphens = Hyphens.Auto,                    // CSS hyphens: auto
    Hyphenation = new HyphenationOptions
    {
        Dictionaries = HyphenationDictionaries.BuiltIn,  // 35 languages, each loaded on first use
        MinWordLength = 6,                     // shorter words stay whole
        MaxConsecutiveLines = 2,               // Word's consecutiveHyphenLimit
        Zone = 18,                             // Word's hyphenationZone: 0.25 inch in points
    },
};

TextLayout layout = Paragraph.Create(
    "Typographers traditionally hyphenate justified paragraphs, because otherwise extraordinarily long words "
    + "leave conspicuous rivers of whitespace.", style).Layout(150);

Property Value

JustifyLineBreaks

Gets whether, in a justified paragraph, a line that ends in a hard break other than U+2029 PARAGRAPH SEPARATOR (LF, CR, CRLF, VT, FF, NEL or U+2028) is justified like a wrapped line, as Word justifies the line before a manual line break (Shift+Enter) unless a document sets doNotExpandShiftReturn. Off by default, as CSS lays such lines out like the last line. When on, and Align justifies and Justify is not None, such lines stretch to the width (or, with SpaceShrink, shrink and stretch as any justified line), and Optimal weighs their stretch as it weighs other lines'; a line without justification opportunities stays at the start, and HardBreak is still true. The paragraph's last line, and lines before U+2029, keep AlignLast; a hard break at the very end of the text adds no empty line, so the line before it is the last line.

public bool JustifyLineBreaks { get; init; }

Property Value

bool

Examples

// Justified as Word lays out Shift+Enter: the line before a line break stretches like a wrapped line, and no-break
// spaces keep their width.
ParagraphStyle style = new()
{
    DefaultStyle = new TextStyle { FontFamilies = [family], Size = 16 },
    Align = TextAlign.Justify,
    JustifyLineBreaks = true,       // lines before LF, CRLF, U+2028 ... stretch; U+2029 and the last line do not
    StretchNoBreakSpaces = false,   // U+00A0 keeps its width
};
string text = "Deliver 10\u00A0kg of flour\nto the mill by Friday.";
TextLayout layout = Paragraph.Create(text, style).Layout(300);

SpaceShrink

Gets how far word spaces on justified lines may shrink to fit more on a line, as a share of their width: from 0 (the default, never) to 1. A line that overflows the width still fits when its word spaces (U+0020 and the other word separators, but not the no-break space U+00A0) need to shrink by no more than this share in all, and each by no more than half of what it would stretch had the line ended at the break before, as Word fills justified lines; the next word is kept whole by shrinking before automatic hyphenation is tried. Such lines are drawn with their word spaces shrunk evenly; glyphs and letter spacing keep their widths. It applies to lines Align or AlignLast justifies and, in a justified paragraph, also to the last line and lines before a hard break, which shrink to fit but never stretch (unless JustifyLineBreaks justifies the latter). Only word spaces after a line's last tab shrink. Optimal uses it as its shrink limit (see ShrinkSpaces). Nothing shrinks when Justify is None.

public float SpaceShrink { get; init; }

Property Value

float

Examples

// Justified lines filled as Word fills them: a line takes the next word when its spaces can shrink by up to a quarter.
ParagraphStyle style = new()
{
    DefaultStyle = new TextStyle { FontFamilies = [family], Size = 16 },
    Align = TextAlign.Justify,
    SpaceShrink = 0.25f,
};
TextLayout layout = Paragraph.Create(text, style).Layout(200);

Exceptions

ArgumentOutOfRangeException

The value is less than 0, more than 1 or not a number.

StretchNoBreakSpaces

Gets whether the no-break space U+00A0 stretches on justified lines, as CSS makes it a word separator: true, the default. False keeps it at its width, as Word does, so text joined by it stays as set; it then takes no stretch on any justified line and counts for none in Optimal. SpaceShrink never shrinks it either way.
