A CSS color (CSS Color 4), or currentcolor: its components in the color space it was written in (Space, C0, C1, C2), and the same color converted to sRGB as red, green, blue and alpha from 0 to 1, gamma-encoded, each channel clipped to the sRGB gamut.

Examples

// Every CSS Color 4 syntax, converted to sRGB (0 to 1) and clipped to its gamut.
bool isColor = CssColor.TryParse("oklch(62.8% 0.258 29.2 / 50%)", out CssColor red);
(byte r, byte g, byte b, byte a) = red.ToRgba8();         // about (255, 0, 0, 128)
bool newer = red.Level == 4;                             // SVG 1.1 knows only level 3

bool isCurrent = CssColor.TryParse("currentColor", out CssColor current);  // current.IsCurrentColor: use the 'color' property
// The color keeps the space it was written in, unclipped; R, G and B are the clipped sRGB.
bool isColor = CssColor.TryParse("color(display-p3 1 0.5 0)", out CssColor orange);
CssColorSpace space = orange.Space;                       // DisplayP3
double red = orange.C0;                                   // 1
bool inSrgb = orange.IsInSrgbGamut;                       // false: sRGB cannot show it

// Convert to any CSS Color 4 space, or build one in code.
(double l, double c, double h) = orange.ToColorSpace(CssColorSpace.Oklch);
CssColor lab = CssColor.FromColorSpace(CssColorSpace.Lab, 60, 40, 70, alpha: 0.5);

// CSS Color 4 gamut mapping lowers chroma until it fits, instead of clipping each channel.
CssColor mapped = orange.ToSrgbGamutMapped();
string text = orange.ToString(keepSpace: true);           // "color(display-p3 1 0.5 0)"
string legacy = orange.ToString();                        // "rgb(255, 117, 0)": clipped sRGB, as before

Remarks

Level says which CSS Color level's syntax the text used, so a consumer that follows an older specification (such as SVG 1.1, which knows only CSS Color 3) can refuse the newer forms.

A color outside the sRGB gamut, such as color(display-p3 1 0 0), keeps its components unclipped; R, G and B clip each channel, and ToSrgbGamutMapped() maps it into the gamut as CSS Color 4 does instead. Two colors are equal when their space, components and alpha are, so color(display-p3 1 0 0) is not rgb(255 0 0).

ToSrgbGamutMapped()

Maps the color into the sRGB gamut as CSS Color 4 does (section 13.2, "CSS gamut mapping to an RGB destination"): it lowers the chroma in OkLCh, holding lightness and hue, until the color clipped to the gamut is within a just-noticeable difference (deltaEOK 0.02) of it. Colors in the gamut, and currentcolor, come back as they are.

public CssColor ToSrgbGamutMapped()

Returns

CssColor
