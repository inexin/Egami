Enum OpusRateMode

Namespace
Egami.Video.Audio.Codecs

How strictly the Opus encoder keeps its bitrate.

public enum OpusRateMode

Fields

Cbr = 2

Constant: every packet of a frame duration has the same size, for links that need that.

ConstrainedVbr = 1

Constrained variable: packets vary, but the rate over a short window stays near the bitrate, for streaming.

Vbr = 0

Variable: the bitrate is the average, and packets grow where the audio is harder. The best quality per bit.

Examples

// Speech at 32 kbit/s. Opus codes 8, 12, 16, 24 and 48 kHz, so this 44.1 kHz audio is resampled to 48 kHz; the
// header keeps 44.1 kHz as the rate the audio came at.
using (AudioWriter writer = AudioWriter.Create("voice.opus", new AudioWriterOptions
{
    Opus = new OpusEncoderOptions { Bitrate = 32_000, Application = OpusApplication.Voice },
}))
{
    writer.Write(tone);
}
