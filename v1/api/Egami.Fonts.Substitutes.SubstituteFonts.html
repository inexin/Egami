Class SubstituteFonts

Namespace
Egami.Fonts.Substitutes
Assembly
Egami.Fonts.Substitutes.dll

Open fonts that stand in for the fonts documents name most without embedding them, each metric-compatible with the font it replaces, so text keeps its line breaks: Liberation Sans for Helvetica and Arial, Liberation Serif for Times and Times New Roman, Liberation Mono for Courier and Courier New, Carlito for Calibri and Caladea for Cambria, each in regular, bold, italic and bold italic. All are under the SIL Open Font License 1.1 and ship inside this assembly, so they work whatever fonts are installed; a face is loaded the first time it is asked for.

Examples

// Bundled faces for the fonts documents name most, on any machine: Arial is Liberation Sans, Calibri is Carlito.
Typeface? arial = SubstituteFonts.Find("Arial", FontStyle.Bold);
Font body = new(SubstituteFonts.Find("Calibri", FontStyle.Normal)!, 11);

// All twenty faces as a collection, matched by family name and style.
FontMatch? mono = SubstituteFonts.Collection.Match("Liberation Mono", FontStyle.Italic);

Methods

Find(string, FontStyle)

The face that stands in for a font: by its family name or a common alias, spaces, hyphens and case ignored (Helvetica, Arial, ArialMT, Times-Roman, TimesNewRoman, Courier New, Calibri, Cambria, or the Liberation, Carlito and Caladea names themselves), in the style nearest to style: bold from weight 600, italic for any slant. null for any other name.
