Class RawVideoCodec

Namespace
Egami.Video.Codecs
Assembly
Egami.Video.dll

Uncompressed video (Uncompressed): I420, YV12, Y42B, 444P, Y800, NV12, NV21, YUY2, UYVY and v210 by FourCC (FourCC), plain planar YUV at 8 to 12 bits with optional alpha as in YUV4MPEG2, and AVI's bottom-up 24-bit BI_RGB (as VfwFourCC), whose frames come out as G, B and R planes (Identity). Decoding and encoding copy samples, so they are lossless.

CreateEncoder(VideoEncoderOptions, MediaContext)

Creates an encoder for planar frames. The layout is the first frame's chroma format, bit depth and alpha, named by FourCC when one exists (I420, Y42B, 444P, Y800); RGB frames are converted to 4:2:0 or ChromaFormat.

public override IVideoEncoder CreateEncoder(VideoEncoderOptions options, MediaContext context)

The picture size and frame rate.

Returns

Examples

// An encoder by hand: frames in, packets out, for a muxer of your own.
VideoEncoderOptions options = new() { Width = duck.Width, Height = duck.Height, FrameRate = new Rational(30, 1), Quality = 90 };
using IVideoEncoder encoder = MotionJpegCodec.Instance.CreateEncoder(options, MediaContext.Default);
using (VideoFrame<Rgb8> frame = new(Raster.Load<Rgb8>("duck.png"), MediaTime.Zero))
{
    encoder.Send(frame);
}

encoder.Flush();
List<EncodedPacket> packets = [];
while (encoder.TryReceive(out EncodedPacket? packet))
{
    packets.Add(packet);
}

// Uncompressed frames go the same way, losslessly.
using IVideoEncoder rawEncoder = RawVideoCodec.Instance.CreateEncoder(options with { ChromaFormat = ChromaFormat.Yuv444 }, MediaContext.Default);
