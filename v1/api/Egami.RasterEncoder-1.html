An image being written a band of rows or a frame at a time, so a huge image never has to exist whole. The bytes are the ones Save(Stream, FormatInfo, WriterOptions?) writes for the same pixels and options, except where a format must write differently without seeking: top-down BMP and TGA rows, and run-length TGA, which is always top-down. Options that need every pixel before the first byte (automatic palettes, PNG's Reduce, automatic alpha) throw at Create instead of quietly writing something else.

Examples

// A huge image written a band at a time: only the band is ever in memory.
const int Width = 8_000, Height = 6_000;
using Raster<Rgb8> band = Raster.Create<Rgb8>(Width, 64);
using RasterEncoder<Rgb8> encoder = RasterEncoder.Create<Rgb8>("big.png", Width, Height);
for (int top = 0; top < Height; top += band.Height)
{
    int rows = Math.Min(band.Height, Height - top);
    for (int y = 0; y < rows; y++)
    {
        band.Row(y).Fill(new Rgb8((byte)(top + y), 128, 200));
    }

    encoder.WriteRows(band, rows);
}

encoder.Complete(); // writes IEND; without it the file is deleted on dispose

Remarks

Write a still image with WriteRows(Raster<TPixel>, int), top to bottom, or an animation with WriteFrame(Raster<TPixel>, FrameMetadata?); then call Complete(), which writes what follows the image data. An encoder is one caller's object and is not thread-safe. Formats from plugins that do not stream gather the image and write it at Complete.

WriteFrame(Raster<TPixel>, FrameMetadata?)

Writes the next frame of an animation (GIF, APNG), with its delay from metadata. A format that holds one image takes one frame, written as the still image.

public void WriteFrame(Raster<TPixel> frame, FrameMetadata? metadata = null)

Parameters

frame Raster<TPixel>

The frame, Width × Height; its first frame is written.

metadata FrameMetadata

The frame's delay, or null for the frame's own metadata.

Examples

// An animation written a frame at a time, each frame from one reused canvas.
using Raster<Rgba8> canvas = Raster.Create<Rgba8>(120, 80);
using FileStream file = File.Create("spinner.gif");
using RasterEncoder<Rgba8> gif = RasterEncoder.Create<Rgba8>(file, GifFormat.Info, 120, 80);
for (int i = 0; i < 12; i++)
{
    for (int y = 0; y < canvas.Height; y++)
    {
        canvas.Row(y).Fill(new Rgba8(255, 255, 255, 255));
    }

    canvas.Row(40)[(i * 10)..((i * 10) + 10)].Fill(new Rgba8(200, 0, 0, 255));
    gif.WriteFrame(canvas, new Metadata.FrameMetadata { Delay = TimeSpan.FromMilliseconds(80) });
}

gif.Complete();

Exceptions

frame is null.

ArgumentException

frame is not Width × Height.

InvalidOperationException

Rows were written, the format holds one image and it was written, an APNG to a stream that cannot seek has no FrameCount, or the encoder is complete.

ObjectDisposedException

The encoder has been disposed.
