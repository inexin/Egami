A parsed XMP packet: its properties by namespace URI and local name, each a simple value, an XmpArray or an XmpStruct, with typed getters and setters for what apps ask for most (Dublin Core, XMP Basic, Photoshop and TIFF properties). An unedited packet writes back byte for byte; an edited one is written as canonical RDF/XML with padding, keeping every property it does not know, qualifiers included.

Examples

XmpData xmp = new()
{
    Title = "Harbour at dawn",
    Creators = ["A. Photographer"],
    Keywords = ["harbour", "Bergen"],
    Rating = 4,
};

// Any property, by namespace URI and local name; structures and arrays nest.
XmpStruct contact = new();
contact.Set(new XmpName(XmpNamespaces.IptcCore, "CiEmailWork"), "photo@example.com");
xmp.Set(new XmpName(XmpNamespaces.IptcCore, "CreatorContactInfo"), contact);
if (xmp.TryGet(new XmpName(XmpNamespaces.DublinCore, "title"), out object? title) && title is XmpArray languages)
{
    languages.SetLanguage("nb-NO", "Havn ved daggry");
}

ReadOnlyMemory<byte> packet = xmp.ToBytes();   // canonical RDF/XML with padding

Parse(ReadOnlySpan<byte>, SafetyLimits?)

Reads an XMP packet (RDF/XML, with or without its xpacket wrapper). Never throws: a packet that is not well-formed or is over MaxMetadataBytes is marked damaged and keeps its bytes. DTDs are refused and nothing is resolved, so external entities and entity expansion cannot run.

public static XmpData Parse(ReadOnlySpan<byte> packet, SafetyLimits? limits = null)

Parameters

packet ReadOnlySpan<byte>

The packet's bytes, UTF-8 or UTF-16.

limits SafetyLimits

The limits whose MaxMetadataBytes caps the packet. Defaults to Default.

Returns

XmpData

The parsed packet; IsDamaged says whether it was readable.

Examples

// An XMP packet from a sidecar file or a database; DTDs are refused and nothing outside it is read.
XmpData xmp = XmpData.Parse(packet.Span, SafetyLimits.Default with { MaxMetadataBytes = 1024 * 1024 });
Console.WriteLine(xmp.IsDamaged ? string.Join(" ", xmp.Warnings) : $"Label: {xmp.Label}");
