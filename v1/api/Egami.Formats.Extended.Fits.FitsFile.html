Class FitsFile

Namespace
Egami.Formats.Extended.Fits
Assembly
Egami.Formats.Extended.dll

A whole FITS file, for the numbers rather than a picture: every HDU's header cards, and an image's physical values, BZERO + BSCALE × stored, unstretched, with missing pixels (BLANK, NaN, damaged tiles, data past the file's end) as NaN. Tile-compressed images decode as plain ones. World coordinate (WCS) keywords are in the header; Egami does no sky coordinate math.

Examples

// FitsFile lists every HDU with its header, tables included, and reads an image's values in file order.
FitsFile file = FitsFile.Load("m51.fits");
foreach (FitsHdu hdu in file.Hdus)
{
    Console.WriteLine($"HDU {hdu.Index}: {hdu.Kind}, {string.Join(" × ", hdu.Axes)}");
}

FitsHdu image = file.FirstImage!;
double exposure = image.Header.GetReal("EXPTIME") ?? 0;
double[] counts = file.ReadValues(image);
using Raster<GrayF32> plane = file.ReadPlane(image);
