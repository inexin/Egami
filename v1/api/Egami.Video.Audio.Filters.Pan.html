Class Pan

Namespace
Egami.Video.Audio.Filters
Assembly
Egami.Video.dll

Places a mono or stereo input in a stereo output. Position pans a mono input with the constant-power law (-3 dB in each channel at the centre, like ffmpeg's pan=stereo|c0=0.7071c0|c1=0.7071c0); on a stereo input it turns one side down along the same law, scaled so the centre is unchanged. Balance turns one side down in a straight line. Swap exchanges left and right, and InvertLeft and InvertRight flip a channel's polarity. Changes to the position or balance between frames move over 5 ms. For any other channel matrix use ChannelMixer.

Examples

// A mono voice at 44.1 kHz over stereo music at 48 kHz, the music at half level: the voice is panned a little left,
// then resampled and placed by its timestamps on the way into the mixer.
using Pan pan = new(-0.3);
using AudioMixer mixer = new(48000, ChannelLayout.Stereo, inputs: 2);
mixer.SetWeight(0, 0.5);
foreach (AudioFrame frame in music)
{
    mixer.Send(0, frame);
}

foreach (AudioFrame frame in voice)
{
    pan.Send(frame);
    while (pan.TryReceive(out AudioFrame? panned))
    {
        mixer.Send(1, panned);
        panned.Dispose();
    }
}

mixer.Flush();
