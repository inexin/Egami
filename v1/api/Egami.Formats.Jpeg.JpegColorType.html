Which components a JPEG is written with.

public enum JpegColorType

Fields

Auto = 0

Gray for gray pixel types, CMYK for CMYK pixel types, YCbCr for everything else.

Cmyk = 2

Four CMYK components with an Adobe marker (transform 0), the values inverted as Photoshop writes them and every reader expects. Other pixel types are converted to ink with the plain formula. Auto picks this for CMYK pixel types.

Gray = 1

One gray component, whatever the pixel type; color is converted to luma.

Ycck = 3

Four YCCK components with an Adobe marker (transform 2): cyan, magenta and yellow converted to YCbCr as libjpeg converts Adobe CMYK, chroma subsampled as Subsampling says, and the inverted black at full size. Usually smaller than Cmyk.

Examples

using Raster photo = Raster.Load("duck.jpg", options: new JpegReaderOptions { FastUpsampling = true });
JpegDetails details = (JpegDetails)photo.Metadata.FormatDetails!;
Console.WriteLine($"{details.ColorSpace}, progressive: {details.Progressive}, quality about {details.EstimatedQuality}");
foreach (JpegComponent component in details.Components)
{
    Console.WriteLine($"Component {component.Id}: sampled {component.HorizontalSampling} × {component.VerticalSampling}");
}

// Gray output, and 4:4:4 (no chroma subsampling) for sharp colored edges.
photo.Save("gray.jpg", new JpegWriterOptions { ColorType = JpegColorType.Gray });
photo.Save("sharp.jpg", new JpegWriterOptions { Quality = 90, Subsampling = ChromaSubsampling.Subsample444 });
