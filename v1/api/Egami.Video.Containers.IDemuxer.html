Interface IDemuxer

Namespace
Egami.Video.Containers
Assembly
Egami.Video.dll

Reads a container's tracks and packets. Packets come in file order, interleaved across tracks.

public interface IDemuxer : IDisposable
Inherited Members
IDisposable.Dispose()

Examples

using IDemuxer demuxer = MediaFile.OpenDemuxer("in.avi");
demuxer.Seek(MediaTime.FromSeconds(30));
while (demuxer.ReadPacket() is { } packet)
{
    using (packet)
        Console.WriteLine($"{packet.TrackNumber} {packet.Timestamp} {(packet.IsKeyframe ? "key" : "")}");
}

Seek(MediaTime, int?)

Moves so that the next packet of the seek track is its last keyframe at or before time (or its first keyframe when time is earlier). Packets of other tracks follow from the same file position. Uses the container's index, building one with a single pass over the file when there is none.

void Seek(MediaTime time, int? trackNumber = null)

Parameters

time MediaTime

The target time.

trackNumber int?

The track to seek on, or null for the first video track (the first track when there is no video).

Exceptions

NotSupportedException

The stream is not seekable.
