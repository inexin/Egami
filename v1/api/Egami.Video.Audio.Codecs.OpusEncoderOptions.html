How the Opus encoder codes: the bitrate and how strictly it is kept, what the audio is, the frame duration, how hard the encoder searches, the widest band and the loss protection. Every one has a default that suits music and most speech.

Examples

// Speech at 32 kbit/s. Opus codes 8, 12, 16, 24 and 48 kHz, so this 44.1 kHz audio is resampled to 48 kHz; the
// header keeps 44.1 kHz as the rate the audio came at.
using (AudioWriter writer = AudioWriter.Create("voice.opus", new AudioWriterOptions
{
    Opus = new OpusEncoderOptions { Bitrate = 32_000, Application = OpusApplication.Voice },
}))
{
    writer.Write(tone);
}

Bitrate

Gets the bitrate in bits per second for all channels together, 500 to 2400000, or null (the default) for 64 kbit/s per channel. Opus codes 500 bit/s to 300 kbit/s per channel; a value outside that is clamped.

FrameDuration

Gets the audio in each packet: 2.5, 5, 10, 20, 40, 60, 80, 100 or 120 milliseconds. Default 20 ms. Shorter frames lower the delay and cost bits; longer ones save a little on speech.

public TimeSpan FrameDuration { get; init; }
