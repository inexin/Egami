Class FlacFormat

Namespace
Egami.Video.Containers
Assembly

Native FLAC files (.flac): "fLaC", the metadata blocks and the frames. STREAMINFO gives the track; Vorbis comments become Tags (a WAVEFORMATEXTENSIBLE_CHANNEL_MASK comment the track's layout) and pictures become attachments, the front cover named cover.*. Frames are found by their sync code, header CRC-8 and footer CRC-16, so each packet is one whole frame; seeking uses the seek table, or one pass over the frames when there is none. The writer stores STREAMINFO, tags, cover art and padding; on a seekable stream it fills in the frame sizes, total samples and MD5 at the end and turns part of the padding into a seek table with a point every 10 seconds.

Examples

// WAV, Wave64 and FLAC are containers like the others: remux PCM from WAV into Wave64 without decoding.
MediaFile.Remux("tone.wav", "tone.w64");
MediaInfo info = MediaFile.Probe("tone.w64");
AudioTrackInfo track = (AudioTrackInfo)info.Tracks[0];
Console.WriteLine($"{info.FormatName}: {track.CodecId}, {track.SampleRate} Hz, {track.BitsPerSample} bits, {track.Layout}");
