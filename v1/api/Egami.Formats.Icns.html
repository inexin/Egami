IcnsEntry

IcnsFormat

Apple's icon format, registered in Default. An icon family holds several images (entries) of different sizes: PNG or JPEG 2000 files, run-length encoded ARGB or RGB with an 8-bit mask, or the old 1, 4 and 8-bit icons with a 1-bit mask. Load returns the best entry, LoadAll every entry, and Save writes one PNG entry per raster or a set resized to Sizes.

IcnsReaderOptions

Options for reading ICNS.

IcnsWriterOptions

Options for writing ICNS. Each raster becomes one PNG entry, or one entry per size in Sizes; entries are 8-bit RGBA, sorted smallest first, and a table of contents comes first as macOS writes it. EXIF, XMP and IPTC are not written.
