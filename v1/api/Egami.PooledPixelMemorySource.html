The default IPixelMemorySource. Small blocks are arrays rented from a shared pool; larger blocks are unmanaged memory aligned to 64 bytes, which stays off the large object heap and suits SIMD. Planes larger than MaxBlockBytes are split into several blocks of whole rows.

Examples

// Every pixel buffer comes from the context's IPixelMemorySource; wrap the pooled one to count what it hands out.
CountingSource counting = new(PooledPixelMemorySource.Shared);
EgamiContext context = EgamiContext.Default with { Memory = counting };
using (Raster<Rgba8> image = Raster.Create<Rgba8>(512, 512, context))
{
    image.Apply(ops => ops.Blur(2));
}

Console.WriteLine($"{counting.Blocks} blocks, {counting.Bytes:N0} bytes");

Remarks

Unmanaged blocks are kept after use, up to MaxRetainedBytes, and reused by later allocations of a similar size, because memory fresh from the operating system is slow the first time it is written. Trim() frees what is kept.

MaxBlockBytes

Gets the largest block, in bytes, the source hands out in one piece. Planes bigger than this are split into several blocks, each holding whole rows. A single row larger than this still gets one block of its own.
