Examples

// Liang's patterns, as hyph-utf8's .pat.txt lists them; a .tex, .dic or .ehyp file loads with Hyphenator.Load.
Hyphenator hyphenator = Hyphenator.FromPatterns(
    ".hy3ph he2n hena4 hen5at 1na n2at 1tio 2io o2n",
    exceptions: "ta-ble",                      // exceptions break exactly where their hyphens are
    minBefore: 2, minAfter: 3);

Span<int> points = stackalloc int[16];
int count = hyphenator.GetPoints("Hyphenation", points);   // 2: offsets 2 and 6, "Hy-phen-ation"

// Compile once, load fast: the .ehyp form skips parsing the pattern text.
using MemoryStream compiled = new();
hyphenator.Save(compiled);
compiled.Position = 0;
Hyphenator loaded = Hyphenator.Load(compiled);
int tablePoints = loaded.GetPoints("table", points);       // 1: offset 2, "ta-ble"

Remarks

Load the patterns from a hyph-utf8 .tex file, a .pat.txt list, a LibreOffice .dic file or the compiled form Save(Stream) writes, or give them as text to FromPatterns(string, string?, int, int). A word in the exception list breaks exactly where the list says; any other word breaks where the patterns' highest value between two letters is odd. Either way no break leaves fewer than MinBefore characters before it or MinAfter after it.

A hyphenator is immutable and safe to share between threads; GetPoints(ReadOnlySpan<char>, Span<int>) allocates nothing for words up to about 60 characters.

FromPatterns(string, string?, int, int)

Makes a hyphenator from patterns in Liang's notation (such as .hy3ph and hen5at, separated by white space, as in hyph-utf8's .pat.txt files) and exceptions in hy-phen-ate form (as in its .hyp.txt files).

GetPoints(ReadOnlySpan<char>, Span<int>)

Finds where word may break with a hyphen. Letter case does not matter. The caller passes a single word: digits, punctuation and spaces are looked up like letters, and patterns rarely match them.

public int GetPoints(ReadOnlySpan<char> word, Span<int> points)

Parameters

word ReadOnlySpan<char>

The word.

points Span<int>

Receives the break offsets: UTF-16 indexes into word of the first character after each break, ascending. word.Length - 1 entries always suffice.

Returns

int

The number of points written.

Exceptions

Reads patterns, exceptions and minimums from stream in one of the formats. Without minimums in the file, TeX formats get TeX's defaults (2 and 3) and LibreOffice files libhyphen's (2 and 2).
