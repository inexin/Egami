Examples

// The built-in lists load on first use; copy the set to add your own words or a script Egami ships no list for.
WordDictionaries.BuiltIn.TryGet(Script.Thai, out WordDictionary? thai);
bool known = thai!.Contains("ภาษา");                            // true: "language" is in ICU's Thai list
WordDictionary withNames = thai.WithWords(["อีกามิ"]);           // a copy with a product name added

WordDictionaries dictionaries = new(WordDictionaries.BuiltIn);
dictionaries.Add(Script.Thai, withNames);

using MemoryStream compiled = new();
withNames.Save(compiled);                                       // the compiled .edict form, far faster to load than a list
compiled.Position = 0;
WordDictionary back = WordDictionary.Load(compiled);

// Line breaking uses the built-in set unless the options name another; WordDictionaries.None breaks only at spaces.
LineBreakOptions options = new() { Dictionaries = dictionaries };   // or ParagraphStyle.LineBreaking
List<int> breaks = [];
foreach (LineBreak b in LineBreaks.Enumerate("ภาษาไทยง่าย", options))
{
    breaks.Add(b.Index);                                        // 4, 7 and 11: ภาษา|ไทย|ง่าย
}

// Double-click and Ctrl+arrow select and step by the same words, with the paragraph's dictionaries.
TextLayout layout = Paragraph.Create("ภาษาไทยง่าย", new ParagraphStyle
{
    DefaultStyle = new TextStyle { FontFamilies = [thaiFamily] },
    LineBreaking = options,
}).Layout(400);
Egami.Fonts.Unicode.TextSegment word = layout.GetWordBoundary(5);                 // 4 and 3: ไทย
TextPosition next = layout.MoveCaret(new TextPosition(4), CaretMove.NextWord); // 7

Remarks

The words are kept as a minimised word graph: Egami's own compiled form (.edict), which Load(Stream) reads back by inflating one byte array, with nothing to build. Words compare exactly, UTF-16 code unit by code unit: no case folding or normalization. A dictionary holds words spelled with at most 255 distinct code units, which a script's block and a few joiners fit.

A dictionary is immutable and safe to share between threads. BuiltIn holds the dictionaries Egami.Fonts ships.

Load(Stream)

Reads a dictionary from stream: the compiled form Save(Stream) writes, or a UTF-8 word list with one word per line, as ICU's dictionary sources are. In a word list, lines whose first non-space character is # are comments, blank lines are skipped, a byte order mark is ignored and each word is trimmed of white space.
