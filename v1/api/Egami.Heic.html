Namespace Egami.Heic

Classes

HeicContextExtensions

Registers Egami.Heic with an EgamiContext.

HeicFormat

The HEIC format (HEIF with HEVC-coded images, as iPhones and most Android phones save photos), registered with WithHeic(EgamiContext). It replaces core Egami's own HEIC entry, which detects and probes HEIC files but does not load them.

HeicImage

Reads the images a HEIC file holds besides the one Load gives: thumbnails, depth maps, gain maps and other auxiliary images, such as an iPhone's portrait and sky mattes. Items lists them.

HeicWriterOptions

Options for writing HEIC. Lossy images are coded on heif-enc's quality scale, so the same Quality gives about the same file as heif-enc -q with x265; lossless images keep every sample of 4:4:4 RGB. The names and meanings match AvifWriterOptions where the two formats share an option.

HevcDecoderOptions

How an HevcStreamDecoder decodes.

HevcStreamDecoder

Decodes an HEVC (H.265) video stream an access unit at a time, as MP4, Matroska and raw .h265 files carry it: intra and inter pictures of the Main, Main 10, Main Still Picture, Main 12 and range extensions profiles to 12 bits, 4:0:0 to 4:4:4, with tiles, wavefronts and every inter tool. The pictures equal the HEVC reference decoder's (HM) sample for sample. Containers are not read here: Egami.Video reads them and uses this decoder, and any other source of HEVC access units can too.
