Examples

// About three times as wide as tall, error level from the standard's table for the amount of data.
Barcode ticket = Barcode.Pdf417("PASSENGER DOE/JANE  FLIGHT EG1234  SEAT 12A  GATE B17");

// Six data columns and error level 5, or the compact form for a narrow space.
Barcode wide = Barcode.Pdf417("PASSENGER DOE/JANE", new Pdf417Options { Columns = 6, ErrorLevel = 5 });
Barcode compact = Barcode.Pdf417("PASSENGER DOE/JANE", new Pdf417Options { Compact = true });

Gets the number of data columns, 1 to 30, or null, the default, for a symbol about three times as wide as it is tall.

Compact

Gets a value indicating whether to write compact PDF417, which leaves out the right row indicators and shortens the stop pattern to one bar, for a narrower symbol that is harder to read when damaged; off by default.

public bool Compact { get; init; }

ErrorLevel

Gets the error correction level, 0 (2 codewords) to 8 (512 codewords), or null, the default, for the standard's recommended minimum for the amount of data: 2 up to 40 data codewords, 3 up to 160, 4 up to 320, else 5.
