Enum DecodeErrorMode

Namespace
Egami.Video

What a decoder or VideoReader does with a frame it cannot decode.

public enum DecodeErrorMode

Fields

Conceal = 2

Reports the frame and keeps going, filling what could not be read from the previous frame (VP8: the damaged macroblocks; mid-gray when there is no previous frame). Codecs with nothing to fill from (Motion JPEG) drop the frame, as in Skip.

Skip = 1

Reports the frame through the Egami context's diagnostics and drops it, then, for codecs whose frames depend on earlier ones (VP8), every frame up to the next keyframe, so no wrong picture is ever shown. The default for VideoReader.

Throw = 0

Throws CorruptDataException. The default for decoders made directly, so callers see every problem.

Examples

// How a reader decodes: which track, what a broken frame does (Skip, the default, drops it up to the next keyframe;
// Conceal repeats the last good frame; Throw throws) and the codec's own options.
VideoReaderOptions options = new()
{
    TrackNumber = 1,
    Errors = DecodeErrorMode.Conceal,
    Decoder = new VideoDecoderOptions { DecodeAlpha = false },
};
using VideoReader reader = VideoReader.Open("alpha.webm", options);
using YuvVideoFrame frame = reader.ReadFrame()!;
