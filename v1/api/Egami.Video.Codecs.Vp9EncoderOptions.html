The VP9 settings beyond VideoEncoderOptions, for experts: quantizer limits, alternate reference frames, golden frame spacing, tile columns, adaptive quantization, error resilience, the bit depth and alpha. Every one has a default that suits most uses.

Examples

// VP9 in WebM at constant quality, on the same Quality and Effort scales as VP8.
VideoWriterOptions options = new() { Codec = VideoCodecs.Vp9, FrameRate = new Rational(30, 1), Quality = 70, Effort = 2 };
using (VideoWriter writer = VideoWriter.Create("duck-vp9.webm", options))
{
    for (int i = 0; i < 10; i++)
    {
        using Raster<Rgb8> frame = duck.Derive(ops => ops.Crop(new Rect(i * 4, i * 2, 320, 240)));
        writer.WriteFrame(frame);
    }
}

// Expert settings: two tile columns, adaptive quantization, quantizer limits on VP9's 0 to 255 scale.
VideoWriterOptions tuned = options with
{
    Vp9 = new Vp9EncoderOptions { TileColumns = 2, AdaptiveQuantization = true, MinQuantizer = 20, MaxQuantizer = 200 },
};

AdaptiveQuantization

Gets whether blocks get finer or coarser quantizers by their detail, through segments (libvpx's aq-mode 1): flat areas, where banding shows, get finer steps. Default off.

public bool AdaptiveQuantization { get; init; }

AlternateReference

Gets whether Quality codes hidden alternate reference frames: a temporally filtered copy of a frame ahead that the frames before it predict from, sent in a superframe with the next shown frame. Default on; Realtime never codes them.

public bool AlternateReference { get; init; }

Property Value

bool

BitDepth

Gets the bit depth to code, 8, 10 or 12, or null (the default) for the frames' own: 10 or 12 for 16-bit planes of that depth, 8 for everything else. 10 and 12 bits make profile 2 (4:2:0) or 3 streams.

public int? BitDepth { get; init; }

TileColumns

Gets the tile columns per frame, a power of two from 1 to 64, or null (the default) for as many as the width allows with each at least 256 pixels wide, up to 4. Tiles let encoders and decoders use more threads; the frame width caps them. The output never depends on the thread count.

public int? TileColumns { get; init; }

Property Value

int?

Exceptions

ArgumentOutOfRangeException
