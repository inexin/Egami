Class Compositor

Namespace
Egami.Operations
Assembly
Egami.dll

Blends rows of pixels with a BlendMode, for code that composites outside an operation chain: a custom IRasterOperation, a rasterizer filling spans, a layer merge. It runs the kernels DrawImage runs, so Blend<TPixel>(BlendMode, ReadOnlySpan<TPixel>, Span<TPixel>, float, ColorSpace) on a row gives the pixels DrawImage gives there. Every method works for every pixel type, allocates nothing once warm, and is safe to call from many threads at once.

Examples

// Blend rows in your own code: a source row, a destination row, and coverage from an antialiased edge.
Rgba8[] source = new Rgba8[256], destination = new Rgba8[256];
byte[] coverage = new byte[256];
for (int x = 0; x < 256; x++)
{
    source[x] = new Rgba8((byte)x, 80, 200, 255);
    destination[x] = new Rgba8(250, 250, 240, 255);
    coverage[x] = (byte)Math.Clamp((x - 100) * 8, 0, 255);   // a soft edge from x = 100 to 132
}

Compositor.Blend<Rgba8>(BlendMode.Multiply, source, destination, coverage);

// One color through coverage, the way a rasterizer fills a shape's spans.
Compositor.Blend(BlendMode.SourceOver, new Rgba8(255, 0, 0, 128), destination.AsSpan(), coverage);

Blend<TPixel>(BlendMode, Rgba8, Span<TPixel>, ReadOnlySpan<byte>, float, ColorSpace)

Blends one color onto every pixel of destination through per-pixel coverage: the span fill a rasterizer draws a shape with. Coverage 0 leaves a pixel as it was.

public static void Blend<TPixel>(BlendMode mode, Rgba8 color, Span<TPixel> destination, ReadOnlySpan<byte> coverage, float opacity = 1, ColorSpace colorSpace = ColorSpace.Encoded) where TPixel : unmanaged, IPixelType<TPixel>

Parameters

mode BlendMode

How the color combines with each pixel.

color Rgba8

The color, with straight alpha.

destination Span<TPixel>

The pixels to change.

coverage ReadOnlySpan<byte>

One coverage value per pixel, 0 to 255; the same length as destination.

opacity float

Multiplies the color's alpha before the mode: 1 uses it as it is.

colorSpace ColorSpace

Where pixels are blended. Defaults to Encoded.

Type Parameters

TPixel

The pixel type of the row.

Blend<TPixel>(BlendMode, ReadOnlySpan<TPixel>, Span<TPixel>, ReadOnlySpan<byte>, float, ColorSpace)

Blends source onto destination through per-pixel coverage, as an antialiased edge needs: each result is mixed with the original destination pixel by its coverage, so 0 leaves the pixel as it was and 255 gives the full blend.
