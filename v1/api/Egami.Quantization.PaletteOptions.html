Class PaletteOptions

How formats with at most 256 colors (GIF, PNG with a palette, and indexed BMP and TGA) build their palette when an image has more colors than fit. Images with few enough colors always keep them exactly, without dithering.

Examples

using FileStream output = File.Create("duck.gif");
photo.Save(output, GifFormat.Info, new GifWriterOptions
{
    Palette = new PaletteOptions { MaxColors = 128, Dither = DitherMode.Ordered }, // FloydSteinberg (default), Ordered or None
    PaletteScope = GifPaletteScope.PerFrame,   // Auto (default): one table when all frames fit, else one per frame
});

ExactMatching

Gets whether each color is matched to its exact nearest palette color. By default a 64-level lookup table answers for each small cube of colors at once, which is faster and can pick a color that is not quite the nearest; the default keeps every 1.x output unchanged.

RefineIterations

Gets how many k-means passes polish the built palette, moving each color to the mean of the pixels nearest it (Lloyd's algorithm on every fourth pixel), from 0 (the default) to 32. 4 to 8 passes gain a few tenths of a decibel at some cost; they never make the palette fit worse.

public int RefineIterations { get; init; }

Property Value

int

Exceptions

ArgumentOutOfRangeException

The value is outside 0 to 32.
