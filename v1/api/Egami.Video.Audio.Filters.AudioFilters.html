Class AudioFilters

Namespace
Egami.Video.Audio.Filters
Assembly
Egami.Video.dll

Whole-file jobs with audio filters: the audio tracks are decoded, filtered and encoded again while every other track is copied as it is, the way Transcode(string, string, AudioCodec?, int?, Func<TrackInfo, bool>?, MediaContext?, IProgress<MediaProgress>?, CancellationToken) copies them. Filtered tracks are encoded with the codec given; else, in Matroska and MP4, with their own codec when Egami.Video encodes it and FLAC when not, and in the other containers with the container's usual codec (FLAC in .flac, Opus in WebM and Ogg, PCM in WAV and AIFF) unless the track's own is of the same kind.

Examples

// Two passes over a file: measure each audio track, then apply one gain (and a true-peak limiter only if needed).
IReadOnlyList<LoudnessNormalization> done = await Egami.Video.Audio.Filters.AudioFilters.NormalizeLoudnessAsync(input, output, LoudnessTarget.Podcast);
Console.WriteLine($"{done[0].Measured.Integrated:F1} LUFS, {done[0].Gain:+0.0;-0.0} dB, limited: {done[0].Limited}");

// The same as a filter, from your own first pass; or one pass, following the loudness as it goes.
LoudnessMeter meter = new();
foreach (AudioFrame frame in Music())
{
    using (frame)
    {
        meter.Add(frame);
    }
}

using LoudnessNormalizer linear = new(LoudnessTarget.EbuR128, meter.Report());
using LoudnessNormalizer live = LoudnessNormalizer.Dynamic(LoudnessTarget.Streaming);

Methods

ApplyAsync(string, string, Func<AudioTrackInfo, IAudioFilter?>, AudioCodec?, int?, MediaContext?, IProgress<MediaProgress>?, CancellationToken)

Copies a file, running each audio track through the filter filters makes for it. A filter that changes the length, such as Tempo or SilenceRemover, takes the sound out of step with the video, so use one only on a file without video or when that is what you want.

public static Task<long> ApplyAsync(string inputPath, string outputPath, Func<AudioTrackInfo, IAudioFilter?> filters, AudioCodec? audio = null, int? audioLevel = null, MediaContext? context = null, IProgress<MediaProgress>? progress = null, CancellationToken cancellationToken = default)

Makes the filter for an audio track, or returns null to copy the track as it is. The job disposes the filters.

OperationCanceledException

The job was cancelled.

NormalizeLoudnessAsync(string, string, LoudnessTarget?, AudioCodec?, int?, MediaContext?, IProgress<MediaProgress>?, CancellationToken)

Brings every audio track of a file to a loudness target in two passes: the first measures each track with LoudnessMeter, the second applies a linear LoudnessNormalizer as the file is copied, so the dynamics stay as they are and a true-peak limiter runs only where it has to.

public static Task<IReadOnlyList<LoudnessNormalization>> NormalizeLoudnessAsync(string inputPath, string outputPath, LoudnessTarget? target = null, AudioCodec? audio = null, int? audioLevel = null, MediaContext? context = null, IProgress<MediaProgress>? progress = null, CancellationToken cancellationToken = default)
