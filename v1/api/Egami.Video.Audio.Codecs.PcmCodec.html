Class PcmCodec

Namespace
Egami.Video.Audio.Codecs
Assembly
Egami.Video.dll

Uncompressed PCM: integer samples of 8 (unsigned), 16, 24 or 32 bits, little-endian (Instance, WAV's) or big-endian (BigEndian, AIFF's and QuickTime's twos), and 32 or 64-bit float (FloatingPoint). Each instance decodes all three codec ids; it encodes its own. Decoded frames are interleaved, in the stored sample type: 24-bit samples come as S32 with ValidBits 24.

Examples

// The same send and receive loop as video, for the track the encoder describes (or one a demuxer read).
using IAudioDecoder decoder = AudioCodecs.CreateDecoder(encoder.Track);
long decoded = 0;
foreach (EncodedPacket packet in packets)
{
    using (packet)
    {
        decoder.Send(packet);
    }

    while (decoder.TryReceive(out AudioFrame? frame))
    {
        using (frame)
        {
            decoded += frame.SampleCount;
        }
    }
}

// FLAC decodes to its own integers: S16Planar up to 16 bits, S32Planar above.
