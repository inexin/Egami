Examples

// The smallest version that holds the text, M1 (11 x 11 modules) to M4 (17 x 17), at level L raised while it fits.
Barcode part = Barcode.MicroQr("PART-0042");

// Level M from version M3 on, for a mark that may get scuffed.
Barcode serial = Barcode.MicroQr("SN 4711", new MicroQrOptions { ErrorCorrection = QrErrorCorrection.M, MinVersion = 3 });

using Raster<Gray8> image = part.ToRaster(pixelsPerModule: 6);

ErrorCorrection

Gets the error correction level: L (the default), M (M2 and up) or Q (M4 only). M1 has error detection only.

Exceptions

ArgumentOutOfRangeException

MinVersion

Gets the smallest version, 1 (M1, 11 x 11 modules) to 4 (M4, 17 x 17), or null, the default, for any; the symbol is the smallest version from it that holds the data.

public int? MinVersion { get; init; }

Property Value

int?

Exceptions

ArgumentOutOfRangeException

The value is not 1 to 4.

RaiseErrorCorrection

Gets whether to raise the level, to M and then Q, while the data still fits the same version. The default is true.
