Class VorbisCodec

Namespace
Egami.Video.Audio.Codecs
Assembly
Egami.Video.dll

Vorbis I, decode only: every stream the specification allows (floors 0 and 1, residues 0 to 2, channel coupling, all block sizes), written from the Vorbis I specification and within 2^-22 of libvorbis on the test files. Frames come out as planar float in the canonical channel order (Vorbis puts center second); the first block's overlap and the end padding are trimmed. Read from Ogg, WebM, Matroska and MP4, where the track's codec private data holds the three header packets, Xiph-laced.

Examples

// Vorbis decodes to planar float at the stream's rate, trimmed to the last granule position; here it becomes FLAC.
using (AudioReader reader = AudioReader.Open("song.ogg"))
{
    Console.WriteLine($"{reader.Track.CodecId}, {reader.SampleRate} Hz, {reader.Layout.ChannelCount} channels");
}

MediaFile.Transcode("song.ogg", "song.flac", audio: FlacCodec.Instance);
