Class VideoReader

Namespace
Egami.Video
Assembly
Egami.Video.dll

Reads the frames of a video file in a few lines: opens the container, picks the video track, decodes it and hands out frames, as the codec's planes (ReadFrames()) or as RGB rasters (ReadFrames<TPixel>()). Frame memory comes from the context's pixel memory source, pooled by default, so disposing each frame keeps memory steady over long files.

Examples

using var reader = VideoReader.Open("camera.avi");
foreach (VideoFrame<Rgb8> frame in reader.ReadFrames<Rgb8>())
{
    using (frame)
    {
        if (frame.Timestamp.ToTimeSpan().TotalSeconds % 10 < 0.04)
            frame.Raster.Derive(x => x.Fit(320, 240)).Save($"thumb-{frame.Timestamp.Ticks}.png");
    }
}

Examples

// Every frame as RGB pixels: VP9, VP8, Motion JPEG or raw, from WebM, Matroska, AVI, IVF or YUV4MPEG2.
using VideoReader reader = VideoReader.Open("movie.webm");
Console.WriteLine($"{reader.Track.Width}x{reader.Track.Height} at {reader.Track.FrameRate?.ToDouble()} fps");
foreach (VideoFrame<Rgba8> frame in reader.ReadFrames<Rgba8>())
{
    using (frame)
    {
        frame.Raster.Save($"frame-{frame.Timestamp.ToTimeSpan().TotalMilliseconds:0000}.png");
    }
}

Seek(MediaTime)

Moves so that the next frame is the one shown at time: the last frame starting at or before it (the first frame when the time is earlier). Decodes from the keyframe before the time and drops the frames up to it, so it costs up to a keyframe interval of decoding; Seek(MediaTime, SeekMode) with Keyframe is the fast seek. Frames in flight are dropped.

Moves to time: to the frame shown then (Exact), or to the keyframe at or before it (Keyframe), which decodes nothing extra. Frames in flight are dropped.
