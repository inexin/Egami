VP9, as WebM, Matroska and IVF carry it, decoded in all four profiles: 8, 10 and 12 bit, 4:2:0, 4:2:2, 4:4:4 and RGB, with every frame equal to libvpx's sample for sample. Frames come out at their own coded size (a stream may change size between keyframes) as 8-bit planes, or 16-bit planes holding 10 or 12 bits; hidden frames (alternate references) give no frame. A WebM track with alpha (HasAlpha) decodes its second VP9 stream, carried in each packet's addition 1, into the frame's alpha plane unless DecodeAlpha is off. 4:4:0 streams are not decoded. Encoding goes through CreateEncoder(VideoEncoderOptions, MediaContext).

Remarks

The frame's color takes the matrix and range from the VP9 header and the primaries and transfer from the container (Color). Broken data follows Errors and is reported through the Egami context's diagnostics as Vp9.CorruptFrame (the frame's data is broken), Vp9.MissingReference (an inter frame with no keyframe before it), Vp9.UnsupportedSubsampling (a 4:4:0 stream, which gives no frames), Vp9.KeyframeFlagMismatch (the container's keyframe flag disagrees with the frame's own bit, which wins) or Vp9.CodecPrivateMismatch (the track's CodecPrivate disagrees with the stream, whose header wins). In Conceal mode a packet that cannot be decoded shows the last good frame again, until the next keyframe.

CreateEncoder(VideoEncoderOptions, MediaContext)

Creates a VP9 encoder. It codes 8-bit 4:2:0: such planes as they are, anything else converted to BT.601 limited range. By default it aims at constant quality 60 at effort 4, looks 25 frames ahead for scene cuts and hidden alternate references (each sent in a superframe with the next shown frame), splits frames into up to four tile columns and places a keyframe at least every 10 seconds; VideoEncoderOptions chooses bitrate, constant bitrate, two passes or real time instead, and Vp9 holds the expert settings. Frames with alpha get a second VP9 stream for it, which WebM and Matroska carry. The output is the same at any thread count.

Examples

// VP9 in WebM at constant quality, on the same Quality and Effort scales as VP8.
VideoWriterOptions options = new() { Codec = VideoCodecs.Vp9, FrameRate = new Rational(30, 1), Quality = 70, Effort = 2 };
using (VideoWriter writer = VideoWriter.Create("duck-vp9.webm", options))
{
    for (int i = 0; i < 10; i++)
    {
        using Raster<Rgb8> frame = duck.Derive(ops => ops.Crop(new Rect(i * 4, i * 2, 320, 240)));
        writer.WriteFrame(frame);
    }
}

// Expert settings: two tile columns, adaptive quantization, quantizer limits on VP9's 0 to 255 scale.
VideoWriterOptions tuned = options with
{
    Vp9 = new Vp9EncoderOptions { TileColumns = 2, AdaptiveQuantization = true, MinQuantizer = 20, MaxQuantizer = 200 },
};

Exceptions

ArgumentException
