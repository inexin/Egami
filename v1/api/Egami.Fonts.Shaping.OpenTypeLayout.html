What a face's OpenType layout tables (GSUB and GPOS) offer: the scripts, language systems and features they list, and the glyphs GSUB can produce from a set of glyphs. A table whose structure is damaged is left out whole, as the shaper leaves it out.

Methods

GetClosure(IEnumerable<ushort>, IEnumerable<FontTag>?)

Gets the glyphs the face's GSUB substitutions can produce from glyphs: the glyphs themselves and every glyph a lookup of the given features (in any script and language system, with the lookups their contextual rules call and their feature variations) can substitute for them, repeated until nothing is added. This is the layout closure hb-subset computes, so a subset that keeps these glyphs can be shaped again as the full face would be.

public IReadOnlySet<ushort> GetClosure(IEnumerable<ushort> glyphs, IEnumerable<FontTag>? features = null)

Parameters

glyphs IEnumerable<ushort>

The glyph ids to start from, such as those of the characters a page uses; ids the face does not have are ignored.

features IEnumerable<FontTag>

The feature tags whose lookups are followed, or null for DefaultClosureFeatures; pass Features to follow every feature and an empty list to follow none.

Returns

IReadOnlySet<ushort>

The glyph ids, ascending when enumerated.

Examples

// The glyphs a web font subset needs so that it shapes "office" as the full font does: the characters' glyphs and every
// glyph GSUB can turn them into (the "ffi" ligature, for one).
ushort[] used = [0, .. "office".Select(c => face.GetGlyph(c))];
IReadOnlySet<ushort> keep = face.Layout.GetClosure(used);                           // hb-subset's default features
IReadOnlySet<ushort> all = face.Layout.GetClosure(used, face.Layout.Features);      // every feature, small caps too
