Metadata that belongs to the whole raster. It is kept apart from the pixels and survives operations unless an operation makes it wrong. Metadata problems never fail a load: broken blocks are kept as bytes and noted in Warnings.

Examples

using Raster photo = Raster.Load("sideways.jpg");
IptcData iptc = photo.Metadata.Iptc ?? new IptcData();
iptc.Headline = "Harbour at dawn";
iptc.Keywords = [.. iptc.Keywords, "harbour", "Bergen"];

// Any dataset by its key; Add appends to the repeatable ones.
iptc.Set(IptcKey.City, "Bergen");

// Text that is not ASCII sets the coded character set (1:90) to UTF-8, so other programs read it right.
iptc.Caption = "Fishing boats at Bryggen, Bergen — first light";
foreach (IptcEntry entry in iptc.Entries)
{
    Console.WriteLine($"{entry.Key} {entry.AsString()}");
}

// JPEG saves it in its Photoshop resource block (APP13), with the digest Photoshop and Lightroom check.
photo.Metadata.Iptc = iptc;
photo.Save("captioned.jpg");

Examples

using Raster photo = Raster.Load("sideways.jpg");

// The parsed view of the packet; it is null when the file has none, so start one.
XmpData xmp = photo.Metadata.XmpData ??= new XmpData();
xmp.Keywords = [.. xmp.Keywords, "harbour"];

// The edit is the packet now: Metadata.Xmp returns it and every format saves it.

GetColorProfile()

Returns what the raster's pixel values mean, resolved from everything the file said, in this order: the H.273 CodePoints (PNG cICP), the embedded ICC profile, an sRGB tag, a gamma or linear tag with the file's Primaries (sRGB's when it has none), the EXIF marker of an Adobe RGB camera, primaries alone with the sRGB curve, and sRGB when the file said nothing. A damaged or unsupported profile, or code points Egami does not know, count as saying nothing. PNG's gAMA 45455 (1/2.2) with no cHRM, or with sRGB's, counts as sRGB, which is what such files mean.

public ColorProfile GetColorProfile()

Returns

ColorProfile

The encoding: RGB unless an ICC profile says gray or CMYK. Gray pixels are read with an RGB encoding's curve.

Examples

// What the pixels mean, from the file's ICC profile, tags and gamma; sRGB when it said nothing.
ColorProfile stored = raster.Metadata.GetColorProfile();

// Convert in place to sRGB for the web: the metadata then says sRGB, so no profile is written.
raster.Apply(ops => ops.ConvertColor(ColorProfile.Srgb));
