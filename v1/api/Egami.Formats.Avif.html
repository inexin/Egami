Namespace Egami.Formats.Avif

Classes

AvifDetails

Details only AVIF has, kept in FormatDetails.

AvifFilmGrain

An AV1 frame's film grain parameters (AV1 specification 5.9.30 and 6.8.20): what the decoder's grain synthesis adds to the output, kept so an image loaded without its grain can have it added again or described.

AvifFormat

The AVIF format (AV1 Image File Format), registered in Default.

AvifImage

Reads the images an AVIF file holds besides the one Load gives: thumbnails, depth maps and other auxiliary images.

AvifItem

An item of an AVIF file, as Items lists them.

AvifReaderOptions

Options for reading AVIF.

AvifWriterOptions

Options for writing AVIF. Lossy images are coded on libavif's quality scale, so the same Quality gives about the same file as avifenc -q; lossless images keep every sample of 4:4:4 RGB.
