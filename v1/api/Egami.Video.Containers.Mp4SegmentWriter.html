Class Mp4SegmentWriter

Namespace
Egami.Video.Containers
Assembly
Egami.Video.dll

Writes a file as segments for HLS and DASH (V4.3 Design Q6 and Q7): for each track a CMAF init segment (ftyp and moov) and numbered media segments (styp, sidx, moof and mdat), cut at the first video keyframe after SegmentDuration so every segment starts with one, plus an HLS multivariant playlist with a media playlist a track and a static DASH MPD. Each segment, read after its track's init segment, is valid fragmented MP4. A track is named after its kind and number: video1-init.mp4, video1-00001.m4s, video1.m3u8; the playlists are master.m3u8 and manifest.mpd. Holds the audio and video codecs Mp4Format writes, one rendition: bitrate ladders, live playlists and encryption are not written (Q8, Q9).

Examples

// HLS and DASH: an init segment and six-second media segments a track, master.m3u8 and manifest.mpd, in a folder.
// Another constructor takes a Func<string, Stream> that opens each file, for blob storage.
using IDemuxer demuxer = MediaFile.OpenDemuxer("movie.webm");
using (Mp4SegmentWriter writer = new("stream", demuxer.Tracks, options: new Mp4SegmentOptions { SegmentDuration = TimeSpan.FromSeconds(6) }))
{
    while (demuxer.ReadPacket() is { } packet)
    {
        using (packet)
        {
            writer.WritePacket(packet);
        }
    }
}
