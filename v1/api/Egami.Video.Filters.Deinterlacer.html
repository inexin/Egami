Class Deinterlacer

Namespace
Egami.Video.Filters
Assembly
Egami.Video.dll

Turns interlaced frames into progressive ones. Each output frame keeps one field's lines and makes the other field's: Adaptive keeps the woven lines where the picture holds still and guesses along edges where it moves, using the fields before and after; Bob guesses from the kept field alone. Every plane is done on its own lines, so a 4:2:0 field keeps its own chroma rows; 8- to 16-bit samples, any chroma format and alpha work. The filter holds one frame back to look at the next.

Examples

// Deinterlace a file: interlaced frames come out progressive, one per frame in, and progressive frames pass unchanged.
// The track gives the field order for frames that do not carry their own.
using VideoReader reader = VideoReader.Open("movie.webm");
using Deinterlacer deinterlacer = new(reader.Track, new DeinterlacerOptions
{
    Mode = DeinterlaceMode.Adaptive,      // or Bob: from each field alone
    Rate = DeinterlaceRate.Frame,         // or Field: one frame per field, 50i becomes 50p
    Frames = DeinterlaceFrames.All,       // also frames the decoder does not flag as interlaced
});
VideoWriterOptions options = new() { Codec = VideoCodecs.Ffv1, FrameRate = reader.Track.FrameRate ?? new Rational(25, 1) };
using (VideoWriter writer = VideoWriter.Create("progressive.mkv", options))
{
    foreach (YuvVideoFrame frame in reader.ReadFrames())
    {
        using (frame)
        {
            deinterlacer.Send(frame);
        }

        while (deinterlacer.TryReceive(out YuvVideoFrame? output))
        {
            using (output)
            {
                writer.WriteFrame(output);
                written++;
            }
        }
    }

    // The deinterlacer holds one frame back to look at the next; Flush hands it out.
    deinterlacer.Flush();
    while (deinterlacer.TryReceive(out YuvVideoFrame? output))
    {
        using (output)
        {
            writer.WriteFrame(output);
            written++;
        }
    }
}

Deinterlacer(VideoTrackInfo, DeinterlacerOptions?, MediaContext?)

Creates a deinterlacer for a track: frames that do not give their field order take the track's FieldOrder, and the track's frame rate times frames that give no duration. Only the H.264 decoder flags each frame; frames of other codecs count as flagged when the container calls the track interlaced.
