Class ColorFilter

Namespace
Egami.Operations
Assembly
Egami.dll

A function of one pixel's color, as a value: build one from a matrix, curves, a 3D table or a tone step, chain filters with Then(ColorFilter), mix two with Lerp(ColorFilter, ColorFilter, float), run one with ApplyFilter(ColorFilter) or on your own pixels with Apply<TPixel>(Span<TPixel>), and save it as a .cube file through ToLut3D(int). Like Skia's SkColorFilter, a filter sees only the pixel's own straight RGBA: no neighbours, position or image statistics, so any chain of filters runs as one pass.

Examples

// A look as a value: build it once, mix it in at 70%, apply it to any image or to your own pixels.
ColorFilter look = ColorFilter.Level(0.03f, 0.97f).Then(ColorFilter.Saturation(1.2f)).Then(ColorFilter.Tint(new Rgba8(255, 190, 140, 255), 0.2f));
ColorFilter subtle = ColorFilter.Lerp(ColorFilter.Identity, look, 0.7f);
raster.Apply(o => o.ApplyFilter(subtle), Ct);

Span<Rgba8> swatch = [new Rgba8(200, 120, 80, 255), new Rgba8(40, 60, 90, 255)];
subtle.Apply(swatch);

Remarks

Filters work on the stored, gamma-encoded values, as photo editors and LUT files do, and clamp to 0..1 after each step, as the color matrices do. Immutable and safe to share between threads.
