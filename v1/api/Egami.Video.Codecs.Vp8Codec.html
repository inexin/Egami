Class Vp8Codec

Namespace
Egami.Video.Codecs

VP8 (RFC 6386), as WebM, Matroska and IVF carry it, decoded by Egami's Vp8StreamDecoder: every frame equals libvpx's sample for sample. Frames come out as 8-bit 4:2:0 planes, BT.601 limited range unless the container says otherwise; hidden frames (alternate references) give no frame. A WebM track with alpha (HasAlpha) decodes its second VP8 stream, carried in each packet's addition 1, into the frame's alpha plane unless DecodeAlpha is off. Encoding goes through CreateEncoder(VideoEncoderOptions, MediaContext).

Remarks

Broken data follows Errors and is reported through the Egami context's diagnostics as Vp8.CorruptFrame (the frame's data is broken), Vp8.MissingReference (an inter frame with no keyframe before it) or Vp8.KeyframeFlagMismatch (the container's keyframe flag disagrees with the frame's own bit, which wins).

CreateEncoder(VideoEncoderOptions, MediaContext)

Creates an encoder through Egami's Vp8StreamEncoder. It codes 8-bit 4:2:0: such planes as they are, anything else converted to BT.601 limited range. By default it aims at constant quality 60 at effort 4, looks 25 frames ahead for scene cuts and hidden alternate references, and places a keyframe at least every 10 seconds; VideoEncoderOptions chooses bitrate, constant bitrate, two passes or real time instead, and Vp8 holds the expert settings. Frames with alpha get a second VP8 stream for it, which WebM and Matroska carry.

Examples

// VP8 in WebM at constant quality: Quality 0 to 100 (default 60) and Effort 0 to 10 (default 4).
VideoWriterOptions options = new() { Codec = VideoCodecs.Vp8, FrameRate = new Rational(30, 1), Quality = 70, Effort = 4 };
using (VideoWriter writer = VideoWriter.Create("duck.webm", options))
{
    for (int i = 0; i < 30; i++)
    {
        using Raster<Rgb8> frame = duck.Derive(ops => ops.Crop(new Rect(i * 4, i * 2, 320, 240)));
        writer.WriteFrame(frame);
    }
}

// Expert settings: no hidden alternate reference frames, and quantizer limits.
VideoWriterOptions tuned = options with { Vp8 = new Vp8EncoderOptions { AlternateReference = false, MinQuantizer = 10, MaxQuantizer = 90 } };

Exceptions

ArgumentException

The options are out of range, or a bitrate mode has no bitrate.
