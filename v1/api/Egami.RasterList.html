The images of a file that holds several, each its own raster with its own size, pixel type and metadata: a TIFF's pages, an icon's entries. The list owns them: disposing it disposes every raster.

Examples

// Every page at its own size and pixel type. The list owns the rasters.
using RasterList pages = Raster.LoadAll("scan.tif");
foreach (Raster page in pages)
{
    Console.WriteLine($"{page.Width} × {page.Height}");
}

// Keep one page after the list is gone.
using Raster first = pages.Detach(0);

Remarks

Frames are for animation and share one size; images of different sizes come as a list. Take a raster out of the list with Detach(int) to keep it after the list is disposed.
