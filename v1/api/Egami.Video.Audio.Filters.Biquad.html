Class Biquad

Namespace

A second-order filter from the Audio EQ Cookbook: low and high pass, band pass, notch, all pass, peaking and shelves. The width is a Q (0.7071, the default, is the flattest low and high pass) or, with FromBandwidth(BiquadKind, double, double, double), a bandwidth in octaves. The filter runs in transposed direct form II with its state in double, so it stays quiet at low frequencies. For steeper low and high pass use Butterworth; for several bands in one filter, ParametricEqualizer.

Examples

// Rumble out below 80 Hz (24 dB per octave), a little warmth, less harshness and some air.
using AudioFilterChain chain = new AudioFilterChain(48000, ChannelLayout.Stereo)
    .Add(new Butterworth(BiquadKind.HighPass, 80, order: 4))
    .Add(new ParametricEqualizer(
        new EqualizerBand(BiquadKind.LowShelf, 150, Gain: 2),
        new EqualizerBand(BiquadKind.Peaking, 3000, Gain: -4, Q: 1.5),
        new EqualizerBand(BiquadKind.HighShelf, 10000, Gain: 3)))
    .Add(Biquad.FromBandwidth(BiquadKind.Notch, 50, octaves: 0.1)); // mains hum

Methods

FromBandwidth(BiquadKind, double, double, double)

Creates a filter with its width as a bandwidth in octaves, like ffmpeg's width_type=o. For band pass, notch, all pass and peaking it is the width between the -3 dB points (or the half-gain points), corrected for the digital filter's warping as the cookbook does; for the other kinds it is turned into a Q.
