Class MediaFile

Namespace
Egami.Video

Entry points for media files: probe what a file holds, open a demuxer to read its packets, or create a muxer to write one. The container is detected from the file's first bytes when reading, and chosen by extension when writing.

Remux(Stream, Stream, string, Func<TrackInfo, bool>?, MediaContext?, bool, IProgress<MediaProgress>?, CancellationToken)

Copies the packets of one stream into another container without decoding, as Remux(string, string, Func<TrackInfo, bool>?, MediaContext?, IProgress<MediaProgress>?, CancellationToken) does for files: for example from one cloud blob to another without a local copy. The input may be non-seekable, except for MP4 files with moov after the media. Matroska, WebM, IVF and YUV4MPEG2 write to a non-seekable stream as they go; so does MP4, written fragmented there with an mp4-fragmented warning (see NonSeekable); AVI needs a seekable stream.

public static long Remux(Stream input, Stream output, string outputFormat, Func<TrackInfo, bool>? tracks = null, MediaContext? context = null, bool leaveOpen = false, IProgress<MediaProgress>? progress = null, CancellationToken cancellationToken = default)

Parameters

input Stream

The source, read from its current position.

output Stream

Where to write.

outputFormat string

The output container: "Matroska", ".mkv", "webm" and so on.

tracks Func<TrackInfo, bool>

Which tracks to keep, or null for all.

context MediaContext

The context, or null for Default.

leaveOpen bool

Whether the job leaves both streams open when it ends.

progress IProgress<MediaProgress>

Receives MediaProgress reports on the job's thread, or null.

cancellationToken CancellationToken

Stops the job between packets; what was written to output stays.

Returns

long

How many packets were copied.

Examples

// Any Stream works, seekable or not: a cloud blob's read and upload streams, an HTTP response body, a pipe.
// Files stand in for them here.
using Stream source = File.OpenRead("movie.webm");
using Stream upload = File.Create("movie.mkv");
long packets = MediaFile.Remux(source, upload, "mkv", leaveOpen: true, cancellationToken: cts.Token);

Exceptions

UnsupportedFormatException

The input is not a registered container, or no container writes outputFormat.

NotSupportedException

The output container cannot hold one of the tracks, or needs a seekable output.

OperationCanceledException

The job was cancelled.

Examples

// Progress<T> runs the handler on the caller's synchronization context: the UI thread in WinForms, WPF or MAUI.

    Console.Write($"\r{p.Position.ToTimeSpan():c} {p.Fraction ?? 0:P0} {p.Frames} frames {p.Speed:0.0}x"));

Transcode(string, string, AudioCodec?, int?, Func<TrackInfo, bool>?, MediaContext?, IProgress<MediaProgress>?, CancellationToken)

Copies a file into another container like Remux(string, string, Func<TrackInfo, bool>?, MediaContext?, IProgress<MediaProgress>?, CancellationToken), but decodes its audio tracks and encodes them again with audio, at the same rate, layout and bit depth: for example keeping a WebM's video and turning its audio into FLAC in Matroska. Audio no registered codec decodes is copied as it is. The output container comes from the extension. Without a codec, a WebM output gets its audio in Opus: Opus and Vorbis tracks are copied and the others encoded, so a Matroska or MP4 source turns into a valid WebM.
