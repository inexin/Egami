Interface IAudioFilter

Namespace
Egami.Video.Audio.Filters
Assembly
Egami.Video.dll

A streaming audio filter: frames go in through Send(AudioFrame) and come out through TryReceive(out AudioFrame?), the same shape as Resampler, decoders and encoders, so filters, the resampler and encoders plug together. Frames of any sample format go in; frames come out as F32Planar with exact timestamps. Implement it to put a filter of your own in an AudioFilterChain.

Examples

// Fade in over 2 s, then turn down 3 dB: frames of any format go in, F32 planar frames come out.
using AudioFilterChain chain = new AudioFilterChain(48000, ChannelLayout.Stereo)
    .Add(new AudioFade(FadeDirection.In, MediaTime.Zero, MediaTime.FromSeconds(2)))
    .Add(new Gain(-3));
foreach (AudioFrame frame in frames)
{
    chain.Send(frame);
    while (chain.TryReceive(out AudioFrame? output))
    {
        samples += output.SampleCount; // write it to an AudioWriter or encoder here
        output.Dispose();
    }
}

chain.Flush();
