Enum DngPreview

Namespace
Egami.Formats.Extended.Raw
Assembly
Egami.Formats.Extended.dll

Which rendered images a DNG carries besides its raw data.

public enum DngPreview

Fields

Full = 3

The thumbnail and a full-size JPEG preview.

Medium = 2

The thumbnail and a JPEG preview of 1024 pixels on the long side, as Adobe DNG Converter writes by default.

None = 0

None: the raw data is the file's first image. The smallest files.

Thumbnail = 1

An 8-bit RGB thumbnail of 256 pixels on the long side, as the file's first image.

Examples

// Any RAW file Egami reads becomes a DNG with its sensor data unchanged: levels, crop, colour data and EXIF come along.
RawFormat.ConvertToDng("photo.dng", "copy.dng", new DngWriterOptions { Preview = DngPreview.Thumbnail }, context);

// A transcode with no operations takes the same route; with operations, the develop is saved as a linear DNG.
Raster.Transcode("photo.dng", "same.dng", context: context);
Raster.Transcode("photo.dng", "small.dng", ops => ops.Fit(800, 800), context: context);
