How RasterizeAnimation<TPixel>(SvgAnimationOptions?) and RenderFrames<TPixel>(SvgAnimationOptions?) turn a document's animations into frames: the frame rate, where to start, how long to go on and how each frame is drawn.

Examples

// One loop (2 s) at 25 frames a second; frames that look the same merge into one longer frame.
using Raster<Rgba8> animation = document.RasterizeAnimation<Rgba8>(new SvgAnimationOptions { FrameRate = 25 });
animation.Save(path);   // loops forever, as the SVG does

Properties

Default

Gets the defaults: 30 frames a second from the start, one loop or the whole animation, still stretches merged.

public static SvgAnimationOptions Default { get; }

Property Value

SvgAnimationOptions

FrameRate

Gets how many frames are drawn a second; 30 by default.

public double FrameRate { get; init; }

Property Value

double

Exceptions

ArgumentOutOfRangeException

The value is not positive, or is more than 1000.

Length

Gets how long the frames go on from Start, or null (the default) to let the document decide: one LoopPeriod when every animation loops, else up to the end of the last animation (Duration), at most MaxLength.

public TimeSpan? Length { get; init; }

Property Value

TimeSpan?

Exceptions

ArgumentOutOfRangeException

The value is not positive.

MaxLength

Gets the longest the document may make the frames go on when Length is not set: an animation that runs forever without a common loop period, ends later or loops more slowly, is cut there (and then plays once) and the context's diagnostics get an Svg.AnimationLength warning. 10 seconds by default.

public TimeSpan MaxLength { get; init; }

Property Value

TimeSpan

Exceptions

ArgumentOutOfRangeException

MergeDuplicates

Gets a value indicating whether frames whose pixels equal the frame before are merged into it, which then lasts longer; true by default. Turn it off for a constant frame rate, as video wants.

public bool MergeDuplicates { get; init; }

Property Value

bool

Render

Gets how each frame is drawn (size, background, languages, canvas and context), or null for Default. Its Time is ignored: each frame sets its own.

public SvgRenderOptions? Render { get; init; }
