Interface IAudioDecoder

Namespace
Egami.Video.Audio
Assembly
Egami.Video.dll

Turns packets into audio frames with the same send and receive loop as IVideoDecoder: after each Send(EncodedPacket) call TryReceive(out AudioFrame?) until it returns false; at the end call Flush() and receive what is left.

public interface IAudioDecoder : IDisposable
Inherited Members
IDisposable.Dispose()

Examples

// The same send and receive loop as video, for the track the encoder describes (or one a demuxer read).
using IAudioDecoder decoder = AudioCodecs.CreateDecoder(encoder.Track);
long decoded = 0;
foreach (EncodedPacket packet in packets)
{
    using (packet)
    {
        decoder.Send(packet);
    }

    while (decoder.TryReceive(out AudioFrame? frame))
    {
        using (frame)
        {
            decoded += frame.SampleCount;
        }
    }
}

// FLAC decodes to its own integers: S16Planar up to 16 bits, S32Planar above.
