Class PathBuilder

Namespace
Egami.Drawing
Assembly
Egami.Drawing.dll

Builds a Path one command at a time. Arcs, ovals and round corners become cubic curves as they are added, so a path holds only lines, quadratics and cubics. A line or curve with no contour open starts one at the last contour's start (or the origin), as SVG and Skia do. Building takes time in proportion to the points added; ToPath(FillRule) copies them, so the builder can go on or be reused.

Examples

// A path is built once and never changes, so it can be drawn many times and from many threads.
Path heart = new PathBuilder()
    .MoveTo(150, 60)
    .CubicTo(150, 30, 100, 20, 90, 60)
    .CubicTo(80, 100, 130, 130, 150, 160)
    .CubicTo(170, 130, 220, 100, 210, 60)
    .CubicTo(200, 20, 150, 30, 150, 60)
    .Close()
    .ToPath();
canvas.FillPath(heart, Rgba8.Red);

// SVG's arc command, and the even-odd rule: an inner contour becomes a hole.
Path frame = new PathBuilder()
    .AddRect(new RectF(10, 10, 60, 60))
    .AddCircle(new Vector2(40, 40), 20)
    .MoveTo(10, 120)
    .ArcTo(radii: new Vector2(30, 20), rotationDegrees: 0, largeArc: false, clockwise: true, end: new Vector2(70, 120))
    .Close()
    .ToPath(FillRule.EvenOdd);
canvas.FillPath(frame, Rgba8.Black);

bool hit = heart.Contains(new Vector2(150, 100));   // hit testing on the curves themselves
RectF box = heart.TightBounds;                       // curves measured at their extremes

ArcTo(Vector2, Vector2, float)

Adds a circular arc of radius that turns from the line towards corner onto the line from corner to end, touching both, with a straight line to where the arc starts: the rounded corner of HTML canvas's and Skia's arcTo. When the lines are parallel or the radius is 0, a line to the corner is added.

ArcTo(Vector2, float, bool, bool, Vector2)

Adds an elliptical arc to end in SVG's endpoint form (the A command), following SVG 1.1's implementation notes: radii too small to reach the end point are scaled up until they do, a zero radius draws a straight line, and an end point equal to the current point adds nothing.

public PathBuilder ArcTo(Vector2 radii, float rotationDegrees, bool largeArc, bool clockwise, Vector2 end)

Parameters

radii Vector2

The ellipse's x and y radius; signs are ignored.

rotationDegrees float

The ellipse's x axis, turned clockwise from the page's x axis.

largeArc bool

Whether to take the arc of more than 180 degrees.

clockwise bool

Whether the arc runs clockwise on screen (SVG's sweep flag of 1).

end Vector2

Where the arc ends.
