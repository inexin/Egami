Class LoudnessMeter

Namespace
Egami.Video.Audio
Assembly
Egami.Video.dll

Measures loudness as ITU-R BS.1770-5 and EBU R 128 define it: momentary (400 ms) and short-term (3 s) loudness while audio comes in, and at any point the gated integrated loudness, the loudness range (EBU Tech 3342), the true peak and the sample peak. It takes any sample format, any rate from 8 to 384 kHz and any channel layout, weighting surround channels by +1.5 dB and leaving the LFE channel out. The audio filters' loudness normalization measures with it too.

Examples

// EBU R 128 loudness: integrated, range and true peak at the end, momentary and short-term while the audio plays.
LoudnessMeter meter = new(new LoudnessOptions { KeepSeries = true });
MediaAnalysis.Run("shots.mkv", new MediaAnalysisOptions { Scenes = null, AudioDetectors = [meter] });
LoudnessReport loudness = meter.Report();
Console.WriteLine($"I {loudness.Integrated:0.0} LUFS, LRA {loudness.Range:0.0} LU, true peak {loudness.TruePeak:0.0} dBTP");
foreach (LoudnessValue value in meter.ShortTermSeries)
{
    Console.WriteLine($"{value.Time.ToTimeSpan()}: {value.Loudness:0.0} LUFS");
}

Remarks

Values update every 100 ms of audio. Integrated loudness and loudness range read negative infinity until a gated block passed, as does a meter fed only silence.
