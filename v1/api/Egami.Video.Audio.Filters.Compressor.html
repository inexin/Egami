Turns the level down above a threshold, by Ratio, like ffmpeg's acompressor: a level 12 dB over the threshold comes out 3 dB over it at a ratio of 4. A soft Knee eases into the ratio, Attack and Release set how fast the gain moves, and Makeup turns the result back up. Every channel gets the same gain, from the loudest one.

Examples

// Music ducks under a voice-over: the voice's level drives the music's compressor.
using Compressor ducker = new() { Sidechain = true, Threshold = -30, Ratio = 8, Release = MediaTime.FromSeconds(0.4) };
for (int i = 0; i < music.Count; i++)
{
    ducker.SendSidechain(voice[i]);
    ducker.Send(music[i]);
    while (ducker.TryReceive(out AudioFrame? output))
    {
        samples += output.SampleCount; // mix it with the voice in an AudioMixer here
        output.Dispose();
    }
}

ducker.CompleteSidechain();
ducker.Flush();

Remarks

With Sidechain on, the level comes from another signal given to SendSidechain(AudioFrame) instead, like ffmpeg's sidechaincompress: music compressed by a voice's level ducks under it. The sidechain is lined up with the input by timestamps and must have the same sample rate; it may have other channels. Input waits until the sidechain covers it or CompleteSidechain() says no more comes; where there is no sidechain, the level counts as silence.
