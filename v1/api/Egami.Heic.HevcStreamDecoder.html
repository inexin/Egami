Class HevcStreamDecoder

Namespace
Egami.Heic
Assembly

Decodes an HEVC (H.265) video stream an access unit at a time, as MP4, Matroska and raw .h265 files carry it: intra and inter pictures of the Main, Main 10, Main Still Picture, Main 12 and range extensions profiles to 12 bits, 4:0:0 to 4:4:4, with tiles, wavefronts and every inter tool. The pictures equal the HEVC reference decoder's (HM) sample for sample. Containers are not read here: Egami.Video reads them and uses this decoder, and any other source of HEVC access units can too.

Examples

// An HEVC stream from any source: Annex B here, or SetConfiguration with an MP4 track's hvcC and its samples.
using HevcStreamDecoder decoder = new(context: heic);
decoder.Send(File.ReadAllBytes("clip.h265"));
decoder.Flush();                                    // the end of the stream: the last pictures come out
int shown = 0;
while (decoder.NextFrame is HevcFrameInfo next)
{
    using YuvRaster<byte> frame = YuvRaster.Create(next.Width, next.Height, next.Chroma, YuvColor.Bt709Limited);
    decoder.TryReceiveFrame(frame, out HevcFrameInfo info);     // info.Poc, info.Kind, info.Color
    shown++;
}

Remarks

Send(ReadOnlySpan<byte>) takes the NAL units of one access unit or more: an Annex B byte stream (start codes), or after SetConfiguration(ReadOnlySpan<byte>) with an MP4 or Matroska hvcC record, NAL units each after a size field. Pictures come out in output order once the stream's reordering allows, through TryReceiveFrame(YuvRaster, out HevcFrameInfo); Flush() lets the rest out at the end of the stream.

Decoding starts at an IRAP picture (IDR, CRA or BLA); leading pictures of a CRA or BLA picture that starts the stream are left out, as the specification says. Only the base layer of a layered stream (Dolby Vision's enhancement layer, MV-HEVC) decodes. The decoder decodes a picture's tiles and wavefront rows on up to MaxParallelism threads and checks its size against the context's Limits. An instance is not thread-safe.
