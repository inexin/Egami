Examples

// Blur the background like a wide-open lens with a six-blade aperture: bright points become hexagons.
LensBlurOptions lens = new() { Blades = 6, Rotation = 15, HighlightGain = 4, HighlightThreshold = 0.8f };
photo.Apply(ops => ops.Within(new Rect(0, 0, photo.Width, photo.Height / 3), o => o.LensBlur(12, lens)), Ct);

HighlightGain

Gets how much brighter than the rest highlights blur: light above HighlightThreshold is multiplied by this before the blur, as a camera sees a bright point as more light than the pixel can hold, so small lights bloom into bright discs. 1, the default, changes nothing.

public float HighlightGain { get; init; }

Property Value

float

HighlightThreshold

Gets the level, 0 to 1 in the blur's color space, above which HighlightGain applies. Defaults to 0.9.

public float HighlightThreshold { get; init; }
