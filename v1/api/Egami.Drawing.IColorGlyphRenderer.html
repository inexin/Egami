Interface IColorGlyphRenderer

Namespace
Egami.Drawing
Assembly
Egami.Drawing.dll

Draws color glyphs of a format Egami.Drawing does not draw itself, such as the SVG documents of an OpenType SVG table (Egami.Svg's SvgGlyphRenderer). Set on ColorGlyphRenderer, it is asked first for every glyph whose font has that format, except where the font has a COLR version 1 glyph, so the order is COLR v1, the renderer, COLR v0, sbix, CBDT, then the outline.

public interface IColorGlyphRenderer

Examples

// Emoji and other glyphs from an OpenType SVG table draw in color on a canvas given the renderer.
using (RasterCanvas<Rgba8> canvas = raster.CreateCanvas(new CanvasOptions { ColorGlyphRenderer = SvgGlyphRenderer.Instance }))
{
    canvas.DrawText("Hello", new System.Numerics.Vector2(10, 35), font, new SolidPaint(new RgbaF32(0, 0, 0, 1)));
}
