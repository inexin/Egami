Class GainMap

Namespace

An HDR gain map: a small image that, with GainMapInfo, turns an SDR base image into its HDR rendition (or the reverse). Read from Ultra HDR, ISO 21496-1 and Apple JPEG files into GainMap; written back by the JPEG writer. Immutable, so rasters can share it.

Examples

// As stored: the SDR base image, with the gain map in the metadata.
using Raster sdr = Raster.Load("ultrahdr.jpg");
GainMap? map = sdr.Metadata.GainMap;                                     // null for a plain JPEG

// The HDR rendition for a display 4x as bright as SDR white: linear half floats, 1.0 = SDR white.
using Raster<RgbaF16> hdr = Raster.Load<RgbaF16>("ultrahdr.jpg", options: new ReaderOptions { Hdr = new HdrDecode { Headroom = 4 } });

// The same from a raster in hand, at the map's full capacity.
using Raster<RgbaF16> full = map!.Apply(sdr);

Methods

Apply(Raster, double?)

Returns the rendition of baseImage for a display with headroom (its peak over SDR white, linear; null for the map's full HDR capacity): linear RgbaF16 with 1.0 as SDR white (203 cd/m²), in the base image's primaries, with MaxContentLightLevel set from the map's largest boost. The map is upsampled bilinearly row by row, so no full-size copy of it is made.

public Raster<RgbaF16> Apply(Raster baseImage, double? headroom = null)

Parameters

baseImage Raster

The base image, in its own encoding (usually sRGB), the size the map was made for (it may differ by scale).

The display headroom, 1 or more, or null for full HDR.

Create(Raster, Raster?, GainMapOptions?)

Computes the gain map that turns sdr into hdr: for each map pixel, the log2 ratio of the HDR light to the SDR light, averaged over the pixels it covers, stored in 8 bits between the smallest and largest gain.

public static GainMap Create(Raster hdr, Raster? sdr = null, GainMapOptions? options = null)

Parameters

hdr Raster

The HDR rendition: linear light with 1.0 as SDR white (as Radiance, OpenEXR and HDR decodes give), or PQ or HLG with its color profile.

sdr Raster

The SDR rendition to show on SDR displays, the same size; or null to make one with Bt2390, as GainMap does.

options GainMapOptions

How to make the map, or null for the defaults.

Returns

GainMap

The gain map, for GainMap of the SDR rendition.

Examples

// An HDR raster as Ultra HDR: the SDR base, tone mapped with BT.2390, and a gain map that brings the HDR raster back.
using Raster<RgbaF32> hdr = Raster.Load<RgbaF32>("render.exr");
hdr.Save("render.jpg", new JpegWriterOptions { Quality = 90, GainMap = new GainMapOptions() });

// Or choose the SDR rendition: the map goes in its metadata, and saving as JPEG writes both.
using Raster<Rgb8> sdr = hdr.Derive(ops => ops.ToneMap(ToneMapping.Reinhard)).As<Rgb8>();
sdr.Metadata.GainMap = GainMap.Create(hdr, sdr, new GainMapOptions { Scale = 4 });
sdr.Save("graded.jpg", new JpegWriterOptions { Quality = 90 });

Exceptions

ArgumentNullException

hdr is null.

ArgumentException

sdr is not the size of hdr.
