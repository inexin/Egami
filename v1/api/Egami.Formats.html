Classes

EgamiInput

The data a reader decodes: the caller's stream behind a pooled 64 KB buffer, with exact-read helpers. It also carries the context, limits and cancellation token for the load, and is the only way a reader allocates pixel memory.

EncodeStart<TPixel>

What an encode starts from: the size, metadata and options, and the whole image when Save has one.

HdrDecode

RasterInfo

What a file's header says, read without decoding pixels.

ReaderOptions

Options for reading. The defaults read everything leniently. Formats with options of their own derive from it, such as JpegReaderOptions.

RowEncoder<TPixel>

One encode in progress: a still image's rows top-down with WriteRow(ReadOnlySpan<TPixel>), or whole frames with WriteFrame(Frame<TPixel>), then Complete().

RowReader

One open image, as a format reader streams it: frames of rows at the stored size. Derive from RowReader<TNatural>, which names the natural pixel type.

RowReader<TNatural>

An open image whose natural pixel type is TNatural, as Load(Stream, EgamiContext?, ReaderOptions?) would give it.

WriterOptions

Options for writing. Each format has a subclass with its own settings; writers given this base class use their defaults.

Interfaces

IFormatReader

Reads one file format. Readers are stateless and safe to share across threads. They read only through EgamiInput and allocate pixel memory only through CreateRaster<TPixel>(long, long, ClearMode), which checks the safety limits first, so no reader can allocate before the size has been checked.

IFormatWriter

Writes one file format. Writers are stateless, safe to share across threads, and never change the raster they are given.

IRowFormatReader

An optional interface for a format's reader: an open image that hands out rows as they are asked for, so RasterDecoder streams the format, with Region and MinimumSize applied on the way out. A reader without it still works everywhere: the decoder reads the whole image with Read(EgamiInput, ReaderOptions) and serves rows from it. Load, Probe and an incremental decode keep using IFormatReader.

IRowFormatWriter

An optional interface for a format's writer: an encoder that takes rows and frames one at a time. A writer that implements it streams through RasterEncoder<TPixel> and Transcode(Stream, Stream, FormatInfo, Action<RasterOps>?, ReaderOptions?, WriterOptions?, EgamiContext?), and Save(Stream, FormatInfo, WriterOptions?) and SaveAsync use it in place of Write<TPixel>(Raster<TPixel>, Stream, WriterOptions), so all of them write the same bytes. A writer without it still works everywhere: the encoder gathers the image and calls Write<TPixel>(Raster<TPixel>, Stream, WriterOptions) at the end.
