Namespace Egami.Video.Subtitles

Classes

SubtitleAttachment

An embedded file of an ASS script (its [Fonts] or [Graphics] section), decoded.

SubtitleCue

One subtitle: when it shows, its text as SubtitleSpan runs, and where and how it is placed. Read from SRT, WebVTT or ASS into the same fields, so a cue converts between them; a cue that is not changed is written back to its own format exactly as it was read.

SubtitleDocument

A subtitle file in memory: its cues, and the styles, regions and header its format carries. Loads SRT, WebVTT, ASS and SSA into one model, saves any of SRT, WebVTT and ASS, and shifts, scales, syncs and clips the timing. A document saved in the format it was read from, unchanged, gives back the same bytes; changed cues are written in the format's canonical form, and what a target format cannot hold is reported once per kind as Subtitle.Dropped.

SubtitleReaderOptions

How SubtitleDocument reads a subtitle file.

SubtitleRegion

A WebVTT region (a REGION block): a box cues can show in, which scrolls lines up as new cues arrive. Cues name it in Region.

SubtitleSpan

A run of a cue's text with one look: bold, italic, color, font and so on, as SRT tags, WebVTT cue tags and ASS override tags set them. Line breaks are \n inside Text. Fields a format cannot show are dropped when it is written, and reported as Subtitle.Dropped.

SubtitleStyle

A named ASS or SSA style (a Style: line of [V4+ Styles] or [V4 Styles]): the font, colors, outline and place cues get unless their override tags say otherwise. Colors are straight RGBA, with ASS's inverted alpha already turned around (255 is opaque).

SubtitleTrackWriter

Turns a SubtitleDocument into a subtitle track for a container: the Track to give the muxer and the Packets to write, in time order. Matroska takes SRT, WebVTT and ASS tracks; WebM takes WebVTT (WebMWebVtt); MP4 takes mov_text and WebVTT (MovText, Mp4WebVtt). What the codec cannot hold is reported as Subtitle.Dropped.

SubtitleWriterOptions

How SubtitleDocument writes a subtitle file. Output is always UTF-8.

WebVttCueSettings

A WebVTT cue's settings (the text after the timings: line:0 position:20% align:start), with the defaults the W3C spec gives and the same meaning as the browser's VTTCue. Read from WebVTT; WebVTT output writes them back, and builds them from Alignment for cues that have none.

Structs

SubtitlePosition

An exact place for a cue (ASS \pos), in the script's pixels (PlayResX by PlayResY, 384 by 288 when the script does not say). The cue's Alignment says which point of the text sits there.

Enums

SubtitleAlignment

Where a cue sits on the screen, as the keys of a numeric keypad lay out (ASS \an): 1 is bottom left, 2 bottom center (the usual place), 9 top right.

SubtitleFormat

A text subtitle format SubtitleDocument reads and writes.

WebVttAlign

How a WebVTT cue's text lines are aligned in its box (align setting).

WebVttLineAlign

Which edge of a WebVTT cue box its line places (the part after the comma in line:50%,center).

WebVttPositionAlign

Which point of a WebVTT cue box its position places (the part after the comma in position:10%,line-left).

WebVttVertical

A WebVTT cue's writing direction (vertical setting).
