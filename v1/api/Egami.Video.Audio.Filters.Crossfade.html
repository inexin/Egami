Class Crossfade

Namespace
Egami.Video.Audio.Filters
Assembly
Egami.Video.dll

Joins two streams with an overlap: the end of the first fades out while the start of the second fades in, like ffmpeg's acrossfade. The output is the first stream up to its last Duration, then the overlap mixed, then the rest of the second stream, so it lasts the two lengths minus the overlap. The overlap shortens to the shorter stream's length when one is shorter. Send each input's frames with Send(int, AudioFrame) and end each with Complete(int); frames of the second input wait until the first has ended. Both inputs must have the same rate and channels. Output starts at the first input's first timestamp and runs on without gaps.

Examples

// Join two clips with a 1 s equal-power overlap: 3 s + 2 s - 1 s = 4 s of output.
using Crossfade crossfade = new(MediaTime.FromSeconds(1));
foreach (AudioFrame frame in first)
{
    crossfade.Send(0, frame);
}

crossfade.Complete(0);
foreach (AudioFrame frame in second)
{
    crossfade.Send(1, frame);
}

crossfade.Complete(1);
int samples = 0;
while (crossfade.TryReceive(out AudioFrame? output))
{
    samples += output.SampleCount;
    output.Dispose();
}
