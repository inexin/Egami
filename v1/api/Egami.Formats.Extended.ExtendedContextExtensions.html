Egami.Formats.Extended

Registers Egami.Formats.Extended's formats with an EgamiContext. Nothing registers them on their own: an app calls WithExtendedFormats(EgamiContext) for every stable format, or one method per format.

Examples

// Every stable format of Egami.Formats.Extended, once at startup before any other Egami call:
// EgamiContext.SetDefault(new EgamiContext().WithExtendedFormats());

// ...or in a context of its own.
EgamiContext context = EgamiContext.Default.WithExtendedFormats();
using Raster image = Raster.Load("duck.png", context);

// A raster saves to a path through the context it was loaded with, so the extension picks PCX.
image.Save("duck.pcx");
using Raster back = Raster.Load("duck.pcx", context);
string format = back.Metadata.FormatName!;               // "PCX"

WithExtendedFormats(EgamiContext)

Returns a copy of context with every stable format of this package registered: PCX, SGI, Sun raster, XBM, XPM, WBMP and Farbfeld. Formats in preview are never included; each has its own method. Call it once, for example EgamiContext.SetDefault(new EgamiContext().WithExtendedFormats()) at startup.

public static EgamiContext WithExtendedFormats(this EgamiContext context)

Parameters

context EgamiContext

The context to add the formats to.

Returns

EgamiContext

The new context, its own formats first, so this package's are detected after them.

Examples

// Every stable format of Egami.Formats.Extended, once at startup before any other Egami call:

EgamiContext context = EgamiContext.Default.WithExtendedFormats();

image.Save("duck.pcx");
using Raster back = Raster.Load("duck.pcx", context);
