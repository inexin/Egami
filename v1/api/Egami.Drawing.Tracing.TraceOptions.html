Examples

// Black and white with potrace-like settings.
TraceResult ink = scan.Trace(new TraceOptions
{
    Mode = TraceMode.BlackAndWhite,
    Threshold = null,      // null: Otsu's method, as Raster.FindThreshold; or a level from 0 (black) to 1 (white)
    PathFidelity = 0.5f,   // 0: fewest curves; 1: every curve kept
    Corners = 0.75f,       // 0: round every corner; 1: keep every corner (a polygon)
    Noise = 4,             // regions under 4 pixels merge into the regions around them
    IgnoreWhite = true,    // the ink alone, no white background shape
});

// Or start from a preset and change one thing.
TraceResult polygon = scan.Trace(TraceOptions.BlackAndWhite with { Corners = 1 });

Corners

Gets how readily corners stay sharp, from 0 (round every corner) to 1 (keep every corner: the outline is a polygon). Defaults to 0.25.

Default

Gets the defaults: black and white at the Otsu threshold, with the paper traced as a white background shape. The defaults match potrace's published ones (corner threshold 1, curve tolerance 0.2, speckles under 2 pixels dropped).

public static TraceOptions Default { get; }

Noise

Gets the smallest region kept, in pixels: a region of fewer pixels merges into the regions around it, smallest first. 0 or 1 keeps every pixel. Defaults to 2, dropping single-pixel specks and holes.

public int Noise { get; init; }

PathFidelity

Gets how closely joined curves follow the shorter curves they replace, from 0 (loose: fewest curves) to 1 (tight: every curve kept). Defaults to 0.5, a tolerance of 0.2 pixels.

public float PathFidelity { get; init; }

Threshold

Gets the level that splits ink from paper, from 0 (black) to 1 (white): a pixel is ink when its intensity, over white by its alpha, is at most this. null (the default) finds it with Otsu's method, as FindThreshold(ThresholdMethod, ThresholdMode) does.

public float? Threshold { get; init; }
