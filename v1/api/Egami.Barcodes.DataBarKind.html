The forms of GS1 DataBar Omnidirectional that DataBar(string, DataBarOptions?) makes.

public enum DataBarKind

Fields

Omnidirectional = 0

One row, 96 modules wide and 33 tall, for scanners at any angle; the default.

Stacked = 2

The two halves stacked, 5 and 7 modules tall, for small items read by hand-held scanners.

StackedOmnidirectional = 3

The two halves stacked, each 33 modules tall, for scanners at any angle.

Truncated = 1

One row 13 modules tall, for small items read by hand-held scanners.

Examples

// A GTIN-14 for a retail item, in the full-height form and stacked for a small pack.
Barcode item = Barcode.DataBar("0950110153000");
Barcode stacked = Barcode.DataBar("09501101530003", new DataBarOptions { Kind = DataBarKind.Stacked });
Barcode limited = Barcode.DataBarLimited("09501101530003");
Console.WriteLine(item.HumanReadableText); // (01)09501101530003
