Class AudioPictures

Namespace
Egami.Video.Analysis
Assembly
Egami.Video.dll

Draws pictures of audio: a waveform (the min and max of each column with the RMS level shaded inside, as editors and podcast players show it) and a spectrogram (frequency over time, loudness as color). Both read the audio once with constant memory, so a three-hour file costs no more memory than a short one, and return a plain Raster<TPixel> without text; the CLI adds axes and legends.

Examples

// A waveform with each channel in its own strip, and a spectrogram on a logarithmic frequency axis in magma colors.
using Raster<Rgba8> waveform = AudioPictures.Waveform("shots.mkv", new WaveformOptions
{
    Width = 1200,
    Height = 240,
    Channels = AudioPictureChannels.Stacked,
});
waveform.Save("waveform.png");

using Raster<Rgba8> spectrogram = AudioPictures.Spectrogram("shots.mkv", new SpectrogramOptions
{
    Width = 1200,
    Height = 400,
    Scale = FrequencyScale.Logarithmic,
    Floor = -100,
});
spectrogram.Save("spectrogram.png");

Parameters

frames IEnumerable<AudioFrame>

The frames, in time order, in any sample format; they are read once and not disposed.

duration MediaTime

How long the audio runs, which sets where each column's window sits.

options SpectrogramOptions

The size, window, scale and colors, or null for Default.

context MediaContext

The context the picture is allocated from, or null for Default.

The picture.
