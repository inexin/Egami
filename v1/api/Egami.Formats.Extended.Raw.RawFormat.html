Class RawFormat

Egami.Formats.Extended.Raw

Camera RAW files: the sensor data a camera recorded, developed into an image on load. Reads DNG (Adobe's open RAW format, which phones, Leica, Pentax, Ricoh, Hasselblad and Adobe DNG Converter write). Load develops the image with the file's own white balance and colour data; RawReaderOptions picks an embedded preview, a half-size develop or the untouched sensor mosaic instead, and sets the develop. Registered with WithRaw(EgamiContext), which places it ahead of TIFF, since DNG files are TIFF files.

Examples

// RAW goes ahead of TIFF, since a DNG is a TIFF file; WithExtendedFormats() registers it too.
EgamiContext context = EgamiContext.Default.WithRaw();

// Load develops the sensor data: the camera's white balance and colour, AHD demosaicing, sRGB in Rgb16.
using Raster photo = Raster.Load("photo.dng", context);
photo.Save("photo.png");

// Probe reads the structure alone: the developed size, the camera and the embedded previews.
RasterInfo info = Raster.Probe("photo.dng", context);
Console.WriteLine($"{info.Width}×{info.Height}, {info.ImageCount} image(s)");
