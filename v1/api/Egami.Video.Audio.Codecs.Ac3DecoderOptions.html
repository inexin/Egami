Examples

// AC-3 decodes to planar float in Egami.Video's order: 5.1 is front left, front right, center, LFE, side left, side right.
using (AudioReader reader = AudioReader.Open("surround.ac3"))
{
    Console.WriteLine($"{reader.Layout}, {reader.SampleRate} Hz");
}

// The full dynamic range (no DRC gain words), mixed down to stereo with the stream's center and surround levels.
AudioReaderOptions stereo = new()
{
    Decoder = new AudioDecoderOptions { Ac3 = new Ac3DecoderOptions { DynamicRange = 0, Downmix = ChannelLayout.Stereo } },
};
using (AudioReader reader = AudioReader.Open("surround.ac3", stereo))
{
    Console.WriteLine($"{reader.Layout.ChannelCount} channels");
}

// Decoded and encoded again as FLAC, all six channels.
MediaFile.Transcode("surround.ac3", "surround.flac", FlacCodec.Instance);

Property Value

Ac3DecoderOptions

Downmix

Gets the layout to mix down to, or null for the stream's own. The mix follows ATSC A/52's LoRo downmix with the stream's center and surround mix levels: channels the layout has pass through, the center and surrounds fold into left and right (or into the center of a mono layout), and all levels are scaled together so the mix cannot clip. The LFE is kept only when the layout has one. A layout with more speakers than the stream gets silence in the others.

public ChannelLayout? Downmix { get; init; }

Property Value

ChannelLayout?

DynamicRange

Gets how much of the dynamic range control the stream carries (its dynrng gain words) to apply: 1, the default, applies it in full as the standard asks of a decoder; 0 ignores it for the full dynamic range; values between scale each gain in decibels, so 0.5 applies half the compression. Values above 1 compress more.

public double DynamicRange { get; init; }
