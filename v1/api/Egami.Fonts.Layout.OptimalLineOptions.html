Class OptimalLineOptions

Namespace
Egami.Fonts.Layout

The penalties and tolerances Optimal weighs, after Knuth and Plass ("Breaking Paragraphs into Lines", 1981) and TeX. Each line costs (LinePenalty + badness)^2, plus its break's penalty squared and the extra demerits below; the breaks with the least total win. A justified line's badness is 100 r^3, where r is how far its word spaces stretch (by up to half a space each at r = 1) or shrink; a ragged line's is 100 r^2, where r is the space left at its end in units of 2 em.

Examples

ParagraphStyle style = new()
{
    DefaultStyle = new TextStyle { FontFamilies = [fonts.Families[0]], Size = 16, Language = "en" },
    Align = TextAlign.Justify,
    LineFill = LineFill.Optimal,                    // Knuth-Plass, as TeX breaks paragraphs
    OptimalLines = new OptimalLineOptions
    {
        HyphenPenalty = 100,                        // hyphenate a little less readily than TeX
        ShrinkSpaces = true,                        // let spaces shrink to a third, as TeX does
    },
};

TextLayout layout = Paragraph.Create(text, style).Layout(160);

ShrinkSpaces

Gets whether word spaces in justified text may shrink, by up to a third of a space, to fit more on a line, as in TeX; false by default, as Word and browsers only stretch them. A last line (before a mandatory break or the paragraph's end) shrinks only when AlignLast justifies it.
