Class CameraMotion

Namespace
Egami.Video.Editing
Assembly
Egami.Video.dll

How the camera moved from one frame to the next, as Analyze(string, StabilizerOptions?, IProgress<MediaProgress>?, CancellationToken) measures it: a shift, a rotation and a scale per frame, in the clip's own pixels. It is pass 1 of stabilization; pass 2, Stabilize(CameraMotion, StabilizeOptions?), smooths the path and warps the frames. Save it as JSON to stabilize again with other settings without measuring again.

Examples

// Two passes: measure the camera's motion, then render the clip warped onto a smoothed path, zoomed to hide the edges.
CameraMotion motion = Stabilizer.Analyze("talk.avi");
File.WriteAllText("talk.motion.json", motion.ToJson());
VideoEdit edit = new();
edit.Track.Add(Clip.Open("talk.avi").Stabilize(motion, new StabilizeOptions { Smoothing = 20, Edges = StabilizeEdges.Zoom }));
edit.Render("steady.mkv");
