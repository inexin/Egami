Examples

// Silent stretches as silencedetect finds them (under -60 dBFS for 2 s by default), and the sample levels volumedetect
// and astats report, per channel and over all channels.
SilenceDetector silence = new(new SilenceOptions { Noise = -50, MinDuration = MediaTime.FromSeconds(0.5) });
AudioLevelMeter levels = new();
MediaAnalysis.Run("shots.mkv", new MediaAnalysisOptions { Scenes = null, AudioDetectors = [silence, levels] });

Console.WriteLine($"{silence.Ranges.Count} silent stretches");
AudioLevelReport report = levels.Report();
Console.WriteLine($"Peak {report.Overall.Peak:0.0} dBFS, RMS {report.Overall.Rms:0.0} dBFS, {report.Overall.Clipped} clipped");

Parameters

Peak double

The largest sample level in dBFS, as volumedetect's max_volume.

Rms double

The RMS level in dBFS, as volumedetect's mean_volume; a full-scale sine reads -3 dBFS.

DcOffset double

The mean sample value, from -1 to 1.

CrestFactor double

How far the peak stands above the RMS level, in dB.

Min double

The lowest sample value, from -1 to 1.

Max double

The highest sample value, from -1 to 1.

Clipped long

How many samples sit at full scale: the largest or smallest integer code, or 1 and beyond for float samples.

PeakCount long

How many samples reached the peak level.

NoiseFloor double

The lowest peak level in dBFS of any 50 ms window, leaving out windows of digital silence, as astats's noise floor.

ZeroCrossings long

How many times the signal changed sign.

Histogram IReadOnlyList<long>

How many samples fell in each 1 dB step below full scale: index 0 counts levels from 0 to -1 dBFS, index k from -k to -(k + 1) dBFS, and the last bin -143 dBFS and below, digital silence included. It has HistogramBins bins.
