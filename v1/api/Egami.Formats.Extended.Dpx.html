CineonDetails

Details only Cineon has, kept in FormatDetails. The writer writes the text and film fields back.

CineonFormat

Cineon, Kodak's film-scan format (version 4.5), from which DPX grew: a 1024-byte header and a 1024-byte film header, then 10-bit printing-density samples, three to a 32-bit word. Load gives the stored code values; DpxReaderOptions turns them into linear light. Registered with WithCineon(EgamiContext).

DpxDetails

Details only DPX has, kept in FormatDetails. The writer writes the text, film and television fields back.

DpxFormat

DPX (SMPTE ST 268, Digital Moving-Picture Exchange), the frame format of film scanning and visual effects: a 2048-byte header of file, image, film and television fields, then up to eight image elements of 1 to 16-bit integer or 32 and 64-bit float samples, usually 10-bit printing-density RGB. Load gives the first element as its stored code values; LoadAll gives every element, and DpxReaderOptions picks one or turns log code values into linear light. Registered with WithDpx(EgamiContext).
