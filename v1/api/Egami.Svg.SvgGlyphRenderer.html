Class SvgGlyphRenderer

Namespace
Egami.Svg
Assembly
Egami.Svg.dll

Draws the glyphs of an OpenType SVG table (question 20): each glyph's document is read once per font and kept, and the element glyphid is drawn in the font's units, its origin on the baseline. Set it on ColorGlyphRenderer; Rasterize<TPixel>(SvgRenderOptions?) uses it already.

Examples

// Emoji and other glyphs from an OpenType SVG table draw in color on a canvas given the renderer.
using (RasterCanvas<Rgba8> canvas = raster.CreateCanvas(new CanvasOptions { ColorGlyphRenderer = SvgGlyphRenderer.Instance }))
{
    canvas.DrawText("Hello", new System.Numerics.Vector2(10, 35), font, new SolidPaint(new RgbaF32(0, 0, 0, 1)));
}
