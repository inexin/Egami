An ordered list of up to 256 colors to map images onto: a brand palette, a display's inks, or one built from an image with Wu's quantizer. Use it as FixedPalette for the GIF, PNG, BMP and TGA writers, with Remap(Palette, DitherMode, float), or to find the nearest color yourself.

Build(Raster, PaletteOptions?)

Builds a palette for every frame of an image together: its own colors when they fit, Wu's quantizer otherwise, polished by RefineIterations. Alpha is kept in the colors, as for a palette PNG.

public static Palette Build(Raster image, PaletteOptions? options = null)

Parameters

image Raster

The image.

options PaletteOptions

The color limit and refinement, or null for Default; a fixed palette in them is returned as it is.

Returns

Palette

The palette.

Examples

// Build one palette from an image, polished by k-means, and use it for other images and for every GIF frame.
Palette shared = Palette.Build(first, new PaletteOptions { MaxColors = 64, RefineIterations = 6 });
second.Apply(ops => ops.Remap(shared), Ct);
second.Save("egret.gif", new GifWriterOptions { Palette = new PaletteOptions { FixedPalette = shared, Dither = DitherMode.Bayer4x4 } });
