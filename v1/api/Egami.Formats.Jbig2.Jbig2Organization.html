Enum Jbig2Organization

Namespace
Egami.Formats.Jbig2
Assembly
Egami.dll

How a JBIG2 stream lays out its segments (T.88 Annex D).

public enum Jbig2Organization

Fields

Embedded = 2

Segments without a file header, as a PDF embeds them (D.3).

RandomAccess = 1

A standalone file, every segment header first and the data after (D.2).

Sequential = 0

A standalone file, each segment's header followed by its data (D.1).

Examples

using Raster page = Raster.Load("book.jb2");
var details = (Jbig2Details)page.Metadata.FormatDetails!;
Console.WriteLine($"Page {details.PageIndex}, {details.Organization}, regions {details.Regions}");
Console.WriteLine($"Default pixel {details.DefaultPixel}, combined by {details.CombinationOperator}, lossless {details.Lossless}");
