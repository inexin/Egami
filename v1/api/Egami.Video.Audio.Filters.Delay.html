Class Delay

Namespace
Egami.Video.Audio.Filters
Assembly
Egami.Video.dll

Delays channels by putting silence in front of them, like ffmpeg's adelay: each channel can have its own delay, for example to line up microphones or fix lip sync. The output keeps the input's timestamps and gets longer by the longest delay; Flush() hands out the tail, so no input is lost.

Examples

// Keep 0.5 s to 2.5 s, start it at zero, delay the right channel 20 ms and add half a second of silence.
using AudioFilterChain chain = new AudioFilterChain(48000, ChannelLayout.Stereo)
    .Add(new Trim(MediaTime.FromSeconds(0.5), MediaTime.FromSeconds(2.5)))
    .Add(new Retime())
    .Add(new Delay([MediaTime.Zero, MediaTime.FromSeconds(0.02)]))
    .Add(new Pad(MediaTime.FromSeconds(0.5)));
