Class AiffFormat

Namespace
Egami.Video.Containers

AIFF and AIFF-C (.aif, .aiff, .aifc; Apple's Audio Interchange File Format 1.3 and its AIFF-C draft): big-endian integer PCM, AIFF-C's little-endian (sowt), 24 and 32-bit (in24, in32), float (fl32, fl64) and G.711 (ulaw, alaw) samples. Other AIFF-C compressions (ima4, MACE, QDesign and so on) pass through undecoded with an "X_AIFC/" codec id. The NAME, AUTH, "(c) " and ANNO chunks and an ID3 chunk become Tags (ID3 pictures become attachments), MARK markers become chapters, and a CHAN chunk gives the channel layout. The writer stores integer PCM as AIFF and float as AIFF-C, the title, artist, copyright and comment in the text chunks, any other tag and cover art in an ID3 chunk, chapters as markers and the layout of more than two channels in a CHAN chunk. A non-seekable output is written through a temporary file, since AIFF's sizes come before the samples. Seeking is sample exact.

Examples

// AIFF holds big-endian PCM; remuxing turns WAV's samples around without decoding. Metadata goes into its text chunks.
MediaFile.Remux("tone.wav", "tone.aiff");
using (AudioWriter writer = AudioWriter.Create("titled.aiff", new AudioWriterOptions
{
    Metadata = new MediaMetadata { Tags = new Dictionary<string, string> { ["TITLE"] = "Tone" } },
}))
{
    writer.Write(tone);
}

// AIFF-C's G.711 (ulaw, alaw), sowt and float samples decode like any other track.
using AudioReader reader = AudioReader.Open("titled.aiff");
Console.WriteLine($"{reader.Track.CodecId}: {reader.Track.SampleRate} Hz, {MediaFile.Probe("titled.aiff").Tags["TITLE"]}");

Methods

CreateMuxer(Stream, IReadOnlyList<TrackInfo>, MediaMetadata, MediaContext, bool)

Creates a muxer for one audio track of integer PCM (8, 16, 24 or 32 bits, either byte order), stored big-endian as AIFF, or float PCM (32 or 64 bits), stored as AIFF-C fl32 or fl64. Attachments other than images are left out with a "metadata-dropped" warning. AIFF cannot hold more than 4 GB of samples; write CAF or Wave64 for longer audio.
