ToRaster<TPixel>(ColorProfile, ColorTransformOptions?)

Converts the planes to RGB in target's encoding: the frame's Color says what it is coded in, and a PQ or HLG frame going to an SDR target is tone mapped (ToneMapping, BT.2390 by default) from its static Hdr metadata, through Egami's color pipeline. The frame's own values are left as they are; ToRaster<TPixel>(EgamiContext?) gives them unconverted.

public Raster<TPixel> ToRaster<TPixel>(ColorProfile target, ColorTransformOptions? options = null) where TPixel : unmanaged, IPixelType<TPixel>

Parameters

target ColorProfile

The encoding to convert to, such as Srgb.

options ColorTransformOptions

The rendering intent and tone mapping, or null for Default.

Returns

Raster<TPixel>

The raster, tagged with target. The caller must dispose it.

Type Parameters

TPixel

The pixel type.

Examples

using var reader = VideoReader.Open("hdr10.webm");
foreach (YuvVideoFrame frame in reader.ReadFrames())
    using (frame)
    using (Raster<Rgba8> sdr = frame.ToRaster<Rgba8>(ColorProfile.Srgb))
        sdr.Save($"frame-{frame.Timestamp.Ticks}.png");

Exceptions

ArgumentNullException

target is null.
