Class Zstandard

Zstandard (RFC 8878) compression in managed code: the codec TIFF's ZSTD compression uses, for format plugins and apps that need it too, such as KTX 2's supercompressed mip levels. Both directions work on spans the caller sizes, and each thread keeps its tables, so a warm call allocates nothing.

Examples

// Compress into a buffer sized for the worst case, then keep the bytes written.
byte[] packed = new byte[Zstandard.MaxCompressedLength(data.Length)];
int written = Zstandard.Compress(data, packed, level: 9);

// Decompress into a buffer of the size you know (KTX 2 stores each level's): it returns the bytes written.
byte[] unpacked = new byte[data.Length];
int length = Zstandard.Decompress(packed.AsSpan(0, written), unpacked);

Decompress(ReadOnlySpan<byte>, Span<byte>)

Decompresses the Zstandard frames of source, one after another, into destination. Skippable frames are skipped and a frame's checksum is checked when it has one.
