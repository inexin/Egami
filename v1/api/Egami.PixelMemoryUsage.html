Examples

PixelMemoryUsage usage = PooledPixelMemorySource.Shared.Usage;
usage.CaptureStackTraces = true;
usage.LeakDetected += (_, leak) => Console.WriteLine($"{leak.Bytes} bytes never disposed, allocated at {leak.StackTrace}");
usage.TrackLeaks = true;
RunTheCodeUnderSuspicion();
Console.WriteLine($"{usage.LiveBlocks} blocks, {usage.LiveBytes} bytes still out");

Remarks

The counts are always kept, at the cost of one atomic addition per allocation and per return. Leak tracking adds a small object with a finalizer to every block allocated while it is on, so turn it on only while looking for a leak.

Events

LeakDetected

Occurs when a block allocated while TrackLeaks was on is collected by the garbage collector without having been disposed. Handlers run on the finalizer thread, so they must be quick, must not throw, and must not touch objects that may already be finalized. Leaks are reported here, not through Diagnostics: they belong to the memory source and are found after any call has ended.
