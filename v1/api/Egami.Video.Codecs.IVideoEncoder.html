Interface IVideoEncoder

Namespace
Egami.Video.Codecs
Assembly
Egami.Video.dll

Turns frames into packets with a send and receive loop, the mirror of IVideoDecoder. After each Send(VideoFrame) call TryReceive(out EncodedPacket?) until it returns false; at the end call Flush() and receive what is left.

public interface IVideoEncoder : IDisposable
Inherited Members
IDisposable.Dispose()

Examples

using IVideoEncoder encoder = VideoCodecs.MotionJpeg.CreateEncoder(new VideoEncoderOptions { Width = 640, Height = 480 }, MediaContext.Default);
using IMuxer muxer = MediaFile.CreateMuxer("out.avi", [encoder.Track]);
encoder.Send(frame);
while (encoder.TryReceive(out EncodedPacket? packet))
    using (packet) muxer.WritePacket(packet);

Encodes a frame with per-frame settings, such as ForceKeyframe. Encoders whose every packet is a keyframe (Motion JPEG, uncompressed video) treat it as Send(VideoFrame).

Examples

// Live: no lookahead, so each packet comes out as soon as its frame goes in, at a constant bitrate.
VideoEncoderOptions options = new()
{
    Width = 320,
    Height = 240,
    LatencyMode = LatencyMode.Realtime,
    RateControl = RateControlMode.ConstantBitrate,
    Bitrate = 300_000,
};
using IVideoEncoder encoder = VideoCodecs.Vp8.CreateEncoder(options, MediaContext.Default);
using IMuxer muxer = MediaFile.CreateMuxer(stream, "webm", [encoder.Track], leaveOpen: true);
for (int i = 0; i < 60; i++)
{
    using VideoFrame<Rgb8> frame = new(Raster.Create(320, 240, new Rgb8((byte)i, 90, 160)), new MediaTime(i, new Rational(1, 30)));

    // A viewer joined: start a keyframe so they can decode from here.
    encoder.Send(frame, new EncodeFrameOptions { ForceKeyframe = i == 30 });
    while (encoder.TryReceive(out EncodedPacket? packet))
    {
        using (packet)
        {
            muxer.WritePacket(packet);
        }
    }
}

encoder.Flush();
muxer.Finish();
