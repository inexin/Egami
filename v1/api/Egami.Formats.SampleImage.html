An image as its codestream stores it: every component's samples at their own precision and sign, with no color conversion, widening or offset. For a container that keeps its own pixel description, such as DICOM, which needs the stored values to apply its rescale, window and color rules itself. JPEG (baseline, extended 12-bit and lossless at 2 to 16 bits), JPEG 2000 and JPEG XL load this way.

Examples

// The values the codestream stores: no color conversion, no widening to 8 or 16 bits, signed samples kept signed.
SampleImage image = SampleImage.Load("duck.jpg");
Console.WriteLine($"{image.Color}, {image.Components.Count} components of {image.Components[0].Precision} bits");

// A YCbCr JPEG stays YCbCr: luma, then the two chroma samples of each pixel, at full resolution.
Span<int> row = image.Row(0);
int luma = row[0], cb = row[1], cr = row[2];

Remarks

Samples are interleaved in component order, one int each, so signed values keep their sign. Components sampled at less than full resolution are brought to the image's size: JPEG's chroma upsampled as Load(Stream, EgamiContext?, ReaderOptions?) does it (or replicated with FastUpsampling), JPEG 2000's replicated.

A preview, as DICOM is: marked [Experimental] with the diagnostic EGAMIX001, so a call does not compile until the app suppresses that id, and it may change in any minor release.

Exceptions

NotSupportedException

The format has no stored samples to give, or this image's do not fit: floating-point or more than 31 bits, or a JPEG with 2 or 4 components. Also thrown for Region, MinimumSize and ConvertColorTo.

UnsupportedFormatException

No registered format matches the data.

CorruptDataException

The data breaks the format's rules.

LimitExceededException

The image breaks a safety limit.

ArgumentNullException

stream is null.

Decodes an image of a known format to its stored samples, without detecting the format: a codestream taken from a container, such as a DICOM pixel data fragment. See Load(Stream, EgamiContext?, ReaderOptions?).

context EgamiContext

Returns

SampleImage

Examples

// A codestream taken out of a container, such as a DICOM pixel data fragment, is read as the format the container names.
SampleImage image = SampleImage.Load(fragment, JpegFormat.Info);
SampleComponent gray = image.Components[0];
int first = image.Samples.Span[0];       // 0 to 4095 for 12 unsigned bits
