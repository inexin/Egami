Class AudioWriter

Namespace
Egami.Video
Assembly
Egami.Video.dll

Writes an audio file in a few lines, the twin of VideoWriter: encodes each frame and muxes it, picking the container from the file extension. Frames may have any length and sample format; the writer resamples, mixes and converts them to what the codec takes. The rate, layout and bit depth come from the options or the first frame.

Examples

// FLAC for .flac files, PCM for .wav, .w64, .mka and .mp4 unless the options name a codec; FLAC levels run 0 to 8.
using (AudioWriter writer = AudioWriter.Create("tone.flac", new AudioWriterOptions { Level = 8, BitsPerSample = 24 }))
{
    writer.Write(tone);
}

// 16-bit WAV at 44.1 kHz: the writer resamples and converts.
using (AudioWriter writer = AudioWriter.Create("tone.wav", new AudioWriterOptions { SampleRate = 44100, BitsPerSample = 16 }))
{
    writer.Write(tone);
}

Create(string, AudioWriterOptions?, MediaContext?)

Creates an audio file, choosing the container by the extension (.wav, .w64, .flac, .mkv, .mka, .mp4, .m4a and so on). An existing file is replaced. Without a codec in the options, .flac files get FLAC, Ogg (.opus, .ogg, .oga) and WebM files Opus, and the others PCM.
