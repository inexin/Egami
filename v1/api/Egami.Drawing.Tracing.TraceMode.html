How Trace(Raster, TraceOptions?, EgamiContext?) turns pixels into shapes.

public enum TraceMode

Fields

BlackAndWhite = 0

Splits the image into ink and paper at Threshold and traces the ink as black shapes, with smooth curves and sharp corners fitted to the pixel edges.

Color = 2

Reduces the image to Colors of its own flat colors (or to Palette), leaving out the blends along edges, and traces each color as a layer of shapes.

Grayscale = 1

Reduces the image to Colors gray levels of its own (or to Palette) and traces each level as a layer of gray shapes.

Logo = 3

For logos, icons and other flat-color art with antialiased edges: reduces the image to its flat colors as Color does, then places each edge to a fraction of a pixel from smooth fields of how much of each pixel each color covers, for smoother curves than Color on small art. Transparency around the art is left out; transparency the art encloses is traced as white. An image that is not flat color (a photo, a gradient) is refused.

Examples

// Black and white with every setting spelled out.
TraceResult ink = scan.Trace(new TraceOptions
{
    Mode = TraceMode.BlackAndWhite,
    Threshold = null,      // null: Otsu's method, as Raster.FindThreshold; or a level from 0 (black) to 1 (white)
    PathFidelity = 0.5f,   // 0: fewest curves; 1: curves that follow the pixels most closely
    Corners = 0.75f,       // 0: round every corner; 1: keep every corner (a polygon)
    Noise = 4,             // regions under 4 pixels merge into the regions around them
    IgnoreWhite = true,    // the ink alone, no white background shape
});

// Or start from a preset and change one thing.
TraceResult polygon = scan.Trace(TraceOptions.BlackAndWhite with { Corners = 1 });
