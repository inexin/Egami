Examples

if (image.Metadata.Exif is ExifData exif)
{
    Console.WriteLine($"{exif.CameraMake} {exif.CameraModel}, {exif.DateTaken}, {exif.Location}");
    if (exif.TryGet(ExifKey.ExposureTime, out ExifEntry? exposure))
    {
        Console.WriteLine($"1/{1 / exposure.AsDouble():0} s");
    }

    exif.Set(ExifKey.Copyright, "© 2026 Example");
    exif.Remove(ExifKey.GpsLatitude);
}

AsString()

Returns the value as text. ASCII values up to the first zero byte, read as UTF-8 when they are valid UTF-8 and as Latin-1 otherwise. The Windows XP tags (XPTitle and the others) as UTF-16. The encoded strings (UserComment, GpsProcessingMethod, GpsAreaInformation) by their character-code prefix: ASCII, UNICODE (UTF-16, either byte order), JIS (Shift-JIS when the app registered the code page provider) or undefined.
