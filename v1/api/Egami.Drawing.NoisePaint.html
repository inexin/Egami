Procedural noise as a paint. Fractal(float, float, int, int, Size?) and Turbulence(float, float, int, int, Size?) follow SVG 1.1's feTurbulence step by step (its random table, lattice and gradients), so the pixels match Skia's noise shaders and browsers within rounding; Simplex(float, int, int, Size?) is smoother and can tile. Each of the four channels is its own noise, straight alpha included. The noise lives in paint coordinates: it scales and turns with the canvas transform and LocalMatrix.

Examples

using (RasterCanvas<Rgba8> canvas = raster.CreateCanvas())
{
    // SVG's feTurbulence fractal noise, stitched so a 128-pixel tile repeats without a seam, made gray by a color matrix.
    Paint stone = NoisePaint.Fractal(0.03f, 0.03f, octaves: 5, seed: 7, tileSize: new Size(128, 128))
        .WithColorMatrix(new ColorMatrix([0.3f, 0.6f, 0.1f, 0, 0, 0.3f, 0.6f, 0.1f, 0, 0, 0.3f, 0.6f, 0.1f, 0, 0, 0, 0, 0, 0, 1]));
    canvas.DrawPaint(stone);

    // Smooth simplex noise as a soft overlay.
    canvas.DrawPaint(NoisePaint.Simplex(0.01f, octaves: 3) with { BlendMode = BlendMode.Overlay, Opacity = 0.5f });
}

Simplex(float, int, int, Size?)

Returns simplex noise: each channel a half plus half the octaves' sum, scaled so it stays within 0 to 1. With a tile size it repeats exactly over that tile, made by running the noise around a torus.
