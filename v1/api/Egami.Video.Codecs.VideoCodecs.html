CreateDecoder(VideoTrackInfo, VideoDecoderOptions?, MediaContext?)

Creates a decoder for a track, which hands out frames in the codec's own planar YUV layout.

public static IVideoDecoder CreateDecoder(VideoTrackInfo track, VideoDecoderOptions? options = null, MediaContext? context = null)

Parameters

track VideoTrackInfo

The track.

options VideoDecoderOptions

How to decode, or null for the defaults.

context MediaContext

The context, or null for Default.

Returns

IVideoDecoder

The decoder. The caller must dispose it.

Examples

// A codec by hand: packets in, frames out. VideoCodecs finds the codec for a track's CodecId (CodecIds.Vp9 here).
using IDemuxer demuxer = MediaFile.OpenDemuxer("movie.webm");
VideoTrackInfo track = demuxer.Info.VideoTrack!;
bool isVp9 = track.CodecId == CodecIds.Vp9;
using IVideoDecoder decoder = VideoCodecs.CreateDecoder(track, new VideoDecoderOptions { Errors = DecodeErrorMode.Throw });
int frames = 0;
while (demuxer.ReadPacket() is { } packet)
{
    using (packet)
    {
        decoder.Send(packet);
    }

    while (decoder.TryReceive(out YuvVideoFrame? frame))
    {
        using (frame)
        {
            frames++;
        }
    }
}

decoder.Flush();

Exceptions

UnsupportedFormatException

No registered codec decodes the track.
