Namespace Egami.Formats.Ccitt

Classes

CcittFax

Raw CCITT fax coding as a PDF filter: Group 3 and Group 4 data (ITU-T T.4 and T.6) with PDF's CCITTFaxDecode parameters, byte-aligned Group 4 included, which a TIFF wrapper cannot express. Decode(ReadOnlySpan<byte>, CcittFaxParameters, out int, EgamiContext?) reads it and Encode(ReadOnlySpan<byte>, CcittFaxParameters) writes Group 4 and one-dimensional Group 3. To load the data as an image instead, use CcittFormat.

CcittFaxParameters

The parameters of CCITT fax data as a PDF's CCITTFaxDecode filter gives them in its DecodeParms dictionary, with PDF's defaults. One record serves both Decode(ReadOnlySpan<byte>, CcittFaxParameters, out int, EgamiContext?) and CcittReaderOptions.

CcittFormat

Raw CCITT fax data (ITU-T T.4 and T.6) as an image, read only. The data has no header, so detection never picks it: load it with the format named and its parameters in CcittReaderOptions, as in Load(ReadOnlyMemory<byte>, FormatInfo, EgamiContext?, ReaderOptions?). It loads as Gray8, black 0 and white 255, whatever BlackIs1 says. It is registered in Default so a context lists it.

CcittReaderOptions

Options for reading raw CCITT data: its parameters, which the data cannot carry itself.
