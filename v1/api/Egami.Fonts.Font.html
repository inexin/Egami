A typeface at a size: the em in canvas units (pixels on a raster, points on a PDF page). Scales the face's font-unit metrics and turns text into a positioned GlyphRun.

Examples

// A caption on a photo: white text with a dark shadow, its baseline 24 pixels above the bottom.
using Raster<Rgba8> photo = Raster.Create(640, 360, new Rgba8(90, 120, 160, 255));
var font = new Font(Typeface.FromFile(FontFile), 28);
using (RasterCanvas<Rgba8> canvas = photo.CreateCanvas())
{
    var origin = new Vector2(24, photo.Height - 24);
    canvas.DrawText("Lofoten, March", origin + new Vector2(2, 2), font, new Rgba8(0, 0, 0, 160));
    canvas.DrawText("Lofoten, March", origin, font, Rgba8.White);
}

Remarks

There is no DPI: a 12-unit font on a raster is 12 pixels per em, and the canvas transform scales it like any other drawing. Use FromPoints(Typeface, float, float) to size from points at a resolution.

default(Font) has no typeface: its Typeface is null, its Scale 0, and the members that need the face (metrics, advances, shaping and measuring) throw InvalidOperationException. Create fonts with the constructor or FromPoints(Typeface, float, float).

Examples

// Measure each word of a longer text in place: a span is measured without making a string of it.
ReadOnlySpan<char> text = "Measure every word of this sentence";
float widest = 0;
foreach (Range word in text.Split(' '))
{
    widest = Math.Max(widest, font.MeasureText(text[word]).Advance);
}

Examples

// A label shrunk until it fits a 200-pixel button, then centred on it.
const string label = "Download the full report";
var box = new RectF(20, 20, 200, 40);
var font = new Font(face, 24);
while (font.MeasureText(label).Advance > box.Width - 16 && font.Size > 8)
{
    font = new Font(face, font.Size - 1);
}

TextMeasure size = font.MeasureText(label);
var origin = new Vector2(
    box.X + ((box.Width - size.Advance) / 2),
    box.Y + ((box.Height - size.Height) / 2) + size.Ascent);
using Raster<Rgba8> image = Raster.Create(240, 80, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = image.CreateCanvas())
{
    canvas.FillRoundRect(new RoundRect(box, 8), new Rgba8(30, 90, 200, 255));
    canvas.DrawText(label, origin, font, Rgba8.White);
}

Shape(string, ShapingOptions?)

Turns text into a glyph run with the full shaper (Shape(string, Font, ShapingOptions?)): ligatures, kerning, marks and the script rules of the font's GSUB and GPOS, bidi order, one glyph run for every line. \n, \r\n, \r, U+0085, U+2028 and U+2029 start a new line one LineHeight lower at x = 0 (a vertical line one LineHeight to the left); other control characters give no glyph; characters the face lacks give .notdef.

public GlyphRun Shape(string text, ShapingOptions? options = null)

Parameters

text string

The text.

options ShapingOptions

The direction, language, script, features and spans, or null for Default. One run has one font, so the options may not ask for fallback or span fonts; draw such text from Shape(string, Font, ShapingOptions?).

Returns

GlyphRun

The run, with the text and a cluster per glyph; positions are relative to the first baseline's left end, y down.
