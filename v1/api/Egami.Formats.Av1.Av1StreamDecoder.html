Class Av1StreamDecoder

Namespace
Egami.Formats.Av1

Decodes an AV1 video stream (AV1 Bitstream and Decoding Process 1.0.0 with errata 1) a temporal unit at a time, as WebM, Matroska, MP4 and IVF files carry it: key, inter, intra-only and switch frames with every inter tool of the Main, High and Professional profiles, 8 to 12 bits and 4:0:0 to 4:4:4, film grain, scaled references and scalable streams. The frames equal libaom's and dav1d's sample for sample. Containers are not read here: Egami.Video reads them and uses this decoder, and any other source of AV1 temporal units can too.

Examples

// AV1 temporal units in stream order, here from an IVF file (Egami.Video reads WebM, Matroska, MP4 and IVF for you).
using Av1StreamDecoder decoder = new(new Av1DecoderOptions { ApplyFilmGrain = true });
foreach (byte[] temporalUnit in IvfFrames("clip-av1.ivf"))
{
    decoder.Send(temporalUnit);
    while (decoder.NextFrame is Av1FrameInfo next)
    {
        // A unit can show no frame (a hidden reference), one, or one per spatial layer.
        using YuvRaster picture = next.BitDepth == 8
            ? YuvRaster.Create(next.Width, next.Height, next.Chroma, YuvColor.Bt601Limited)
            : YuvRaster.Create(next.Width, next.Height, next.Chroma, next.BitDepth, YuvColor.Bt601Limited);
        decoder.TryReceiveFrame(picture, out Av1FrameInfo info); // the picture is the caller's: change it or keep it
        shown++;
    }
}

Remarks

Send(ReadOnlySpan<byte>) takes one temporal unit: low-overhead OBUs (section 5), each with its size field, as containers store them. It can show no frame (a hidden frame, kept as a reference), one, or with OutputAllLayers one per spatial layer; TryReceiveFrame(YuvRaster, out Av1FrameInfo) then copies each out in order. A frame shown with show_existing_frame comes out again without decoding.

The decoder keeps at most eight reference frames and the frame being decoded, decodes a frame's tiles and its loop filters' rows on up to MaxParallelism threads, and checks each frame's size against the context's Limits. An instance is not thread-safe.

TryReceiveFrame(YuvRaster, out Av1FrameInfo)

Copies the next shown frame of the last temporal unit into destination, film grain applied unless the options turn it off. The copy is the caller's: the decoder's references do not share it.

public bool TryReceiveFrame(YuvRaster destination, out Av1FrameInfo info)

Parameters

destination YuvRaster

A raster of the frame's size (NextFrame) and chroma format: 8-bit for an 8-bit stream, else 16-bit of the stream's bit depth. A monochrome frame needs a 4:0:0 raster. Its color is left as it is.

info Av1FrameInfo
