Class CodecHeaders

Namespace
Egami.Video.Codecs
Assembly
Egami.Video.dll

Lists what a compressed frame's header says, field by field under the codec specification's names, for tools such as egami-video info --headers and for checking an encoder's output. VP8 (RFC 6386 sections 9 and 19) and VP9 (VP9 bitstream specification sections 6.2 and 6.3) are described; later codecs add theirs to the same call.

Examples

using IDemuxer demuxer = MediaFile.OpenDemuxer("clip.webm");
TrackInfo track = demuxer.Info.VideoTrack!;
while (demuxer.ReadPacket() is { } packet)
{
    using (packet)
    {
        if (packet.TrackNumber == track.Number)
            foreach (CodecHeaderField field in CodecHeaders.Describe(track, packet))
                Console.WriteLine($"{field.Name} = {field.Value}");   // key_frame = 0, show_frame = 1, refresh_golden_frame = 0 ...
    }
}

Describe(TrackInfo, EncodedPacket)

Lists the header fields of one packet of track, in bitstream order. Lists in the header give one field per entry, named with an index (segment_prob[1]); fields the frame does not code are left out, not filled with the values they imply. For VP8, the coefficient and motion vector probability updates are given as counts (coeff_prob_updates, mv_prob_updates). For VP9, a superframe lists its index (frames_in_superframe_minus_1, frame_sizes[i]) and then each frame after a frame field with its index; each frame gives its uncompressed header, then the compressed header's tx_mode and reference mode with its probability updates as counts (coef_prob_updates and so on). A VP9 frame that takes its size from a reference is read with the track's size, which decides how many tile bits it has.
