A picture held as separate luma (Y) and chroma (U, V) planes, plus an optional alpha plane, the way video codecs, AVIF, lossy WebP and JPEG store it. This base class is used when the sample type is not known at compile time; YuvRaster<TSample> gives the planes. Convert to and from a Raster with ToRaster(YuvConvertOptions?), CopyTo<TPixel>(Raster<TPixel>, YuvConvertOptions?, CancellationToken) and FromRaster(Raster, ChromaFormat, YuvColor, bool, YuvConvertOptions?).

Examples

// A 1080p frame as video stores it: full-size luma, chroma at half width and height, BT.709 at limited range.
using YuvRaster<byte> frame = YuvRaster.Create(1920, 1080, ChromaFormat.Yuv420, YuvColor.Bt709Limited);

// 10-bit HDR planes hold samples 0 to 1023 in ushorts; an alpha plane is optional.
using YuvRaster<ushort> hdr = YuvRaster.Create(3840, 2160, ChromaFormat.Yuv420, 10, YuvColor.Bt2020Limited, alpha: true);
Console.WriteLine($"Chroma planes are {frame.U!.Width}×{frame.U.Height}");

Remarks

A YUV raster is not a Raster: one pixel is spread over planes of different sizes. Operations other than Crop and Resize run on a Raster after conversion. It is not thread-safe for writing, like a raster.

CopyFromPacked(YuvPackedFormat, ReadOnlySpan<byte>, int, ReadOnlySpan<byte>, int)

Copies a frame in an interleaved layout into this raster's planes, with one SIMD pass. The raster must match the layout: 4:2:0 8-bit for NV12 and NV21, 4:2:0 10-bit for P010, 4:2:0 at 10, 12 or 16 bits for P016, 4:2:2 8-bit for YUYV and UYVY.

public void CopyFromPacked(YuvPackedFormat format, ReadOnlySpan<byte> data, int stride = 0, ReadOnlySpan<byte> chroma = default, int chromaStride = 0)

Parameters

format YuvPackedFormat

The layout.

data ReadOnlySpan<byte>

The frame: the luma plane for two-plane layouts, or the only plane for packed 4:2:2.

stride int

The distance between rows of data, in bytes. 0 means rows are packed.

chroma ReadOnlySpan<byte>

The interleaved chroma plane of a two-plane layout, or empty when it follows the luma rows in data (at stride × Height). Ignored for YUYV and UYVY.

chromaStride int

The distance between chroma rows, in bytes. 0 means the luma stride, or the packed chroma row when an odd width makes that longer.

Examples

// An NV12 frame from Media Foundation or MediaCodec: Y rows, then interleaved U, V rows, both at the same stride.
int width = 640, height = 360, stride = 704;
byte[] nv12 = new byte[stride * height * 3 / 2];
using YuvRaster<byte> frame = YuvRaster.Create(width, height, ChromaFormat.Yuv420, YuvColor.Bt709Limited);
frame.CopyFromPacked(YuvPackedFormat.Nv12, nv12, stride);

// A webcam's YUYV, 4:2:2 in one plane, the other way.
using YuvRaster<byte> webcam = YuvRaster.Create(width, height, ChromaFormat.Yuv422, YuvColor.Bt601Limited);
byte[] yuyv = new byte[width * 2 * height];
webcam.CopyToPacked(YuvPackedFormat.Yuyv, yuyv);

Exceptions

ArgumentException

The raster does not match the layout.

ArgumentOutOfRangeException

A stride is too small or a span too short.

ObjectDisposedException

The raster has been disposed.

Examples

using YuvRaster<byte> frame = YuvRaster.Create(1920, 1080, ChromaFormat.Yuv420, YuvColor.Bt709Limited);

// Scale the planes before converting, as video does; crops start on a chroma sample (even x and y at 4:2:0).
using YuvRaster<byte> small = frame.Resize(1280, 720, ResampleFilter.Bicubic);
using YuvRaster<byte> center = small.Crop(new Rect(320, 180, 640, 360));

// A player scales every frame into the same raster.
using YuvRaster<byte> screen = YuvRaster.Create(960, 540, ChromaFormat.Yuv420, YuvColor.Bt709Limited);

// Everything else (rotate, color adjustments, drawing) runs on a Raster after conversion.
using Raster<Rgba8> rgb = center.ToRaster<Rgba8>();

FromRaster(Raster, ChromaFormat, YuvColor, bool, YuvConvertOptions?)

Converts the first frame of a raster to a new 8-bit YUV raster. Metadata is copied.

public static YuvRaster<byte> FromRaster(Raster source, ChromaFormat chromaFormat, YuvColor color, bool alpha = false, YuvConvertOptions? options = null)

Parameters

source Raster

The raster to convert, of any pixel type.

chromaFormat ChromaFormat

The chroma resolution.

color YuvColor

The matrix, range and siting to encode with.

alpha bool

Whether to add an alpha plane, holding the source's alpha (opaque for sources without). Defaults to false: alpha is dropped.

Returns

Examples

Load(Stream, EgamiContext?, ReaderOptions?)

Decodes a format's own planes, with no color conversion or chroma upsampling: for JPEG, a YCbCr file's planes at its own sampling (4:2:0, 4:2:2 or 4:4:4; other samplings are replicated up to 4:4:4) and a gray file's as 4:0:0, all Jpeg. MinimumSize decodes at a reduced scale (1/2, 1/4 or 1/8).

public static YuvRaster Load(Stream stream, EgamiContext? context = null, ReaderOptions? options = null)

Parameters

stream Stream

The encoded image. It is read from its current position and left open.

context EgamiContext

The context, or null for Default.

options ReaderOptions

How to read, or null for Default.

Returns

YuvRaster

The raster. The caller must dispose it.

Examples

// A JPEG's own planes, as decoded: no chroma upsampling and no color conversion.
YuvRasterInfo info = YuvRaster.Probe("duck.jpg");
Console.WriteLine($"{info.Info.Width}×{info.Info.Height}, planes: {info.ChromaFormat}");
using YuvRaster planes = YuvRaster.Load("duck.jpg");

// Saving JPEG-colored 8-bit planes skips color conversion and downsampling; other planes are converted first.
planes.Save("copy.jpg", new JpegWriterOptions { Quality = 90 });

Exceptions

NotSupportedException

UnsupportedFormatException

No registered format matches the data.

CorruptDataException

The data breaks the format's rules.

LimitExceededException

The image breaks a safety limit.

ArgumentNullException

stream is null.

Resize(int, int, ResampleFilter)

Returns a new raster with every plane resized by filter, as a Gray8 or Gray16 resize would, keeping the chroma format, siting and color. Samples are clamped to the bit depth, since some filters overshoot. Scaling planes before converting costs half as much at 4:2:0 as scaling RGB after.

public YuvRaster Resize(int width, int height, ResampleFilter filter = ResampleFilter.Bicubic)

Parameters

width int

The new luma width, at least 1.

height int

The new luma height, at least 1.

filter ResampleFilter

The resampling kernel. Defaults to Bicubic.

Returns

YuvRaster

The new raster, with a copy of the metadata. The caller must dispose it.

Examples

using YuvRaster<byte> frame = YuvRaster.Create(1920, 1080, ChromaFormat.Yuv420, YuvColor.Bt709Limited);

// Scale the planes before converting, as video does; crops start on a chroma sample (even x and y at 4:2:0).
using YuvRaster<byte> small = frame.Resize(1280, 720, ResampleFilter.Bicubic);

The target must have the same sample type, chroma format, bit depth and color. An alpha plane is resized when both have one; a target alpha plane with no source alpha is made opaque. The target's metadata is left alone.
