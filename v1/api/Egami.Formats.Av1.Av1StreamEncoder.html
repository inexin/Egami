Class Av1StreamEncoder

Namespace
Egami.Formats.Av1
Assembly
Egami.dll

Encodes an AV1 video stream (AV1 Bitstream and Decoding Process 1.0.0 with errata 1) a frame at a time: key, intra-only and inter frames, inter blocks predicted from up to seven references with every single and compound mode, inter-intra, overlapped and warped motion, and hidden frames shown later with show_existing_frame. Each frame's Av1FramePlan says what it is (its type, whether it is shown), its quality or quantizer, and which reference slots it reads and refreshes, so rate control and group-of-frames planning stay with the caller: Egami.Video drives this encoder for its containers, and any other source of frames can too. The frames decode in libaom and dav1d exactly as in Av1StreamDecoder.

Examples

// Pictures of one size, here decoded from a clip; Egami.Video writes WebM, MP4 and IVF and plans the frames for you.
using Av1StreamEncoder encoder = new(new Av1SequenceOptions { Width = pictures[0].Width, Height = pictures[0].Height });
units.Add(encoder.Encode(pictures[0], new Av1FramePlan { Kind = Av1FrameKind.Key, Quality = 60 }).Data.ToArray());

// A hidden frame from four pictures ahead goes into slot 1; the three pictures between read it as ALTREF (from the future)
// and the frame before as LAST, then the hidden frame is shown when its time comes.
Av1FramePlan between = new() { Quality = 60, ReferenceSlots = [0, 0, 0, 0, 1, 1, 1] };
encoder.Encode(pictures[4], new Av1FramePlan { Quality = 55, Show = false, OrderHint = 4, RefreshSlots = 0b10 });
for (int i = 1; i < 4; i++)
{
    Av1EncodedFrame frame = encoder.Encode(pictures[i], between); // the first unit also holds the hidden frame
    units.Add(frame.Data.ToArray()); // an MP4 sample or a Matroska block; frame.LumaPsnr says how close it came
}

units.Add(encoder.ShowExisting(1).Data.ToArray());

Remarks

Encode(YuvRaster, Av1FramePlan) returns low-overhead OBUs (section 5), each with its size field and without temporal delimiters, as MP4, Matroska and WebM store them: a key frame starts with the sequence header. A hidden frame's OBUs are held and lead the temporal unit of the next shown frame, so every Data that is not empty is one whole temporal unit.

The encoder keeps the eight reference slots as a decoder does, decides each frame on up to MaxParallelism threads (one per tile) and checks the frame size against the context's Limits. The output does not depend on the thread count. An instance is not thread-safe.

Methods

Analyze(IReadOnlyList<Av1AnalysisFrame>)

Runs the temporal model over frames ahead, in the order they will be coded (References says which earlier ones each predicts from): how much of each frame's content, block by block, the frames after it reuse. A frame's Av1FrameAnalysis goes in its plan (Analysis), and its Importance can set a group's base quantizer. The frames are not coded and the stream does not change; the result depends only on the pictures and references, not on the thread count.

public IReadOnlyList<Av1FrameAnalysis> Analyze(IReadOnlyList<Av1AnalysisFrame> frames)

Parameters

frames IReadOnlyList<Av1AnalysisFrame>

The frames, in coding order, at the stream's size.

Returns

IReadOnlyList<Av1FrameAnalysis>

Each frame's analysis, in the same order.

Examples

// The frames ahead in coding order: a key frame, a hidden frame four pictures on, then the three between, each predicting
// from the frames on both sides of it (their places in this list).
IReadOnlyList<Av1FrameAnalysis> analysis = encoder.Analyze(
[
    new Av1AnalysisFrame { Picture = pictures[0] },
    new Av1AnalysisFrame { Picture = pictures[4], References = [0] },
    new Av1AnalysisFrame { Picture = pictures[1], References = [0, 1] },
    new Av1AnalysisFrame { Picture = pictures[2], References = [0, 1] },
    new Av1AnalysisFrame { Picture = pictures[3], References = [0, 1] },
]);

// The more the frames after them reuse the key and hidden frames, the finer their steps; each plan carries its analysis.
int keyQ = (int)Math.Round(100 / Math.Sqrt(analysis[0].Importance));
encoder.Encode(pictures[0], new Av1FramePlan { Kind = Av1FrameKind.Key, QIndex = keyQ, Analysis = analysis[0] });
encoder.Encode(pictures[4], new Av1FramePlan { QIndex = 110, Show = false, OrderHint = 4, RefreshSlots = 0b10, Analysis = analysis[1] });
for (int i = 1; i < 4; i++)
{
    encoder.Encode(pictures[i], new Av1FramePlan { QIndex = 140, Layer = 1, ReferenceSlots = [0, 0, 0, 0, 1, 1, 1], RefreshSlots = 0, Analysis = analysis[i + 1] });
}

encoder.ShowExisting(1);
