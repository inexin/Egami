A conversion from one color encoding to another, compiled once and then applied to spans of pixels of any type. Reusable and safe to share between threads. Transforms are cached per EgamiContext, so creating the same one again is cheap.

Examples

// A transform is compiled once (and cached), then applied to spans of any pixel type, in place or into another type.
ColorTransform transform = ColorTransform.Create(ColorProfile.DisplayP3, ColorProfile.Srgb, new ColorTransformOptions { Intent = RenderingIntent.Perceptual });
Rgba8[] pixels = [new(255, 0, 0, 255), new(0, 128, 255, 128)];
transform.Apply<Rgba8>(pixels);
RgbaF32[] wide = new RgbaF32[pixels.Length];
transform.Apply<Rgba8, RgbaF32>(pixels, wide);   // float types keep values outside 0..1

Remarks

Pixels are read in the source encoding's model and written in the target's: RGB pixel types give and take red, green and blue; gray types their gray value; CMYK types (Cmyk8, Cmyk16) their inks. A pixel type of another model is converted to the encoding's model numerically first, as PixelConvert would (an RGB pixel's gray is its luma), and results land in it the same way. Alpha is carried over unchanged, and is opaque when the source has none.

8-bit RGB, BGR, RGBA, BGRA, gray, gray-alpha and CMYK pixels take a fast path; other types go through floats, so float and half types keep values outside 0..1 (as wide-gamut and HDR conversions produce) and integer types are clamped.

Methods

Apply(ReadOnlySpan<float>, Span<float>)

Converts colors stored as floats, InputChannels per color in and OutputChannels out, each 0 to 1 (inks as tints): the way to convert from or to an n-colour profile, which no pixel type holds, and for any other values that are not pixels. Inputs are clamped to 0 to 1; outputs keep any value the conversion gives.
