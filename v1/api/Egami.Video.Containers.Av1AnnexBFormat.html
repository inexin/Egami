Class Av1AnnexBFormat

Namespace
Egami.Video.Containers
Assembly
Egami.Video.dll

A raw AV1 stream in the length-delimited format of the AV1 specification's Annex B, as the AV1 conformance streams and aomenc --annexb=1 write it: each temporal unit, each frame unit in it and each OBU in that carries its length as leb128, and OBUs have no size field. Readers give each temporal unit as a packet of low-overhead OBUs with their size fields, the form every other container uses; writers turn such packets back, dropping the size fields and adding the lengths, with a temporal delimiter at the start of each unit. There are no timestamps: temporal unit n is at n frames of FrameRate. Reading a file and writing it back gives the same bytes. Not detected from the extension, which .obu files share: an Annex B file is recognized by its first temporal delimiter.

Examples

// Raw AV1 streams have no timestamps: frames are timed at the format's frame rate, 30 a second unless you register another.
MediaContext context = MediaContext.Default.WithContainer(new Av1ObuFormat { FrameRate = new Rational(24, 1) });

// An IVF clip to a low-overhead .obu file (what aomdec and dav1d read) and to Annex B, then read back.
MediaFile.Remux("clip-av1.ivf", "clip.obu");
using (IDemuxer demuxer = MediaFile.OpenDemuxer("clip-av1.ivf"))
using (IMuxer annexB = Av1AnnexBFormat.Instance.CreateMuxer(File.Create("clip-annexb.obu"), demuxer.Tracks, MediaContext.Default, leaveOpen: false))
{
    while (demuxer.ReadPacket() is { } packet)
    {
        using (packet)
        {
            annexB.WritePacket(packet);
        }
    }
}

using VideoReader reader = VideoReader.Open("clip.obu", context: context);
Console.WriteLine($"{MediaFile.Probe("clip-annexb.obu").FormatName}; {reader.Track.FrameRate} fps");
