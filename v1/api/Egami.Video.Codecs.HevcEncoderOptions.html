The HEVC settings beyond VideoEncoderOptions, for experts (Hevc): the profile and level, quantizer limits, adaptive quantization, B-frames and the framing of the packets. Every one has a default that suits most uses. The encoder lives in the Egami.Video.Hevc package.

Examples

// HEVC in MP4 (an hvc1 track): Main for 8-bit frames, Main 10 for 16-bit planes, the level picked from the frame size and rate.
VideoWriterOptions options = new() { Codec = HevcCodec.Instance, FrameRate = new Rational(30, 1), Quality = 60 };
using (VideoWriter writer = VideoWriter.Create("duck.mp4", options))
{
    for (int i = 0; i < 10; i++)
    {
        using Raster<Rgb8> frame = duck.Derive(ops => ops.Crop(new Rect(i * 4, i * 2, 320, 240)));
        writer.WriteFrame(frame);
    }
}

// Expert settings: Main 10 at level 4.1, without adaptive quantization (to measure PSNR).
VideoWriterOptions main10 = options with { Hevc = new HevcEncoderOptions { Profile = HevcProfile.Main10, Level = 41, AdaptiveQuantization = false } };

Properties

AdaptiveQuantization

Gets whether each block's quantizer follows how busy it is (adaptive quantization): detail and texture, where errors show less, are coded coarser and flat areas finer, which looks better at the same size. Default on; turn it off to measure PSNR, which it lowers.

public bool AdaptiveQuantization { get; init; }

Property Value

bool

AnnexB

Gets whether packets are Annex B byte streams (start codes, with the parameter sets in every keyframe's packet), as raw .h265 files, MPEG-TS and RTP senders want. Default off: packets are length-prefixed and the parameter sets go in the track's hvcC record (CodecPrivate), as MP4 (hvc1) and Matroska store them.

public bool AnnexB { get; init; }

Property Value

bool

BFrames

Gets the most B-frames between two reference frames, 0 to 16, or null (the default) for the effort's: none at effort 0, else 3. B-frames predict from the frames on both sides and take fewer bits. They need Quality (the frames are coded out of order, and packets carry decode timestamps).

public int? BFrames { get; init; }

Property Value

int?

Level

Gets the level, ten times the level number (41 for level 4.1), 10 to 62, or null (the default) for the lowest Main tier level that the frame size and rate fit. A stream that does not fit the level given is refused when the encoder is made.

public int? Level { get; init; }

Profile

Gets the profile, or null (the default) to follow the first frame: Main10 for 16-bit planes, else Main. 8-bit frames coded as Main 10 keep their values, shifted up two bits; deeper frames coded as Main are converted to 8 bits.
