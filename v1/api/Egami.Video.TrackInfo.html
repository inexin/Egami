Class TrackInfo

Namespace
Egami.Video

A track in a container: its number, kind and codec, as a demuxer reports it and a muxer takes it. Codecs are named with Matroska codec ids (CodecIds), which every container maps to and from, so a track read from AVI can be written to Matroska unchanged.

Properties

CodecDelay

Gets the codec's built-in delay (Matroska CodecDelay, such as Opus pre-skip), or null when it has none. Demuxers have already subtracted it from packet timestamps, so the first packet may start before zero; muxers that store it add it back.

public MediaTime? CodecDelay { get; init; }

CodecId

Gets the codec as a Matroska codec id, such as MotionJpeg or PcmLittleEndian. Codecs with no id of their own use the Matroska compatibility ids VfwFourCC and AcmAudio, with the Windows header in CodecPrivate.
