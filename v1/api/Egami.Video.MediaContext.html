Class MediaContext

Egami.Video

The registered containers and codecs, the safety limits for reading, and the Egami context frames are allocated from. Every entry point takes one, or uses Default. Immutable: derive a new one with with or WithContainer(ContainerFormat) and WithCodec(VideoCodec).

Examples

MediaContext context = MediaContext.Default with
{
    Egami = EgamiContext.Default with { MaxParallelism = 2 },
    Limits = MediaLimits.Default with { MaxTracks = 8 },
};
MediaInfo info = MediaFile.Probe("in.mkv", context);
