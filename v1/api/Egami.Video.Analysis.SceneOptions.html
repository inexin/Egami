Examples

// Content compares each frame with the one before, as ffmpeg's scene score does; Adaptive (the default) also weighs the
// frames around it, so fast motion is not taken for a cut. Fades through black end a scene in the dark.
SceneOptions options = new()
{
    Method = SceneMethod.Content,
    Threshold = 0.3,
    MinSceneLength = MediaTime.FromSeconds(0.5),
    DetectFades = true,
    KeepSeries = true,
};
MediaAnalysisResult result = MediaAnalysis.Run("shots.mkv", new MediaAnalysisOptions { Scenes = options });
SceneScore sharpest = result.SceneScores.MaxBy(s => s.Score);
Console.WriteLine($"{result.Cuts.Count} cuts; the sharpest at {sharpest.Time.ToTimeSpan()}");

FadeLevel

Gets the mean luma, from black level (0) to white level (1), at or under which a frame counts as black for DetectFades. Default 0.02: true black, so a dark scene is not taken for a fade (a higher level made dark shots end in fades and hid their cuts). White uses 1 less this.

public double FadeLevel { get; init; }

Gets the shortest scene: a cut closer than this to the previous scene's start (the first frame for the first cut) is not taken. Default 0.6 s, as PySceneDetect's 15 frames at 25 frames a second.

Gets the lowest score, from 0 to 1, that starts a scene, or null for the method's own: 0.15 for Adaptive (which also needs AdaptiveRatio), 0.4 for Content and Histogram. Lower finds more cuts.
