Class AacCodec

Namespace
Egami.Video.Audio.Codecs

AAC (MPEG-4 Audio, ISO/IEC 14496-3): AAC LC decode and encode from 8 to 96 kHz, mono to 7.1 (channel configurations 1 to 7), with block switching, TNS, mid/side and intensity stereo and perceptual noise substitution. Frames come out as planar float, 1024 samples each, in Egami.Video's channel order: a 5.1 stream as front left, front right, center, LFE, back left, back right. HE-AAC (v1 and v2) decodes its AAC LC core only, without SBR or parametric stereo, at twice the core rate and with a "aac-sbr-ignored" warning; it sounds band-limited. AAC Main, LTP, SSR, the low-delay and error-resilient types, coupling channel elements and channel maps set by a program config element are not decoded. Read from .aac (ADTS) files and from AAC tracks in MP4, Matroska, AVI and CAF. The encoder codes at an average bit rate or a variable-bit-rate quality (AacEncoderOptions), with a psychoacoustic model, block switching, TNS, mid/side and intensity stereo and noise substitution; the first packet's 1024 samples of priming go in the container's edit list or CodecDelay.

Examples

// AAC LC decodes to planar float, 1024 samples a frame; the MP4 edit list trims the encoder's priming and padding.
using (AudioReader reader = AudioReader.Open("song.m4a"))
{
    Console.WriteLine($"{reader.Layout}, {reader.SampleRate} Hz");
}

// Decoded and encoded again as FLAC.
MediaFile.Transcode("song.m4a", "song.flac", audio: FlacCodec.Instance);

Examples

// AAC LC at 128 kbit/s in an .m4a file. The MP4 edit list records the encoder's priming and padding, so the file decodes
// to exactly the samples written.
using (AudioWriter writer = AudioWriter.Create("tone.m4a", new AudioWriterOptions
{
    Codec = AacCodec.Instance,
    Aac = new AacEncoderOptions { Bitrate = 128_000 },
}))
{
    writer.Write(tone);
}
