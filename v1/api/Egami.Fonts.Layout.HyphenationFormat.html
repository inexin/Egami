The file formats Load(Stream, HyphenationFormat) reads hyphenation patterns from.

public enum HyphenationFormat

Fields

Auto = 0

Tell the format from the data: Compiled by its signature, TeX when it has a \patterns group, LibHyphen when the first line names a character set, otherwise PatternList.

Compiled = 4

Egami's compiled form (.ehyp), written by Save(Stream).

LibHyphen = 3

A LibreOffice (libhyphen) hyph_xx_YY.dic file: a character set line, LEFTHYPHENMIN, RIGHTHYPHENMIN, NOHYPHEN and standard patterns. Replacement rules (patterns with /) throw NotSupportedException.

PatternList = 2

Plain patterns, one or more per line in UTF-8, as in hyph-utf8's hyph-xx.pat.txt.

TeX = 1

A hyph-utf8 hyph-xx.tex file: \patterns{} and \hyphenation{} groups, % comments, ^^ escapes, and the minimums from the hyphenmins header.

Examples

// Liang's patterns, as hyph-utf8's .pat.txt lists them; a .tex, .dic or .ehyp file loads with Hyphenator.Load.
Hyphenator hyphenator = Hyphenator.FromPatterns(
    ".hy3ph he2n hena4 hen5at 1na n2at 1tio 2io o2n",
    exceptions: "ta-ble",                      // exceptions break exactly where their hyphens are
    minBefore: 2, minAfter: 3);

Span<int> points = stackalloc int[16];
int count = hyphenator.GetPoints("Hyphenation", points);   // 2: offsets 2 and 6, "Hy-phen-ation"

// Compile once, load fast: the .ehyp form skips parsing the pattern text.
using MemoryStream compiled = new();
hyphenator.Save(compiled);
compiled.Position = 0;
Hyphenator loaded = Hyphenator.Load(compiled);
int tablePoints = loaded.GetPoints("table", points);       // 1: offset 2, "ta-ble"
