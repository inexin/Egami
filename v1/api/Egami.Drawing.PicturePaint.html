Class PicturePaint

Namespace
Egami.Drawing

A Picture as a paint: a tiling pattern, the shape of PDF's and SVG's tiling patterns and Skia's picture shader. The Tile rectangle of the picture, in its own coordinates, is repeated by TileX and TileY under LocalMatrix and the canvas transform. The raster backend renders one tile at the device scale the paint is drawn at and keeps it with the picture, so a pattern stays sharp when zoomed and is rendered once for repeated fills at one scale. A tile is at most 4096 pixels a side.

Examples

// A tile drawn once as vectors fills any shape, repeated, and stays sharp when the canvas is zoomed.
PictureRecorder tile = new(new RectF(0, 0, 20, 20));
tile.FillCircle(new Vector2(10, 10), 4, new Rgba8(220, 60, 60, 255));
tile.StrokeRect(new RectF(0.5f, 0.5f, 19, 19), new Stroke(1), new Rgba8(230, 230, 230, 255));
PicturePaint dots = new(tile.Finish(), TileMode.Repeat, TileMode.Repeat) { LocalMatrix = Matrix3x2.CreateRotation(MathF.PI / 8) };
using (RasterCanvas<Rgba8> canvas = raster.CreateCanvas())
{
    canvas.FillRoundRect(new RoundRect(new RectF(10, 10, 280, 180), 24), dots);
}
