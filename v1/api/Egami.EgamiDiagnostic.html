Examples

// With Microsoft.Extensions.Logging: one line at startup sends every call's warnings to the app's log, with the id as
// a property to filter and count on. Egami itself has no logging dependency.
EgamiContext.SetDefault(new EgamiContext
{
    Diagnostics = d => logger.Log(d.Level.ToLogLevel(), "{Source} {Id} at {Offset}: {Message}", d.Source, d.Id, d.Offset, d.Message),
});

Parameters

Level DiagnosticLevel

How much the event matters.

Source string

The part of Egami that found it, such as "Png", "Tiff", "Exif" or "Limits": the id up to its first dot.

Id string

A stable id, such as "Png.ChecksumMismatch", for filtering and counting without parsing Message.

Message string

What happened and what Egami did, as a sentence.

Offset long?

The byte offset in the input the event is about, or null when not known.

Frame int?

The frame or page index the event is about, or null when not known or not frame-specific.
