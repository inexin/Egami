Enum ArgbDrawing

Namespace
Egami.SystemDrawing

Egami.SystemDrawing.dll

How a Graphics draws on a 32-bit ARGB bitmap, the format new Bitmap(width, height) makes.

public enum ArgbDrawing

Fields

Exact = 1

Draws on a premultiplied copy of the area each call touches and writes it back, rounding exactly as GDI+ does.

InPlace = 0

Draws on the bitmap's own pixels, blending straight alpha with Egami's rounding: many times faster, and within a level of GDI+ where colors blend. SourceCopy still rounds as GDI+ does.

Examples

// Draw on a bitmap as with System.Drawing: GDI+'s defaults are aliased shapes and whole-pixel centers.
using Bitmap bitmap = new(80, 60);
using (Graphics g = Graphics.FromImage(bitmap))
{
    g.Clear(Color.White);
    g.SmoothingMode = SmoothingMode.AntiAlias;
    g.PageUnit = GraphicsUnit.Millimeter;  // 1 mm is 96 / 25.4 pixels at the bitmap's 96 dpi
    using Pen pen = new(Color.Navy, 0.5f);
    g.DrawEllipse(pen, 2, 2, 15, 10);
}

Color corner = bitmap.GetPixel(0, 0);  // white

// Egami's own setting: 32-bit ARGB bitmaps draw in place by default; Exact rounds blends exactly as GDI+ does, more slowly.
using (Graphics exact = Graphics.FromImage(bitmap))
{
    exact.ArgbDrawing = ArgbDrawing.Exact;  // or SystemDrawingOptions.ArgbDrawing for every Graphics made afterwards
    exact.FillRectangle(Brushes.Gold, 60, 40, 10, 10);
}
