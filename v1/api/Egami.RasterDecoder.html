Class RasterDecoder

Namespace
Egami

One open image, decoded a band of rows or a frame at a time. Opening reads the header and the metadata that comes before the image data; ReadRows<TPixel>(Raster<TPixel>) and ReadFrame<TPixel>(Raster<TPixel>) then hand out the image in any pixel type, with Region and MinimumSize applied as in Load(Stream, EgamiContext?, ReaderOptions?).

Examples

// A band of rows at a time: memory is the band plus the format's working set, whatever the image size.
using RasterDecoder decoder = RasterDecoder.Open("egret.png");
Console.WriteLine($"{decoder.Info.Width}×{decoder.Info.Height}, {decoder.Info.Access}, holding {decoder.Info.WorkingBytes:N0} bytes");
using Raster<Gray8> band = Raster.Create<Gray8>(decoder.Info.Width, 64);
int rows;
while ((rows = decoder.ReadRows(band)) > 0)
{
    for (int y = 0; y < rows; y++)
    {
        foreach (Gray8 pixel in band.Row(y))
        {
            sum += pixel.L;
        }
    }
}

Remarks

A decoder is one caller's object and is not thread-safe. Access says whether the format streams its rows or is decoded into a buffer first, and WorkingBytes how much that holds.

OpenAsync(Stream, EgamiContext?, ReaderOptions?, CancellationToken)

Opens an image from a stream read asynchronously: the header is read before this returns, and ReadRowsAsync<TPixel>(Raster<TPixel>, CancellationToken), ReadFrameAsync<TPixel>(Raster<TPixel>, CancellationToken) and NextFrameAsync(CancellationToken) read on as they need. Only the bytes since the decode's last step are held, not the whole file; formats from plugins, and files decoded into a buffer first, gather the file and are read at the end. The stream is left open; the decoder does not dispose it.

OpenIncremental(EgamiContext?, ReaderOptions?)

Starts an incremental decode: bytes are given with Append(ReadOnlySpan<byte>) as they arrive, and rows, frames and previews come out as far as the bytes reach. Status says when more bytes are needed and HeaderRead when Info is known; EndOfInput() says the last byte has come.

public static RasterDecoder OpenIncremental(EgamiContext? context = null, ReaderOptions? options = null)

Parameters

context EgamiContext

The context, or null for Default.

options ReaderOptions

How to read, or null for Default.

Returns

RasterDecoder

The decoder. The caller must dispose it.

Examples

// Decode while the bytes arrive, a chunk at a time, as from a download.
using RasterDecoder decoder = RasterDecoder.OpenIncremental();
Raster<Rgb8>? band = null;
foreach (ReadOnlyMemory<byte> chunk in file.Chunk(4096).Select(c => new ReadOnlyMemory<byte>(c)))
{
    decoder.Append(chunk.Span);
    if (decoder.HeaderRead)
    {
        band ??= Raster.Create<Rgb8>(decoder.Info.Width, 16);
        int rows;
        while ((rows = decoder.ReadRows(band)) > 0)
        {
            rowsSoFar += rows; // the rows finished so far; an interlaced file shows RenderPreview instead
        }
    }
}

decoder.EndOfInput();
while (decoder.ReadRows(band!) is int rest and > 0)
{
    rowsSoFar += rest;
}

band?.Dispose();

Remarks

Every 1.x format decodes as its bytes arrive, keeping only the bytes since the step it is in (an MCU row, a PNG chunk or scanline, a GIF block, a row). Files that are decoded into a buffer first (PFM, plain-text PNM, bottom-up BMP and TGA, a 32-bit BMP whose alpha may not count, TGA alpha set by a footer) and formats from plugins wait for EndOfInput() and are then read whole.

RenderPreview<TPixel>(Raster<TPixel>)

Draws what is known of the frame in progress: an interlaced PNG from the passes received so far, a progressive JPEG from its scans so far, a progressive (layered) AVIF from its best layer received so far at full size, a GIF frame from the rows received so far (interlaced ones repeated over the rows they stand for), each later pass sharpening it. Region and reduction apply as to rows. The decode does not move on.
