Gets the text: the data decoded with the symbol's ECI or, without one, as ISO 8859-1 (or UTF-8 or Shift JIS when the bytes are clearly that). GS1 data is in its human-readable form, such as (01)09501101530003(10)AB12. For EAN and UPC, the main digits only; an add-on is in AddOn.
