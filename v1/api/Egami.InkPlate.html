Examples

// A page as plates: CMYK and the spot, 8 bits each, plus alpha. Rows are written in place; a plate is also a gray raster.
using InkRaster page = new(inks, 200, 100, InkDepth.Unorm8);
page.Plate("PANTONE 186 C")!.Row8(10).Fill(255);              // a full-tint line of the spot
page.Alpha.Row8(10).Fill(255);
using Raster<Gray8> spot = page.Plate("PANTONE 186 C")!.AsRaster<Gray8>();   // no copy: 0 = no ink, 255 = full ink

Methods

AsRaster<TPixel>()

Returns the plane as a gray raster over the same memory, without copying: Gray8 for an 8-bit plane, Gray16 for a 16-bit one. Writing to it writes the plate. 0 is no ink and the maximum full ink, so saved as an image the plate shows ink as light. Dispose the raster when done; it frees nothing, and stops working when the ink raster is disposed. An operation that changes its size gives it memory of its own.
