Namespace Egami.Formats.Iso

Structs

FourCC

A four-character code as ISO/IEC 14496-12 (ISO BMFF) stores box, brand, handler and sample entry types: four bytes read as a big-endian number.

IsoBox

A box of ISO/IEC 14496-12 (ISO BMFF), as MP4, QuickTime, HEIF and AVIF files are made of: its type and where its header and contents lie. Positions are byte offsets in the file when the reader was told where its data starts, else in the data read.

IsoBoxReader

Reads the boxes of ISO/IEC 14496-12 from bytes in memory, one level at a time: 32-bit sizes, 64-bit large sizes, size 0 (to the end of the enclosing box) and uuid boxes. A box that runs past its parent, or whose size is too small for its header, raises a CorruptDataException; nothing is allocated.
