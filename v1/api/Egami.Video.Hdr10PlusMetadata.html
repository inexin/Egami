Class Hdr10PlusMetadata

Namespace
Egami.Video
Assembly
Egami.Video.dll

HDR10+ dynamic metadata for one frame (SMPTE ST 2094-40, application version 0 or 1), as WebM carries it in each block's BlockAdditional with BlockAddID 4 (an ITU-T T.35 payload). The values are the first processing window's, which covers the whole frame; luminances are in cd/m². Egami.Video reads and keeps it but does not tone map with it: HDR to SDR conversion uses the static metadata (Hdr).
