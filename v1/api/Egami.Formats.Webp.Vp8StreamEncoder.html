Class Vp8StreamEncoder

Namespace
Egami.Formats.Webp
Assembly
Egami.dll

Encodes a VP8 video stream (RFC 6386) a frame at a time: key frames, and inter frames that search the last, golden and alternate references for motion and code every VP8 vector mode. Each frame's Vp8FramePlan says what it is (key or inter, shown or hidden), its quality or quantizer, and which references it uses and refreshes, so rate control and group-of-frames planning stay with the caller: Egami.Video drives this encoder for WebM, MKV and IVF, and any other source of frames can too. The frames decode in libvpx exactly as in Vp8StreamDecoder.

Examples

// 4:2:0 pictures of one size, here decoded from a clip; Egami.Video writes WebM and IVF and plans the frames for you.
using Vp8StreamEncoder encoder = new(pictures[0].Width, pictures[0].Height);
for (int i = 0; i < pictures.Count; i++)
{
    Vp8FramePlan plan = new()
    {
        KeyFrame = i % 30 == 0,     // a key frame a second at 30 frames a second
        RefreshGolden = i % 10 == 0, // and a golden frame to fall back on every tenth
        Quality = 70,
    };
    Vp8EncodedFrame frame = encoder.Encode(pictures[i], plan);
    packets.Add(frame.Data.ToArray()); // a WebM block or an IVF frame; frame.LumaPsnr says how close it came
}

Remarks

The encoder keeps the stream's references in four frame buffers from the context's Memory and decodes each frame it writes to keep them, on up to MaxParallelism threads; the output does not depend on the thread count. The frame size is checked against the context's Limits. An instance is not thread-safe.
