Class Stroke

Namespace
Egami.Drawing
Assembly
Egami.Drawing.dll

How a path is outlined: the pen's width, caps, joins and miter limit. The settings travel with the drawing call as data, so a vector backend can write them as they are (PDF's w, J, j and M). The pen is applied in the canvas's local space and then transformed, so a non-uniform scale gives an elliptical pen, as in PDF, SVG and Skia.

Examples

// The pen is data: width, caps, joins and miter limit. Width 1, butt caps and miter joins by default.
Stroke thick = new(12) { Cap = LineCap.Round, Join = LineJoin.Round };
canvas.DrawLine(new Vector2(20, 20), new Vector2(280, 20), thick, new Rgba8(30, 90, 200, 255));

Path zigzag = Path.Polygon([new(20, 120), new(80, 60), new(140, 120), new(200, 60), new(260, 120)], close: false);
canvas.StrokePath(zigzag, new Stroke(8) { Join = LineJoin.Miter, MiterLimit = 4 }, Rgba8.Black);

// A hairline is one device pixel wide whatever the transform.
canvas.StrokeCircle(new Vector2(150, 160), 30, Stroke.Hairline, Rgba8.Red);

Methods

ToPath(Path, float, bool)

Returns the outline this pen draws around a path, as a path to fill with the nonzero rule: the effect and dashes applied, then each piece offset by half the width with the joins and caps, as the raster backend fills it. Curves become straight pieces within a tenth of a unit divided by scale, so filling the outline at that scale gives exactly the pixels stroking does. The raw outline overlaps itself where the path turns sharply or crosses itself; with simplify the overlaps are removed by Simplify(float), for export or hit testing.

public Path ToPath(Path path, float scale = 1, bool simplify = false)

Examples

// A dashed route: the pattern travels with the stroke, so a PDF backend writes [8 4] 0 d instead of hundreds of pieces.
Path route = new PathBuilder().MoveTo(10, 90).CubicTo(60, 0, 140, 160, 190, 60).ToPath();
Stroke dashed = new(3) { Cap = LineCap.Round, Dash = new DashPattern([8, 4]) };
using Raster<Rgba8> map = Raster.Create(200, 120, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = map.CreateCanvas())
{
    canvas.StrokePath(route, dashed, new Rgba8(200, 60, 30, 255));
}

// The outline the stroke fills, as a path: for hit testing, or to export without strokes.
Path outline = dashed.ToPath(route, simplify: true);

Exceptions

ArgumentOutOfRangeException

scale is not positive and finite.

ArgumentException

The outline does not fit in float coordinates.
