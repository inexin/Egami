Enum Easing

Namespace
Egami.Video
Assembly
Egami.Video.dll

How an animated value moves from a Keyframe to the next one.

public enum Easing

Fields

EaseIn = 1

Starts slowly and speeds up (quadratic).

EaseInOut = 3

Starts and ends slowly (smoothstep, 3t² - 2t³).

EaseOut = 2

Starts fast and slows down (quadratic).

Hold = 4

Keeps the value until the next keyframe, then jumps.

Linear = 0

A straight line. The default.

Examples

// Duck to -12 dB from 1 s to 2 s, easing down and back up over a quarter second.
using Gain duck = new()
{
    Envelope = new GainEnvelope(
        new Keyframe(MediaTime.FromSeconds(0.75), 0, Easing.EaseInOut),
        new Keyframe(MediaTime.FromSeconds(1), -12),
        new Keyframe(MediaTime.FromSeconds(2), -12, Easing.EaseInOut),
        new Keyframe(MediaTime.FromSeconds(2.25), 0)),
};
