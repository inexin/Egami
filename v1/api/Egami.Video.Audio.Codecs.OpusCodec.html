Opus (RFC 6716 with the RFC 8251 updates). Decodes SILK, CELT and hybrid frames at every bandwidth, mono, stereo and the multichannel mapping families 0, 1 and 255 (RFC 7845), with packet loss concealment and in-band FEC. Frames come out as planar float at 48 kHz, Opus's own rate, in the canonical channel order; other rates go through a Resampler. Encodes 1 to 8 channels at 8, 12, 16, 24 or 48 kHz (mapping family 0 for mono and stereo, 1 above) in every mode, with the settings of OpusEncoderOptions; the default is 64 kbit/s per channel, variable bitrate, 20 ms frames. Both are translated from libopus 1.5.2 and match its output exactly. Ambisonic mappings (families 2 and 3) are not supported.

Examples

// Opus decodes to planar float at 48 kHz; pre-skip and end padding are trimmed, so the length is the original's.
using AudioReader reader = AudioReader.Open("talk.opus");
Console.WriteLine($"{reader.Track.CodecId}, {reader.Track.Channels} channels, pre-skip {reader.Track.CodecDelay?.ToTimeSpan()}");
long samples = 0;
while (reader.TryRead(out AudioFrame? frame))
{
    using (frame)
    {
        samples += frame.SampleCount;
    }
}

// Speech at 32 kbit/s. Opus codes 8, 12, 16, 24 and 48 kHz, so this 44.1 kHz audio is resampled to 48 kHz; the
// header keeps 44.1 kHz as the rate the audio came at.

{
    Opus = new OpusEncoderOptions { Bitrate = 32_000, Application = OpusApplication.Voice },
}))

    writer.Write(tone);
