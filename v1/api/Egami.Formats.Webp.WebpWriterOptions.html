Options for writing WebP. The defaults follow libwebp's: quality 75 and effort (libwebp's method) 4. A raster read from a WebP file keeps its kind, lossless or lossy; anything else is written lossy.

Examples

// Lossy, the default for rasters not read from WebP: quality 0 to 100 and effort 0 to 6 on cwebp's scales.
photo.Save("small.webp", new WebpWriterOptions { Quality = 80 });

// Lossless: every pixel exact, colors under full transparency included. Effort 0 (fastest) to 6 (smallest).
photo.Save("duck.webp", new WebpWriterOptions { Lossless = true, Effort = 6 });

// A raster read from a WebP file keeps its kind when saved with the defaults.
using Raster again = Raster.Load("duck.webp");
again.Save("copy.webp");

KeepTransparentColors

Gets whether the colors of fully transparent pixels are kept: exactly in lossless data, so every pixel round-trips, and as closely as the quality allows in lossy data. Defaults to true; false lets either encoder change those colors for smaller files (lossy flattens them), as libwebp does unless told to stay exact.
