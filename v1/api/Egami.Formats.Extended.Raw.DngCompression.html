How a DNG stores its raw data.

public enum DngCompression

Fields

Deflate = 2

Deflate (compression 8) with TIFF's horizontal predictor for integers and its floating-point predictor for floats.

JpegXl = 3

Lossless JPEG XL (compression 52546), from DNG 1.7: small files that readers older than DNG 1.7 cannot open.

LosslessJpeg = 0

Lossless JPEG (compression 7) in tiles, a colour filter array row coded as pairs as Adobe DNG Converter writes it. Integer data only: floating-point data is written with Deflate instead. The default.

None = 1

Uncompressed: the largest files, the fastest to read.

Examples

// Any RAW file Egami reads becomes a DNG with its sensor data unchanged: levels, crop, colour data and EXIF come along.
RawFormat.ConvertToDng("photo.dng", "copy.dng", new DngWriterOptions { Preview = DngPreview.Thumbnail }, context);

// A transcode with no operations takes the same route; with operations, the develop is saved as a linear DNG.
Raster.Transcode("photo.dng", "same.dng", context: context);
Raster.Transcode("photo.dng", "small.dng", ops => ops.Fit(800, 800), context: context);
