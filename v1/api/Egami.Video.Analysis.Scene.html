Examples

// One pass over the file: the scene detector runs by default, and any detectors of your own run with it.
MediaAnalysisResult result = MediaAnalysis.Run("shots.mkv");
foreach (Scene scene in result.Scenes)
{
    Console.WriteLine($"Scene {scene.Number}: {scene.Start.ToTimeSpan()} to {scene.End.ToTimeSpan()}, starts with a {scene.StartKind}");
}

Parameters

Number int

The scene's number, from 1.

StartFrame long

Its first frame, counted from 0 in presentation order among the frames the detector saw.

EndFrame long

Its last frame, inclusive.

Start MediaTime

Its first frame's timestamp.

End MediaTime

When it ends: the next scene's start, or the end of the video for the last scene.

Score double

How sharp the change that starts it is, from 0 to 1; 0 for the first scene.

StartKind SceneStart

How it starts: the first frame, a cut, or the middle of a fade through black.
