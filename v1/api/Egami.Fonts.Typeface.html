One font face: its names, style, metrics, character map, glyph outlines and kerning, read from a TrueType or OpenType font, a collection, or a bare CFF stream. Immutable and safe to share across threads, canvases and backends.

Examples

// One face from a file; a collection takes an index. The bytes are read once and every table is parsed when first needed.
Typeface face = Typeface.FromFile(FontFile);
Console.WriteLine($"{face.FamilyName} {face.SubfamilyName}, {face.GlyphCount} glyphs, {face.UnitsPerEm} units per em");

// What a file holds, from its header alone.
FontProbe probe = FontLoader.Probe(File.ReadAllBytes(FontFile));
Console.WriteLine($"{probe.Kind}, {probe.FaceCount} face(s), {probe.Outlines} outlines");

// Damaged fonts load leniently with diagnostics; Strict throws instead.
var seen = new List<EgamiDiagnostic>();
var options = new FontLoadOptions { Context = EgamiContext.Default with { Diagnostics = seen.Add } };
Typeface lenient = Typeface.FromMemory(File.ReadAllBytes(FontFile), 0, options);

Remarks

Loading reads the table directory, head and maxp, and checks that glyph data is there; every other table is parsed the first time it is needed and kept. The font's bytes are held once, as the ReadOnlyMemory<T> given or read, and every table is a slice of them. Memory given to FromMemory(ReadOnlyMemory<byte>, int, FontLoadOptions?) must not change afterwards.

Loading is lenient by default: see FontLoadOptions for the defaults damaged or missing tables get and the diagnostics they raise. All glyph metrics and outlines are in font units with y up; Font scales them to a size.

Examples

// A symbolic TrueType font in PDF looks a code up in (3,0) first, then (1,0); a non-symbolic one uses (3,1).
CharacterMap? map = trueType.FindCharacterMap(3, 0) ?? trueType.FindCharacterMap(1, 0) ?? trueType.FindCharacterMap(3, 1);
ushort forA = map?.GetGlyph('A') ?? 0;

// A Type1C font without /Encoding uses the CFF program's own encoding.
CharacterMap? own = face.BuiltInEncoding;                  // platform 7, encoding 0: the Standard Encoding

// Every code the map gives a glyph, in code order, for a PDF writer's /Widths or a ToUnicode table.
int mapped = map?.GetMappings().Count() ?? 0;

Remarks

GetGlyph(int) keeps choosing its one Unicode subtable as before; these maps are for callers that need a particular one, such as PDF's (3,0) or (1,0) for a symbolic TrueType font and (3,1) otherwise.

TryGetColorGlyph(ushort, FontPalette?, out ColorGlyph?, float)

Gets a glyph's color description in the first format that has it: COLR version 1, then version 0, then sbix, then CBDT (OpenType SVG glyphs are not drawn; see TryGetSvgDocument(ushort, out ReadOnlyMemory<byte>, out ushort, out ushort)). COLR graphs are read at this face's variation position with the palette's colors; bitmaps come from the strike for pixelsPerEm.

public bool TryGetColorGlyph(ushort glyph, FontPalette? palette, out ColorGlyph? colorGlyph, float pixelsPerEm = 0)

Parameters

glyph ushort

The glyph.

palette FontPalette

The palette, or null for Default.

colorGlyph ColorGlyph

The color glyph, or null.

pixelsPerEm float

The size the glyph is drawn at, for choosing a bitmap strike: the smallest at or above it, else the largest; 0 for the largest.

Returns

bool

true if the glyph has color data; otherwise it draws as its outline.

Examples

// Color glyphs draw in color by themselves: COLR (layers and gradients), sbix and CBDT (images), per glyph.
using (RasterCanvas<Rgba8> canvas = image.CreateCanvas())
{
    canvas.DrawText("Ship it", new Vector2(8, 40), new Font(text, 24), Rgba8.Black);
    canvas.DrawText("\U0001F680\U0001F389", new Vector2(100, 42), new Font(emoji, 32), Rgba8.Black);
}

// The palette is a font setting; the paint's color fills a glyph's foreground parts and its alpha the whole glyph.
var darkMode = new Font(emoji, 32) { Palette = FontPalette.Dark };
ColorGlyphFormats formats = emoji.ColorFormats;

// The paint graph is there to walk, for writers that draw color glyphs their own way.
emoji.TryGetColorGlyph(emoji.GetGlyph(0x1F680), darkMode.Palette, out ColorGlyph? rocket);

WithVariations(params ReadOnlySpan<FontVariation>)

Returns this face at another position on its axes, sharing the file's memory and parsed tables: outlines, advances, extents, kerning, names and subsets all answer for that position. Axes not named keep this face's values; values clamp to each axis's range; a tag the font repeats sets every axis with it; axes the font does not have are ignored.

public Typeface WithVariations(params ReadOnlySpan<FontVariation> variations)

Parameters

variations ReadOnlySpan<FontVariation>

The axis values, such as FontVariation.Weight(650).

Returns

Typeface

The face at that position: the default face when every axis is at its default, this face for a static font.

Examples

// A variable font's axes and named instances, and the face at any position on them.
Typeface flex = Typeface.FromFile(VariableFile);
foreach (VariationAxis axis in flex.VariationAxes)
{
    Console.WriteLine($"{axis.Tag} {axis.Name}: {axis.Min} to {axis.Max}, default {axis.Default}");
}

Typeface semiBold = flex.WithVariations(FontVariation.Weight(600), FontVariation.Width(90));
Typeface black = flex.WithNamedInstance(flex.NamedInstances.Count - 1);

// The optical size follows the font size unless the face sets it (OpticalSizing.None turns that off).
var caption = new Font(semiBold, 11);
Typeface drawn = caption.EffectiveTypeface;

// For a PDF, the subset is a static font at the face's position, which every viewer draws as it is.
FontSubset subset = FontSubsetter.Subset(semiBold, caption.Shape("Static at 600").Glyphs.ToArray());
