A curve from 0..1 to 0..1 for one channel, as a photo editor's curves dialog draws it: inputs outside 0..1 are clamped first and results are clamped to 0..1. Use one in Curves(ToneCurve); the tone steps (Level, Gamma and the rest) are curves too, evaluated exactly.

Examples

// Curves as a photo editor draws them: a smooth curve through the points that never overshoots, here a mild S on all
// three channels and a lift in the blue shadows.
ToneCurve s = ToneCurve.FromPoints([(0, 0), (0.25f, 0.2f), (0.75f, 0.82f), (1, 1)]);
ToneCurve blue = ToneCurve.FromPoints([(0, 0.06f), (0.5f, 0.5f), (1, 1)]);
raster.Apply(o => o.ApplyFilter(ColorFilter.Curves(s, s, s.Then(blue))), Ct);

FromPoints(ReadOnlySpan<(float X, float Y)>)

Returns the smooth curve through points: a monotone cubic (Fritsch and Carlson, 1980), so a curve through rising points rises everywhere and never overshoots, as photo editors' curves do. Before the first point and after the last the curve stays flat at their values.

public static ToneCurve FromPoints(ReadOnlySpan<(float X, float Y)> points)
