Tate-chu-yoko (CSS text-combine-upright): short horizontal text, such as "12" or "!?", set upright in one em of a vertical line. Set it on CombineUpright; horizontal lines and sideways text ignore it.

Examples

// 12年3月 in a vertical line: each run of digits stands upright, its digits side by side, in one em.
ParagraphStyle style = new()
{
    DefaultStyle = new TextStyle
    {
        FontFamilies = [fonts.Families[0]],
        Size = 20,
        Language = "ja",
        CombineUpright = TextCombine.Digits(2),  // runs of up to two ASCII digits; TextCombine.All for a span's text
    },
    WritingMode = WritingMode.VerticalRl,
};
TextLayout layout = Paragraph.Create("12年3月", style).Layout(300);

Remarks

The combined text is shaped horizontally and fit into one em: with the font's hwid, twid or qwid feature for two, three or four characters where the font has it, then squashed across the line if it is still wider, as CSS Writing Modes 3 says (its height stays). It breaks, justifies and takes an emphasis mark as one ideograph.
