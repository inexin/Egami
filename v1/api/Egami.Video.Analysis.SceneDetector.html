Class SceneDetector

Namespace
Egami.Video.Analysis
Assembly
Egami.Video.dll

Finds the scenes of a video: where one shot cuts to the next, and where a fade or cut through black separates two. Each frame is summarized from its planes (a 16 by 9 grid of mean Y, Cb and Cr and a luma histogram) and scored against the frame before by Method; a high enough score starts a scene, unless it comes within the minimum scene length or turns out to be a flash. Feed it every frame with Add(YuvVideoFrame) and call Complete(MediaTime) at the end, or let Run(string, MediaAnalysisOptions?, MediaContext?, IProgress<MediaProgress>?, CancellationToken) do it. Memory stays flat over any length of video unless KeepSeries is set.

Examples

// A detector takes frames in time order; this one finds the darkest frame. The scene detector can run on its own too.
DarkestFrame darkest = new();
SceneDetector scenes = new(new SceneOptions { Method = SceneMethod.Histogram });
using (VideoReader reader = VideoReader.Open("shots.mkv"))
{
    foreach (YuvVideoFrame frame in reader.ReadFrames())
    {
        using (frame)
        {
            darkest.Add(frame);
            if (scenes.Add(frame) is { } cut)
            {
                Console.WriteLine($"Cut at frame {cut.Frame}");
            }
        }
    }

    scenes.Complete(reader.Info.Duration ?? MediaTime.Zero);
}

Console.WriteLine($"Darkest frame at {darkest.Time.ToTimeSpan()}, {scenes.Scenes.Count} scenes");

SettledFrames

Gets how many frames are settled: no cut can still be added before this frame. A caller that keeps recent frames, to save the first frame of each scene for instance, may let go of the frames before it. The adaptive window, a cut held for the flash test and a dark run that may end in a fade keep it behind FrameCount.
