Examples

// Decode straight into the type you want to work in.
using Raster<Rgba8> rgba = Raster.Load<Rgba8>("duck.png");

// Pixels are a row at a time: each row is a Span<Rgba8>.
for (int y = 0; y < rgba.Height; y++)
{
    Span<Rgba8> row = rgba.Row(y);
    for (int x = 0; x < row.Length; x++)
    {
        row[x].A = 128;
    }
}

// Convert a whole raster; the result is a new raster you dispose too.
using Raster<Gray8> gray = rgba.As<Gray8>();
gray.Save("duck-gray.png");

Methods

Apply(Action<RasterOps>, CancellationToken)

Runs a chain of operations on every frame, changing this raster in place. Steps that keep the size work on the existing pixels; steps that change it get new pixel memory, and the old memory is returned at once.

public void Apply(Action<RasterOps> build, CancellationToken cancellationToken = default)

Parameters

build Action<RasterOps>

Records the chain, for example ops => ops.Add(operation).

cancellationToken CancellationToken

Cancels between steps and between bands of rows.

Remarks

Arguments are checked while the chain is recorded, before any pixel changes. If a step fails or the chain is cancelled part way, the raster may be left partly changed. Spans from Row(int) taken before a size change become invalid.

Exceptions

ObjectDisposedException

The raster has been disposed.

LimitExceededException

A new plane would break MaxTotalBytes.

OperationCanceledException

The token was cancelled.
