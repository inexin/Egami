A bevel along a shape's edge, lit by a light: the rim the width wide rises by the profile to the height, and where it faces the light more than the flat face does it is lightened, where less it is darkened. DrawBevel(Path, Bevel) draws it over a shape that is already filled.

Examples

// A raised button: fill the shape, then draw a bevel over it, lit from the top left.
using Raster<Rgba8> button = Raster.Create(220, 90, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = button.CreateCanvas())
{
    Path shape = Path.RoundRect(new RoundRect(new RectF(10, 10, 200, 70), 16));
    canvas.FillPath(shape, new Rgba8(40, 110, 200, 255));
    canvas.DrawBevel(shape, new Bevel
    {
        Profile = BevelProfile.Circle,
        Width = 10,
        Height = 8,
        Material = BevelMaterial.Plastic,
        Light = BevelLight.FromDirection(LightDirection.TopLeft),
    });
}

Remarks

This is DrawingML's top bevel (a:sp3d/a:bevelT) seen straight on, with its preset materials and the rig's direction. Width and height are in the canvas's local units (DrawingML gives them in EMUs, 6 points by default).
