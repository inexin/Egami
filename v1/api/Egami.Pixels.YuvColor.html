How the samples of a YuvRaster turn into RGB: the matrix, the range and where chroma sits. Every load, wrap and conversion states one, so a picture is never read with a guessed matrix.

Examples

// How samples turn into RGB is always stated: a preset, or the codes a video container carries (ITU-T H.273).
YuvColor jpeg = YuvColor.Jpeg;                                         // BT.601, full range, chroma centered
YuvColor custom = new(YuvMatrix.Bt709, YuvRange.Full, ChromaSiting.Left);
if (YuvColor.TryFromH273(matrixCoefficients: 9, fullRange: false, ChromaSiting.TopLeft, out YuvColor fromStream))
{
    Console.WriteLine($"{fromStream.Matrix}, {fromStream.Range}; back to code {fromStream.ToH273()}");
}

// Or straight from the code points an AVIF or PNG cICP box carries.
Egami.Colors.ColorCodePoints hdr10 = new(Primaries: 9, TransferCharacteristics: 16, MatrixCoefficients: 9, FullRange: false);
hdr10.TryGetYuvColor(ChromaSiting.TopLeft, out YuvColor fromBox);

TryFromH273(int, bool, ChromaSiting, out YuvColor)

Gets the color that ITU-T H.273's matrix_coefficients code and full-range flag name, as AV1, VP9, HEVC and CICP boxes carry them: 0 is identity (GBR), 1 BT.709, 5 and 6 BT.601, 9 BT.2020 non-constant luminance.

public static bool TryFromH273(int matrixCoefficients, bool fullRange, ChromaSiting siting, out YuvColor color)

Parameters

matrixCoefficients int

fullRange bool

The full-range flag.

siting ChromaSiting

Where chroma sits, which H.273 does not carry.

color YuvColor

The color, or the default when the code is not one Egami knows.

Returns

bool

true if the code names a matrix Egami knows; unknown codes return false rather than a guess.
