Class CodecHeaderReader

Namespace
Egami.Video.Codecs
Assembly
Egami.Video.dll

Lists the header fields of a track's packets read in order, keeping what a codec's later headers depend on. For AV1 it decodes each temporal unit with Egami's Av1StreamDecoder, so each frame header is listed whole, as the decoder read it (LastHeaders, under the specification's syntax element and variable names), in place of the start Describe(TrackInfo, EncodedPacket) gives. Other codecs give what Describe(TrackInfo, EncodedPacket) gives.

Examples

// An AV1 frame header depends on the frames before it: a CodecHeaderReader reads the packets in order and lists each whole.
using IDemuxer demuxer = MediaFile.OpenDemuxer("av1.webm");
using CodecHeaderReader headers = new(demuxer.Tracks[0]);
while (demuxer.ReadPacket() is { } packet)
{
    using (packet)
    {
        IReadOnlyList<CodecHeaderField> fields = headers.Describe(packet);
        Console.WriteLine(string.Join(", ", fields.Where(f => f.Name is "frame_type" or "order_hint" or "base_q_idx").Select(f => $"{f.Name} = {f.Value}")));
    }
}
