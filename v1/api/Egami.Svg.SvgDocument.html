Examples

// .svg and .svgz alike; nothing outside the file is opened unless a resolver allows it.
SvgDocument document = SvgDocument.Load(path);
Console.WriteLine($"{document.Title}: {document.Root.Descendants().Count()} elements");

// What a lenient load skipped is in Warnings, and in the context's diagnostics.
foreach (EgamiDiagnostic warning in document.Warnings)
{
    Console.WriteLine($"{warning.Id}: {warning.Message}");
}

Remarks

Loading is lenient, as browsers and resvg read SVG: what cannot be used is skipped and reported through the context's diagnostics, and the rest is kept. Strict throws instead. Nothing outside the file is opened unless Resolver allows it.

RenderTree

Gets the render tree: the elements resolved for drawing (styles applied, units in pixels, use expanded, shapes as paths), in the document's pixels (Size). It is built at load and again on first use after an edit; what an edit leaves undrawable is reported to the context's diagnostics then. It is immutable and safe to read from many threads.

Examples

// The resolved tree: groups, paths with their paints and strokes, images; styles applied and units in pixels.
static void Walk(SvgNode node, int depth)
{
    string what = node switch
    {
        SvgPath path => $"path {path.Path.Bounds} fill {path.Fill}",
        SvgGroup group => $"group of {group.Children.Count}",
        SvgImage image => $"image {image.Destination}",
        _ => node.GetType().Name,
    };
    Console.WriteLine($"{new string(' ', depth * 2)}{node.Id} {what} opacity {node.Opacity}");
    if (node is SvgGroup g)
    {
        foreach (SvgNode child in g.Children)
        {
            Walk(child, depth + 1);
        }
    }
}

Walk(document.RenderTree, 0);

Draw(Canvas, RectF?, SvgRenderOptions?)

Draws the document on a canvas: at its own size from the canvas's origin, or fitted into box by the root's preserveAspectRatio. Drawing calls only the public canvas API, so a raster canvas, a PDF page, SvgCanvas or a PictureRecorder receive the same calls. It never throws on content.

public void Draw(Canvas canvas, RectF? box = null, SvgRenderOptions? options = null)

Parameters

canvas Canvas

The canvas.

box RectF?

The rectangle to fit the document into, in the canvas's coordinates, or null.

options SvgRenderOptions

Languages, text as paths and filter scale, or null for the defaults.

Examples

// Fitted into a box by the root's preserveAspectRatio; a PDF page or SvgCanvas receives the same calls.
document.Draw(canvas, new RectF(10, 10, 180, 180));

// One element of a sprite sheet, fitted into its own box.
document.Draw(canvas, "body", new RectF(200, 10, 48, 48));

Examples

// Images, style sheets and fonts the file refers to open only through a resolver; data: URIs always work.
var options = new SvgLoadOptions
{
    Resolver = SvgResolvers.SameDirectory(folder),
    Dpi = 96,
    Context = EgamiContext.Default with { Limits = SafetyLimits.Default with { MaxTotalBytes = 64L << 20 } },
};

Save(Stream, SvgSaveOptions?)

Writes the document as SVG: the element tree with everything read from the file (unknown elements, foreign namespaces, comments, the DOCTYPE), so a load and save without edits keeps the document's meaning; attribute order and whitespace inside tags may change, and entities are written out.

public void Save(Stream stream, SvgSaveOptions? options = null)

Parameters

stream Stream

The stream to write to; it is left open.

options SvgSaveOptions

How to write, or null for Default.

Examples

// Numbers and paths set in code are written with Precision decimals; what was read keeps its text.
document.FindById("body")!.Attributes.Set("width", 17.666666);
document.Save(path, new SvgSaveOptions { Precision = 2, Gzip = true });

using var stream = new MemoryStream();
document.Save(stream);
