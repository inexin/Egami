Class H264EncoderOptions

Namespace

The H.264 settings beyond VideoEncoderOptions, for experts (H264): the profile and level, the entropy coder, quantizer limits and the framing of the packets. Every one has a default that suits most uses. The encoder lives in the Egami.Video.H264 package.

Examples

// H.264 in MP4: High profile with CABAC by default, the level picked from the frame size and rate.
VideoWriterOptions options = new() { Codec = H264Codec.Instance, FrameRate = new Rational(30, 1), Quality = 60 };
using (VideoWriter writer = VideoWriter.Create("duck.mp4", options))
{
    for (int i = 0; i < 10; i++)
    {
        using Raster<Rgb8> frame = duck.Derive(ops => ops.Crop(new Rect(i * 4, i * 2, 320, 240)));
        writer.WriteFrame(frame);
    }
}

// Expert settings: Constrained Baseline (CAVLC) at level 3.0 for the simplest players.
VideoWriterOptions baseline = options with { H264 = new H264EncoderOptions { Profile = H264Profile.ConstrainedBaseline, Level = 30, Entropy = H264EntropyCoder.Cavlc } };

Properties

AdaptiveQuantization

Gets whether each macroblock's quantizer follows how busy it is (adaptive quantization): detail and texture, where errors show less, are coded coarser and flat areas finer, which looks better at the same size. Default on; turn it off to measure PSNR, which it lowers.

public bool AdaptiveQuantization { get; init; }

Property Value

bool

AnnexB

Gets whether packets are Annex B byte streams (start codes, with the parameter sets in every keyframe's packet), as raw .h264 files, MPEG-TS and RTP senders want. Default off: packets are length-prefixed and the parameter sets go in the track's avcC record (CodecPrivate), as MP4 and Matroska store them.

public bool AnnexB { get; init; }

bool
