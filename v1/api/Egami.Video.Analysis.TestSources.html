Class TestSources

Namespace
Egami.Video.Analysis

Generates test video and audio: a moving test pattern with frame numbers and timecode, SMPTE color bars, solid colors and gradients, and sine tones, silence, white or pink noise and sweeps. The frames come out one at a time, so any length costs the same memory; hand them to WriteFrame(VideoFrame) and WriteAudio(AudioFrame), or to a detector. Dispose each frame.

Examples

// Generated pictures and sounds for tests and demos: bars, a moving pattern, solid colors, gradients, tones and noise.
TestVideoFormat format = new() { Width = 320, Height = 180, FrameRate = new Rational(25, 1) };
MediaTime second = MediaTime.FromSeconds(1);
using VideoWriter writer = VideoWriter.Create(path, new VideoWriterOptions
{
    FrameRate = format.FrameRate,
    AudioCodec = Egami.Video.Audio.Codecs.FlacCodec.Instance,
    AudioSampleRate = 48000,
    AudioLayout = ChannelLayout.Stereo,
});
IEnumerable<YuvVideoFrame> shots = TestSources.ColorBars(format, second)
    .Concat(TestSources.Solid(format, second, new Rgba8(30, 40, 220, 255)))
    .Concat(TestSources.Pattern(format, second));
int index = 0;
foreach (YuvVideoFrame frame in shots)
{
    using (frame)
    {
        writer.WriteFrame(frame.Raster, new MediaTime(index++, format.FrameRate.Reciprocal()));
    }
}

foreach (AudioFrame block in TestSources.Sine(null, MediaTime.FromSeconds(3), frequency: 1000, level: -18))
{
    using (block)
    {
        writer.WriteAudio(block);
    }
}

Methods

ColorBars(TestVideoFormat?, MediaTime, ColorBarsStyle)

Generates SMPTE color bars: the HD layout of SMPTE RP 219 (40 % gray sides, 75 % bars, a row with 100 % cyan and blue, a ramp row with 100 % yellow and red, and a PLUGE row with -2 %, +2 % and +4 % steps) or the SD layout of SMPTE EG 1 (75 % bars, reverse blue castellations, and -I, white, +Q and a -4 %, 0, +4 % PLUGE). Levels follow the format's matrix, range and bit depth.

public static IEnumerable<YuvVideoFrame> ColorBars(TestVideoFormat? format, MediaTime duration, ColorBarsStyle style = ColorBarsStyle.Auto)

Noise(TestAudioFormat?, MediaTime, NoiseColor, double, int)

Generates noise, different on each channel: white (flat spectrum) or pink (3 dB less per octave, by the Voss-McCartney method). The same seed gives the same samples.

public static IEnumerable<AudioFrame> Noise(TestAudioFormat? format, MediaTime duration, NoiseColor color = NoiseColor.White, double level = -18, int seed = 1)
