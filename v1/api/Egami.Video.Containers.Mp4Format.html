Class Mp4Format

Namespace
Egami.Video.Containers

Egami.Video.dll

MP4 and QuickTime (ISO/IEC 14496-12 and 14496-14, and Apple's QuickTime File Format): .mp4, .m4v, .m4a and .mov files, flat or fragmented (CMAF, DASH segments). Reads every track: AV1, VP9, VP8, Motion JPEG, Opus, FLAC, PCM and mov_text map to their codec ids, and any other track (H.264, HEVC, AAC, timecode) is passed through so a remux keeps it. Edit lists are applied, the display matrix becomes Orientation, and tags, chapters and cover art are read.

IgnoreEditLists

Gets whether readers ignore edit lists (V4.1 Design Q5). By default an edit list is applied: packet timestamps follow it, an empty edit delays the track, and packets wholly outside the edit are marked IsDiscardable. Ignored, timestamps are the media's own. Register a format with this set through WithContainer(ContainerFormat).

MoovAtEnd

Gets whether writers put moov after the media (V4.1 Design Q4). By default moov comes first, so the file plays while it downloads: on a stream that can seek and read, the media is written in place and moved forward at the end, else it waits in a temporary file. With moov at the end the media goes straight to the output, which must be able to seek.

CreateMuxer(Stream, IReadOnlyList<TrackInfo>, MediaMetadata, MediaContext, bool)

Creates a muxer that writes ISO MP4: tracks numbered from 1 in the order given, chunks of about half a second interleaved by time, edit lists for start offsets and codec delays, the display matrix from Orientation, tags as iTunes items, cover art, and chapters both as Nero chpl and as a QuickTime chapter track. Holds AV1, VP9, VP8, Motion JPEG, H.264, HEVC, MPEG-4 Part 2, Opus, FLAC, AAC, MP3, PCM, mov_text, and tracks read from MP4 or QuickTime with any other codec. A file read as QuickTime is written as MP4 (Q11).
