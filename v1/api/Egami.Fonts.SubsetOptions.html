Examples

// Keep only the glyphs a page uses, as a PDF writer embeds them: renumbered from 0, with the map to write the text with.
GlyphRun run = new Font(face, 12).Shape("Invoice 2026-10");
FontSubset subset = FontSubsetter.Subset(face, run.Glyphs.ToArray(), new SubsetOptions
{
    FontNamePrefix = "ABCDEF+",
    KeepCmap = false,
});
byte[] fontFile2 = subset.Data.ToArray();
ushort first = subset.GlyphMap[run.Glyphs[0]];

// The face's embedding permissions are reported, never enforced: the writer decides.

LayoutClosure

Gets whether the subset can be shaped again as the full face would be: the kept glyphs gain every glyph GSUB can substitute for them (GetClosure(IEnumerable<ushort>, IEnumerable<FontTag>?) with DefaultClosureFeatures), and GSUB, GPOS and GDEF are copied unchanged. Copied layout tables hold the old glyph ids, so this needs RetainGlyphIds and sfnt output. Defaults to false, as a PDF needs only the glyphs drawn. To follow other features, pass the glyphs of GetClosure(IEnumerable<ushort>, IEnumerable<FontTag>?) with them, and keep the three tables with KeepTables.

public bool LayoutClosure { get; init; }

Property Value

bool

Examples

// Keep what the text's characters can become (ligatures, contextual forms) and the layout tables, so the subset shapes
// the text as the full face does; the copied tables use the old glyph ids, so the ids are kept.
ushort[] glyphs = [.. "office".Select(c => face.GetGlyph(c))];
FontSubset subset = FontSubsetter.Subset(face, glyphs, new SubsetOptions { RetainGlyphIds = true, LayoutClosure = true });
GlyphRun shaped = new Font(subset.ToTypeface(), 12).Shape("office");

Remarks

The tables of a variable face are copied with their variation data, so in the static subset GPOS positions and feature variations are those of the default instance, whatever Variations says.

RetainGlyphIds

Gets whether glyphs keep their ids, with empty glyphs in the gaps, rather than being renumbered densely in ascending order. Defaults to false.

public bool RetainGlyphIds { get; init; }

Property Value

bool

Variations

Gets the position a variable face's subset is written at, applied over the face's own position, or null (the default) for the face's position. A variable face's subset is always a static font: glyf with gvar's deltas applied and rounded, hmtx from the varied metrics, OS/2 and post with MVAR's values, CFF2 written as CFF with blends resolved, and the variation tables left out, so PDF viewers draw the position rather than the default instance.

public IReadOnlyList<FontVariation>? Variations { get; init; }
