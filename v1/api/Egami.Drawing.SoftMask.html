Class SoftMask

Namespace
Egami.Drawing
Assembly
Egami.Drawing.dll

A mask made by drawing, as a PDF soft mask: Draw runs on a canvas of its own with the layer's transform and clip, and its alpha, or its luminosity over Backdrop, through the optional Transfer curve, multiplies the layer. A luminosity mask of a white shape on black shows the layer only inside the shape.

Examples

using (RasterCanvas<Rgba8> canvas = raster.CreateCanvas())
{
    // A luminosity mask, as a PDF soft mask: white shows the photo, black hides it, a gradient fades it out to the right.
    RectF area = new(0, 0, photo.Width, photo.Height);
    SoftMask fade = new(mask => mask.FillRect(area, new LinearGradient(new Vector2(area.Width * 0.6f, 0), new Vector2(area.Width, 0), new RgbaF32(1, 1, 1, 1), new RgbaF32(0, 0, 0, 1))));
    canvas.SaveLayer(new LayerOptions { Mask = fade });
    canvas.DrawImage(photo, Vector2.Zero);
    canvas.Restore();
}

Parameters

draw Action<Canvas>

Draws the mask, in the layer's local coordinates.

kind SoftMaskKind

Whether alpha or luminosity becomes the mask.

backdrop RgbaF32?

The color a luminosity mask is drawn over; black when null, so undrawn areas mask everything out. An alpha mask ignores it.

transfer Func<float, float>

A curve from the mask value to the value used, both 0 to 1, as PDF's transfer function; null for none.
