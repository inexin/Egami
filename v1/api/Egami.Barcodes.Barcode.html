A barcode symbol: its format, its modules, the quiet zone its standard asks for and the human-readable text that goes with it. It draws on any canvas as vector paths (CanvasBarcodeExtensions), becomes one Path, or renders to a raster with whole-pixel modules. A barcode is immutable and safe to use from many threads.

Code128(string, Code128Options?)

Makes a Code 128 barcode (ISO/IEC 15417). The code sets A, B and C, and the changes and shifts between them, are picked to give the shortest symbol; runs of digits go in pairs in code set C. Characters 128 to 255 (ISO 8859-1) take an FNC4 each.

public static Barcode Code128(string text, Code128Options? options = null)

Parameters

text string

The text, of characters 0 to 255.

options Code128Options

The bar height, or null for Default.

Returns

Barcode

The barcode, with the text as its human-readable text (control characters shown as spaces).

Examples

// The shortest mix of code sets A, B and C; the digits go in pairs.
Barcode code = Barcode.Code128("ORDER-1180042", new Code128Options { Height = 40 });
using Raster<Gray8> image = code.ToRaster(pixelsPerModule: 2);

Exceptions

ArgumentException

The text is empty, longer than 1000 characters, or has a character above 255.

Code39(string, Code39Options?)

Makes a Code 39 barcode (ISO/IEC 16388): digits, capital letters, space and - . $ / + %. Other ASCII characters are written as Full ASCII pairs when FullAscii allows it.

public static Barcode Code39(string text, Code39Options? options = null)

Parameters

text string

The text.

options Code39Options

The check character, Full ASCII, wide ratio and height, or null for Default.

Returns

Barcode

The barcode, with the text (and a check character, when there is one and the text is not Full ASCII) as its human-readable text.

Examples

// Capitals, digits and a few symbols; lowercase switches to Full ASCII on its own.
Barcode part = Barcode.Code39("PART-0042", new Code39Options { CheckDigit = true });
Console.WriteLine(part.HumanReadableText); // PART-0042 and its mod 43 check character

Exceptions

ArgumentException

The text is empty, longer than 1000 characters, or has a character Code 39 cannot hold.

Ean13(string, EanUpcOptions?)

Makes an EAN-13 barcode (ISO/IEC 15420), such as a GTIN-13 or an ISBN. Twelve digits get their check digit added; thirteen are checked. With a Font, the first digit is drawn left of the symbol and the others between the guard bars, which reach down into the text line.

public static Barcode Ean13(string digits, EanUpcOptions? options = null)

Parameters

digits string

12 or 13 digits.

options EanUpcOptions

The add-on and height, or null for Default.

Returns

Barcode

The barcode, with the 13 digits (and the add-on after a space) as its human-readable text.

Examples

// A book: the ISBN as EAN-13, its check digit added, and the price as an EAN-5 add-on.
Barcode book = Barcode.Ean13("978020137962", new EanUpcOptions { AddOn = "52495" });

// Fitted into a rectangle, with the digits between the guard bars.
using Raster<Rgba8> label = Raster.Create(400, 200, Rgba8.White);
using (RasterCanvas<Rgba8> canvas = label.CreateCanvas())
{
    canvas.DrawBarcode(book, new RectF(10, 10, 380, 180), Rgba8.Black, new BarcodeDrawOptions { Font = font });
}

// A UPC-A number written in its short UPC-E form.
Barcode small = Barcode.UpcE("042100005264");

Exceptions

ArgumentException

The text is not 12 or 13 digits, or the check digit is wrong.

Gs1_128(IReadOnlyList<Gs1ElementString>, Code128Options?)

Makes a GS1-128 barcode: Code 128 with FNC1 first and the element strings after it, an FNC1 after each one whose AI has no predefined length unless it is the last.

[SuppressMessage("Naming", "CA1707:Identifiers should not contain underscores", Justification = "GS1-128 is the symbology's name; Gs1128 would read as one number.")]
public static Barcode Gs1_128(IReadOnlyList<Gs1ElementString> elements, Code128Options? options = null)

Parameters

elements IReadOnlyList<Gs1ElementString>

The element strings, from Parse(string) or Create(string, string).

options Code128Options

The bar height, or null for Default.

Returns

Barcode

The barcode, with the element strings in their human-readable form as its text.

Examples

// Each element string is checked: the AI, the length, the GTIN's check digit, the date.
IReadOnlyList<Gs1ElementString> elements = Gs1.Parse("(01)09501101530003(17)261231(10)AB12");
Barcode label = Barcode.Gs1_128(elements);

// Mistakes say what is wrong.
if (!Gs1.TryParse("(01)09501101530004", out _))
{
    Console.WriteLine("(01) has a wrong check digit");
}

Exceptions

ArgumentException

There are no element strings, or more than 1000 characters.

ToPath(float, BarcodeDrawOptions?)

Returns the symbol as one path: a rectangle per run of dark modules in a row, all filled with the nonzero rule. The quiet zone's top-left corner is at the origin, so with the quiet zone on the symbol starts at QuietZone modules in. Linear bars are Height modules tall. No text is included.

public Path ToPath(float moduleSize = 1, BarcodeDrawOptions? options = null)

Parameters

moduleSize float

The width of a module in path units; 1 by default.

options BarcodeDrawOptions

The quiet zone and bar width reduction, or null for Default.

Returns

Path

The path.

Examples

// One path, a rectangle per run of dark modules; the quiet zone's corner is at the origin.
Path path = qr.ToPath(moduleSize: 4);
string svg = path.ToSvg();

Exceptions

ArgumentOutOfRangeException

moduleSize is not positive and finite.

ToRaster(int, BarcodeDrawOptions?)

Renders the symbol black on white, each module a square of whole pixels, with the quiet zone around it and, when Font is set, the human-readable text under it. Linear bars are Height modules tall.

UpcE(string, EanUpcOptions?)

Returns

Barcode

Examples

// A book: the ISBN as EAN-13, its check digit added, and the price as an EAN-5 add-on.
