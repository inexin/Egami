A barcode symbol: its format, its modules, the quiet zone its standard asks for and the human-readable text that goes with it. It draws on any canvas as vector paths (CanvasBarcodeExtensions), becomes one Path, or renders to a raster with whole-pixel modules. A barcode is immutable and safe to use from many threads.

AustraliaPost(string, AustraliaPostOptions?)

Makes an Australia Post 4-State Customer Barcode: the eight-digit Delivery Point Identifier (DPID), followed for Customer Barcodes 2 and 3 by the customer information, such as 39549554 or 54516251ABC123. The Format Control Code, filler bars and four Reed-Solomon check symbols are added. The modules are a grid of 8 rows (3 for the ascender, 2 for the tracker, 3 for the descender); draw it at a module size of 0.55 mm for bars 4.4 mm tall at 23 bars per 25.4 mm, within Australia Post's sizes.

public static Barcode AustraliaPost(string text, AustraliaPostOptions? options = null)

Parameters

text string

The DPID and the customer information.

options AustraliaPostOptions

The format and the customer information's encoding table, or null for the defaults.

Returns

Barcode

The barcode, with the text representation Australia Post gives as its human-readable text: the Format Control Code, the DPID, the customer information and the four check symbols as two-digit numbers, such as 11 39549554 54 17 53 58.

Examples

// A Standard Customer Barcode holds the eight-digit DPID; customer information after it takes Customer Barcode 2 or 3.
Barcode mail = Barcode.AustraliaPost("39549554");
Barcode withInformation = Barcode.AustraliaPost("54516251ABC123");
Barcode digits = Barcode.AustraliaPost("5451625112345", new AustraliaPostOptions { Format = AustraliaPostFormat.Customer3 });

// Drawn at a 0.55 mm module (here in millimetres): 37 bars, 40.15 mm long and 4.4 mm tall.
Path bars = mail.ToPath(moduleSize: 0.55f);
Console.WriteLine(mail.HumanReadableText); // 11 39549554 54 17 53 58, the FCC, the DPID and the check symbols

Exceptions

ArgumentException

The text does not start with eight digits, has customer information for a format without it, has a character the encoding table lacks, or holds more customer information than the format does.

Codabar(string, CodabarOptions?)

Makes a Codabar barcode (EN 798): digits and - $ : / . + between a start and a stop character, A to D. Text that begins and ends with A to D keeps those as its start and stop characters; other text gets Start and Stop.

public static Barcode Codabar(string text, CodabarOptions? options = null)

Parameters

text string

The text, with or without its start and stop characters.

options CodabarOptions

The start and stop characters, check character, wide ratio and height, or null for Default.

Returns

Barcode

The barcode, with every character of the symbol as its human-readable text: start, text, check character when there is one, and stop, as readers return it.

Examples

// A library card number between start character A and stop character B.
Barcode card = Barcode.Codabar("A31117013206375B");

// Start and stop characters from the options, and a modulo 16 check character.
Barcode checkedCode = Barcode.Codabar("40156", new CodabarOptions { Start = 'C', Stop = 'D', CheckDigit = true });
Console.WriteLine(checkedCode.HumanReadableText); // C40156, its check character, D

Exceptions

ArgumentException

The text is empty, longer than 1000 characters, gives a start character A to D without a stop character (or the reverse), has another character Codabar cannot hold, or makes a symbol of fewer than four characters (start, two characters or one and the check character, stop).

// Labels from a table that stores each barcode's format with its data.

JapanPost(string, JapanPostOptions?)

Makes a Japan Post customer barcode (カスタマバーコード) from prepared data: the 7-digit postal code, with or without its hyphen (NNN-NNNN), then the address number, the digits, hyphens and letters A to Z the manual's extraction rules leave of the address, such as 100-0013 1-3-2-503. Spaces, or one hyphen, between the postal code and the address number are dropped, and lowercase letters are made uppercase. The symbol holds 20 characters: the postal code takes 7, a letter 2 (a control code and a digit), and CC4 pads the rest; an address number that does not fit loses its end, as the manual says, unless TruncateAddress is off. The modules are a grid of 6 rows, one per 0.6 mm at the manual's size; draw it at a module size of 0.6 mm for a 79.8 by 3.6 mm symbol.
