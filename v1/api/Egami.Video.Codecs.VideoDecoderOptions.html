Examples

// How a reader decodes: which track, what a broken frame does (Skip, the default, drops it up to the next keyframe;
// Conceal repeats the last good frame; Throw throws) and the codec's own options.
VideoReaderOptions options = new()
{
    TrackNumber = 1,
    Errors = DecodeErrorMode.Conceal,
    Decoder = new VideoDecoderOptions { DecodeAlpha = false },
};
using VideoReader reader = VideoReader.Open("alpha.webm", options);
using YuvVideoFrame frame = reader.ReadFrame()!;

Properties

DecodeAlpha

Gets whether a track's alpha plane is decoded when it has one (WebM VP8 with alpha decodes a second stream for it). Turn it off to save that work when only the color is needed. Default on.

Errors

Gets what to do with a frame that cannot be decoded: throw (the default), skip it and report it, or conceal it where the codec can. See DecodeErrorMode. VideoReader sets this from Errors.

public DecodeErrorMode Errors { get; init; }

ScaleDenominator

Gets the scale denominator: 1 for full size, or 2, 4 or 8 to decode at 1/2, 1/4 or 1/8 size where the codec supports it (Motion JPEG does, through Egami's scaled JPEG decode). Default 1.
