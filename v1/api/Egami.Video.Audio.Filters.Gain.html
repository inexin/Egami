Class Gain

Namespace
Egami.Video.Audio.Filters
Assembly
Egami.Video.dll

Changes the level, by a fixed gain and, optionally, an Envelope that changes over time. A change to Decibels or Factor between frames moves to the new gain over 5 ms, so it does not click. Unity gain with no envelope passes samples through unchanged. Works in place; nothing is clipped, so a gain above 0 dB can take samples past full scale until an encoder or a limiter clamps them.

Examples

// Fade in over 2 s, then turn down 3 dB: frames of any format go in, F32 planar frames come out.
using AudioFilterChain chain = new AudioFilterChain(48000, ChannelLayout.Stereo)
    .Add(new Fade(FadeDirection.In, MediaTime.Zero, MediaTime.FromSeconds(2)))
    .Add(new Gain(-3));
foreach (AudioFrame frame in frames)
{
    chain.Send(frame);
    while (chain.TryReceive(out AudioFrame? output))
    {
        samples += output.SampleCount; // write it to an AudioWriter or encoder here
        output.Dispose();
    }
}

chain.Flush();
