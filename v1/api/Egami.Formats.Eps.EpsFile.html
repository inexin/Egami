Class EpsFile

Namespace
Egami.Formats.Eps

The parts of an Encapsulated PostScript file, read without running the PostScript: the PostScript itself, the TIFF or Windows metafile preview a DOS binary header points at, an EPSI bitmap preview, the DSC header comments and Photoshop's sections. Written from Adobe's EPSF 3.0 specification (Technical Note 5002) and the Document Structuring Conventions 3.0. Load(ReadOnlyMemory<byte>, EgamiContext?, ReaderOptions?) reads the same parts to load the preview; load an EpsFile to get at them yourself, such as to draw a metafile preview as vectors.

Examples

// EpsFile gives the parts: the PostScript, the TIFF or metafile preview, and the header comments.
EpsFile eps = EpsFile.Load(File.ReadAllBytes("logo.eps"));
if (eps.Preview == EpsPreviewKind.Tiff)
{
    File.WriteAllBytes("logo-preview.tif", eps.TiffPreview.ToArray());
}

Console.WriteLine($"{eps.Title} by {eps.Creator}: {eps.BoundingBox}, {eps.PostScript.Length} bytes of PostScript");

Remarks

Damage is reported in Warnings, never thrown: sections that run past the end of the file are cut short or dropped, and comments that cannot be read are left unset.
