Reads the boxes of ISO/IEC 14496-12 from bytes in memory, one level at a time: 32-bit sizes, 64-bit large sizes, size 0 (to the end of the enclosing box) and uuid boxes. A box that runs past its parent, or whose size is too small for its header, raises a CorruptDataException; nothing is allocated.

Examples

// List an AVIF, HEIC or MP4 file's top-level boxes and the boxes inside meta.
IsoBoxReader top = new(avif, "AVIF");
while (top.Next(out IsoBox box))
{
    found.Add($"{box.Type} {box.Size}");
    if (box.Type == FourCC.Parse("meta"))
    {
        // meta is a full box: its version and flags (4 bytes) come before its children.
        IsoBoxReader children = top.Children(box, skip: 4);
        while (children.Next(out IsoBox child))
        {
            found.Add($"  {child.Type} at {child.Start}");
        }
    }
}

Remarks

To walk a large file, read its top-level box headers from the stream with ReadHeader(ReadOnlySpan<byte>, long, long, string), load the boxes you need (such as moov) and walk each with a reader told where the box starts in the file, so every position it reports is a file offset.
