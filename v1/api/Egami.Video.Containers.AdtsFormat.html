Class AdtsFormat

Namespace

Raw AAC in ADTS frames (.aac, .adts; ISO/IEC 13818-7 and 14496-3 Annex 1.A): each frame a short header and one raw data block, with no container around them. Reading gives one Aac packet per frame, the header and CRC stripped as MP4 and Matroska store AAC, and the AudioSpecificConfig built from the first header; ID3v2 tags at the start are read into the tags. Writing adds a header without a CRC to each packet, so an AAC track from MP4, Matroska, CAF or AVI can be extracted without decoding. Seeking builds a frame index in one pass.

Examples

// Raw AAC in ADTS frames: each packet is one raw data block, as MP4 stores it.
MediaInfo info = MediaFile.Probe("song.aac");
AudioTrackInfo track = (AudioTrackInfo)info.Tracks[0];
Console.WriteLine($"{track.CodecId}: {track.SampleRate} Hz, {track.Channels} channels, {info.Duration}");

// Out of an .m4a into a raw .aac file, and back into Matroska, without decoding.
MediaFile.Remux("song.m4a", "copy.aac");
MediaFile.Remux("song.aac", "song.mka");
