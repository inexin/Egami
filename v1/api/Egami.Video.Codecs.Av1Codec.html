Class Av1Codec

Namespace
Egami.Video.Codecs
Assembly
Egami.Video.dll

AV1, as WebM, Matroska, MP4, IVF and raw OBU files carry it, decoded by Egami's AV1 decoder in the Main, High and Professional profiles: 8, 10 and 12 bit, 4:0:0, 4:2:0, 4:2:2 and 4:4:4, film grain, scaled references and scalable streams, every frame equal to libaom's sample for sample. A packet is a temporal unit. Frames come out at their own size (a stream may change size at a key frame) as 8-bit planes, or 16-bit planes holding 10 or 12 bits; a monochrome stream gives 4:0:0 planes. Hidden frames give no frame; a frame shown later with show_existing_frame comes out then. Encoding goes through CreateEncoder(VideoEncoderOptions, MediaContext).

Examples

// AV1 from WebM, Matroska, MP4 or IVF reads like any other video: 10 and 12-bit streams give 16-bit planes.
using (VideoReader reader = VideoReader.Open("av1.webm"))
{
    foreach (YuvVideoFrame frame in reader.ReadFrames())
    {
        using (frame)
        {
            Console.WriteLine($"{frame.Timestamp}: {frame.Width}x{frame.Height}, {frame.Raster.BitDepth} bit {frame.Raster.ChromaFormat}, {frame.Color}");
        }
    }
}

// The frames as coded, without the film grain the stream asks for; broken units are skipped to the next key frame and
// reported as Av1.CorruptFrame or Av1.MissingReference, or repeat the last good frame with Conceal.
VideoReaderOptions options = new()
{
    Decoder = new VideoDecoderOptions { ApplyFilmGrain = false },
    Errors = DecodeErrorMode.Conceal,
};
using VideoReader plain = VideoReader.Open("av1.webm", options);
using YuvVideoFrame first = plain.ReadFrame()!;

Remarks

The frame's color comes from the sequence header; the container's (Color) fills only what the header leaves unspecified. Content light level and mastering display metadata OBUs give Hdr (held until the stream sends new ones; the track's Hdr before any), and an ITU-T T.35 metadata OBU with HDR10+ gives Hdr10Plus. ApplyFilmGrain turns film grain off.

A track's av1C (CodecPrivate) supplies the sequence header when the first unit, or the first after a seek, has none. Broken data follows Errors and is reported through the Egami context's diagnostics as Av1.CorruptFrame (the unit's data is broken), Av1.MissingReference (a unit that needs frames from before the first key frame) or Av1.KeyframeFlagMismatch (the container's keyframe flag disagrees with the unit, which wins: a keyframe is a unit starting with a shown key frame). After a broken unit, decoding resumes at the next shown key frame; in Conceal mode the units in between show the last good frame again.

CreateEncoder(VideoEncoderOptions, MediaContext)

Creates an AV1 encoder, which codes frames with Egami's Av1StreamEncoder. 8 and 10-bit 4:2:0 planes make Main profile streams, 4:4:4 High and 12-bit or 4:2:2 Professional, coded as they are; RGB frames are converted to 8-bit 4:2:0 BT.601 limited range unless BitDepth or ChromaFormat say otherwise. By default it aims at constant quality 60 at effort 4, looks 25 frames ahead for scene cuts and for a hidden alternate reference at each group's end with a hidden frame halfway to it, both shown later with show_existing_frame, and places a keyframe at least every 10 seconds; VideoEncoderOptions chooses bitrate, constant bitrate, two passes or real time instead, and Av1 holds the expert settings. Each packet is a temporal unit; the track's av1C comes from the sequence header, which also carries the frames' color code points, and keyframes carry their static HDR metadata as metadata OBUs (HDR10+ goes into the frames that have it). Alpha is not coded: AV1 has no alpha in Matroska or MP4. The output is the same at any thread count.

Examples

// AV1 in MP4 at constant quality, on the same Quality and Effort scales as VP8 and VP9. Each group's hidden alternate
// reference, and a hidden frame halfway to it, are shown later with show_existing_frame.
VideoWriterOptions options = new() { Codec = VideoCodecs.Av1, FrameRate = new Rational(30, 1), Quality = 70, Effort = 1 };
using (VideoWriter writer = VideoWriter.Create("duck-av1.mp4", options))
{
    for (int i = 0; i < 10; i++)
    {
        using Raster<Rgb8> frame = duck.Derive(ops => ops.Crop(new Rect(i * 4, i * 2, 320, 240)));
        writer.WriteFrame(frame);
    }
}

// Expert settings: no pyramid, no adaptive quantization, quantizer limits on AV1's 0 to 255 base_q_idx scale.
VideoWriterOptions tuned = options with
{
    Av1 = new Av1EncoderOptions { Pyramid = false, AdaptiveQuantization = false, MinQuantizer = 20, MaxQuantizer = 200 },
};
