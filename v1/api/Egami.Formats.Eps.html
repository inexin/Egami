EpsFile

The parts of an Encapsulated PostScript file, read without running the PostScript: the PostScript itself, the TIFF or Windows metafile preview a DOS binary header points at, an EPSI bitmap preview, the DSC header comments and Photoshop's sections. Written from Adobe's EPSF 3.0 specification (Technical Note 5002) and the Document Structuring Conventions 3.0. Load(ReadOnlyMemory<byte>, EgamiContext?, ReaderOptions?) reads the same parts to load the preview; load an EpsFile to get at them yourself, such as to draw a metafile preview as vectors.

EpsFormat

Encapsulated PostScript, registered in Default and read only. Egami never runs PostScript: Load returns the preview image the file carries, in this order: a TIFF preview, a Windows metafile preview (drawn by a format the context has registered for metafiles, such as Egami.Metafiles' MetafileFormat.Info, at the bounding box size), or an EPSI bitmap. A file with only PostScript probes at its bounding box size and fails to load with an UnsupportedFormatException. Detected by the DOS binary header or a %!PS first line; plain PostScript is detected too, so it fails with that message rather than as an unknown format.
