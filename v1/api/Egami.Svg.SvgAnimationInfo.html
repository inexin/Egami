Class SvgAnimationInfo

Namespace
Egami.Svg

What a document's SMIL and CSS animations do over time, as Animation finds them: whether it animates, how long it plays and whether it loops. Animations that wait for a click, a key or a wall-clock time never begin, as in a browser nobody touches.

Examples

// What the SMIL animations do: here a 2 s loop that never ends.
SvgAnimationInfo info = document.Animation;
Console.WriteLine($"Animated: {info.HasAnimations}, loop: {info.LoopPeriod}, ends: {info.Duration?.ToString() ?? "never"}");

// The document half a second in: the circle has moved, the element tree has not changed.
using Raster<Rgba8> frame = document.Rasterize<Rgba8>(new SvgRenderOptions { Time = TimeSpan.FromSeconds(0.5) });
SvgGroup tree = document.RenderTreeAt(TimeSpan.FromSeconds(0.5));

Properties

Duration

Gets when the last animation ends, or null when one runs forever (or the document has none); zero when no animation ever begins.

public TimeSpan? Duration { get; }

HasAnimations

Gets a value indicating whether the document has animation elements (animate, set, animateTransform, animateMotion, discard) with a target, or elements whose style names an @keyframes rule in animation-name.

public bool HasAnimations { get; }

Property Value

bool

HasEventTriggers

Gets a value indicating whether some animation waits for a user event, an access key or a wall-clock time to begin, and so never plays.

public bool HasEventTriggers { get; }

Property Value

bool

LoopPeriod

Gets the period after which the whole document repeats, when every animation repeats forever: the least common multiple of their periods on a 1 ms grid, if it is at most 10 seconds and every animation has begun by then; otherwise null.

public TimeSpan? LoopPeriod { get; }
