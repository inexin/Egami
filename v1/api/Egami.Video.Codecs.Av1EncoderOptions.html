The AV1 settings beyond VideoEncoderOptions, for experts: quantizer limits, hidden alternate reference frames and their pyramid, golden frame spacing, the temporal filter, adaptive quantization, screen content tools, error resilience and the bit depth. Every one has a default that suits most uses.

Examples

// AV1 in MP4 at constant quality, on the same Quality and Effort scales as VP8 and VP9. Each group's hidden alternate
// reference, and a hidden frame halfway to it, are shown later with show_existing_frame.
VideoWriterOptions options = new() { Codec = VideoCodecs.Av1, FrameRate = new Rational(30, 1), Quality = 70, Effort = 1 };
using (VideoWriter writer = VideoWriter.Create("duck-av1.mp4", options))
{
    for (int i = 0; i < 10; i++)
    {
        using Raster<Rgb8> frame = duck.Derive(ops => ops.Crop(new Rect(i * 4, i * 2, 320, 240)));
        writer.WriteFrame(frame);
    }
}

// Expert settings: no pyramid, no adaptive quantization, quantizer limits on AV1's 0 to 255 base_q_idx scale.
VideoWriterOptions tuned = options with
{
    Av1 = new Av1EncoderOptions { Pyramid = false, AdaptiveQuantization = false, MinQuantizer = 20, MaxQuantizer = 200 },
};

Properties

AdaptiveQuantization

Gets whether each 64x64 superblock gets its own quantizer (delta q): on a group's base frames from the temporal model, finer where the frames after it reuse most; on the others by its detail (Egami's Variance Boost), finer where the picture is flat and banding shows, which SSIM rewards more than PSNR loses. Default on.

public bool AdaptiveQuantization { get; init; }

Property Value

bool

AlternateReference

Gets whether Quality codes hidden alternate reference frames: a temporally filtered copy of a frame ahead that the frames before it predict from, shown later with show_existing_frame at its own place. Default on; Realtime never codes them.

public bool AlternateReference { get; init; }

Property Value

bool

BitDepth

Gets the bit depth to code, 8, 10 or 12, or null (the default) for the frames' own: 10 or 12 for 16-bit planes of that depth, 8 for everything else. 8 and 10-bit 4:2:0 make Main profile streams, 4:4:4 High, and 12 bits or 4:2:2 Professional.

public int? BitDepth { get; init; }

Property Value

int?

ErrorResilient

Gets whether frames start from the default probabilities and keep no motion vectors for the frames after them, so a lost packet spoils only its own frame, or null (the default) for on in Realtime and off otherwise.

GoldenInterval

Gets the most frames between golden frame refreshes (and alternate reference frames), 4 to 64, or null (the default) for 16 with the Pyramid, else 8 to 16 chosen by how much the picture moves.

Pyramid

Gets whether each group is a pyramid, as libaom and SVT-AV1 build them: after the hidden alternate reference at its end, a hidden frame halfway to it, then halfway again, down to pairs of frames, each shown later the same way; the frames between predict from both sides and nothing predicts from them. Groups are 16 frames (five layers) unless GoldenInterval says otherwise, and each group and the one after it are run through the AV1 encoder's temporal model first, which sets the alternate reference's and keyframe's quantizers. Default on; off codes one hidden alternate reference a group, its group 8 to 16 frames long by how much the picture moves.

public bool Pyramid { get; init; }

Property Value

bool

ScreenContent

Gets whether the screen content tools (palettes, and intra block copy in keyframes) are on, or null (the default) to turn them on per frame when the frame looks like screen content.

public bool? ScreenContent { get; init; }

TemporalFilterFrames

Gets how many frames the temporal filter blends into an alternate reference frame, 1 (none) to 15. Default 7.

public int TemporalFilterFrames { get; init; }

TemporalFilterStrength

Gets how strongly the temporal filter blends, 0 (weakest) to 6, or null (the default) for a strength that follows each picture's noise and the frame's quantizer: clean pictures and fine quantizers blend little, noisy pictures at coarse quantizers most. With the Pyramid, keyframes are blended with the frames after them too.

public int? TemporalFilterStrength { get; init; }

Property Value

int?

Exceptions

ArgumentOutOfRangeException

The value is outside 0 to 6.
