One plane of a YuvRaster<TSample>: a width × height grid of raw samples, stored row by row. A row is always one contiguous span. Samples are stored low-bit aligned: a 10-bit sample is 0 to 1023 in a ushort.

public sealed class YuvPlane<TSample> where TSample : unmanaged

Type Parameters

TSample

The sample type: byte for 8 bits, ushort for 10 and 12 bits.

Examples

using YuvRaster<byte> yuv = YuvRaster.Create(640, 480, ChromaFormat.Yuv420, YuvColor.Jpeg);

// Planes are read and written by row, like a raster's pixels.
for (int y = 0; y < yuv.Y.Height; y++)
{
    yuv.Y.Row(y).Fill((byte)(y / 2));
}

yuv.U!.Row(0)[0] = 128;

// An 8-bit plane can be viewed as Gray8 pixels, without copying.
PixelPlane<Gray8> luma = yuv.Y.AsGray8();

Remarks

Spans returned by Row(int) and TryGetContiguous(out Span<TSample>) point into the raster's memory. Do not keep them after the raster is disposed.
