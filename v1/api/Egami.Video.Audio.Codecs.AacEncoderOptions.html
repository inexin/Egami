How the AAC encoder codes: an average bit rate (the default, 64 kbit/s per channel) or a variable-bit-rate quality, and the highest frequency it keeps. The encoder picks its tools (block switching, TNS, mid/side, intensity stereo and noise substitution) per block from the rate.

Examples

// AAC LC at 128 kbit/s in an .m4a file. The MP4 edit list records the encoder's priming and padding, so the file decodes
// to exactly the samples written.
using (AudioWriter writer = AudioWriter.Create("tone.m4a", new AudioWriterOptions
{
    Codec = AacCodec.Instance,
    Aac = new AacEncoderOptions { Bitrate = 128_000 },
}))
{
    writer.Write(tone);
}

Properties

Bandwidth

Gets the highest frequency coded in hertz, 1000 to 24000, or null (the default) to choose it from the rate: about 11 kHz at 16 kbit/s per channel, 15 kHz at 24 and 20 kHz from 32. It never exceeds half the sample rate.

public int? Bandwidth { get; init; }

Property Value

int?

Exceptions

ArgumentOutOfRangeException

The value is outside 1000 to 24000.

Bitrate

Gets the average bit rate in bits per second for all channels together, 8000 to 1536000, or null (the default) for 64 kbit/s per channel. Blocks that need more bits take them from a reservoir that quieter blocks fill, so the rate holds over a few seconds. AAC LC carries at most 6144 bits per channel in a block, which caps the rate at about 6 bits per sample and channel.

Quality

Gets the variable-bit-rate quality, 1 (smallest) to 5 (best), or null (the default) to code at Bitrate. Each level keeps the noise at one level against the masking thresholds, so the rate follows the audio; music in stereo comes out at roughly 50, 80, 112, 170 and 235 kbit/s.
