# Egami.Fonts

Egami.Fonts reads fonts and lays out text in managed code.

- TrueType, OpenType (CFF), WOFF, WOFF2, variable and color fonts: faces, glyph outlines, metrics, kerning, installed fonts
  and subsetting.
- OpenType text shaping, bidi, and paragraph layout with wrapping, alignment and hit testing.
- Font data for PDF writers.

See [Fonts and text](https://github.com/inexin/Egami/blob/main/docs/articles/guides/text.md), [Unicode text and shaping](https://github.com/inexin/Egami/blob/main/docs/articles/guides/unicode-text.md) and
[Paragraph layout](https://github.com/inexin/Egami/blob/main/docs/articles/guides/paragraph-layout.md).

Egami is MIT-licensed, fully managed C# for .NET 10: no native binaries, no P/Invoke and no third-party dependencies, trimming
and Native AOT clean. Source, documentation and changelog: [github.com/inexin/Egami](https://github.com/inexin/Egami).
