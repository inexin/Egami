# Egami.Barcodes

Egami.Barcodes writes and reads barcodes.

- Writes 1D and 2D barcodes and draws them onto Egami.Drawing's canvas, so they stay vectors in PDF and SVG output, or onto
  rasters.
- Reads barcodes from rasters.

See the [barcodes guide](https://inexin.github.io/Egami/v1/articles/guides/barcodes.html), and the
[reading guide](https://inexin.github.io/Egami/v1/articles/guides/barcode-reading.html).

Egami is MIT-licensed, fully managed C# for .NET 10: no native binaries, no P/Invoke and no third-party dependencies, trimming
and Native AOT clean. Documentation: [inexin.github.io/Egami](https://inexin.github.io/Egami/). Source and changelog:
[github.com/inexin/Egami](https://github.com/inexin/Egami).
