# Egami.Css

Egami.Css parses and applies CSS, with no dependencies.

- The CSS Syntax 3 tokenizer and parser, Selectors 4 matching over any element tree, and the cascade with custom properties
  and `var()`.
- Media queries, the box, background, list, table and page properties, `@page` with its margin boxes.
- Value parsers for colors, lengths, `calc()`, transforms, fonts and page sizes.

See the [CSS guide](https://github.com/inexin/Egami/blob/main/docs/articles/guides/css.md).

Egami is MIT-licensed, fully managed C# for .NET 10: no native binaries, no P/Invoke and no third-party dependencies, trimming
and Native AOT clean. Source, documentation and changelog: [github.com/inexin/Egami](https://github.com/inexin/Egami).
